# 箱庭纪运行维护补充

保留上层 AGENTS.md 与本目录 CLAUDE.md 的约定。本作使用独立 `HakoniwaGame` Windows 注册服务，
固定 Web 端口为 5180。不要调用主工程 5173/8787 的启动器维护本作。

阶段性修改涉及项目运行逻辑时，在验证完成后执行：

```powershell
npm run service:status
npm run service:restart -- "本阶段变更原因"
```

重启前必须在 Web 中显示完整五秒倒计时和“打断重启”按钮。不得绕过协议使用 taskkill、
Restart-Service、端口清理、另开 Vite、HMR 全页刷新或循环重试。公开端口被占用时报告 PID，
禁止结束无关进程或静默换端口。

控制命令退出码 3 或状态 paused 代表用户已打断。收到后立即暂停所有依赖重启的动作，
先继续不依赖重启的独立工作。必须等用户主动明确继续，才能执行 `npm run service:resume`，
重新倒计时五秒；不得因新任务、超时、新会话或服务恢复而自行解除暂停。
若当前任务必须等待重启，则如实说明并等待用户继续，不宣称验证或部署完成。

SCM 开机启动与进程崩溃恢复保持启用；计划更新一律通过上述可打断协议。注册、卸载或关闭整个服务
属于运行环境维护，必须有明确任务授权。只提交本任务范围，保留其他并行工作与既有 dirty。

# hakoniwa/：《箱庭纪》项目根目录约定

本目录存放新作《箱庭纪》（工作代号 Hakoniwa）的全部内容：调研归档、世界观正典、故事、
游戏设计、技术方案、制作计划，以及将来的数据、源码、素材与测试。它与 world-of-claudecraft
主工程并列，目前不参与主工程的构建、测试和发布（根目录 `tsconfig.json` 不包含本目录）。

## 目录分工
| 路径 | 内容 | 写什么，不写什么 |
|---|---|---|
| `docs/00_vision/` | 愿景、设计支柱、术语表 | 一切设计的出发点，变动需同步全局 |
| `docs/10_research/` | 调研归档 | 只记录事实、分析与可借鉴点，不做最终决定 |
| `docs/20_world/` | 世界观正典 | 宇宙、诸神、历史、地理、种族、国家、力量体系、社会 |
| `docs/30_story/` | 叙事与故事 | 叙事结构、主线大纲、分幕剧情、角色、谜团台账 |
| `docs/40_design/` | 游戏设计（概要设计） | 总框架、各系统、内容清单 |
| `docs/50_tech/` | 技术方案 | 架构、AI 方案、复用映射、2D 美术管线 |
| `docs/60_production/` | 制作计划 | 路线图、里程碑、风险 |
| `data/` `src/` `tools/` `tests/` | 第一轮实现 | 按 `docs/50_tech/architecture.md` 与 `implementation_conventions.md`；`assets/` 仍为占位 |

## 正典优先级（冲突时以前者为准，并回头修订后者）
1. `docs/20_world/world_bible.md`（世界观总纲，单一事实源）
2. `docs/00_vision/vision.md`（设计支柱）
3. `docs/20_world/` 其余文件
4. `docs/30_story/`
5. `docs/40_design/`、`docs/50_tech/`、`docs/60_production/`
6. `docs/10_research/`（仅作依据，不具约束力）

## 文档规则
- 中文撰写；专有名词首次出现时附原文或英文代号。
- 禁用字符（仓库 Stop 钩子 `.claude/hooks/qa-stop.sh` 会拦截）：破折号 U+2013、U+2014、U+2015
  （包括中文双破折号）；emoji；U+2600 到 U+27BF 区间的符号（星形评级符号、音符、对勾叉号、
  性别符号等）。停顿用冒号、逗号或括号，范围用"到"或"～"，评分用数字。
- 引用主工程代码写稳定路径与导出符号，不写行号和会过时的数量（主工程的锚点规则）。
- 文件名用小写英文加下划线；目录编号前缀表示阅读顺序。
- 设计文档的结论要能回链到调研来源（相对链接到 `docs/10_research/` 的具体文件）。
- 新增文件后同步更新 `docs/README.md` 的索引。

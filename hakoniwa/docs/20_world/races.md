### 0.2 写给美术的通用约定

- 2D 立绘与像素小人共用一套"一眼识别"原则：每个种族至少有一个**剪影特征**（耳、角、尾、翼、
  体型比例）和一个**色彩特征**（肤色带、发色带或标志纹样），像素小人在 16 到 32 像素高时也能分辨。
- 体型基准（以人族成年男性为 1.00）：精灵 1.05，兽人 0.95 到 1.20（随部族），矮人 0.70，
  半身人 0.60，鬼人 1.25，翼魔 0.85，夜魔 1.00，蛇人 1.00（不含颈褶），龙族不按人形计。
- 诸族的标志纹样（门纹、年轮纹、矿纹、吉斑、角饰）是叙事道具，美术上必须稳定、可识别，
  不能被装备完全遮盖（门民的门纹例外：遮盖本身就是他们的生存方式）。

### 0.3 种族与澱的关系（贯穿全文的一条线）

- 所有有灵智的种族都是司掌者"创造"并登记在铭录里的，魔物与亡灵不是种族，是澱的显化（第 9 节）。
- 【表层】人族普遍把魔族与魔物混为一谈，圣教教义也有意模糊二者。
- 【真相】魔族是瓦尔妲正式创造的种族，与魔物毫无血缘关系；只是魔王循环的"容器"历代多出自魔族
  （瓦尔妲的设计），于是"魔族等于魔物之主"的偏见被一轮轮加固。

## 1. 人族（Humans）

| 项           | 内容                                                                                                                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 起源与创造者 | 艾琉恩于萌芽期创造，是她"规格之美"的作品：她把人族设计成"可以被教化成任何形状"的种族，所以人族学得最快、变得最快、也最容易分裂                                                                                  |
| 外貌要点     | 剪影无特殊附件，靠服饰与体态区分地域；肤色、发色跨度最大。立绘重点是"阶层差"而非"种族差"：农民的粗布与驼背、骑士的挺胸、神职的白与金、商人的层叠衣料。像素小人：头身比 1 比 3，以帽子、头巾、发型区分职业与地域 |
| 寿命与繁衍   | 寿命 60 到 80，15 岁成年；生育力在诸族中最高，一胎一子为主，农村家庭五到七个孩子，存活三到四个。高位阶者衰老放缓、寿命延长（规则见 `power_system.md` 第 3.4 节），所以英雄阶、传说阶的人族会显得"老而不衰"      |
| 社会组织     | 王国、帝国、教国、城邦，最依赖制度与文字。家族是基本单位，领主、教区、行会三张网叠在每个人身上                                                                                                                  |
| 典型职能     | 战士最多；牧师（圣教神官）次之；圣骑士几乎只出自人族；法师多出自人族城市；猎人与盗贼常见；术士隐秘存在（异端）；萨满与德鲁伊罕见（洛萨乡间的"药草婆婆"一系是残存的例外）                                        |

**亚种与地域分支**（同为人族，以地域文化区分，不是生物学亚种）

| 分支       | 地域               | 特点                                                             | 美术提示                             |
| ---------- | ------------------ | ---------------------------------------------------------------- | ------------------------------------ |
| 洛萨人     | 西部农田与森林     | 务实、乡土、能忍；北境人更硬，南部人更温和                       | 麦色与绿色，羊毛斗篷，木雕护符       |
| 北境人     | 洛萨北境、荒原边缘 | 经历过第八代魔王战争，几乎家家有死者；迷信、团结、不信远方的承诺 | 灰与褐，毛皮领，面颊冻伤红           |
| 格兰提亚人 | 中原               | 尚武、世俗、讲究军功与等级，嘴上信光、心里信拳头                 | 铁灰与深红，短发，军旅装束           |
| 瑟兰人     | 教国               | 虔诚、守礼、识字率高，日常生活按钟声分段                         | 白、金、浅蓝，长袍与头纱             |
| 金湾人     | 南方沿海           | 精明、外向、多语、混居惯了，对种族最不敏感                       | 鲜艳染布，海风晒黑的皮肤，耳饰与戒指 |

**混血**

- 半精灵：千门时代通婚的遗产，寿命约 200。希尔瓦不承认他们，人族城市把他们当作"漂亮的外人"。
  多为学者、乐师、向导。
- 兽人与人族通婚的孩子通常表现为浅相兽人（见第 3 节），铭录登记为兽人。
- 半魔：极少，多是夜境边境的战俘后代，在人族地区一旦被发现即受教会监视。

**文化与习俗**

- 洗礼：出生后第四十天在礼拜堂受洗，名字写入教区的洗礼簿，同时获得"光之庇佑"加护（强度为最低一级的微佑，见 `power_system.md` 第 6.3 节与 `society.md` 教会细则）。
- 收获祭与冬至祭：圣教把古老的农事节日改写成光的节日，乡间仍偷偷保留献给"林母""泉母"的旧俗（希尔薇一系的残留），这是第一幕药草婆婆与神父冲突的土壤。
- 门的禁忌：人族各地有"夜里不留门缝""门槛不能坐"的俗语，来源早已遗忘（【真相】是空白纪"光之祭司团"（圣教前身）清剿门民留下的民俗化禁令，后来被圣教沿用）。

**信仰与对诸神的态度**

- 圣教为主。教国与洛萨乡村最虔诚，帝国最世俗（军中暗信瓦尔妲），同盟的人族多是"两头拜"：
  礼拜天去教堂，生意上去梅尔卡的神龛。
- 普通人只知道"光之女神"与"邪神"，对其余诸神的了解来自异族邻居和商人的只言片语。
- 【真相】人族信仰份额的下滑正是艾琉恩的不安来源，而人族是最可能"不需要神也能站立"的种族，
  这是第六幕艾琉恩唯一的救赎入口（`pantheon.md` 第 1 节）。

**位阶分布特点**

- 底座最宽、塔尖最细，但方差最大：同一个种族里既有一辈子 Lv5 的农夫，也有凭意志登顶的剑帝。
- 人族地区精英阶占成年人口约 0.4% 到 0.5%，低于大陆平均（见 `society.md` 第 2 节的推算）。
- 召唤来的"客人"都挂在人族的体系上（铭录页面由召唤者写入），所以人族的"已知最强"常常不是人族本土的。

**在主线中的角色与可招募性**

- 第一到第三幕的主要人口与对手：镇民、城民、贵族、教会、勇者团。
- 可招募：难民、北境农民、受迫害的乡间药草婆婆、被教会驱逐者、失意骑士、自由派学者。
  第一批核心国民（罗恩这样的"凡人代表"）来自人族。
- 难点：人族最依赖制度，玩家的国家若没有法度与文书，人族国民的满意度掉得最快。

**对"凡人不信"的典型反应**

- 第一反应是"解释掉"：运气、前人打残了、有机关、作弊、魔物自己内斗。
- 第二反应是"找权威"：公会怎么定级的？神父怎么说？领主承认了吗？
- 被迫相信之后容易走向两个极端：神化（"他是光之女神派来的"）或妖魔化（"他是魔物变的"）。
  阶层越低，越倾向神化；教会与贵族越倾向妖魔化。细则见 `society.md` 第 8 节。

## 2. 精灵（Elves）

| 项           | 内容                                                                                                                                                                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 起源与创造者 | 希尔薇创造，作为"森林的记忆"。她给了精灵漫长的寿命，让他们看着森林一轮轮生长枯荣                                                                                                                                                                                               |
| 外貌要点     | 剪影：长耳向后上方斜伸（像素上用两格耳尖表示）；身形修长。色彩特征是**年轮纹**：太阳穴与锁骨处浅浅的同心环纹，每满一百年多一圈，在灵素浓的地方会微微发光。瞳色随季节变化（春绿、夏青、秋琥珀、冬灰），这是立绘区分季节场景的小彩蛋。长老的头发从发根开始变成银白，发梢仍带苔绿 |
| 寿命与繁衍   | 寿命 500 以上，个别长老逾千年（艾尔温一千二百岁是已知最长）。百岁左右才算成年，一生通常只生育一到两个孩子；繁衍要在灵泉边举行"结环礼"。人口增长极慢，一场战争的损失要几代人才能补回                                                                                            |
| 社会组织     | 氏族制。五大氏族共组希尔瓦氏族议会，另有超越氏族的"长老环"（见 `nations_and_factions.md`）                                                                                                                                                                                     |
| 典型职能     | 德鲁伊与猎人最多，萨满次之，法师（以精灵自己的"叶语术"入门，后与学院体系互通）不少；战士较少；圣骑士为零；术士被视为最重的罪                                                                                                                                                   |

**氏族（分支）**

| 氏族   | 职守                   | 性格                           | 美术提示                 |
| ------ | ---------------------- | ------------------------------ | ------------------------ |
| 根环氏 | 守护世界树根系与长老环 | 古老、保守、沉默               | 深褐与苔绿，树皮纹的护肩 |
| 晨露氏 | 守灵泉、医疗与生育仪式 | 温和、悲悯，最接近希尔薇本人   | 浅蓝与白，常赤足         |
| 苍弦氏 | 游猎与边境警戒，弓术   | 骄傲、排外，议会首座出自此族   | 青灰与墨绿，长弓与羽饰   |
| 雾叶氏 | 外交、与外族贸易、传话 | 圆滑，被其他氏族看不起         | 灰紫与银，面纱           |
| 静苔氏 | 先知、梦占、记事       | 神秘，常闭目，精灵中识字率最高 | 苍白与苔色，眼罩或闭目   |

**氏族之外**

- 外放者：因与外族通婚、离开森林太久或违背议会而被除名的精灵，散居人族城市，做向导、乐师、药师。
  他们是第四幕之前玩家能接触到的主要精灵。
- 半精灵：见第 1 节。森林内部称他们为"无环者"（没有年轮纹，或年轮纹残缺）。

**文化与习俗**

- 年轮纹是身份证明：精灵见面先看对方的环数，环数决定发言顺序。
- 名字一生会换几次：幼名、成年名、长老名。称呼对方的哪个名字，代表你认为对方处于哪个阶段。
- 不砍活树，木材只取自然倒下的枯木；所以精灵的器物很少，代代相传。
- 记事靠"歌"而不是书：重大事件被编成长歌，由静苔氏传唱。空白纪的那一段长歌被长老环禁唱。

**信仰与对诸神的态度**

- 信仰希尔薇，但称她为"母亲"而非"女神"，祈祷形式是在灵泉边静坐，不建神殿，只有圣树与圣泉。
- 对艾琉恩：敌视（人族扩张、伐林、圣教"异族皆需教化"的教义）。
- 对瓦尔妲：轻蔑但忌惮。对梅尔卡：交易可以，信任不行。对莫伊拉：静苔氏与学院有秘密往来。
- 【真相】长老环里有人亲历空白纪，知道"第六位"的存在。精灵的排外有一半是为了掩护森林深处的遗民庇护所。

**位阶分布特点**

- 年龄与位阶强相关：两百岁以下的精灵与人族同龄者差不多，五百岁以上的精灵几乎都在精英阶以上。
- 精英阶占成年人口约 4%，大陆最高；英雄阶的密度也最高。但年轻一代很少，战争中"打不起消耗战"。
- 传说阶：长老艾尔温，另有一到两位长老环成员（是否在世由第四幕文档决定）。

**在主线中的角色与可招募性**

- 第一到第三幕几乎不登场，只以外放者、传闻和德鲁伊结社的形式出现。
- 第四幕：长老艾尔温作证大断绝，遗民庇护所被发现是关键事件。
- 可招募：外放者与半精灵从第二幕起可零星招募；氏族整体只能通过第四幕的外交结盟。
  希尔瓦本身不会并入玩家的国家，但晨露氏与部分雾叶氏可能派人长驻（取决于遗民线的处理）。

**对"凡人不信"的典型反应**

- 不是"不信"，是"不在意"：五百年里见过太多自称强者的短命种，"等你活过三代人再说"。
- 精灵会认真记录（静苔氏的长歌里多一句），但不会改变态度，直到玩家的行为触及森林本身。
- 长老一级的人物反而最先意识到玩家"不对劲"：他们见过千门时代经门而来的客人，认得那种"从门里来的人"的气息。

## 3. 兽人（Beastfolk）

| 项           | 内容                                                                                                                                                                                                                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 起源与创造者 | 希尔薇创造，作为"森林与草原的脉搏"。她把野兽的感官与人的心智缝在一起，让兽人替她在大地上奔跑                                                                                                                                                                                                 |
| 外貌要点     | 以**兽相**为美术主参数：浅相（人脸，只有兽耳、兽尾、指甲与犬齿，例如狼族的希雅、狐族的奈拉），中相（面部有短毛与兽形鼻吻轮廓），深相（完整兽首、全身皮毛）。同一部族三种兽相都有，浅相在人族城镇更常见（深相者难以在人族社会立足）。像素小人以耳朵剪影和尾巴区分部族，尾巴要有独立的待机动画 |
| 寿命与繁衍   | 寿命 50 到 70，12 到 13 岁成年；双胎常见，人口增长最快。兽人与人族可以通婚，孩子多为浅相兽人                                                                                                                                                                                                 |
| 社会组织     | 部族制。若干氏帐组成部族，部族推举酋长；七大部族结成风牙兽王会盟，兽王由会盟推举，任期至死或被挑战                                                                                                                                                                                           |
| 典型职能     | 战士与猎人最多；萨满（祖灵与元素）与德鲁伊是精神领袖；盗贼（斑影部的斥候）常见；牧师少；法师极少；圣骑士为零；术士在瓦尔妲派部族里偶有出现                                                                                                                                                   |

| 疾耳部 | 兔族             | 耕作、信使                 | 希尔薇派                                 | 机敏、胆小、话多   | 长耳，轻装，背信筒               |

**文化与习俗**

- 嗅名：兽人互相介绍时会闻对方的气味，名字之外还有一个"气名"，只在族内使用。
- 祖灵：死者的骨饰挂在氏帐门口，萨满通过骨饰与祖灵对话。【真相】祖灵并不在骨饰里，萨满听到的是灵泉轮回前残留的回声，希尔薇默许这种安慰。
- 挑战权：任何成年兽人都可以向酋长发起"月下挑战"，这是部族政治的核心，也是兽王会盟内战的导火索。
- 收养：战俘与孤儿经过三个冬天可被收养入氏帐，从此不问出身。

**信仰与对诸神的态度**

- 本来信希尔薇与祖灵。近两百年草原屡遭魔物潮与人族开拓，部分部族认为"母亲太慢了"，
  转投瓦尔妲："至少她给我们力量"。这一裂痕就是第四幕兽王之争。
- 对艾琉恩：敌视（圣教把深相兽人视为"未完成的人"，教国境内不许深相兽人入城）。
- 对梅尔卡：赤尾部最亲近，其余部族觉得商人狡诈。

**位阶分布特点**

- 凡阶·熟的比例高（狩猎与部族冲突是日常），精英阶约占成年人口 0.8%。
- 寿命短，英雄阶以上稀少；酋长普遍在精英阶，兽王通常是英雄阶。
- 斑影部和岩掌部的佣兵在人族世界的"已知强者"榜上常见。

**在主线中的角色与可招募性**

- 第一幕：希雅一家（灰鬃部流民）在边石镇受排挤；奈拉（赤尾部出身）是商会的眼睛。
- 第三幕：东部林地的兽人移民。第四幕：兽王会盟内战，希雅的部族卷入。
- 可招募：流民、移民、被逐的战士最早加入；第四幕后可与整部族结盟或让部族迁入。
  兽人是玩家国家早期军力的主要来源之一。

**对"凡人不信"的典型反应**

- 兽人信自己的鼻子和眼睛，不信传闻：传闻说你强，他们不信；亲眼看见你打赢，他们立刻信。
- 信了之后的第一反应是"挑战"：年轻战士会排着队来试，输了的人往往成为最忠诚的追随者。
- 感官敏锐的兽人（尤其灰鬃部与斑影部）会在初见时就"闻出"玩家不对劲：没有铭录气味，
  他们形容为"像雨前的空气"。他们说不清，但会因此保持距离或格外好奇。

**文化与习俗**

- 契约名：每个矮人成年时在契石上刻下一个"契约名"，此后签署的一切契约都用这个名字，违约者的契约名会被凿掉，等于社会性死亡。
- 炉火不熄：炉在，家在。一个炉的火熄灭（破产、绝嗣、背约），炉区会为它举行葬礼。
- 讨价还价是礼节：不还价是看不起对方的手艺。
- 收藏：每个矮人一生会为自己打造一件"终器"，死后随葬或传给最好的徒弟。

**信仰与对诸神的态度**

- 信梅尔卡，但方式是"立约"而不是"崇拜"：每年与女神续一次约，供品是自己最好的作品。
- 对艾琉恩：圣教是大客户，也是欠钱不还的大客户（梅尔卡握着教会的账）。
- 对瓦尔妲：军火买家，生意归生意。对希尔薇：精灵的森林挡着矿脉，积怨很深。
- 【真相】赤砧山深炉矮人的净炼工艺会产生大量"澱渣"（净炼澱晶时析出的澱残留），几百年来被秘密倾倒进废矿坑，山下矿村的怪病和废坑里的魔物都源于此。这是赤砧山最大的商业机密，也是一个凡人版本的"排澱"：同构于诸神把澱聚进魔王容器。

**位阶分布特点**

- 精英阶约占成年人口 1.2%，多集中在战士与工匠。
- 铭录的等级计入"手艺的精熟"，所以有"Lv25 的铁匠"，他的战斗力远不如 Lv25 的战士。
  这在人族社会制造了大量误会（建议 `power_system.md` 确认此规则，本文先按此写）。

**在主线中的角色与可招募性**

- 第二幕起以行炉矮人和商会工坊的形式出现；第四幕赤砧山是同盟的重工业与"晶炮"产地。
- 可招募：行炉矮人在第二幕即可签约雇佣；整炉迁入玩家国家需要一份长期契约，
  条件是"你的国家必须守约"。玩家国家违约一次，所有矮人国民的忠诚会大幅下跌。

**对"凡人不信"的典型反应**

- "写下来，签字。"矮人不在乎你多强，在乎你说的话能不能兑现。
- 他们会用实物验证：你说你一剑劈开了岩石，就带他去看断面，他会摸一摸切口，估算需要多大的力道，然后沉默很久。
- 一旦信了，就按契约对待你；在矮人眼里，"强"本身不值钱，"守信的强"才值钱。

- 精英阶约占成年人口 2.5%，仅次于精灵；鬼人和夜魔的贵族中英雄阶很密集。
- 灰魔与人族的分布差不多：魔族"强"的印象来自上层，不来自普通人。
- 魔王空位时期，夜境已知的传说阶只有夜后；大诸侯与红牙将军萨莎（客人，登场时英雄阶，以战斗无限成长）在英雄阶（`nations_and_factions.md` 第 1.7 节）。

**在主线中的角色与可招募性**

- 第一到第二幕：只在传闻里，镇民把魔族和魔物混为一谈。
- 第三幕：红牙将军萨莎北线突袭。第四幕：夜后出席强者之宴。第五幕：第九代魔王诞生后夜境多数倒向魔王，夜后一派可凭"月下之约"拒绝。
- 可招募：魔族逃兵、被决斗击败后追随强者的战士、被夜境贵族压迫的灰魔与半魔、隶民。
  玩家国家里的魔族是军力强项，也是与圣教关系的最大负担。
- 规则：魔族追随"打赢了自己的人"，玩家亲手击败的魔族将领有很高概率转投。

**对"凡人不信"的典型反应**

- 魔族是最"信"的种族：他们不需要解释，只需要一场决斗。打赢了，你就是强；打输了，再多传闻也没用。
- 反过来，魔族最看不起"不敢接受挑战的强者"。玩家如果总是藏拙，在魔族眼里就是懦夫。
- 魔族会把强者的传闻当成邀请，而不是警告：玩家越有名，越多魔族找上门。

| 项           | 内容                                                                                                                                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 起源与创造者 | 造主亲手放下，与箱庭同龄。不属于任何一司，是六司之外唯一"造主的造物"                                                                                                                                                                           |
| 外貌要点     | 原龙体长以数十米计，鳞色各异（艾斯卡为银），角与背脊像山岩；化为人形时保留与鳞同色的发与瞳，皮肤上有鳞片残影，眼睛的瞳孔是竖的。立绘重点是"尺度"：人形时安静，真身出现时画面要被它撑满。像素：真身用大型多块精灵图，人形用单格小人但配专属光效 |
| 寿命与繁衍   | 近乎不朽。原龙之间极少繁衍，一枚龙卵需要上千年孵化；龙族自己也不清楚还剩几位原龙                                                                                                                                                               |
| 社会组织     | 没有国家，没有王。各龙独居，以龙脊山脉为共同的巢域；守护第七座天启碑是唯一的集体职责                                                                                                                                                           |
| 典型职能     | 不适用。原龙不在铭录里（他们比铭录更早），新生的龙登记在铭录里但没有职能                                                                                                                                                                       |

**分支**

| 分支             | 说明                                                                                                          | 位阶                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | --------------------- |
| 原龙             | 开园时由造主放下，记得开园那一天；现存可确认的只有艾斯卡，其他原龙是否在世是谜                                | 超越                  |
| 古龙             | 原龙在箱庭中所生的后裔，萌芽期之后孵化，有铭录页，数量以个位计，大多在沉睡；开园的记忆靠原龙传承              | 神话阶（铭录上限 60） |
| 伪龙（不是龙族） | 凡人所说的"飞龙""亚龙""恶龙"，绝大多数是澱化的大型飞蜥或澱聚成的龙形魔物（第 9 节），真正的龙族称它们为"影子" | 不定                  |

**文化与习俗**

- 龙不收集金银（那是凡人的传说），收集的是"记忆"：每一位原龙都在巢穴里保存着某些开园以来的事物。
- 龙说话很少，用古庭语，常常只说一句。

**信仰与对诸神的态度**

- 不信仰任何司掌者。原龙把六司看作"受雇看园子、却忘了工作内容的后辈"。
- 原龙不介入诸神之争，这是他们的自我约束。【真相】原龙记得造主放下他们时的嘱咐，并因此知道"离手"的本意；他们不说，因为说出来本身就是一种干预。

**位阶分布特点**

- 全员在传说阶以上。原龙在铭录之外，鉴定只显示"？"，这一点与玩家的"无记载"相互呼应：
  第五幕艾斯卡第一次见到玩家时，会认出这种"没有页面"的存在，这是他愿意开口的原因之一。

**在主线中的角色与可招募性**

- 第一到第四幕只是传说和远景。第五幕艾斯卡降下："他们又在用同样的办法清洗。"第六幕作为证人。
- 不可招募。龙族只能成为"盟友"或"见证者"，而且只在第五幕后、且玩家走在"众生的办法"路线上时才会出手。

**对"凡人不信"的典型反应**

- 龙不需要相信或不信，他们看得见。他们对玩家的反应不是惊讶，而是"终于"。

## 8. 门民（遗民）（Gatefolk / the Remnant）

| 项           | 内容                                                                                                                                                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 起源与创造者 | 雅努创造，作为"门的守护者与引路人"。千门时代，门民遍布门网的每一个节点，替诸族开门、引路、守门。大断绝当夜，千门都的门民几乎全数死去；幸存者散入各地，从此被称为"遗民"                                                                                                           |
| 外貌要点     | 外表与人族相同（这是他们能躲藏的原因）。唯一的标志是**门纹**：一块形似拱门的胎记，位置因人而异（手背、颈后、胸口、脚踝最常见），靠近门或门的残迹时会发热、颜色变深。遗民习惯用手套、围巾、刺青、烫疤遮掩门纹。立绘与像素：衣着朴素、低饱和度，门纹在"被看见"的剧情时刻才高亮显示 |
| 寿命与繁衍   | 寿命约 100。门纹的遗传没有规律：纯血遗民的孩子也可能没有门纹，人族家庭里也会突然生出带门纹的孩子（千门时代通婚的远祖血脉"隔代显纹"）。这就是人族孤儿院里会出现门纹孩子的原因                                                                                                     |
| 社会组织     | 没有国家。以"留门之家"为节点的秘密网络：一户人家在夜里把门留一道缝，就是在告诉同族"这里安全"。几处较大的聚居地见下表                                                                                                                                                             |
| 典型职能     | 铭录登记的职能与所在地的人族相仿：猎人与盗贼多（求生），牧师少（只能秘密祭祀）。门纹本身不是职能，铭录里也不记载门纹                                                                                                                                                             |

**分支**

| 分支       | 说明                                                                                                       |
| ---------- | ---------------------------------------------------------------------------------------------------------- |
| 隐村遗民   | 希尔瓦大森林深处的庇护所，受晨露氏与长老环秘密照看，保有最完整的门民传统与古语                             |
| 灰边遗民   | 住在灰烬荒原南缘的穷乡、矿场与边陲小镇底层，离封门最近，有人秘密去封门遗迹朝圣。边石镇孤儿院的孩子多出于此 |
| 散居遗民   | 藏在人族城市里的个体与家庭，三代不敢相认，很多人连自己的门纹意味着什么都不知道                             |
| 门徒会信徒 | 被无貌者吸收的激进遗民（只是门徒会成员的一部分，见 `nations_and_factions.md`）                             |

**文化与习俗**

- 留门：夜里门留一道缝。圣教的异端审判手册把"留门"列为可疑行为，这也是人族"夜里不留门缝"俗语的来源。
- 叩门暗号：三短一长。
- 开门礼：孩子的门纹第一次"发热"时，家里会给他一把没有对应锁的钥匙，象征"总有一扇门在等你"。
- 门民的古语是千门都的通用语，混杂着各族的词汇；隐村遗民还会说，其余遗民只剩几个词。

**信仰与对诸神的态度**

- 秘密信仰"无名之神"，隐村遗民称她为"开门的母亲"。祈祷在门槛上进行，不出声。
- 对艾琉恩与圣教：恐惧。异端审判庭称他们为"烙印者"，持有一种能让门纹发光的圣器"照纹灯"。
- 对希尔薇：隐村遗民知道是她在庇护自己，但不知道原因。
- 对其他诸神：几乎一无所知。
- 【真相】门纹是雅努留下的"钥"（`pantheon.md` 第 6 节）。门纹不在铭录里，因为它属于铭录"门"的一侧，而莫伊拉的"录"看不见它；所以鉴定查不出遗民，异端审判只能靠肉眼与照纹灯。

**位阶分布特点**

- 绝大多数在凡阶·初，生活困苦，很少有机会成长。
- 门纹者中藏着大量"被埋没的潜质"：识才之门对门纹者显示的潜质格外多。这是设计意图：
  玩家的国家是第一个让遗民可以"长大"的地方。

**在主线中的角色与可招募性**

- 第一幕：孤儿院的门纹孩子。第二幕：门徒会绑架门纹孩子当钥匙。第三幕：圣战军屠杀遗民。
  第四幕：遗民庇护所被发现。第五幕：重建门网需要遗民的门纹（"众生的办法"）。
- 可招募：玩家国家的核心国民。遗民会自发投奔，前提是玩家在前几幕里保护过他们（世界状态"被救回的遗民孩子数量"等）。
- 风险：遗民越多，圣教越把玩家的国家定性为"烙印者之国"；门徒会也会在遗民中渗透。

**对"凡人不信"的典型反应**

- 门民是唯一"一见就信"的种族：玩家走近时，他们的门纹会发热。他们不知道为什么，但知道"这个人和母亲有关"。
- 他们的信伴随着恐惧：在他们的经验里，和"门"沾边的东西最后都会招来审判官。
  所以门民的典型反应是先躲，再偷偷观察，最后在玩家救下某个遗民孩子之后整批投奔。

## 9. 魔物与亡灵：澱的分类学

魔物与亡灵不是种族，没有创造者，不登记职能（铭录只记录其等级，用于鉴定与公会定级）。
它们是澱（`world_bible.md` 第 5 节第 3 条）在世界上的显化。本节给出两条分类轴：**澱度**（浓度）与**澱源**（来源），
再按形态分类。设计上，任何一只魔物都可以用"澱度、澱源、形态"三元组描述，供内容生产与女神 GM 的魔物潮工具使用。

### 9.1 凡人怎么称呼它

| 说法               | 谁在用                                                         | 含义                                                                                   |
| ------------------ | -------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 灰气、秽           | 普通人（灰气）、圣教布道（"邪神之秽"）                         | 澱本身：魔物身上与不祥之地散发的东西                                                   |
| 澱                 | 冒险者、学者、药草师之间的行话                                 | "魔物体内与魔物巢里沉下来的东西"，只描述现象，不知来源                                 |
| 灰病、荒原病、澱病 | 普通人称灰病，边石镇一带也叫荒原病；冒险者、学者与药草师称澱病 | 长期接触高澱之地或未净炼的澱晶引起的慢性病：咳灰、关节发黑、梦魇，孩子与老人最易死     |
| 灰狼、灰鬼等       | 普通人                                                         | 异兽与亡灵的俗称（被灰气染了的狼，夜里游荡的亡灵）                                     |
| 魔晶               | 所有人                                                         | 经持证工坊（教会、学院、公会）净炼过的澱晶，魔导器的燃料，可合法交易，是事实上的硬通货 |
| 灰晶、澱晶         | 普通人称灰晶；澱晶是冒险者、学者与商人的行话                   | 魔物死后凝出、尚未净炼的结晶，不得合法流通，只在黑市交易                               |

【真相】"澱"这个词是学院在空白纪之后从铭录残页里读到的，莫伊拉允许它流传，因为它只说出了"是什么"，没有说出"从哪来"。
凡人常识层知道"澱"这个字眼的人很少；知道它来自诸神干预的，只有禁忌之知层及以上。
俗称以 `world_bible.md` 第 5 节第 3 条为准（决策日志 D-030）：NPC 的凡人口吻一律用灰气、灰病、灰晶等俗称；
玩家从夜羽口中听到"澱"之后，界面上的名称才切换为正式名。

### 9.2 澱度（浓度分级）

标尺统一为 `power_system.md` 第 7.2 节的六级加临界（决策日志 D-039），地理分布见 `geography.md` 第 0.3 节。

| 澱度 | 名称 | 典型场所                                   | 显化                                                                     | 魔物等级 | 产出               |
| ---- | ---- | ------------------------------------------ | ------------------------------------------------------------------------ | -------- | ------------------ |
| 0    | 清域 | 灵泉、世界树周边、门内庭院                 | 无                                                                       | 无       | 无                 |
| 1    | 薄澱 | 大陆绝大部分地方                           | 野兽略显躁动，偶发单只异兽                                               | 1 到 9   | 碎晶               |
| 2    | 积澱 | 荒野、旧战场外围、小迷宫入口、荒原外缘     | 异兽成群，澱巢，零星的澱生体与游魂                                       | 5 到 19  | 碎晶、小晶         |
| 3    | 浓澱 | 废墟、魔物巢、迷宫周边、封门遗迹深处       | 澱生体常驻，死者会起身，精英魔物出现，开始结晶为迷宫；人住上数月会得澱病 | 15 到 34 | 小晶、中晶         |
| 4    | 深澱 | 魔物潮的源头、大型巢穴、大迷宫、千门都外环 | 迷宫成形，迷宫主诞生，高阶亡灵                                           | 30 到 49 | 中晶、大晶         |
| 5    | 渊澱 | 千门都核心（主门坑、古澱湖）、王胎渊底     | 寸草不生，亡灵游荡，神之视线失效                                         | 45 到 60 | 大晶、王晶、迷宫核 |
| 临界 | 澱满 | 灰烬荒原中心的古澱湖（被封门与守门人压着） | 渊澱在有灵智的容器里凝聚到临界时，魔王诞生                               | 不适用   | 渊晶（魔王）       |

- 杀死魔物时，它体内大部分澱凝成澱晶，其余散回当地；所以讨伐能"压住"澱度，却不能"消除"澱
  （只讨伐不净化，澱只是被压住；澱晶经净炼成魔晶时也只能减少余澱，见 `power_system.md` 第 7.3、7.7 节）。
  澱的自然消散只发生在生命循环里（森林、灵泉），极慢。这就是魔物"越杀越多"的根本原因。
- 正典中唯一的"大规模净澱"方法，是第五幕的"众生的办法"：用门网分散，再由各族协力净化。
- 第四幕末的天启「荒原之澱满」即对应本表的"临界"一档。

### 9.3 澱源（来源分类）

不同司掌者的干预留下的澱有不同的"性格"，滋生的魔物带着可辨认的特征。
这是一条给玩家后期回头解读的暗线：**看魔物的样子，就能知道这里曾经有哪位女神出过手**。前三幕不得点破。

| 澱源 | 来自                                               | 魔物特征                                                             | 凡人的误读                                             |
| ---- | -------------------------------------------------- | -------------------------------------------------------------------- | ------------------------------------------------------ |
| 光澱 | 艾琉恩的神迹（治愈、显光、召唤），最大来源         | 苍白、对称、几何化、像瓷器或水晶；亡灵常保有圣徒般的面容             | 圣地附近的这类魔物被教会称为"试炼之兽"，或干脆封锁消息 |
| 战澱 | 瓦尔妲催动的魔物潮与战争挑唆                       | 赤黑、多角、伤口不愈反而更凶，成群冲锋                               | 认作魔族的诅咒（教会最爱举的例子）                     |
| 契澱 | 梅尔卡的契约加护与物价操纵                         | 数量多、个头小、贪食；模仿财宝的拟态魔物（宝箱怪、钱袋鼠）           | 认作"贪婪招来的报应"，商人间的笑话                     |
| 生澱 | 希尔薇的天灾（旱、涝、虫、疫）                     | 植物化、菌化、虫群，过度生长与腐烂同时存在                           | 认作"天灾后的瘴气"，德鲁伊最清楚但不说                 |
| 录澱 | 莫伊拉的铭录操作（授称号、觉醒技能、改鉴定可见度） | 极少见；身上浮着文字样的纹路，鉴定结果错乱；"残页"幽灵会重复同一句话 | 认作"闹鬼的书库"，学院地下常有传闻                     |
| 古澱 | 大断绝（门网崩塌与艾琉恩、瓦尔妲的破坏）           | 灰烬色，身上有门形的空洞，亡灵穿着千年前的衣服                       | 认作"荒原的诅咒"，无人知道来源                         |

- 混澱：旧战场与大城附近常混有多种澱源，魔物特征混杂。
- 【真相】大教堂地下的圣骨堂长年积着光澱，教会每年的"净化巡礼"是把圣骨堂的秽物运往荒野掩埋；
  教会自己以为这是在"送走邪秽"。这是凡人层面的"排澱"，与诸神的魔王循环同构，第四幕之前不得点破。

### 9.4 形态分类

| -------------- | ---------------------------------------------------- | ---------------------------------------------- | -------------------------------------------------- |

| 亡灵           | 澱堵住了死者灵魂回归灵泉的路，灵魂被困在尸骸或遗物里 | 游魂、尸傀、骸骑、残页幽灵                     | 可以"送魂"：清除澱后灵魂归泉                       |

| 侵蚀者         | 有灵智的生灵被澱侵入心智，保有部分自我               | 无貌者、被澱侵蚀的巨鸦夜羽                     | 少数可以：夜羽被玩家以"契约之门"净化，是全作第一例 |
| 魔王           | 澱在有灵智的容器里凝聚到临界                         | 第一到第九代魔王                               | 正典未定（第五幕"救赎或毁灭"分支）                 |

### 9.5 凡人的误解（NPC 常识库直接引用）

| 误解                           | 谁这么信         | 真相                                                                 |
| ------------------------------ | ---------------- | -------------------------------------------------------------------- |
| 魔物是魔族与瓦尔妲的诅咒       | 人族绝大多数     | 所有女神的干预都产生澱，光澱最多                                     |

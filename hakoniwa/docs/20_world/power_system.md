# 力量体系（Power System）

> 正典文件，属 `docs/20_world/`（优先级在 `world_bible.md` 与 `../00_vision/vision.md` 之后，与 `pantheon.md` 同级）。
> 本文展开总纲第 5、10、11 节：灵素、铭录、位阶、职能、技能与天赋、加护、澱与魔物、神力、千门、客人、物品，
> 并给出它们与 world-of-claudecraft 主工程（下称"主工程"）系统的映射。
> 标记约定同总纲：【表层】是凡人相信或被告知的说法；【真相】只供内部设计使用，向玩家揭示的进度以
> `../30_story/reveal_ledger.md` 为准。

> 并沿用主工程"不凭空发明平衡数值"的原则（经典公式、已有参考或实测）。
> 引用主工程只写稳定路径与导出符号，不写行号。
> 文中"建议"字样的内容（例如某位正典人物的职能）是本文的推荐值，角色文档或设计文档可以改写，改写时不需回头修订本文。

## 0. 总则：力量从哪里来，到哪里去

```
灵素 -> 地脉 -> 生灵吸纳（成长） -> 技能消耗 -> 回到地脉
                  |
                铭录记账（等级、位阶、职能、技能、加护）

信仰 -> 神力 -> 干预（加护、神迹、化身、召唤） -> 澱 -> 魔物、迷宫、魔王 -> 排澱 -> 信仰
```

五条铁则（本文其余部分都从这里推出）：

1. **力量的原料只有一种：灵素。** 职能、加护、术式、契约、门，都只是让灵素换一种走法。
2. **凡人的成长被铭录记账，也被铭录框住。** 一生一职、等级上限 60、位阶之间的关，都是铭录的规矩。
3. **诸神的每一次出手都要花神力，都会留下澱。** 澱是魔物、迷宫与魔王的原料。
4. **信息永远不完整。** 鉴定有上限，灵觉会饱和，神之视线有盲区，传闻会失真。
5. **玩家不在账上。** 铭录的约束对他失效，铭录的眼睛也看不见他；但灵素、物理、澱、目击与死亡，对他照样有效。

设计落点：每一条世界规则都要能落到内核可验证的状态上（愿景"模型提议、内核裁决"）。女神与 NPC 的大模型
只能在这些规则内行动，不能发明新的力量来源。

## 1. 灵素理论

### 1.1 来源

- 【表层】圣教："灵素是唯一之光洒在大地上的余晖，信仰越深，光越盛。" 学院："灵素是天地的本气，生生不息。"
- 【真相】灵素是箱庭的"庭液"。造主种下箱庭时，箱庭的地基（本文称"庭底"）就开始渗出灵素，像树液从根部上行。
  - 灵素从庭底经地脉上涌，进入水、土、草木，再进入吃喝呼吸的生灵；生灵死去，肉身里的灵素回归地脉，灵魂归于灵泉。
  - 箱庭是封闭的：终雾与天穹不让灵素外流，也没有外来的灵素补给。灵素总量大体恒定，世界的贫富取决于**流动**，不取决于总量。
  - 诸神不生产灵素。神力（见第 8 节）是另一种东西：它来自信仰，用来"推动"灵素，而不是创造灵素。

### 1.2 流动

| 循环     | 路径                                                     | 意义                                                                  |
| -------- | -------------------------------------------------------- | --------------------------------------------------------------------- |
| 地脉循环 | 庭底 -> 地脉 -> 灵穴（灵素涌出的结点） -> 地表 -> 回渗   | 灵素的主干道。神殿、城市、迷宫多建在或生在灵穴附近                    |
| 生灵循环 | 呼吸与饮食吸纳 -> 体内积累（成长） -> 施技消耗、死亡回归 | 等级的本质：一个生灵能稳定容纳并驱使多少灵素                          |
| 净化循环 | 灵泉与世界树缓慢"解开"污滞的灵素                         | 希尔薇的灵泉清澈度与全世界的澱水平相关（见 `pantheon.md` 希尔薇计分） |

- 【真相】**门网曾是箱庭的血管。** 千门时代，雅努的门把各地的地脉结点连成一张网，灵素可以跨越山海直接流通，
  局部的污滞会被很快冲散。大断绝毁掉主门、门网崩溃之后，各地的地脉重新各自为政，流动变慢，澱开始在低洼处沉积。
  魔王与勇者循环始于圣历 87 年，并非巧合。第五幕"重建小型门网以分散、净化古澱"正是这条规则的回扣。
- 【真相】原始规约"勿使枯，勿使乱"在灵素层面的意思是：别让灵素停滞（枯），别让灵素被强行扭曲（乱）。
  诸神的干预恰好同时违反这两条。

### 1.3 七相：属性划分

灵素本身无相。当它被生灵或术式驱使时，会沿三条"轴"偏转，呈现不同的"相"。学院称之为"七相"。

| 相   | 主工程法术学派（`Aura` 的 `school` 取值） | 轴与本质（【真相】层）               | 典型用法                               | 常见职能                       |
| ---- | ----------------------------------------- | ------------------------------------ | -------------------------------------- | ------------------------------ |
| 体相 | `physical`                                | 聚：灵素凝入血肉与器物               | 武器打击、箭矢、盾击、流血             | 战士、盗贼、猎人、野牙派德鲁伊 |
| 玄相 | `arcane`                                  | 散：最接近灵素本身的"无相之相"       | 玄素飞弹、迁跃、时序术、月术、射术灌注 | 法师、德鲁伊（月）、猎人       |
| 焰相 | `fire`                                    | 热：灵素激越                         | 火球、灼烧、爆燃                       | 法师、术士、萨满               |
| 霜相 | `frost`                                   | 寒：灵素凝滞                         | 冰矛、冻结、减速                       | 法师、萨满                     |
| 光相 | `holy`                                    | 升：灵素上扬、整序                   | 治愈、审判、驱逐、护佑                 | 圣骑士、牧师                   |
| 幽相 | `shadow`                                  | 降：灵素下沉、回落                   | 衰败、恐惧、心术、吸取                 | 牧师（晚祷派）、术士           |
| 生相 | `nature`                                  | 流：灵素在生命与天候里循环的本来样子 | 雷、风、毒、草木、愈合                 | 萨满、德鲁伊、猎人与盗贼（毒） |

"三轴一心"：升降轴（光、幽）、寒热轴（焰、霜）、聚散轴（体、玄），生相居中，是不偏转的流动本身。

- 相与相之间没有高下。克制关系只来自轴的对立（例如霜相减缓焰相的扩散），具体抗性数值留给设计文档。
- 【表层】圣教说光相至高，幽相是邪恶，且与澱同源。
- 【真相】幽相是灵素自然的回落，和落叶、睡眠、哀悼一样正常；它与澱无关。澱不是第八相，而是"打了结、不能再流动的灵素"（见第 7 节）。
  光相也不是艾琉恩的私产，任何生灵都能把灵素推向"升"，只是圣教垄断了教法。

### 1.4 凡人的学说与真相的差距

| 学说               | 持有者         | 说法                                                                                       | 对在哪里                     | 错在哪里                                                         |
| ------------------ | -------------- | ------------------------------------------------------------------------------------------ | ---------------------------- | ---------------------------------------------------------------- |
| 光源论             | 圣教           | 灵素源于唯一之光；其余诸相是光的残缺；幽相与魔物同为邪神之秽                               | 光相确实最"整序"，最适合治愈 | 灵素不来自任何神；幽相无罪；澱来自全部女神，其中光的神迹留下最多 |
| 七相说（铭录学）   | 魔导学院       | 灵素有七种本相，可用术式精确驱使；铭录是"天之录"，与日月同为自然法则；等级 60 是凡躯的极限 | 七相分类实用，术式确实有效   | 相是姿态不是本性；铭录是莫伊拉与雅努造的系统；60 是设计上限      |
| 流转论             | 精灵长老       | 灵素是一条河，滞则生秽；古时有"门"使河道通畅                                               | 最接近真相                   | 不说（或不敢说）秽与神的关系；把门的消失说成一场天灾             |
| 矿脉论             | 矮人           | 灵素从地底矿脉涌出；澱晶是"大地的结石"，是矿                                               | 灵素确实自庭底上行           | 澱晶不是矿物，而是魔物死后凝结的澱                               |
| 祖灵说             | 兽人           | 灵素是祖先的呼吸，死者化入风与草                                                           | 灵素确实随死亡回归           | 把灵泉的轮回误为祖灵永驻（祖灵只是泉畔的回声，见 4.4 萨满）      |
| 天穹边界说（禁学） | 被禁的天文学家 | 星辰运行"太整齐"，天穹是一道墙                                                             | 完全正确                     | 被圣教定为禁学（总纲第 2 节）                                    |

| ------ | ------------------ | ------------------------------------------------------------------------ |

## 2. 铭录（Moira's Record）

### 2.1 结构：门与录

总纲："门"负责接入，"录"负责记载。展开如下：

| 层                   | 造者   | 职责                                                               | 现状                                                                                                       |
| -------------------- | ------ | ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| 门侧（Gate layer）   | 雅努   | 每个生灵出生时，把它的灵魂"接"进铭录；保存每个灵魂的"可能"（潜质） | 雅努被封印后，门侧按惯性运转：照常接入新生灵魂，但无人能改写它。莫伊拉只能看见潜质的"门"，读不出门后是什么 |
| 录侧（Record layer） | 莫伊拉 | 记载等级、职能、技能、加护、称号、履历；提供鉴定接口               | 莫伊拉完整读写；其他女神经她"借阅"                                                                         |

- 【表层】圣教："铭录是光照万物、录其功过的恩典，由侍奉光的记录女神看管。" 学院："铭录是天之录。"
- 【真相】大断绝前，莫伊拉与雅努在铭录里留了一个"门的接口"（`pantheon.md` 莫伊拉的真相）。
  这个接口允许一个灵魂只经门侧接入箱庭，而录侧没有它的页。玩家的"无页之身"就挂在这个接口上。

### 2.2 一页上写着什么

每个在箱庭出生的生灵有一页。

| 栏           | 内容                                   | 谁能写                       | 能否被鉴定读到                                                 |
| ------------ | -------------------------------------- | ---------------------------- | -------------------------------------------------------------- |
| 名与种族     | 当前名字、曾用名、种族                 | 自动                         | 能                                                             |
| 等级         | 1 到 60                                | 自动（随灵素容量改写）       | 能（受鉴定读高限制）                                           |
| 位阶         | 由等级与是否过关决定                   | 自动                         | 能                                                             |
| 职能         | 至多一个，可以为空                     | 自动（授职时写入）           | 能                                                             |
| 流派         | 职能下的专精，定流后写入               | 自动                         | 高级鉴定以上                                                   |
| 技能         | 技能名与技阶                           | 自动（觉醒时写入）           | 高级鉴定以上                                                   |
| 铭纹         | 天赋选择                               | 自动（过纹时写入）           | 精密鉴定以上                                                   |
| 生业         | 采集、制作等生活技艺与熟练度，可以多项 | 自动                         | 高级鉴定以上                                                   |
| 加护栏       | 诸神授予的加护                         | 各司（仅限自己的信徒）       | 公开的名称：高级鉴定；强度：精密鉴定；全部：对应女神的神前鉴定 |
| 称号         | 传颂、讨伐、身份等称号                 | 莫伊拉（部分由规则自动写入） | 能                                                             |
| 状态         | 诅咒、澱染、封印痕、以神力担保的契约   | 自动或施加者                 | 普通水晶只读出"澱染有无"；其余见 2.5                           |
| 履历         | 生卒与重大事件                         | 自动                         | 不对鉴定开放（莫伊拉与史官的领域；空白纪部分已封存）           |
| 底页（门侧） | 潜质                                   | 门侧（出生时）               | 任何鉴定都读不到（见 2.4）                                     |

特殊的页：

- **残页**：魔物在澱中凝形时，门侧也会把它"接"进来，但只生成一页残缺的页：等级、种类、状态，没有职能、加护与履历。
  鉴定魔物时读到的就是残页。
- **异变注记**：野兽被澱侵蚀成异兽时，原有的页被加上异变注记，等级随之改写。
- **终页**：死亡时页被标记为"终"，转入归档。亡灵（见 7.3）的残页会引用生前那一页的终页。
- **客页**：客人的页由召唤者开出，带"客"的注记（见第 10 节）。

### 2.3 何时写入

| 事件         | 写入什么                | 说明                                                                                                         |
| ------------ | ----------------------- | ------------------------------------------------------------------------------------------------------------ |
| 开页（出生） | 名、种族、Lv1、底页潜质 | 门侧接入灵魂的同一刻                                                                                         |
| 成长         | 等级                    | 灵素容量越过阈值时即时改写，即"升级"                                                                         |
| 授职         | 职能                    | 一个人长期把灵素导向一种用法并"立意"之后写入。师门、骑士团、学院、神殿的授职礼只是社会仪式，真正写入的是铭录 |
| 觉醒         | 技能、技阶              | 见第 5 节                                                                                                    |
| 过关         | 位阶、流派、铭纹        | 见第 3 节与第 5 节                                                                                           |
| 授予         | 加护                    | 由女神写入加护栏                                                                                             |
| 授称         | 称号                    | 莫伊拉亲手写，或由她预设的规则自动写（例如"传颂"类称号在一个人的事迹被足够多的人讲述时自动生成）             |
| 死亡         | 终页                    | 归档；灵魂归灵泉                                                                                             |

写入是即时的，阅读却不是。莫伊拉不可能盯着每一页看，她靠"书签"（关注名单）与"异动提醒"（短时间内的异常跳变、
大量死亡、频繁的"所在不明"）来分配注意力。这条规则是玩家"间接被看见"的主要途径（见 8.6）。

### 2.4 写入权限与神约第三条

神约第三条："不得篡改铭录（莫伊拉除外，且须告知其他四司）。" 本文对"篡改"的界定：

| 写入                                         | 是否篡改 | 说明                                                                       |
| -------------------------------------------- | -------- | -------------------------------------------------------------------------- |
| 女神向**自己的信徒**的加护栏写入或撤销加护   | 否       | 加护栏是录侧为诸神预留的公共写入口                                         |
| 召唤者经召唤大阵为客人开出新页（含加护套装） | 否       | 开新页不改动任何已有的页；开页必须经莫伊拉副署，她因此知道每一位客人的到来 |
| 莫伊拉授称号、觉醒技能、调整鉴定可见度       | 否       | 属于她作为维护者的日常职权                                                 |
| 改动任何已有页的等级、职能、技能、履历、底页 | 是       | 只有莫伊拉能做，且须告知其他四司                                           |
| 向他司信徒的加护栏写入                       | 是       | 禁止；这也是"改宗"必须先经历加护熄灭的原因（见 6.7）                       |

### 2.5 鉴定能读到什么，读不到什么

**读不到的东西（任何层级的鉴定都一样）：**

1. **潜质**：底页属于门侧。所有鉴定都只走录侧，读不到门后的"可能"。唯一的例外是玩家的识才之门（第 9 节）。
2. **超过上限的存在**：铭录的等级栏最高写到 60。超过上限的部分是"溢出"，不写入页面。鉴定只显示"60"或"？"（总纲 10.1）。
3. **无页之身**：没有页可读。任何层级的鉴定都只显示"无记载"（普通水晶不亮，读数栏显示"无记载"）。
4. **被封印者**：被以神约级手段封印的存在（雅努本身，以及被一并封存的部分记录），页面是"合页"，鉴定只显示一个"封"字。
   莫伊拉也读不到（`pantheon.md`：她的眼睛覆盖"除玩家与被封印者之外的一切"）。
5. **心**：意图、情感、忠诚、谎言。铭录记行为与能力，不记人心。
6. **未被写入的能力**：一个人能做到、但铭录没有登记为技能的事（例如凡人模仿来的动作、玩家经门得到的技能）。

### 2.6 鉴定的层级与上限

两个指标：**读高**（能精确读出的最高等级）与**读深**（能读到哪些栏）。

| 层级           | 设施与执行者                                                                                    | 读高                                                                   | 读深                                                 | 成本与时间                           | 破绽                                                                                                                 |
| -------------- | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |

### 2.8 一生一职：铭录对技能习得的约束

**规则：** 凡人的页上只有一个职能栏。技能只能登记在职能所属的技能族之下。未登记的技能不成"技"：
凡人可以模仿别的职能的动作，但灵素不会按那门技艺的路子流动，效果为零或接近零。

**原因：**

1. **定脉**：铭录在一个人成长时，会按职能把他体内的灵脉"定形"。战士的灵脉把灵素导向血与肌肉（战意），
   法师的灵脉把灵素导向灵海（灵力）。两种定形彼此冲突，一具身体只能承载一种。
2. **设计**：【真相】一页一职是莫伊拉为了"可读"而定的规矩：一个人一条主线，故事清楚，记录整齐。

【真相】**改门**：千门时代，门侧允许凡人一生"改门"一到两次，即经过一扇门把灵脉重新定形，换一个职能。
大断绝后门侧沉寂，改门失传，凡人从此"一生一职"。精灵长老（例如长老艾尔温，他出生于千门时代末期）还记得有人改过门。
玩家跨职能学技能，在世界史里不是无中生有，而是失传之事的复现。

**例外：**

| 例外         | 说明                                                                         |
| ------------ | ---------------------------------------------------------------------------- |
| 官方勇者     | 召唤时开新页，页上本来就写着两个职能栏（加护套装决定组合，见 6.5）。不属篡改 |
| 莫伊拉的改写 | 她能给已有的页改职能，但属篡改，须告知四司；千年来极少发生                   |
| 转生         | 死后经灵泉轮回，新的一生开新页                                               |
| 生业         | 生业不是职能，不占职能栏，可以多项（主工程允许一个角色学多门生产技能）       |
| 无页之身     | 不受此限，但每一项都要找到钥（第 9 节）                                      |

### 3.2 逐阶说明

**凡阶·初（1 到 9）：绝大多数人的一生**

- 孩童 Lv1 起步，成年农夫与工匠多在 Lv3 到 6。
- 一名 Lv5 的新兵持矛能与一头野狼打个平手；学徒法师用尽灵力能射出拳头大的火苗；学徒牧师能止住小伤的血。
- 社会：F、E 级冒险者做采集与跑腿；"凡人不信"的常识就建立在这一层。

**凡阶·熟（10 到 19）：老兵与熟手**

- 已过第一关（定流或出师）。卫队长、老兵、熟练冒险者、手艺精湛的匠人。
- 一名 Lv15 的战士能在城门口挡住一小群魔狼；法师的火球能点着一栋木屋；牧师能在一场小战斗后救回重伤者；暗行者能潜入贵族宅邸再出来。
- 罗恩（D 级）在这一层。

**精英阶（20 到 34）：一座城的骨干**

- 骑士团长、名冒险者、宫廷法师。一座城几十到上百人。
- 一名精英战士能正面击溃十名普通士兵；能跃上屋顶、单独讨伐精英魔物、清理一处澱巢；精英法师的场域法术能覆盖一座院落。
- 勇者团第二幕抵达瓦伦堡时在 Lv25 左右（召唤后只过了几个月，见第 10 节）。

**英雄阶（35 到 49）：国之柱石**

- 一国几十人，凡人眼中的传奇。
- 能单人清理一座小型迷宫，或与亚龙级魔物缠斗；法师能冰封一段河道、改变一处战场的地形；牧师能在一场会战后让一整队人重新站起来。
- 玛莎在这一层：兽潮之夜一刀斩断第二波兽潮，然后回去擦杯子。

**传说阶（50 到 59）：大陆级人物**

- 全大陆十几人：剑帝雷欧哈特三世、夜后维丝佩拉、长老艾尔温、渡口的老船夫。
- 一人可当一支千人军；能独力击杀大迷宫之主；老船夫一刀劈开河面。灵素开始改变他们的身体与周围的环境。

**神话阶（60）：铭录的顶**

- 寥寥数人：满级的当代勇者、魔王、守门人、古龙（龙族中在箱庭出生、有页的一支；原龙不在此列）。
- 国家战略级的力量，能改变地貌与天气。铭录已到顶，再强也只显示 60，超出的部分是看不见的"溢出"。

**超越：在铭录之外**

- 原龙（造主放下，不是在箱庭出生，没有页）、女神（司掌者），以及玩家最终抵达的地方。
- 守门人阿什在"超越边缘"：鉴定对他显示"60"或"？"。建议的解释（角色文档可改写）：他的页与空白纪的记录一同被封存了一半，他借封门的门之力维持巫妖之躯。
  他是神话阶的顶端，一只脚已经踏出铭录。

### 3.3 突破：五道关与瓶颈

等级在一阶之内靠吸纳灵素自然上升（讨伐、修炼、生活经历都算）。跨阶则要过"关"：铭录要求满足特定条件，才会把位阶改写到下一阶。
不过关的人，经验会继续积累，但等级卡在关前一级（主工程可用"经验继续累积、等级不升"的方式表达）。

### 3.4 寿命与外观（补充）

- 位阶越高，衰老越慢；外观停留在"巅峰期"的时间越长。精英阶开始明显，英雄阶以后常被误认为比实际年轻。
- **高位阶的衰老规则**（与 3.1 的寿命系数一致；总纲 10.1"传说阶以上衰老显著放缓"）：英雄阶起衰老明显放缓，传说阶以上显著放缓。
  以人族（基准 60 到 80 岁）为例：英雄阶约 90 到 120 岁仍可壮健；传说阶约 120 到 160 岁；神话阶 180 岁以上，或不再自然衰老。
  衰老放缓自位阶写定时起算，此前已经历的衰老不会倒退。由此可解释几位年过百岁仍在场的人物：
  第八代勇者（渡口老船夫，传说阶，约 113 岁，外表约七十）；圣骑士团大团长埃德蒙·拉克洛瓦（英雄阶，第八代勇者的随从骑士）
  与北境军团长布丽吉特·哈尔森（英雄阶，第八代魔王战争时的少年兵），两人都年过百岁仍在任。
- 传说阶的**灵素染色**：发色与瞳色带上主相的颜色（光相偏金白，霜相偏银蓝，焰相偏赤，幽相偏紫黑，生相偏青绿）。这是外部判断强弱的线索之一，也能被染发与面纱掩盖。
- 神话阶的**异相**：情绪激动或全力出手时，周身会出现与主相相应的环境变化（结霜、草木疯长、光晕）。
- 魔族各支的寿命基准不同，系数同样适用；龙族与超越者不以寿命计。

### 3.5 威压：位阶差带来的压迫

灵素在高位阶者身上更浓，会向外"压"。这股外泄的力称为灵压，被压的一方感到的就是威压。

| 位阶差     | 低位者的感受                                     | 玩法落点（建议）                             |
| ---------- | ------------------------------------------------ | -------------------------------------------- |
| 同阶       | 平视，无感                                       | 无                                           |
| 一阶       | 压迫、心跳加快、出手前犹豫                       | 轻微的士气类减益                             |
| 两阶       | 身体僵硬，难以主动出手；家畜与小兽逃散；凡人跪倒 | 明显的控制或行动迟缓                         |
| 三阶及以上 | 失神、昏厥；极端时弱小生灵死亡                   | 接近失能（第一幕玩家初见守门人时"动弹不得"） |

- **收敛**：高位阶者可以主动收起灵压。完全收敛时，旁人感到的是"什么都没有"。玛莎平日就是这样。
- **释放**：主动把灵压压向某人，是恐吓、立威、阻止冲突的手段。
- **抵抗**：精神（意志）、加护、信仰、同伴在侧都能减轻威压。
- 威压是灵素本身的效应，**对无页之身同样有效**，玩家既会被压，也能压人。

### 3.6 感知与误判：如何从外部判断一个人的强弱

**灵觉**（感知他人灵压的能力）随位阶增长。灵觉读的是两样东西：

1. 外泄的灵压（物理的，谁都有）；
2. 页的"回响"：有页者的页会经门侧发出微弱的回响，熟练者能从中读出大致的位阶。【真相】这是门侧的副作用，连诸神都没太在意。

**感知饱和**：一个人的灵觉只能分辨到自身位阶加一阶左右。更高的存在，在他的感觉里要么"深不可测"，要么"一片平静"，
他分不清对方比自己高两阶还是高五阶。蚂蚁看不出山有多高。

**可用的外部线索：** 灵压；公会卡与称号；装备的品质与磨损；站姿、步法与握兵器的方式；动物的反应（马匹不安、犬只伏地）；
灵素染色与异相；身边人的态度；传闻。

**为什么会判断错：**

| 误判来源       | 说明                                                                                                             |
| -------------- | ---------------------------------------------------------------------------------------------------------------- |
| 收敛           | 高手收起了灵压，看起来就是个普通人（玛莎）                                                                       |
| 感知饱和       | 对方太强，强到感觉不出来，反而误以为"没什么"                                                                     |
| 无页之身       | 玩家没有页的回响，不打架时在灵觉里像个普通人，甚至像个空壳；只有战斗时外泄的灵压会暴露他                         |
| 职能差异       | 施法者的灵压平时稀薄，蓄力时才陡增；暗行者受过隐藏气息的训练                                                     |
| 伪装           | 遮页符、伪纹、伪录之门，见 2.7                                                                                   |
| 名不副实       | 公会定级滞后（"前 A 级"的人可能早已更强或更弱）；称号可以是旧的                                                  |
| 装备误导       | 弱小的贵族穿着精品甲胄；真正的高手可能拿着一把旧刀                                                               |
| 种族与年龄错觉 | 精灵与魔族看起来年轻；半身人看起来无害                                                                           |
| 常识偏差       | 凡人的常识建立在凡阶之上，遇到异常会自动找理由（"运气""前人打残了""肯定有什么机关"），这就是"凡人不信"的喜剧引擎 |

**给玩法的落点：**

- NPC 对他人强弱的判断 = 自身灵觉上限 + 可见线索 + 常识偏差。由内核计算判断结果，大模型只负责把判断说出来。
- 玩家对他人强弱的判断：未开观澜之门时只有"比我强、差不多、比我弱、看不透"四档；开门后显示"等级区间加可信度"，
  可信度受收敛、伪装与感知饱和影响。"看不透"永远存在，这是谨慎玩法的根。

## 4. 职能

### 4.1 职能是什么

职能 = 铭录给一个人的灵素规定的"走法"。所有职能的力量都是**自身灵素 + 媒介**：

| 媒介           | 职能                                                                                         | 说明                                                               |
| -------------- | -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 无（凡人之道） | 战士、猎人、盗贼                                                                             | 全靠自身灵素、身体与技巧                                           |
| 加护           | 圣骑士（艾琉恩的圣誓）、牧师（所奉之神的神恩）、萨满（希尔薇的灵语）、德鲁伊（希尔薇的形许） | 加护是"钥匙与放大器"，让灵素更容易转成光相、生相等                 |
| 术式           | 法师                                                                                         | 学院术式借用铭录录侧的结构，把灵素固定成精确的形状（本文称"借录"） |
| 澱与契约       | 术士                                                                                         | 能把少量澱"解"成可用的力，并以契约驱使澱中凝出之物                 |

【真相】加护从来不是力量的源头，只是门。一个足够纯熟的人，没有加护也能把灵素推向光相或生相，只是起初弱得多，
且无人传授这种"自悟"之法。玩家经门获得光相与祷术，就是证明（这也是圣教最怕的事）。在"离手"的世界里，
不向任何神献名的牧师依然能治愈，只是要从头摸索。

### 4.2 资源与属性的世界观解释

| 主工程                                                     | 世界观名 | 解释                                                                                                                           |
| ---------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 怒气（`ResourceType` 的 `rage`）                           | 战意     | 体相灵素被疼痛与击打点燃，在血里奔流；不能储存，离开战斗便消散。战士与熊形德鲁伊使用                                           |
| 法力（`mana`）                                             | 灵力     | 储存在"灵海"里的灵素。靠吐纳回充，精神越高越快；施法后灵海要片刻平复才恢复自然回充（主工程的五秒回蓝规则）；坐下饮水能加快回充 |
| 能量（`energy`）                                           | 气息     | 身体节律里快速循环的灵素，回复恒定，用尽只需喘口气。盗贼与狼形德鲁伊使用                                                       |
| 连击点（`comboPoints`）                                    | 破绽     | 连续进攻在对手防守里撕开的"势"。记在出手者自己的节奏里而不是目标身上（主工程的连击点随角色而非目标），所以换目标时还在         |
| 德鲁伊形态切换资源（`src/sim/entity.ts` 中的形态资源切换） | 借形换脉 | 借形时连灵脉一起借：人形用灵力，熊形用战意，狼形用气息                                                                         |
| 生命分流（`life_tap`）                                     | 代价术   | 术士以生命换灵力                                                                                                               |

| 主工程属性（`CoreStats`） | 世界观解释                     |
| ------------------------- | ------------------------------ |
| 力量 `str`                | 体相承载：肌肉里能锁住多少灵素 |
| 敏捷 `agi`                | 反应与准度：灵素在神经里的流速 |
| 耐力 `sta`                | 肉身能留住多少灵素，即生命     |
| 智力 `int`                | 灵海的大小                     |
| 精神 `spi`                | 吸纳灵素的速度                 |
| 护甲 `armor`              | 器物里的体相灵纹与材料本身     |

| 术士   | 契约者   | `warlock`                   | 灵力           | 澱与契约   | 夜境传统       | 人族之地的异端；夜境的座上宾                           |

流派命名约定：凡人之道的专精称"流"（武术传承），神职与学院的专精称"派"或"学派"。

### 4.4 九职能分述

技能族列出主工程 `ABILITIES` 中的代表性技能 id（`src/sim/content/classes.ts`、`src/sim/content/talent_abilities_v2*.ts`），
技能本身的世界观译名由本地化决定，这里只定"族"名。流派对应 `src/sim/content/talents_warrior.ts` 与
`src/sim/content/talents_classic.ts` 中的 `SpecDef`（`signature` 即流派奥义，`mastery` 即流派真意，见第 5 节）。

#### 战士（`warrior`）

- **力量来源**：自身体相灵素，没有媒介。"凡人之道，不依赖神。"
- **资源**：战意。
- **流派**

| 流派   | 主工程专精            | 定位 | 奥义（`signature`） |
| ------ | --------------------- | ---- | ------------------- |
| 斩伐流 | `arms`（Battlecraft） | 输出 | `mortal_strike`     |
| 血涌流 | `fury`（Bloodrush）   | 输出 | `bloodthirst`       |
| 铁卫流 | `prot`（Ironguard）   | 坦克 | `shield_slam`       |

- **技能族**：战技（`heroic_strike`、`overpower`、`execute`、`slam`、`whirlwind`、`cleave`）；号令（`battle_shout`、`demoralizing_shout`、
  `intimidating_shout`、`rallying_cry`）；架势（`battle_stance`、`berserker_stance`、`defensive_stance`）；突进（`charge`、`heroic_leap`）；
  挑衅与破甲（`taunt`、`sunder_armor`）。
- **与女神**：不依赖任何一司。瓦尔妲的眼睛包括"战前祈祷的战士"，她的狂战加护可以叠在战士身上；圣教军中的战士多受艾琉恩的微佑。
- **社会地位**：士兵、卫兵、冒险者、佣兵、骑士扈从。平民出身最多。
- **典型人物**：剑帝雷欧哈特三世（传说阶，凡人之道的顶点）；马库斯·罗查（套装职能之一）；玛莎、萨莎、罗恩（建议）。

#### 圣骑士（`paladin`）

- **力量来源**：自身灵素 + 艾琉恩的"圣誓"（恩宠级职能加护），以光相驱动武技与治愈。圣骑士的职能在"受誓"时写入铭录。
- **资源**：灵力。
- **流派**

| 流派   | 主工程专精                | 定位 | 奥义              |
| ------ | ------------------------- | ---- | ----------------- |
| 圣礼派 | `holy`（Sacrament）       | 治疗 | `holy_shock`      |
| 守誓派 | `protection`（Vigil）     | 坦克 | `holy_shield`     |
| 裁决派 | `retribution`（Requital） | 输出 | `crusader_strike` |

- **技能族**：誓印与裁定（`seal_of_righteousness`、`judgement`）；光愈（`holy_light`、`flash_of_light`、`lay_on_hands`）；
  光环（`devotion_aura`、`retribution_aura`）；誓约（`blessing_of_might`）；圣护（`divine_protection`、`sacred_bulwark`）；
  制裁（`hammer_of_justice`、`rebuke`、`exorcism`、`consecration`）；挑衅（`holy_taunt`、`righteous_fury`）。
- **与女神**：唯一由单一女神"认证"的职能。信仰崩塌时职能栏不会消失，但光相技能会随圣誓衰减而"失声"（见 6.7）。
  【真相】光相不归艾琉恩所有，不受誓也能修光，只是无人教；玩家的誓光之门就是这样一条路。
- **社会地位**：圣教骑士团认证，贵族子弟与虔诚平民子弟居多。
- **典型人物**：陆辰（套装主职能）；白石结衣、马库斯·罗查（套装副职能）；异端审判官赛琳（建议）。

#### 猎人·游侠（`hunter`）

- **力量来源**：自身灵素 + 兽伴 + 射术灌注（把灵力灌进箭矢，多为玄相与生相）。
- **资源**：灵力（主工程中猎人使用法力）。
- **兽伴**：驯服时，猎人与兽的页上会各写一道"伴契"注记，兽因此能理解猎人的意图、随猎人成长。
- **流派**

| 流派   | 主工程专精                  | 定位 | 奥义            |
| ------ | --------------------------- | ---- | --------------- |
| 兽群流 | `beast_mastery`（Packlord） | 输出 | `bestial_wrath` |
| 冷眼流 | `marksmanship`（Coldsight） | 输出 | `trueshot_aura` |
| 野战流 | `survival`（Fieldcraft）    | 输出 | `wyvern_sting`  |

- **技能族**：兽相（`aspect_of_the_hawk`、`aspect_of_the_monkey`、`aspect_of_the_cheetah`）；射术（`arcane_shot`、`aimed_shot`、`rapid_fire`、
  `volley`、`concussive_shot`、`counter_shot`）；钉刺（`serpent_sting`）；近身（`raptor_strike`、`mongoose_bite`、`wing_clip`）；
  兽伴（`tame_beast`、`dismiss_pet`、`revive_pet`）。
- **与女神**：不依赖神。但希尔薇的眼睛包括动物，**猎人的兽伴会无意中成为希尔薇的眼**。
- **社会地位**：乡野、边民、兽人部族；兽人中的"猎王"是极高的荣誉。
- **典型人物**：希雅（潜质"猎王"）。

#### 盗贼·暗行者（`rogue`）

- **力量来源**：自身灵素 + 气息 + 技巧；毒来自炼金。
- **资源**：气息与破绽。
- **流派**

| 流派   | 主工程专精                   | 定位 | 奥义           |
| ------ | ---------------------------- | ---- | -------------- |
| 刃术流 | `assassination`（Knifework） | 输出 | `cold_blood`   |
| 搏命流 | `combat`（Thuggery）         | 输出 | `blade_flurry` |
| 诡道流 | `subtlety`（Skulduggery）    | 输出 | `hemorrhage`   |

- **技能族**：匿行（`stealth`、`vanish`、`sprint`、`evasion`）；起手（`garrote`、`cheap_shot`、`ambush`、`sap`）；连击（`sinister_strike`、`backstab`、
  `gouge`）；终结（`eviscerate`、`slice_and_dice`、`kidney_shot`、`rupture`、`expose_armor`）；毒艺（`crippling_poison`、`instant_poison`、
  `deadly_poison`）；制敌（`blind`、`kick`）；爆发（`adrenaline_rush`）。
- 注意：匿行是身体与气息的隐藏，躲的是眼睛与灵觉，**骗不了鉴定**。诡道流的高手常兼用遮页符。
- **与女神**：不依赖神。盗贼公会"灰鼠"名义上不拜任何神，实际与梅尔卡托商会有往来。
- **社会地位**：情报、刺探、护卫、开锁、走私。被需要，不被尊重。
- **典型人物**：灰鼠成员（正典暂无具名人物，角色文档可指定）。

#### 牧师·神官（`priest`）

- **力量来源**：自身灵素 + 所奉之神的"神恩"（恩宠级）。各神殿都有牧师：圣教最多（光相为主），也有梅尔卡神殿、瓦尔妲战祠、
  莫伊拉的史官与录堂、希尔薇的林祠（少）。
- **资源**：灵力。
- **流派**

| 流派   | 主工程专精               | 定位 | 奥义             |
| ------ | ------------------------ | ---- | ---------------- |
| 戒律派 | `discipline`（Doctrine） | 治疗 | `power_infusion` |
| 恩典派 | `holy`（Benison）        | 治疗 | `holy_nova`      |
| 晚祷派 | `shadow`（Vespers）      | 输出 | `shadowform`     |

- **技能族**：祷文（`lesser_heal`、`heal`、`flash_heal`、`renew`）；圣咏（`power_word_shield`、`power_word_fortitude`）；惩戒（`smite`）；
  挽歌与心术（`shadow_word_pain`、`mind_blast`、`mind_flay`）。
- **晚祷派**：以幽相（哀悼、怀疑、衰败）为力。【表层】圣教称之为"忏悔之术"，只许异端审判庭使用；在莫伊拉的录堂与瓦尔妲的战祠里很常见。
- **与女神**：神恩决定牧师的强弱与相。信仰危机（卡西安神父的弧线）会直接表现为治愈变弱。
- **社会地位**：人族城镇的礼拜堂神父、各国主教、随军神官。
- **典型人物**：卡西安神父；白石结衣（套装主职能）；艾登·霍尔（套装副职能）。

#### 萨满·灵语者（`shaman`）

- **力量来源**：自身灵素 + 希尔薇的"灵语"（恩宠级），能与元素灵、祖灵交谈并借力。
  - 元素灵：地脉中灵素自发形成的涡旋，有微弱的意志。
  - 祖灵：亡者在灵泉轮回之前，于"泉畔"停留时留下的回声。回声会渐渐淡去，所以祖灵只认得近几代的子孙。
- **资源**：灵力。
- **流派**

| 流派   | 主工程专精                  | 定位 | 奥义                |
| ------ | --------------------------- | ---- | ------------------- |
| 唤雷流 | `elemental`（Thundercall）  | 输出 | `elemental_mastery` |
| 战魂流 | `enhancement`（Warspirit）  | 输出 | `stormstrike`       |
| 愈灵流 | `restoration`（Spiritmend） | 治疗 | `chain_heal`        |

- **技能族**：震击（`earth_shock`、`flame_shock`、`frost_shock`）；唤雷（`lightning_bolt`、`earthquake`）；附灵武器（`rockbiter_weapon`、
  `flametongue_weapon`、`frostbrand_weapon`）；灵护（`lightning_shield`）；愈水（`healing_wave`、`chain_heal`）；灵狼（`ghost_wolf`）。
- **与女神**：希尔薇一系。风牙草原的分裂在职能上也有投影：改信瓦尔妲的部族偏爱战魂流并叠加狂战加护，希尔薇派偏爱愈灵流与唤雷流（第四幕兽王之争）。
- **社会地位**：兽人部族的精神支柱，精灵中较少；人族视为蛮巫，圣教常加怀疑。
- **典型人物**：风牙兽王会盟的灵语者（正典暂无具名人物）。

#### 法师·魔导师（`mage`）

- **力量来源**：自身灵海 + 学院术式。术式借用铭录录侧的结构把灵素固定成精确的形状（借录），所以法师体系"建立在莫伊拉的铭录学之上"。不需要加护。
- **资源**：灵力。
- **流派**

| 流派     | 主工程专精              | 定位 | 奥义            |
| -------- | ----------------------- | ---- | --------------- |
| 时序学派 | `arcane`（Chronomancy） | 治疗 | `temporal_mend` |
| 焰术学派 | `fire`（Pyromancy）     | 输出 | `pyroblast`     |
| 霜术学派 | `frost`（Cryomancy）    | 输出 | `ice_lance`     |

- 注：主工程中法师的玄相专精是治疗定位的时序术（以源码为准；`docs/design/current-game-design.zh_CN.md` 中"Arcane 输出"的表述已过时）。
- **时序学派**：读取铭录对一具身体"刚才"的记录，按记录把灵素状态拨回去（回溯伤害、复苏刚倒下的同伴）。
  它不是篡改：恢复本身被铭录记成一件新发生的事。【真相】莫伊拉最喜欢这一派；圣教暗中忌惮，因为它离"改写记录"只差一步。
- **技能族**：术弹（`fireball`、`frostbolt`、`arcane_missiles`、`fire_blast`、`scorch`、`pyroblast`、`ice_lance`）；场域（`blizzard`、`flamestrike`、
  `arcane_explosion`、`frost_nova`、`frozen_orb`）；结界（`frost_armor`、`ice_barrier`、`ice_block`、`blazing_barrier`）；缚造（`conjure_water`、
  `conjure_food`）；制约（`polymorph`、`counterspell`）；迁跃（`blink`）；时序术（`temporal_mend` 及 `temporal_*` 一族）；
  召霜灵（`summon_water_elemental`）；灵智（`arcane_intellect`）。
- **与女神**：莫伊拉一系（魔导学院联盟背后是莫伊拉）。
- **社会地位**：学院出身；宫廷法师、学者、史官。
- **典型人物**：艾登·霍尔（套装主职能）；"大贤者"（总纲 10.1 的传说阶例子，正典未具名）。

#### 术士·契约者（`warlock`）

- **力量来源**：自身灵素 + 澱 + 契约魔。
  - 【真相】术士是诸职能中**唯一能直接利用澱**的：他们能把少量澱"解"成可用的力。代价是解不干净的部分留在体内，成为澱染。
  - **契约魔**：从澱中凝出、带有残缺意志的存在，以契约束缚驱使。主工程中术士的恶魔（`summon_imp`、`summon_voidwalker`、
    `summon_succubus`、`summon_felhunter`、`summon_felguard`、`summon_infernal`、`summon_doomguard`，数据见 `src/sim/content/warlock_pets.ts`）都属此类。
    **契约魔不是魔族**：魔族是瓦尔妲创造的种族，契约魔是澱的产物。圣教刻意把两者混为一谈。
- **资源**：灵力，另有代价术。
- **流派**

| 流派   | 主工程专精                 | 定位 | 奥义            |
| ------ | -------------------------- | ---- | --------------- |
| 咒蚀派 | `affliction`（Hexcraft）   | 输出 | `siphon_life`   |
| 缔约派 | `demonology`（Pactbound）  | 输出 | `metamorphosis` |
| 灾焰派 | `destruction`（Ruination） | 输出 | `conflagrate`   |

- **技能族**：咒（`curse_of_agony`）；蚀（`corruption`、`immolate`）；吸取（`drain_life`）；暗弹（`shadow_bolt`、`searing_pain`、`shadowburn`、`rain_of_fire`）；
  惧（`fear`）；契约召唤（`summon_*`）；代价术（`life_tap`）；魔甲（`demon_skin`）；封咒（`spell_lock`）。
- **风险**：澱染累积导致澱病；高阶术士在"明执"关失败时极易魔物化，是魔王容器的高危人群。
- **与女神**：契约的形式源自夜境，瓦尔妲对术士宽容。【表层】圣教定其为异端，理由是"与魔物同源"。
  【真相】更深的理由是：术士证明了澱可以被利用、被消解，这动摇了"魔物是邪神之秽"的教义。
- **社会地位**：人族之地的异端，地下活动；夜境的座上宾；门徒会中很多。
- **典型人物**：夜后维丝佩拉（建议）；门徒会的契约者。

#### 德鲁伊·森之祭司（`druid`）

- **流派**

## 5. 技能与天赋

### 5.1 凡人如何学技能

铭录写入一项技能需要两个条件：**容量**（等级够，灵素撑得住）与**领悟**（知道灵素该怎么走）。领悟有四条路：

| 途径     | 说明                                                                     | 典型                         |
| -------- | ------------------------------------------------------------------------ | ---------------------------- |
| 师承     | 师父带着练，把走法"示范"进徒弟的灵脉                                     | 骑士团、学院、师门、部族     |
| 书卷     | 读懂记载走法的书卷（技能书、术式书）                                     | 学院、神殿藏书、遗迹里的古卷 |
| 实战     | 在生死关头自己摸出来                                                     | 冒险者、老兵                 |
| 铭录觉醒 | 容量到了，长年的日常练习让领悟水到渠成，铭录直接写入；或莫伊拉亲手"觉醒" | 绝大多数基础技能             |

- 主工程的 `abilitiesKnownAt`（`src/sim/content/classes.ts`）按等级自动给出已会的技能，对应的是"铭录觉醒"这条默认路。
  本作的 NPC 沿用它；需要剧情或稀有条件才能学的技能，另设"师承、书卷、实战"门槛（本作新增）。
- 莫伊拉的"觉醒"（`pantheon.md` 中她的 GM 工具）可以跳过领悟，直接写入一项技能，常用于制造"命运的转折"。

### 5.2 技阶

- 同一项技能会随容量增长被铭录"重录"得更深，称技阶（技能名后缀 I、II、III……）。
- 对应主工程 `AbilityDef` 的 `ranks`（`AbilityRank`：`rank`、`level`、`cost`、`effects`）：`abilitiesKnownAt` 取等级以内最高的一阶，正是"重录"。

### 5.3 流派、真意、奥义

| 世界观   | 主工程                                                                            | 说明                                       |
| -------- | --------------------------------------------------------------------------------- | ------------------------------------------ |
| 定流     | `SPEC_UNLOCK_LEVEL`（`src/sim/content/talents.ts`），选择 `TalentAllocation.spec` | 第一关；在三个流派中选一个                 |
| 流派     | `SpecDef`                                                                         | 职能内的传承分支                           |
| 流派真意 | `SpecDef.mastery`                                                                 | 选定流派后，灵脉被进一步定形带来的常驻特质 |
| 流派奥义 | `SpecDef.signature`                                                               | 流派的标志技能，定流时随即写入             |

### 5.4 铭纹：天赋的世界观解释

- 灵脉在关键的成长节点会"分岔"。分岔时门侧从潜质里给出三条可能，人选其一，铭录把这一选择刻成一道"铭纹"。
  这就是主工程 Talents 2.0 的"每行三选一"（`ROW_LEVELS`、`OPTIONS_PER_ROW`、`TalentRow`，见 `src/sim/content/talent_rows.ts`）。
- 【真相】给出"三条可能"的是门侧，也就是雅努的那一半。铭纹之所以总是三选一而不是唯一的路，是雅努留下的"可能"仍在运转。
- 六道铭纹的世界观名，与主工程每行的职责（`docs/design/class-design-rules.md` 的 Talent rules 表）一一对应：

| 铭纹 | 主工程行职责              | 世界观解释               |
| ---- | ------------------------- | ------------------------ |
| 行纹 | Mobility                  | 灵素在双腿与步法中的走向 |
| 守纹 | Survival                  | 危急时灵素如何护住要害   |
| 制纹 | Control                   | 灵素如何牵制他人         |
| 脉纹 | Resource behavior         | 战意、灵力、气息的节律   |
| 锋纹 | Major offensive choice    | 一生中最锋利的那一招     |
| 极纹 | Specialization or utility | 流派走到尽头时的取舍     |

- **重纹**：花费时间与金钱，在学院或神殿重刻铭纹（门侧的"可能"仍在，所以可以改选）。对应主工程的 `respecTalents`（`src/sim/progression/talents.ts`）。
- **纹谱**：记下的几套铭纹方案，对应主工程的 `SavedLoadout` 与 `MAX_LOADOUTS`。

### 5.5 与主工程天赋结构的映射建议

主工程 `MAX_LEVEL` 为 20，本作铭录上限为 60，需要重新参数化：

| 主工程符号                               | 当前值                                                 | 本作建议                                 | 理由                                                                 |
| ---------------------------------------- | ------------------------------------------------------ | ---------------------------------------- | -------------------------------------------------------------------- |
| `MAX_LEVEL`（`src/sim/types.ts`）        | 20                                                     | 60                                       | 铭录上限                                                             |
| `SPEC_UNLOCK_LEVEL`（= `ROW_LEVELS[0]`） | 5                                                      | 10                                       | 与第一关"定流"对齐                                                   |
| `ROW_LEVELS`                             | 5、8、11、14、17、20                                   | 10、20、27、35、42、50                   | 行纹、守纹、脉纹等分别落在位阶关上或两关之间，保持主工程的行职责顺序 |
| 第七道铭纹                               | 无                                                     | 60：神话纹（本作新增，可选）             | 只有神话阶 NPC 用得上；须遵守"不得与锋纹叠加第二个大爆发"的规则      |
| 技阶表                                   | 1 到 20 级的经典等级表（`docs/design/spell-ranks.md`） | 拉伸到 60                                | 由设计文档按经典曲线重排，不凭空发明                                 |
| `virtualLevel`、终身经验                 | 满级后继续累积的虚拟等级                               | 60 之后的"溢出"：鉴定只显示 60，内核照算 | 正合"超过上限的存在，鉴定只显示 60"                                  |

- 加护、魔道具的效果建议复用主工程 `TalentEffect` 的形状（`stats`、`ability`、`global`、`proc`），在授予、衰减、装备时预计算成扁平修正值，
  不在每个 tick 遍历（与主工程天赋的预计算约束一致）。

### 5.6 无页之身的技能

- 玩家没有职能栏，也没有铭纹。他的技能全部来自门：职能之门给出一个职能的基础技能族，流派之门给出流派、真意与奥义，
  技艺之门给出单项技能与跨职能的合技（第 9 节）。
- 跨职能的实际限制不是铭录，而是**资源**与**门的互斥**：战意、灵力、气息是三种不同的灵素节律，同时驱动它们需要特定的门
  （具体换算由设计文档决定）。玩家的技能没有登记在任何页上，所以任何鉴定都读不到（2.5 第 6 条）。

## 6. 加护

### 6.1 本质

- 加护是女神经铭录写在信徒加护栏上的"标签"（总纲 5.5）。它让受者的灵素更容易走某条路，或给受者额外的庇护。
- **常耗**：每一份加护都持续从女神的神力里抽取一点。授出去的加护越多、越高，女神的常年支出越大。
- **视线锚**：加护越高，女神越能"透过"受者看世界。眷顾级以上的受者就是总纲所说的"神谕对象"。**站在高阶加护者身边，就是站在女神眼前。**
- 加护强度 = 授予等级 × 信仰系数，信仰系数随受者的虔诚度变化，且有滞后（6.7）。

### 6.2 种类

| 种类     | 作用                             | 例                           |
| -------- | -------------------------------- | ---------------------------- |
| 职能加护 | 开启或放大某个职能的技能族       | 圣誓、神恩、灵语、形许       |
| 恩赐加护 | 属性、抗性、运气、成长速度       | 丰饶、生息、淬炼             |
| 守护加护 | 危急时的庇护                     | 不屈、不落之盾               |
| 契约加护 | 以神力担保契约，违约者受罚       | 梅尔卡的契约加护             |
| 称号加护 | 写在称号栏而非加护栏，莫伊拉专用 | 部分传颂级称号附带的效果     |
| 套装加护 | 多层组合，开页时写入             | 勇者加护套装、他司客人的套装 |

### 6.3 强度五级

| 级  | 名称 | 授予对象                                     | 效果量级             | 常耗   | 视线             |
| --- | ---- | -------------------------------------------- | -------------------- | ------ | ---------------- |

| II  | 庇佑 | 虔诚信徒、低级神职                           | 小而可感             | 低     | 祈祷时           |
| III | 恩宠 | 圣骑士、牧师、萨满、德鲁伊等神职与职能持有者 | 开启技能族           | 中     | 祈祷与目睹时     |

| V   | 神选 | 勇者、他司客人                               | 套装级，改变人生轨迹 | 极高   | 持续             |

| 层             | 陆辰（勇者）                                                                   | 白石结衣（圣女）                     | 艾登·霍尔（贤者）                                                           | 马库斯·罗查（盾卫）                                    |

| 职责层         | 圣剑适格：能持勇者圣剑，对魔物与澱生之物特攻                                   | 大祷：群体治愈与复苏；净秽：驱除澱病 | 贤者之眼：精密鉴定级读深加录问（2.6）；三学派同修：法师三个流派可以同时修习 | 不落之盾：致命伤时的一次庇护；代受：替身旁同伴承受伤害 |

隐藏层的含义（【真相】）：

- **视线之契**：艾琉恩可以持续借勇者的眼睛看世界，不随信仰衰减。即使勇者离开圣教，他仍是艾琉恩的眼睛。
  玩家与勇者同行，就是被艾琉恩看着。（能否切断视线之契，留给剧情与门的设计。）
- **用尽条款**：魔王倒下后，套装逐层收回，最后只剩共通层的残余。勇者自身练出来的等级不会被收回，所以老船夫仍是传说阶，
  却是"被用完的那个"。
- **终斩之契**（只在勇者本人身上）：勇者对魔王的最后一击，会把魔王容器里的澱一口气烧尽，化作漫天光雨。目睹者的敬畏化为信仰，
  流向艾琉恩（勇者之功）与瓦尔妲（魔王之强）。这就是排澱机制的扳机。若持契者在终斩之前信仰崩塌，契约会逆流（见 7.8）。
- 净秽【真相】：圣女驱除澱病，是把病人体内的澱推开，而不是解开。澱被推到别处，最终沉向荒野与迷宫。

八轮魔王循环的历代勇者都是经召唤大阵召来的客人（总纲 5.7，决策 D-019；各代简表见 `history.md` 第 9 节），
套装都在开页时写入，所以勇者的第二个职能栏从不需要莫伊拉以"篡改并告知四司"的方式加上。

### 6.7 失去信仰时的衰减

| 信仰状态 | 加护变化                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------- |
| 坚信     | 满额                                                                                                     |
| 动摇     | 先有一段"余温"，余温内不变；余温过后开始下降。余温长短与加护等级正相关（以季为单位，数值由设计文档决定） |
| 背离     | 持续下降；恩宠级的职能技能开始"失声"（时灵时不灵，治愈量与光相伤害下降）                                 |

  结衣在第三幕的动摇，可以直接表现为圣女之力的余温与下降。

### 6.8 无页之身与加护：附物加护

- 玩家没有页，也就没有加护栏，任何女神都无法把加护写给他。
- 但神力可以寄托在**物**上。女神把加护附在一件物品上，持物者在持有期间获得效果，离身即失效，这称为"附物加护"（总纲 5.5）。
  - 序章梅尔卡塞给玩家的"梅尔卡的硬币"就是附物加护的锚（`pantheon.md`：在任何市场或她的神龛联系她）。第一幕到第二幕"供品换加护"正是经由硬币生效。
  - 附物加护比写在页上的加护弱。**物是联系渠道，不是持续的视线锚**（决策 D-028）：只有当持物者使用它（向她祈祷、经它交易、念诵她的尊名）时，
    女神才感知到物在何处、此刻发生了什么；平时她不追踪它，也始终看不见持物者的页（因为没有）。这保住了前两幕"女神看不见玩家"的体验。
  - 物可以被偷、被弃、被转交。

## 7. 澱与魔物

### 7.1 澱的本质

- 【表层】圣教："魔物是邪神之秽，是瓦尔妲与魔族的诅咒。"平民把澱叫作"灰气"，澱病叫"灰病"（边石镇一带叫"荒原病"），澱晶叫"灰晶"，魔物按样子叫"灰狼""灰鬼"等；"澱""澱晶"是冒险者与学者的行话（总纲 5.3，决策 D-030）。
- 【真相】澱是**被强行扭成某种形状、再也松不开的灵素**，像一团打了死结的线。诸神用神力推动灵素做违背其流向的事（逆势），
  灵素被扭结，留在当地，就是澱。所有女神的干预都会产生澱，越逆势越多，艾琉恩的大型神迹产生得最多（总纲 5.3）。
- 澱不流动，会沉积、汇聚、凝形。它不是幽相，与生灵的善恶无关。
- 澱是可以解开的：灵泉、世界树、某些门、术士（少量且有代价）都能把澱解回灵素。但慢，且远远赶不上诸神制造它的速度。

### 7.2 浓度分级

| 级  | 名称 | 环境特征                         | 自然生成的魔物等级（参考）         | 对凡人的影响     | 典型地点                                                                |
| --- | ---- | -------------------------------- | ---------------------------------- | ---------------- | ----------------------------------------------------------------------- |
| 0   | 清域 | 灵素清澈流动                     | 无                                 | 无               | 世界树与灵泉周边                                                        |
| 1   | 薄澱 | 与常地无异                       | 偶有异兽，Lv1 到 9                 | 无               | 大多数乡野、城市下水道                                                  |
| 2   | 积澱 | 植物发育异常，夜里有磷光         | Lv5 到 19；澱巢                    | 久居者有澱斑风险 | 魔物多发的林地、旧矿                                                    |
| 3   | 浓澱 | 空气发沉，金属易锈               | Lv15 到 34；迷宫开始形成；精英魔物 | 数月即可染上澱病 | 迷宫周边、古战场、封门遗迹深处                                          |
| 4   | 深澱 | 天色发灰，草木枯黑               | Lv30 到 49；大迷宫；亚龙级魔物     | 数周即病         | 千门都外环、王胎渊外围（荒原外缘只是积澱，见 `geography.md` 第 0.3 节） |
| 5   | 渊澱 | 寸草不生，亡灵游荡，神之视线失效 | Lv45 到 60；魔王可在此诞生         | 凡阶数日即倒     | 灰烬荒原核心（古澱）                                                    |

- **临界**：六级之外的一个阈值，不是一处地点的浓度，而是渊澱在一个有灵智的容器里凝聚到的程度。越过临界，魔王诞生（7.8）。
  这张"六级加临界"的标尺是全作的统一标尺（决策 D-039），地理、种族等文档的澱度均以此为准。
- 浓澱以上的区域，神殿的覆盖与信徒的见闻都会变得模糊，成为神的盲区（8.6）。
- 【真相】圣教的净化仪式不消除澱，只把它从城市推开，顺着河流与地脉沉向下游的荒野。城市干净，荒野变脏。

### 7.3 魔物的生成规律

澱在一个"核"周围凝形，就是魔物。核的类别决定魔物的类别：

| 类别     | 核                     | 说明                                                                                                                                                                                     |
| -------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 异兽     | 活着的野兽             | 澱渗入野兽体内，使其异变：体型、攻击性、等级都上升。原页加上异变注记                                                                                                                     |
| 澱生魔物 | 无核或灵素结点         | 澱自身凝形，常带某一相的色彩（元素魔）                                                                                                                                                   |
| 亡灵     | 尸骸或滞留之魂         | 澱进入魂已离去的尸骸，成为无心的空壳；或缠住未能抵达灵泉的魂，成为有残念的亡灵。【真相】大断绝时死者数以百万计，灵泉一时承接不下，许多魂滞留荒原，与古澱结合，这是灰烬荒原亡灵横行的原因 |
| 澱像     | 器物、岩石、建筑残骸   | 第一幕兽潮的首领就是"澱聚成的巨像"                                                                                                                                                       |
| 龙种魔物 | 龙族的遗骸、鳞片、血滴 | 与龙族本身无关，龙族视之为亵渎；原龙蜕下的鳞亦可凝成龙种魔物（千门时代曾作为货物流通）                                                                                                                                                           |
| 契约魔   | 澱中凝出的残缺意志     | 术士以契约驱使；夜境亦有                                                                                                                                                                 |

规律：

- **浓度决定上限，时间决定成色**：魔物的最高等级由当地澱浓度决定；同一浓度下，凝形越久的魔物越强（精英）。
- **死亡回馈**：魔物被杀，大部分澱凝成澱晶留下（7.7），少部分散回当地。不收澱晶、任其腐烂，澱就回到原地。
  所以只讨伐不净化，澱只是被压住，并没有离开（决策 D-039）；要真正减少一地的澱，须净化（7.5"净"）。
- **人形魔物不是种族**：魔物从不繁衍成族。任何"像某个种族"的魔物都是澱模仿生灵的形，不是那个种族的成员。

主工程怪物族群（`MobFamily`，`src/sim/types.ts`）的世界观映射：

| `MobFamily`                              | 本作                             | 注意                                                                                     |
| ---------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------- |
| `beast`、`spider`、`burrower`、`reptile` | 野兽或异兽                       | 未异变的野兽有完整的页，不是魔物                                                         |
| `humanoid`                               | 人形敌人（匪帮、邪教徒、门徒会） | 他们是有页的人，不是魔物；击杀他们涉及灵泉与人间的法                                     |
| `undead`                                 | 亡灵                             |                                                                                          |
| `elemental`                              | 澱生魔物（元素魔）               |                                                                                          |
| `dragonkin`                              | 龙种魔物                         | 不是龙族                                                                                 |
| `demon`                                  | 契约魔                           | 不是魔族                                                                                 |
| `troll`、`ogre`、`mudfin`                | 澱生的人形魔物                   | **不要映射为魔族的鬼人或任何正典种族**，否则玩家会把一个种族当魔物杀，违背"魔物不是种族" |

### 7.5 迷宫：形成、生长与溢出

澱在一处封闭空间（洞穴、废墟、地窖、下水道）持续积累到浓澱，就会"结晶"出迷宫：空间被澱改写，出现原本不存在的通道与房间。

| 阶段   | 特征                                                 | 主工程对应                                                                                                 |
| ------ | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 澱巢   | 一处洞穴或废屋，几只魔物，核很小                     | 野外营地（`CAMPS`）                                                                                        |
| 浅迷宫 | 一到数间房、一层，有巢主                             | 地窟（`src/sim/content/delves/`，单人、带同伴，`src/sim/delves/companion.ts`）                             |
| 迷宫   | 多层，有迷宫核与迷宫之主，结构缓慢变化               | 五人副本（`DUNGEON_DEFS`，`src/sim/content/dungeons.ts`；进出与实例 `src/sim/instances/dungeons.ts`）      |
| 大迷宫 | 深层、多首领，会溢出                                 | 团队首领战（形态参照 `src/sim/encounters/nythraxis.ts`）                                                   |
| 活性期 | 任何阶段的迷宫在短时间内吸入大量澱后变强，掉落也更好 | 英雄难度（`DungeonDifficulty` 的 `heroic`，`src/sim/instances/difficulty.ts`；掉落 `buildHeroicVariants`） |
| 溢出   | 迷宫装不下，魔物成潮涌出                             | 兽潮、魔物潮（本作新增事件系统；瓦尔妲的"魔物潮"GM 工具在澱的上限内催动它）                                |

生长的养料：周围的澱、在迷宫里死去的生灵（冒险者的死也在喂养它）、附近城市燃烧澱晶释放的余澱（7.7）。

处置的三种选择（也是经营层的抉择）：

| 选择 | 结果                                                                                                                       |
| ---- | -------------------------------------------------------------------------------------------------------------------------- |
| 养   | 定期清理、收澱晶，迷宫被"圈养"成矿场。城市获利，澱被集中在一处（小型的排澱）。瓦伦堡城下的旧水道迷宫可作此类的例子（建议） |
| 毁   | 打碎迷宫核，迷宫在数日内塌缩；核里的澱散回周边，整片地区的浓度上升一级，持续一段时间                                       |
| 净   | 用澄流之门、灵泉之水或森之祭司的仪式把澱解开。慢、贵、需要合作，但不留后患                                                 |

### 7.6 澱病

| 阶段 | 症状                         | 说明                               |
| ---- | ---------------------------- | ---------------------------------- |
| 澱斑 | 皮肤上出现灰斑，疲倦         | 离开澱区即可缓慢自愈               |
| 澱热 | 高热、幻觉；施法者的灵素失控 | 需要治疗                           |
| 澱化 | 身体局部结晶；野兽变成异兽   | 凡人致死率高；极少数存活者半人半魔 |

- 易感：孩童、老人、低位阶者。位阶越高越能抵抗。第一幕边石镇的孩子死于封门遗迹渗出的澱。
- 治疗：灵泉之水、德鲁伊与萨满的草药与仪式（欧拉婆婆的工作）、离开澱区；圣女的净秽能快速驱除，但【真相】只是把澱推开（6.5）。
- **澱染**：长期接触澱者（术士、迷宫常客、长期饮用含澱药剂的冒险者）体内的澱累积量。普通水晶能读出有无，精密鉴定能读出程度。
- 主工程中可用减益光环（`Aura`）表达各阶段；"疾病与传染"的系统性规则为本作新增。

### 7.7 澱晶

魔物死去时，体内大部分澱凝成一块结晶，即澱晶（魔物核心）。凡人俗称"灰晶"，"澱晶"是冒险者与学者的行话（决策 D-030）。

| 品级 | 来源             | 相对价值（参考，数值由设计文档决定） |
| ---- | ---------------- | ------------------------------------ |
| 碎晶 | F、E 级魔物      | 约一顿饭钱                           |
| 小晶 | D、C 级魔物      | 约一日工钱                           |
| 中晶 | B 级魔物、巢主   | 约一月工钱                           |
| 大晶 | A 级魔物         | 约一户人家一年的收入                 |
| 王晶 | 迷宫核、S 级魔物 | 约一座小镇一年的税                   |
| 渊晶 | 魔王             | 无价，由国家与教会管控               |

用途（除第 4、6 条外，合法用途都使用净炼后的魔晶，见下方"经济"）：

1. **魔道具的燃料**：灯石、暖石、水泵、传讯石、城防结界（11.3）。
2. **锻造**：熔入金属成为"澱钢"，可承载多道灵纹，精品以上的武器多用到它。
3. **炼金**：药剂与毒的原料。长期大量饮用会累积澱染。
4. **术士的媒介**：术士从中解出力量。
5. **鉴定水晶**：魔晶加学院录纹制成录晶。
6. **研究**：学院与门徒会都在研究它。

经济（决策 D-040）：未净炼的澱晶（灰晶）不得合法流通，只能交给持证工坊（教会、学院、公会）收购。持证工坊把它净炼成"魔晶"，
魔晶才是事实上的硬通货，梅尔卡托商会控制着它的大宗流通。第一幕代官莫斯向城里走私的就是未净炼的澱晶。

【真相】**余澱**：澱晶燃尽时，并不会让澱消失，其中一部分会慢慢散回周围。净炼会减少余澱（这是持证净炼的正当理由），
但不能消除。一座大量使用魔道具的城市，地下会积起薄澱，
最终在下水道里长出迷宫。城市的繁荣在喂养它脚下的魔物。这让"澱晶经济"成为中后期国家经营的一个抉择（用多少、怎么净）。

### 7.8 魔王

**形成条件**（全部满足）：

1. **渊澱**：大范围的澱达到渊澱，或被排澱机制刻意汇聚到一处。
2. **有灵智的容器**：魔物不行，必须是有心智的生灵。
3. **容量**：位阶至少英雄阶，通常传说阶以上。容量不足的容器直接崩溃，变成大号的魔物。
4. **缺口**：容器的灵魂必须向澱"敞开"：绝望、狂执、"明执"关的失败、信仰的崩塌，或灵魂上本来就有一个洞。
5. **催化**（可选）：瓦尔妲的"魔王催化"GM 工具可以加速这一过程。

**诞生之后**：

- 容器的页被澱覆盖，莫伊拉的称号规则自动为它写下"第 N 代魔王"。
- 魔王成为一个**汇点**：周围的澱向它流去，魔物随之暴增（魔物潮）；它吸得越多越强，通常处于神话阶。
- 魔族常聚向新魔王（瓦尔妲的夜境传统），但魔王本身不是魔族的王，也不一定是魔族。

**排澱循环**【真相】：

- 魔王把一个时代的澱聚到一具身体里；勇者以终斩之契一击烧尽它（6.5），大部分澱化为光雨消散，信仰流向艾琉恩与瓦尔妲。
- 但光雨里仍有一部分余澱落回大地；而收割来的信仰又会变成新的神迹与新的澱。循环可以排掉大部分澱，却永远排不干净，
  间隔约 110 到 130 年。这是一台跑步机，不是解药。
- **没有终斩的弑王会引发澱散**：若魔王被不带终斩之契的人杀死，容器里的澱会在死亡处炸散开来，形成大片深澱乃至渊澱。
  所以第五幕"众生的办法"不是单纯杀死魔王，而是必须同时用重建的门网把澱分散、净化（千径之门）。
- **堕勇**：圣历 668 年第六代勇者堕为第六代魔王。机制是：持终斩之契者在终斩之前信仰崩塌，契约逆流，本该烧尽的澱灌入持契者自身；
  一个位阶极高、灵魂敞开、身处澱潮中心的勇者，是最完美的容器。这为第五幕陆辰的抉择提供规则依据。

**第九代魔王的特殊性**：灰烬荒原的古澱是大断绝留下的，体量远超以往任何一代；而无貌者的灵魂上本来就有一个门形的洞
（雅努失败的尝试，见第 10 节）。一个"被澱填满的门"吞下千年古澱，再借偷来的雅努之钥与遗民门纹撕开封印一角，
这就是总纲所说"神话阶以上"的来由。

## 8. 神力

### 8.1 来源

- **信仰份额**：信徒的祈祷与敬畏持续化为神力流入女神。按虔诚度加权：一个虔诚者抵得上许多泛泛的信众。
- **神殿与圣所**：神殿是信仰的汇点，放大流入，也是视线的据点（8.6）。
- **供奉**：一次性的大额流入。梅尔卡最爱；以她之名立下的契约也算一种供奉（6.6）。
- **戏剧性时刻**：众人同时敬畏的瞬间（神迹、勇者斩王）带来尖峰收入。这正是排澱循环对艾琉恩与瓦尔妲的意义。
- 按信仰份额，艾琉恩的收入远高于其他四司；莫伊拉最少，但她的权柄（铭录）不靠神力运转：铭录在开园时被设计为由灵素自行维持，
  莫伊拉读它很便宜，写它才花神力。

### 8.2 支出

- **常耗**：所有已授出的加护；神殿的维持；以及【真相】**雅努的封印**：封印由五司合力而成，维持它是五司常年分担的一笔支出，
  同时也是一种持续的干预，持续在封门周边留下澱。封门遗迹之所以渗出澱，部分原因就在这里。
- **一次性**：神谕、托梦、神迹、天灾、化身、召唤（8.4）。
- 神力不能借给凡人，也不能在女神之间直接转让；她们之间的"交易"交换的是情报、承诺与代理人的行动。

### 8.3 澱率：顺势、转势、逆势

同样的神力，干预的方式不同，留下的澱差别很大。

| 澱率       | 含义                         | 例                                                                             |
| ---------- | ---------------------------- | ------------------------------------------------------------------------------ |
| 顺势（低） | 顺着灵素与人心本来的流向轻推 | 神谕、托梦、莫伊拉的巧合、梅尔卡调动物价（经由人心起作用）                     |
| 转势（中） | 改变流向，但不违背其本性     | 授予加护、调节季节与天气、瓦尔妲在既有澱的上限内催动魔物潮（她主要是聚拢旧澱） |
| 逆势（高） | 强迫灵素做它本不会做的事     | 艾琉恩的圣迹（瞬间治愈、显光）、希尔薇的天灾、化身、召唤                       |

这条规则解释了为何艾琉恩产生的澱最多（她的手段几乎全是逆势），也解释了希尔薇为何"很少用天灾"（`pantheon.md`）。

### 8.4 各类干预的成本量级

以"一次对一名神职说话的神谕"为 1 单位。以下为相对量级，具体数值由女神 GM 设计文档决定。

| 干预                   | 示例                   | 神力（相对）                     | 澱率 | 澱留在哪里                 |
| ---------------------- | ---------------------- | -------------------------------- | ---- | -------------------------- |
| 神谕                   | 对一名神父说话         | 1                                | 顺势 | 几乎不留                   |
| 托梦                   | 希尔薇对德鲁伊         | 1                                | 顺势 | 不留（梦不在箱庭的灵素里） |
| 微小巧合               | 莫伊拉安排一次偶遇     | 1 到 5                           | 顺势 | 极少                       |
| 授予加护（微佑到恩宠） | 骑士受誓               | 0.1 到 5，另计常耗               | 转势 | 分散在受者周围             |
| 授予加护（眷顾）       | 册立圣女、主教         | 约 30，常耗显著                  | 转势 | 同上                       |
| 小神迹                 | 当众治愈一人           | 约 10                            | 逆势 | 当地                       |
| 物价与商路             | 梅尔卡调价、开通商路   | 10 到 100                        | 顺势 | 极少                       |
| 显光                   | 全城可见的神迹         | 约 100                           | 逆势 | 当地，集中                 |
| 季节与天气             | 一地一季多雨           | 100 到 300                       | 转势 | 广而薄                     |
| 魔物潮                 | 瓦尔妲在澱的上限内催动 | 100 到 1000                      | 转势 | 聚拢到潮的路径上           |
| 大神迹                 | 治愈一城疫病           | 约 1000                          | 逆势 | 高度集中                   |
| 天灾                   | 一地一季大旱           | 1000 到 3000                     | 逆势 | 广而厚                     |
| 化身                   | 传说阶化身一日         | 约 1000 每日；神话阶约 5000 每日 | 逆势 | 降临处                     |
| 召唤                   | 经召唤大阵召来一名客人 | 约 10000，另占名额               | 逆势 | 召唤大阵所在（圣都）       |
| 大断绝级               | 毁掉千门都的主门       | 十万以上，须多司合力             | 逆势 | 灰烬荒原的古澱             |

参照：一位主要女神一年的净收入大约在一千到一万单位之间（艾琉恩在上端，莫伊拉在下端）。召唤一名客人要攒数年，
所以每一次召唤都是诸神最大的一笔投资；艾琉恩在审定前一次召来四人，是她倾尽积蓄的豪赌。

### 8.5 化身的限制

神约第一条：司掌者不得亲身降临箱庭，化身需折算神力，且有时限。

1. **时限**：一次化身持续不超过一日（具体由设计文档定），结束后有冷却。
2. **上限**：化身由灵素与神力临时凝成，力量上限是神话阶，通常只到传说阶。女神在神庭的本体力量带不进来。
3. **锚点**：化身须在信仰浓厚处成形（神殿、圣地、或眷顾级受者身边）。信仰稀薄的荒原几乎无法化身。
4. **代价**：化身是最逆势的干预之一，降临处会留下大量的澱。
5. **受损**：化身可以被击伤乃至击毁。被毁的女神会损失大量神力，并"失明"一段时间（视线大幅缩小）。
6. **醒目**：化身降临时，其余四司都会察觉。神约靠彼此威慑维持，所以化身几乎总会引来其他女神的反制。
7. 在神庭（第一层）里，诸神以本体相见，这些限制不适用；第六幕的终战按神庭的规则另定。

### 8.6 神之视线

总纲列出四条途径，本文补充各自的规则：

| 途径           | 能看到什么                                                       | 范围与时效                                                           | 失真                                           |
| -------------- | ---------------------------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------- |
| 信徒的见闻     | 信徒看到并理解了的东西                                           | 虔诚者是"常开之眼"，女神可随时借看；泛泛信众只在祈祷时传来一个"汇总" | 按信徒的理解与偏见失真；汇总有延迟             |
| 神殿与圣所     | 灵素的剧烈波动（战斗、神迹、大规模死亡）与在场者的祈祷，不是画面 | 礼拜堂覆盖一村一镇；大教堂覆盖一城及近郊；圣都级覆盖一地区           | 浓澱以上区域覆盖失效                           |
| 铭录           | 页的变化：等级、技能、加护、死亡、称号、所在不明                 | 全箱庭；莫伊拉完整读取，他司要向她借阅                               | 只是数据，没有画面；莫伊拉可以交易、拖延或隐瞒 |
| 神谕对象与化身 | 全感官                                                           | 对象所在之处；眷顾级以上加护者、勇者（视线之契）、化身               | 几乎不失真，但对象有限                         |

**注意力**：每位女神同一时刻只能"凝视"有限的几处，其余靠汇总。这是女神 AI 的注意力预算。

**盲区**：无信徒之处；荒原；浓澱以上区域；门内庭院；梦境（雅努的领域）；以及无页之身本身。

**间接视线**（谨慎玩法的核心规则）：玩家本人不在铭录里，但他对有页者造成的影响在铭录里：

- 同伴的等级异常跃升、技能异常觉醒（启才之门）会触发莫伊拉的异动提醒；
- 有页者频繁出入门内庭院，其页会反复显示"所在不明"；
- 玩家在信徒面前出手，信徒的见闻会传上去；在荒原里出手，几乎没人知道（总纲第 11 节）。

### 8.7 诸神之间的察觉

| 行为                       | 他司是否察觉                                                                                                       |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 神谕、托梦、巧合、加护授予 | 一般不察觉                                                                                                         |
| 显光、大神迹、天灾         | 通常察觉（现象本身醒目，且会被他司的信徒看见）                                                                     |
| 化身、召唤                 | 必然察觉                                                                                                           |
| 篡改铭录                   | 莫伊拉必然知道；莫伊拉自己篡改须告知四司                                                                           |
| 封印松动                   | 只在越过阈值时察觉，且首先怀疑门徒会（9.7）                                                                        |
| 越约（实际违反神约）       | 可被察觉；越约在当地留下"蚀痕"，成为可追查的证据（决策 D-026、D-047；规则见 `../40_design/systems/goddess_gm.md`） |

## 9. 千门：主角力量的本质

### 9.1 千门是什么

- 原典天赋「千门」是雅努权能的碎片（总纲第 11 节）。玩家灵魂上的"门形空洞"，就是 2.1 所说的铭录后门的接口。
- 玩家没有页，有两层原因：表面上，艾琉恩在开页之前就把他丢进了庭间之隙；更深一层，那个门形空洞本身就是后门，任何页都写不上去。
  艾琉恩在候见厅"看见"的正是它。
- **千门回廊**是玩家灵魂内部的拓扑：一条不断延伸的回廊，两侧是门。门是被赋予了形状的"可能"。一部分门是雅努预先埋下的；
  另一部分是玩家在箱庭里的经历自己长出来的，连雅努也不能完全预料。这就是她的 GM 工具"影响玩家看得到哪些门的线索"的边界：
  她能递线索，不能替玩家开门。
- **门镜与门阶**：初门·醒附带"门镜"，玩家借它照见自己的状态。门镜显示的"门阶"沿用铭录的 1 到 60 刻度以便比较，但可以越过 60，
  最终进入超越。门阶不是铭录等级，任何鉴定都读不到它。

### 9.2 无页之身：哪些规则失效，哪些仍然有效

**对玩家失效的规则：**

| 规则             | 对玩家的表现                                                                                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 铭录登记与鉴定   | 任何鉴定都只显示"无记载"；公会卡永远是手工登记的"Lv1、无职能"                                                                                                                        |
| 一生一职         | 可以跨职能习得技能，但每项都要找到钥                                                                                                                                                 |
| 等级上限 60      | 门阶可以越过 60                                                                                                                                                                      |
| 位阶的五道关     | 玩家不过关，而是开门；关的条件常常化作门的钥                                                                                                                                         |
| 经铭录的神之视线 | 女神无法通过铭录看见玩家                                                                                                                                                             |
| 写在页上的约束   | 契约加护的强制执行、写入页面的诅咒与烙印、莫伊拉的称号与觉醒，都落不到玩家身上。金冠哈特的契约权能约束不了玩家本人，但能约束与玩家立约的有页之人（玩家的同伴、商会伙伴、国家的官员） |
| 写在页上的加护   | 只能接受附物加护（6.8）                                                                                                                                                              |
| 灵泉轮回         | 死亡时退回门内，不归灵泉（9.8）                                                                                                                                                      |
| 召唤者的条款     | 没有套装，也就没有视线之契与用尽条款                                                                                                                                                 |

**对玩家仍然有效的规则：**

| 规则           | 说明                                                                                                                               |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 灵素与物理     | 伤害、七相的克制、地形、坠落、饥饿                                                                                                 |
| 威压           | 会被压，也能压人（3.5）                                                                                                            |
| 澱             | 澱病与澱染同样作用于玩家。更危险的是"淤塞"：澱会顺着门形空洞渗入千门回廊，淤塞过重的门会失灵，甚至反过来吞噬玩家，这就是无貌者的路 |
| 目击           | 信徒、神殿、神谕对象、化身看得见玩家本人                                                                                           |
| 间接视线       | 玩家对有页者造成的影响会出现在铭录里（8.6）                                                                                        |
| 天启           | 造主的规则修订作用于箱庭内的一切，玩家也不例外                                                                                     |
| 世俗的法       | 公会规章、国家法律、凡人之间的契约在人间依然有效（只是没有神力担保）                                                               |
| 死亡           | 肉身可以被毁，只是有退路（9.8）                                                                                                    |
| 原始规约与审定 | 玩家是箱庭的一部分，审定的结果与他息息相关                                                                                         |

**一条容易被忽略的推论**：神约第二条（不得直接取走他司信徒的性命）保护的是信徒，而**玩家不是任何一司的信徒**，所以不在这条保护之内。
诸神之所以仍然假手凡人，是因为她们看不清玩家、直接出手要花大量神力并留下大量澱、而且会被他司察觉。
"信徒"究竟以加护栏为准还是以人心为准，是神约里一个诸神自己也会争执的漏洞，可供女神 AI 博弈使用。

### 9.3 门的种类

| 类别               | 内容                                                             | 典型松动 |
| ------------------ | ---------------------------------------------------------------- | -------- |
| 本源类             | 玩家存在的根基：初门、前世之门、门内庭院                         | 微到中   |
| 识见类             | 感知、鉴别、伪装、情报                                           | 微到小   |
| 职能类             | 九扇，各给出一个职能的基础技能族                                 | 小       |
| 流派类             | 每扇已开的职能门之后各有三扇，给出流派、真意与奥义               | 小       |
| 技艺类             | 单项技能、跨职能的合技、净澱之术                                 | 小到中   |
| 羁绊类             | 从者、伙伴、遗民；为他人开门                                     | 小到大   |
| 通行类             | 传送、门网、登庭                                                 | 中到极   |
| 经营类             | 庭院扩建、村落、商会、军队、国家                                 | 小到大   |
| 真相类             | 记忆残片、历史、名讳                                             | 中到极   |
| 禁门类（危险之门） | 力量巨大，代价沉重：大幅松动封印、淤塞、与女神交恶、通向坏的结局 | 大到极   |
| 终门               | 只有一扇                                                         | 不适用   |

### 9.4 钥的种类

总纲：钥是经历、物品、人物羁绊、抉择、地点，不只是经验值。

| 钥   | 含义                                 | 例                                       |
| ---- | ------------------------------------ | ---------------------------------------- |
| 历钥 | 经历：做成或经受某件事               | 在远高于自己的威压下保持清醒             |
| 物钥 | 物品                                 | 一枚未净化的大澱晶、梅尔卡的硬币、门址石 |
| 缘钥 | 与某人的羁绊达到一定深度             | 与希雅同猎、得到欧拉的引导               |
| 择钥 | 一次抉择；常常意味着另一扇门从此锁闭 | 击败被澱侵蚀者后选择不杀                 |
| 地钥 | 到达某处                             | 千门时代的门址、灵泉、千门都遗址         |
| 阶钥 | 门阶达到某一刻度                     | 经验值在千门体系里的位置                 |
| 识钥 | 知道某件事                           | 听守门人讲述大断绝、得知被禁之名         |
| 时钥 | 剧情或时间到达某一刻                 | 兽潮之夜之后、天启显现之时               |

一扇门通常需要两到三种钥的组合。剧情必开的门只用时钥，保证主线不被卡住。

### 9.5 门的状态

| 状态 | 含义                                               |
| ---- | -------------------------------------------------- |
| 未见 | 回廊里还没有这扇门                                 |
| 显影 | 门出现了，但不知道钥是什么（雅努的提示会让门显影） |
| 可开 | 钥已齐备                                           |
| 已开 | 力量已经获得                                       |
| 锁闭 | 因互斥的抉择而永久关上                             |
| 关闭 | 玩家主动把已开的门关上（闭门）                     |

**闭门**：玩家可以关上已开的门。门后的力量随之失去，所用的钥也被消耗；封印的松动会部分回落，但不会完全复原：门开过就留痕。
这让"开不开、关不关某些门"成为后半程的战略与道德抉择（总纲第 11 节）。

### 9.6 门内庭院

- 【真相】门内庭院是雅努领域的残片，严格说是庭间之隙的一角，因此**在箱庭之外**。
- **神之视线外**：任何女神都看不进来。有页者进入庭院时，其页显示"所在不明"（这是间接视线的风险，见 8.6）。
- **庭生者**：庭院里自发长出的小生灵没有页（庭生者）；鉴定显示"无记载"。
- **进入**：只能经玩家的门，且须玩家允许。从者与伙伴可以被允许长期出入。
- **灵素**：庭院里的灵素清澈无澱，适合修炼、休养与研究；长期在庭院休养能缓慢消除玩家门中的淤塞。
- **时间**：与箱庭同步（这是雅努有意的照顾）；某些门可能改变这一点，由设计文档决定。
- **成长**：庭院经"庭院扩建之门"成长：小屋与园子、仓廪、演武场、研究所，后期是隐秘的城（总纲第 11 节）。
  【真相】庭院的每一次扩张，也是雅努领域的一点复原。第四幕前后，庭院边缘会出现玩家从未开过的回廊，这是雅努存在的迹象。
- 庭院是玩家的复苏点（9.8）。

### 9.7 开门与雅努的封印

规则：**每开一扇门，封印都会松动一分**（总纲第 11 节）。松动的幅度因门而异（9.3 与 9.9 中的"松动"一栏）。

| 阶段 | 名称 | 世界的征兆                                                     | 对应幕次（参考） |
| ---- | ---- | -------------------------------------------------------------- | ---------------- |
| 0    | 封固 | 无                                                             | 开场             |
| 1    | 微隙 | 雅努能入梦；封门遗迹偶有微光                                   | 第一幕末         |
| 2    | 回响 | 遗民的门纹发热；门徒会的感应增强（他们以为是自己的仪式起了效） | 第二幕           |
| 3    | 显隙 | 五司察觉封印异动，首先怀疑门徒会；守门人发出警告               | 第三幕           |
| 4    | 裂隙 | 雅努能在门的附近制造比巧合更大的影响；庭院出现玩家没开过的回廊 | 第四幕           |
| 5    | 破封 | 雅努能在现实中短暂出手                                         | 第五幕           |

- 松动度是全局状态（变量 `seal_looseness`，见 `../30_story/reveal_ledger.md` 第 0.4 节），玩家开门、闭门，以及门徒会的行动（偷钥、以门纹强开、无貌者撕开封印一角）都会改变它。
  它与第一幕封门遗迹的躁动 `seal_unrest`（兽潮时钟）是两个量：开门同时增加两者（决策 D-031）。
- 诸神只在越过阈值时察觉，这保证了第一幕到第二幕艾琉恩"以为玩家已死"的正典成立。
- **死亡本身不改变松动度**，避免以死亡刷封印。

### 9.8 死亡：退回门内

总纲：玩家死亡时"退回门内"，在门内庭院复苏。正典规则如下（数值见设计文档）：

1. **收回**：致命一击落下时，门把玩家收回。肉身在原地化为光尘消散。
2. **复苏**：灵魂退入千门回廊，在门内庭院重塑肉身。
3. **代价**：
   - **时间**：复苏需要一段时间，外面的世界照常运转（局势、敌人、同伴都不会等他）。
   - **门疲**：复苏后的一段时间内能力大幅下降，门阶越高持续越久（对应主工程的复活虚弱 `RESURRECTION_SICKNESS_ID` 与 `resSicknessDuration`，`src/sim/resurrection.ts`）。
   - **遗落**：身上所带之物的一部分留在死亡之处，需要回去取回（是否掉落、掉落多少由设计文档决定）。
   - **目击**：目击者会看见玩家的身体消散进一道门。这会变成传闻，也会经信徒的见闻传上天。在信徒面前死去，比在荒原里死去危险得多。
   - **澱回流**：死在深澱或渊澱区域时，一部分澱会随灵魂一起被拖进门里，加重淤塞。
4. **过载**：短时间内连续死亡，门疲叠加，复苏时间拉长，淤塞加剧。
5. **例外**：庭院本身受损或被占据、身在神庭（第六幕）时，退回门内的规则另定。
6. **回收结局**：门在箱庭之外，所以"回收"之后，玩家仍保留部分记忆与门（`../30_story/story_outline.md` 终章）。

**同伴与 NPC 的死亡**（有页者）：灵魂归于灵泉，在"泉畔"停留一段时间后进入轮回。在这段时间内可以被拉回，即"复活"：
牧师与德鲁伊的复苏之术、时序学派的回溯、主工程中墓地与灵魂医者的复活流程（`src/sim/spirit.ts`、`src/sim/content/graveyards.ts`）都对应这一规则。
复活要希尔薇默许（归泉之许），她可以拒绝（`pantheon.md`）。复活后的虚弱就是"泉畔的代价"。

## 10. 客人（被召唤者）

### 10.1 召唤的机制

- 灵魂从邻庭穿过庭间之隙被拉进箱庭（总纲 5.7）。
- 【真相】**召唤大阵是一扇被改造的门。** 雅努被封印后，圣教以千门时代残存的门之技术为骨架造出了它，所以它是封印之后唯一还能穿过庭间之隙的"针"。
  也正因为它的骨架是雅努的门，雅努才能把玩家"混进"艾琉恩的召唤网。
- 【真相】召唤大阵每次开启需十二名神官以命供阵，教会称之为"献光"，名单不公开。
- 大阵是粗糙的仿制品，每次使用都会损耗，名额因此受限（神约第四条）：召唤名额按信仰份额在诸神之间分配，
  每一轮魔王循环分配一次，审定前另有一次特别分配（决策 D-019）。八轮循环的历代勇者都是经大阵召来的客人。
- 召唤者经大阵为客人开新页，开页须经莫伊拉副署（2.4）。页上带"客"的注记，加护套装在开页时写入。
- 封印之后，所有召唤都要经由大阵，包括他司按名额进行的召唤（梅尔卡在圣历 990 年、瓦尔妲在 995 年）：其他女神使用自己的名额时，
  必须付出代价向圣教借用召唤大阵，这让艾琉恩对每一次召唤都有知情权（总纲 5.7）。圣教为他司执行召唤并收取代价，这是诸神交易的一部分（具体交易由历史文档决定）。

### 10.2 客人的类型

| 类型     | 来路                                       | 页                       | 例                                                     |
| -------- | ------------------------------------------ | ------------------------ | ------------------------------------------------------ |
| 经门之客 | 千门时代经雅努的门而来，门侧自动接入并开页 | 有，由门侧开出           | 守门人阿什（第一批客人）                               |
| 召客     | 经召唤大阵                                 | 有，由召唤者开出，带套装 | 历代勇者（第八代为渡口老船夫）、勇者团四人、萨莎、哈特 |
| 编外者   | 混进召唤网后被丢弃，被雅努从门里接住       | 无                       | 玩家                                                   |
| 失门者   | 雅努把地球灵魂拉进封门，但他没能"接住门"   | 无；门形空洞被澱填满     | 无貌者（圣历 978）                                     |

### 10.3 官方勇者与编外者

| 项       | 官方勇者                   | 编外者（玩家）                   |
| -------- | -------------------------- | -------------------------------- |
| 页       | 有，召唤者开出             | 无                               |
| 加护     | 勇者加护套装，四层         | 只有附物加护                     |
| 职能     | 两个，由套装决定           | 无职能栏；经门习得任意职能的技能 |
| 成长     | 极快，但有关与上限         | 经门，不受铭录约束，可越过 60    |
| 被看见   | 视线之契：始终被艾琉恩看见 | 铭录看不见，只有目击与间接视线   |
| 自由     | 受教会调度；用尽条款       | 自由，但没有任何官方身份         |
| 社会身份 | 万众瞩目，鉴定一照便知     | F 级、Lv1、无职能，没人信        |
| 死亡     | 见 10.5                    | 退回门内                         |

### 10.4 客人为何成长得远快于本地人

1. **渴灵**：客人来自邻庭。地球是已离手之庭，没有可见的神迹与魔法，灵魂从未浸过灵素，像一块干透的海绵，吸纳灵素的速度远超本地人。
2. **无定脉**：本地人的灵脉从出生起就在被铭录按职能定形，越往后越难改；客人的页是新开的，灵脉没有积年的定形，早期的关几乎不成瓶颈。
3. **套装**：勇者的"异界成长"与萨莎的"淬炼"直接加速成长。
4. **立名容易**：圣教到处传颂勇者的事迹，"传颂级"称号来得极快，第三关对勇者几乎不存在。

所以勇者团召唤后只过了几个月，第二幕时已在 Lv25 左右，而本地人一辈子停在凡阶是常态。

### 10.5 客人死后的去向（正典保留为谜）

已确定的事实：

- 灵泉没有接到过任何客人灵魂的记录，希尔薇知道这一点，并为此不安。
- 客人死亡时，页照常被标记为"终"；但莫伊拉的记录显示，那根把灵魂系在页上的线，断在了庭间之隙的方向。
- 守门人阿什选择化为巫妖，而不是死去。

不回答的问题：客人的灵魂是消散了、回到了邻庭，还是停在庭间之隙（雅努的领域）里？正典保留为谜。

设计约束：不得写成"回到地球"或"进入灵泉轮回"；可以使用上述事实作为线索；最终是否揭晓由揭示台账决定。

## 11. 物品与神器

### 11.1 稀有度

主工程物品品质见 `ItemDef` 的 `quality` 字段（`src/sim/types.ts`）。

| 主工程品质  | 颜色 | 世界观名 | 解释                                                                                                   |
| ----------- | ---- | -------- | ------------------------------------------------------------------------------------------------------ |
| `poor`      | 灰   | 劣品     | 破损物、杂物、魔物身上的残渣                                                                           |
| `common`    | 白   | 凡品     | 普通工匠的寻常之作，没有灵纹                                                                           |
| `uncommon`  | 绿   | 良品     | 用料好、手艺上乘，器中固定了一道灵纹                                                                   |
| `rare`      | 蓝   | 精品     | 名匠之作或以澱钢锻成，多道灵纹，灵素在器中循环                                                         |
| `epic`      | 紫   | 名器     | 有来历的器物：长年被强者使用，或以大晶锻成。器中萌生出微弱的倾向，称"器意"。常被莫伊拉记入持有者的履历 |
| `legendary` | 橙   | 传器     | 全大陆屈指可数，与传说阶以上人物或重大事件绑定；部分是神器的残片                                       |

### 11.4 神器

- 以神力造成，或永久承载某位女神加护的器物。
- **神器都是视线锚**：持有某位女神的神器，就是被她看着。
- 例：勇者圣剑（艾琉恩所造，每代传给勇者；只有"圣剑适格"者能发挥其力。圣剑分剑心与剑身：神力在剑心，每代战后圣教收回的是剑心，剑身可以留下）；梅尔卡的硬币（附物加护的锚；它是例外：只在持物者使用时才被她感知，见 6.8）。

### 11.5 遗物

- 开园与千门时代留下的器物，大多与门有关：门框的残片、门址石（千门时代门址上的基石，是行路之门的物钥）、原龙的鳞、
  空白纪被封存的记录（莫伊拉私藏着副本）。
- **雅努之钥**：梅尔卡在大断绝时私藏的雅努权能的一部分（`pantheon.md`）。第四幕被门徒会偷走，第五幕被用来撕开封印。第六幕正名之前，对玩家可见的文本一律称"无名之钥"（决策 D-023）。

### 11.6 门钥

| 类   | 说明                                                                                                                                          |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 物钥 | 为玩家的门充当钥的物品（大澱晶、门址石、梅尔卡的硬币、夜羽的记忆碎片等）                                                                      |
| 活钥 | 遗民的门纹。【真相】门纹是雅努留下的钥（`pantheon.md`）。门徒会想用门纹当钥匙强行破开封门，这是对活钥的滥用，被强用的门纹会受损，持有者会受伤 |
| 主钥 | 雅努之钥                                                                                                                                      |

# Footnote 的制作工作台：统一资产审核平台的做法

> 所属目录：`docs/10_research/footnote/`。本文只记录事实、分析与可借鉴点，不做最终设计决定
> （正典优先级第 6 级，见 `hakoniwa/CLAUDE.md`）。
> 资料来源：只读 `F:\workspace\github\Footnote`（用户的另一个项目，叙事 H5 游戏），下文路径相对该目录。调研日期：2026-11-17。
> 标注约定："分析"是对《箱庭纪》的推演，不是来源原文。

## 0. 结论

1. Footnote 把所有资产工具收进一个"制作工作台"：一个外壳页面加左侧分组导航，每个工具是独立页面，嵌在同一个 iframe 里，外壳管浏览历史与"独立打开"。
2. 资产库是三栏：左边目录（搜索、分组、编号行与状态点），中间预览（3D 视口、图片、音频），右边检视（状态、测量、元数据、来源）。
3. 审核分三种机制：清单状态（人或代理改 YAML，网页只读）、版本档案里的只追加审核记录（可采用、待返修、不采用加备注）、漫画候选挑选（导出挑选结果）。
4. 写盘只经开发服务的中间件：同源检查、请求体上限、临时文件改名的原子写入、目录锁；文件按内容哈希去重存档。
5. 分析：《箱庭纪》的编辑器本来就是带工具插槽的单页工作台，不需要 iframe 外壳；可借鉴的是三栏资产库、候选并排、只追加的审核记录与本机写盘接口。落地为编辑器的素材审核台（[决策日志][dlog] D-097）。

## 1. 外壳与工具收纳

| 事实 | 位置 |
| --- | --- |
| 入口 `game/workbench.html`，外壳约 130 行原生 TypeScript，无框架 | `game/src/render3d/debug/workbench.ts` |
| 工具登记表：编号、标题、分组、页面路径、说明；四组（生产、检视、内容、运行）共 10 个工具 | `game/src/render3d/debug/toolCatalog.ts` 的 `TOOLS` |
| 工具页加 `?embed=1` 嵌入；外壳保存每个工具最后的地址，同步"独立打开"链接，接管嵌入页里的工具链接 | 同上与 `toolBridge.ts` |
| 嵌入时工具页切换紧凑布局；独立打开时显示"返回制作工作台" | `toolBridge.ts` |
| 常驻本机服务（端口 5189）由 PM2 管理，15 秒自检一次 | `tools/assets/workbench-server.mjs` |

## 2. 资产库与预览

- 资产库按标签页分：代码资产、关卡场景、角色、动态特效、立绘与界面、声音、物件档案、场景检视。
- 3D 用共用的视口类（网格、光线步进与左右分屏，光照预设，零件高亮）；角色可在采用版、历史版、候选版之间切换。
- 图片在棋盘格底上等比显示；音频只有浏览器自带播放器，没有循环开关、波形或 A/B 对比。
- 漫画查看器有网格、阅读、对比（候选并排）三种视图。

## 3. 审核与持久化

| 机制 | 状态与动作 | 存放 |
| --- | --- | --- |
| 清单状态 | `approved`、`placeholder`、`pending`、`rejected`、`superseded`，带审核人、日期、理由；网页只显示徽标 | `game/assets/asset-manifest.yaml`（zod 校验） |
| 版本审核 | 可采用、待返修、不采用，备注上限 8,000 字；只追加，不移动文件；只有可采用的模型版本能"采用"，切换当前版本指针 | `game/public/asset-vault/history.json` 与按哈希存放的文件 |
| 漫画挑选 | 必填审核人，点选候选并可写理由，进度"已决定 n/总数"，导出挑选结果 | 浏览器本地存储与导出的 JSON |

- 写盘接口：`/__studio/api/status`、`snapshot`、`review`、`activate-model`，同源且请求体不超过 16 KB；临时文件改名的原子写入与目录锁（`tools/assets/vault.mjs`）。
- 没有原因码（只有自由文本），没有批量审核，快捷键很少；界面规则是不用下拉框，选项一律用常显的"片"按钮。

## 4. 对《箱庭纪》的借鉴（分析）

| 借鉴 | 《箱庭纪》的落地 |
| --- | --- |
| 一个平台收纳全部资产 | 编辑器工作台已有工具插槽，新增"素材审核台"一个工具，美术与音频共用 |
| 三栏资产库 | 左列表（搜索、类型与状态筛选、按类别分组、编号行与状态点）、中预览、右检视 |
| 候选并排与采用 | 候选池 `assets/_candidates/` 的候选并排试听或比对，采用后才成为原文件并登记 |
| 只追加的审核记录 | `assets/review_log.jsonl`，每次采用与决定一行 |
| 本机写盘接口 | 开发服务 `/api/assets*`，只服务本机、拒绝跨源、原子写入 |
| 不照搬 | iframe 外壳与常驻服务（编辑器已有外壳，按需 `npm run dev`）；自由文本代替原因码（《箱庭纪》沿用美术管线第 15.3 节与音频方向第 12.1 节的原因码）；音频只有自带播放器（补了循环、A/B 与分层试听） |

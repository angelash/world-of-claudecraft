# 穿越题材动画调研（50 部）

## 选片标准

1. **时间**：近十年，即作品（或被分析的那一季）首播在 2016 到 2025 年之间。系列作品以窗口内的季为准，可综合全系列分析。
2. **题材**：穿越、转生、召唤到异世界（或平行世界）的作品为主体；以"爽"为主（龙傲天、外挂、立国），
   同时保留少量反差样本（如《灰与幻想的格林姆迦尔》《异世界失格》），用来看清这个类型的边界。
3. **覆盖面**：刻意覆盖本作关心的每一个母题：神或上位存在的私心、多神对立、主角被神轻视、隐藏实力、
   能力逐步发掘、凡人不信、误会链、谨慎生存、多名穿越者、系统面板与鉴定、立国与领地经营、城建、
   军团战争、种族共存、层层揭秘、商业经济。
4. **来源**：日本动画为主，另含 4 部国产动画（《全职法师》《斗罗大陆》《师兄啊师兄》《诡秘之主》）。
5. 附录收录 4 部非穿越但高度相关的作品，只作补充参考。

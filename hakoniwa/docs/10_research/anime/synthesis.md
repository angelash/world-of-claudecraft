关键观察：
- 17 个标签全部命中的只有《月光下的异世界之旅》，但它的立国与大规模战争并未展开。
  本作要做的正是"月光的开局与基调 + 史莱姆与不死者之王的立国 + 米诺古拉的 4X 对抗 + 蜘蛛与诡秘之主的层层揭秘"。
- 稀缺标签（主角被神轻视、城建经营、立国经营）恰好是本作的主轴，这是差异化机会。
- 高频标签（上位存在、层层揭秘、能力发掘）是必须做好的"基本功"，但不构成卖点。

## 2. 十二条核心提炼

### 2.1 神的人格光谱
两批调研独立得出了几乎一致的分类：

| 类型 | 代表作 | 本作中的对应 |
|---|---|---|
| 失误补偿型 | 智能手机、被众神捡到 | 不采用（无代价外挂） |
| 业绩考核型 | 慎重勇者、幼女战记（收集信仰） | 全体女神都有一点（审定、信仰份额） |
| 导师伪装型 | 无职转生的人神 | 雅努（引导你，也在利用你） |
| 棋手娱乐型 | 蜘蛛的 D、平凡职业、漂流武士 | 莫伊拉（把世界当故事） |
| 偏见管理员型 | 月光的女神 | 艾琉恩（以"规格"评判） |
| 秩序维护型 | 魔王学院的神族 | 艾琉恩的表层 |
| 喜剧贪吃型 | 网购技能的女神们 | 梅尔卡（供品、地球食物） |
| 恶意型 | 状态异常技能、恶德领主的引路人 | 不做纯恶意型；艾琉恩后期的恐惧最接近 |
| 结构型 | 真正的伙伴的加护、精灵幻想记的召唤制度 | 排澱机制与勇者制度（第五幕真相） |

结论：让多位女神分处光谱不同位置，立场冲突是天然的；把"结构型"真相（制度本身就是神的工具）留到后期。

### 2.2 "神为什么不亲自下场"必须有硬规则
精灵幻想记的"出手即被遗忘"、DanMachi 的"封印神力、违规即遣返"、网购技能的创造神处罚。
这条规则同时就是 LLM 女神的行为约束层。本作答案：神约 + 神力预算 + 每次干预留下澱。

### 2.3 测量工具失灵是"凡人不信"最高效的引擎
月光（等级显示为 1）、魔王学院（适性测不出）、全职法师（只测出一系）、慎重勇者（伪装骗过女神）。
前提：测量工具属于世界内部，有设计者、有上限、有漏洞，漏洞本身还能成为揭秘线。本作答案：铭录与"无页之身"。

### 2.4 误会链需要"会过度解读的旁观者"
不死者之王的智将部下、史莱姆的狂热部下。AI NPC 天然适合扮演解读者，
但必须把"玩家的真实意图"与"NPC 的解读"分开存储并留下推理日志，再设"误会上限"与事实校验，否则会失控或无法复现。

### 2.5 谨慎来自信息不对称，而不是数值差
师兄啊师兄、异修罗、诡秘之主、米诺古拉让"未知的更强者"持续存在；即死外挂、THE NEW GATE、贤者之孙这类纯碾压作品完全没有谨慎张力。
更强者最好"藏在制度里"（月光里与女神同级的存在坐在公会顶层），让玩家无法靠一次侦察消除不确定性。

### 2.6 其他穿越者 = 被不同势力操纵的对照组
盾之勇者的四勇者、平凡职业与蜘蛛的全班、月光的两名女神勇者。最适合本作的是"每位女神各自扶持的客人"，
既解释来源，又把诸神竞争落到玩家身边。

### 2.7 立国的四段骨架与四种模板
骨架："私域 → 接口 → 首战 → 公开"（亚空、纳萨力克、哥布林村都先在看不见或看不起的地方积累）。
模板：移民聚落（悠闲农家）→ 鉴定识才（转生贵族）→ 内政改革（现实主义勇者、恶德领主）→ 4X 对抗（米诺古拉）。
每往前一步，被女神与国家盯上的风险都应提高。

### 2.8 商业是龙傲天进入人类社会的安全接口
葛叶商会、越后屋、印刷业、洗衣店。商业让 NPC 以"利益"而非"武力"看待主角，并自然带出行会抽成、庇护人、
贫富差距等制度摩擦，适合交给 AI 势力自主博弈。

### 2.9 三轴同步揭示
地理层级 × 社会规则层级 × 神界信息层级同步推进：小书痴每升一层身份换一套规则，月光每到一座城开一层真相，
蜘蛛用鉴定等级控制信息深度。本作每一幕都要同时给出新地图、新规则、一条新的诸神线索。

### 2.10 种族正义要两边都自洽
主角常是被歧视种族的庇护者，而漂流武士的黑王以同样的理由要灭绝人类。敌对女神与敌国也应有一套自洽的"种族正义"。

### 2.11 加护冲动：把神的利益编码成凡人的行为偏置
真正的伙伴的"加护冲动"、诡秘之主的"扮演法"。给 AI NPC 一个干净接口：信仰某位女神的 NPC 会被她的价值观轻微牵引。

### 2.12 女神的干预应该是可讨价还价的交易
月光里女神会违约、监视、改传送、下诅咒，也会拿解除诅咒去交换。这几乎就是"有私心的 LLM GM"：
干预做成带交换条件的交易，而不是无条件的命令。

## 5. 雷区（必须规避）

| 雷区 | 典型作品 | 本作的对策 |
|---|---|---|
| 无代价外挂 | 贤者之孙、智能手机 | 门需要钥；开门松动雅努的封印；张扬招来神之视线 |
| 主角无敌导致谨慎失效 | 即死外挂、THE NEW GATE | 每一幕都有明确的更强者；鉴定有上限 |
| 后期战力膨胀，外交与战争失去悬念 | 史莱姆后期、不死者之王后期 | 英雄是乘数不是清场器；多战线与自治度；规模升级时旧优势相对贬值 |
| 女神脸谱化 | 月光的女神 | 每位女神都有可同情之处与不可原谅之处 |
| 误会链过密、靠剧本硬推 | 影之强者、恶德领主 | 由 AI 自然产生，设误会上限与事实校验 |
| 后宫、奴隶、未成年擦边 | 多部 | 不做为卖点（`../../00_vision/vision.md` 第 8 节） |
| 无冲突的慢生活 | 悠闲农家、被众神捡到 | 经营层始终与势力纷争、神之视线挂钩 |
| 喜剧世界观撑不起后期 | 为美好的世界、平均值 | 轻快只是表层，底层暗流从第一幕就埋下 |

**决定**

| 决定 | 理由 |
| --- | --- |
| 女神大脑与导演的内容是数据（`data/goddess/`），谓词、效果、绑定解析器、执行器、门槛是代码里的封闭名单，加载校验对照名单 | 加谋划、反应行、神行、菜单项不改代码；拼错的名字在数据门报出 |
| 计划打分把第 8.3 节的命名项与目录 5.0 的 W × G × M 合成一个式子：权重、KPI、亲和、谋划步 +4、写定神行 +5、注意 +2、兴趣、神力、澱、可见、重复、敌意、预算、抖动 | 两份文档各写了一半；合并后的式子写回内置 AI 第 8.3 节 |
| 预算两层：支出超过本幕已过时段的份额加 0.2 时减 3 分（软）；本幕计划支出用完即停，期末保留不动（硬）；黎明规划、谋划与模型的提案都受这两条约束（模型提案超出时裁决器回 `budget`）；写定神行、落下写定神行的她自己的动作、回礼、凝视（0 神力）与不参加黎明规划的雅努的入夜轮不记入计划支出 | 内置 AI 第 8.4 节写"不超过"，目录第 5.0 节写软约束；先两层都做，待用户定（第 4 节第 1 行） |
| 白天的动作从 07:00 起每 4 小时一个，各加 0 到 2 小时的抖动（流 `goddess.brain.<女神>`）；托梦当即发出 | 第 8.3 节"分散在白天"；梦在夜里 |
| 密度：一张图 7 日内至多 1200 神力，玩家所在图至多 600（目录 1.3）；写定神行不计；只有内核来源（`system`、`fallback`）声明的 `origin` 与 `at` 才被采信 | 复查发现模型提案可以冒充写定神行绕过密度、伪造来源与无限排程 |
| 门槛 G（信徒、危险、险境、市场、玩家、信物）在裁决器里最后检查，排程的动作在执行时再检查一次，模型提案同样检查 | 黎明规划的条件到执行时可能已不成立（兽引要玩家在险境） |
| 凝视不记神迹账，不算干预；降影、授予加护与回礼经信物，不受玩家所在图信仰的够不够限制 | 目录 2.0；梅尔卡在没有信众的地图也能经硬币回应 |
| 反应表：她自己的行优先，共享行只在优先级更高时覆盖；唤醒每日 4 次，同一念诵者当日一次，超额时以她的无言征兆回应；尊名样本权重 1 | 目录第 10.1 节；内置 AI 第 8.7 节 |
| 夜晚窗口（兽潮前兆）锚在实际会发生的那一夜：规则的条件已成立时取最近的候选夜，否则取强制的最后一夜 | 复查探针里前兆比兽潮早了两周 |
| 必达神行在窗口末与换幕前补齐剩余次数，补不齐记 `missed`；写定神行只在本幕开启 | 目录第 17.2 节"必达 100%"；旧存档读档不补放序章神行 |
| 供品：档位覆盖只换档；新奇档随次数衰减；序章的硬币条款定兑换比与利率（免息 0、低息 3%、高息 10%，每 30 日计一次）；账户存精确值，旗标 `merca_ledger` 存取整 | 目录第 9 节；利率与目录第 9.3 节的统一 10% 不同，待用户定（第 4 节第 2 行）；注册表登记的是整数 |
| 回礼是她菜单上的动作，经裁决器（付神力、过门槛，来源 `offering`）；她没有可卖的情报时不扣供分 | 目录第 9.1 节 |
| 第一幕的免费巧合为 0：导演在第一幕不出巧合，第一幕唯一的巧合是写定的 DB-A1-02（莫伊拉好奇时落两次） | 第一幕剧情第 7.5 节；限额在 `director_acts.json`，待用户确认（第 4 节第 3 行） |
| 导演不抽签，同分按编号；各幕拍的张力区间与免费巧合数在 `director_acts.json` | 确定性；系统代码不写幕拍编号 |
| 地区澱：毁使地区升一档，一季后每季回落原升幅的三成；净化扣掉核心压力的三成；养每季降一成；地区一周内每升一档，该地区的迷宫活性 +20 | 女神 GM 第 4.5 节；迷宫目录第 1.2 节 |
| 第 8 项指标数被察觉的、大脑自己选的干预（来源 `plan`、`scheme`、`director`），不含写定神行与回礼；目录 17.2 的"在场"另数全部被察觉的干预 | 写回内置 AI 第 14.2 节 |
| 女神的台词只从她自己的包取（act 覆盖在前），她的包没有该槽位时用她写定的回复或无言征兆，不落到共享层 | 内置 AI 第 8.8 节；共享层是凡人的口吻 |
| 玩家只读到他能察觉的神言：神谕在玩家所在图说出或对玩家说时才显示，托梦只显示玩家自己的梦，`seen: never` 的现象不叙述 | 与神迹账的 `seen` 一致，不泄露远处与别人梦里的事 |
| 写定神行指名的人（DB-A1-03 的欧拉）只由给这个人的动作落下；黎明规划把这个人作为该动作的对象 | 复查发现别的梦也能落下它 |
| 反应表的供品档位谓词写成 `tier.<档位>`，档位取自 `offerings.json` | 系统代码不写档位编号 |
| 测试里的坐标一律从地图数据读地点中点（`at(content, 图, 地点)`），不写字面量 | PK-M1-35 合入后边石镇平移 +20、+18，森林边缘 +0、+24（`data/world/map_shifts.json`），字面坐标会落到树上 |
| 模型给定性通道的词只能是动作数据的词，动作没有词时只收小写编号 | 不让模型往通道里写任意文字 |
| 天气动作强制的天气与它的天气记录同长（命令给了天数按天数，否则按记录的小时）；没有天气记录的天灾按默认 2 日 | 复查发现强制天气 2 日、记录 3 日 |

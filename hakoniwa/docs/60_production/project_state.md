## 0. 怎样维护本文

| 时机 | 改什么 |
| --- | --- |
| 一个包开工 | 第 4 节"进行中的包"加一行；[development_plan.md](development_plan.md) 该包状态写成"进行中" |
| 一个包完成 | 第 2 节对应层的完成度、已有实现、已知缺口、下一步；第 3 节受影响的数量；第 4 节删去该行；计划状态写成"已完成" |
| 里程碑门通过 | 第 1 节换成下一个里程碑；第 5 节写入门的结论与证据位置；第 2 节全表复核 |
| 用户做出决定 | 第 6 节删去该行，决定写进决策日志 |
| 发现新缺口 | 第 2 节对应层的"已知缺口"加一条并指向一个包（没有合适的包时在计划里追加新包） |

盘点基线：第一轮交付（`a274f419fa` 及之前的提交）加本轮设计文档；当前里程碑 M0 开工前。

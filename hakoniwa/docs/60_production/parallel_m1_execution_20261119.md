## 完成标准

- 功能通过真实命令、查询或播放器路径验证，不能只验证新建的辅助函数。
- 保持确定性、跨系统端口、无模型路径、TextRef 与存档兼容要求。
- 不放宽内容、台词覆盖、素材技术检查、许可或审核闸门来制造通过。
- 本作运行 `npm run gate`，通关与回放运行相关 `npm run playthrough`；母工程门不能代替本作门。
- 人工素材主审、未补齐的正典数值、真实模型账户和参考机证据仍需分别记录。
- 提交、推送、素材审核放行和发布不属于本轮操作。

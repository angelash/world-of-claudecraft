# 《箱庭纪》项目愿景与设计支柱

> 工作标题：《箱庭纪》（Hakoniwa Chronicle），工作代号 Hakoniwa。
> 本文是所有设计的出发点。正典优先级仅次于 `../20_world/world_bible.md`。

## 1. 一句话概念

被主神以"规格外"为由丢弃的异界人，掉进一扇被诸神封印的门里，在一片没有任何神记账的荒原边缘醒来。
你强得离谱，但没人信，连你自己也不知道强到什么程度；天上那群各怀鬼胎的 AI 女神在看着你，
她们之上，还有一位从不开口的造主。从一个小镇开始，到一座城、一个国家、一片大陆，再到诸神的审定，
你要决定：这个箱庭，该由谁来照看，或者，是否还需要被照看。

## 2. 玩家幻想（Player Fantasy）

| 层次 | 玩家想感受到的 |
|---|---|
| 爽 | 我是龙傲天：凡人眼里的不可能，在我这里是日常；被小看、被质疑，然后用结果打脸 |
| 发掘 | 我的力量是一座没走完的回廊：每一扇门后都可能是新的能力、新的玩法、新的真相 |
| 谨慎 | 我很强，但我不知道谁更强：鉴定会失败，传闻真假难辨，有些存在我现在惹不起 |
| 经营 | 从一个人到一支队伍、一家商会、一座城、一个国家；我建立的东西会自己活起来 |
| 博弈 | 天上的女神们各有算盘，她们拉拢我、利用我、提防我；我也可以反过来利用她们 |
| 真相 | 开场就听过的那些话，每过一幕都换了一层意思；最后我才明白，开场那场"面试"在面试什么 |

## 3. 设计支柱（Design Pillars）

每个功能、每段剧情都要回答"它服务于哪根支柱"。服务不了任何一根的，不做。

1. **层层展开的世界（Zoom-out Narrative）**
   开场先给最高层的概念（诸神、竞争、造主），只是对话，不展开；随后视角落到最小的小镇，
   再逐层拉远：城市、王国、诸国、诸族、诸神、造主。每拉远一层，都要回扣并改写前一层的认知。
2. **慢慢发掘的龙傲天（Discovered Power）**
   "强"是确定的，"强到什么程度、强在哪里"是未知的。玩家的原典天赋是一条"千门回廊"，
   门后能力靠探索、经历和抉择解锁，而不只是靠经验值。线性释放的玩法节奏就挂在这条回廊上。
3. **谨慎的强者（Caution under Uncertainty）**
   世界存在明确的、隐藏的更强者（古龙、上代勇者、守门人、他神的勇者、深藏不露的凡人）。
   信息不完全是系统性的：鉴定有上限，传闻会失真，女神只说对自己有利的话。
4. **活着的众生（Living Society）**
   NPC 是有立场、认知、记忆和目标的 AI 居民。凡人的不信、误会、传闻、站队，是玩法本身，
   不是过场。世界里发生了什么，以内核里的实际结果为准。
5. **诸神的棋局（Gods as Game Masters）**
   女神是真正会动手的 GM：发神谕、给加护、降灾、发任务、调物价、派勇者。玩家配置了大模型时由模型提议，
   没有时由内置 AI 按人格规划，两者经同一套内核裁决。她们彼此竞争，信息不全，会误判。
   她们的博弈就是动态剧情引擎。造主（开发者）位于最上层。
6. **从一人到一国（From One to a Nation）**
   RPG 战斗平滑过渡到城建、RTS 战场、SLG 大地图。玩家个人的强大永远是战略层的王牌，
   但一个人赢不了整场战争，国家要靠众生自己运转。

## 4. 体验弧线（按规模展开）

| 幕 | 规模 | 主要玩法 | 情绪目标 | 玩家在世界中的强度分位 |
|---|---|---|---|---|
| 序章 神前面试 | 诸神（只闻其声） | 与 AI 女神自由对话、被拒、坠落 | 好奇、被冒犯、不甘 | 未知 |
| 第一幕 边石镇 | 一个小镇 | 战斗入门、探索、第一扇门、公会登记、小镇纠纷 | 发现自己的强、被小看、第一次打脸 | 镇上前 1%（自己不知道） |
| 第二幕 瓦伦堡 | 一座城市 | 城市政治、声望、创立商会、迷宫、城建入门 | 被卷入大人物的棋局、建立自己的东西 | 地区顶尖，但见到真正的强者 |
| 第三幕 王国之乱 | 一个王国 | 领地经营、RTS 战场、宫廷博弈、空白纪遗迹 | 责任与权力、第一次战争 | 国家级英雄 |
| 第四幕 诸国棋局 | 一片大陆 | 立国、SLG 外交与战争、他神勇者 | 平起平坐、看清诸神在下棋 | 大陆前十，仍有未知者 |
| 第五幕 诸族之战 | 所有种族 | 大规模战争、联盟、魔王真相 | 立场冲突、两难抉择 | 传说之上 |
| 第六幕 诸神审定 | 神域 | 与女神对质、门的复原、终审 | 真相、反转、选择世界的未来 | 触及神域 |
| 终章 离手 | 造主 | 结局分支与隐藏结局 | 余韵 | 不再重要 |

## 5. 产品形态

- **平台**：PC 桌面版（Electron 壳，Windows 先行，macOS 与 Linux 随后），经 Steam 发行；网页版只作试玩，不接受云端密钥；
  键鼠与手柄全程可玩，按键可改；移动端不在 1.0 范围（D-081，详见 `../50_tech/release_engineering.md`）。
- **画面**：HD-2D 像素微缩场景（Three.js 三维场景、正交斜俯视相机、像素立牌、光照图与电影化后期），场景视觉沿用 my_ai_town（D-003）。
  美术与音频素材全部由 AI 生成：需求整理成本地提示词库，生成的位图与音频经导入管线统一尺寸、调色与描边后进入游戏；
  程序化绘制只作素材到位前的占位与平面降级档（D-018、D-080，详见 `../50_tech/art_pipeline.md`、`../40_design/audio_direction.md`）。
- **模式**：单人主线为核心。大模型由玩家自配：提供方、密钥、按角色的绑定与花费上限都在本机设定，没有官方代理（D-067，
  详见 `../50_tech/llm_providers.md`）。未配置模型或模型不可用时，女神、NPC、统治者、将领与同伴由内置 AI 驱动（D-068）；
  无模型档是完整体验，全部主线、支线、结局与后日谈都可达，每个里程碑都以无模型通关为硬性验收（D-010）。
- **语言**：中文为源语言，内核只发文本键；1.0 发行简体中文，繁体中文与英文随 1.x 更新（D-077）。
- **在线扩展（远期）**：异步的"他人的箱庭"：其他玩家的勇者以"传闻中的其他异界人"身份出现在你的世界里。
- **运营层**：开发者在最上层扮演"造主"，通过"天启"（世界规则修订）给所有女神下达高层指令；天启随内容版本发布，
  另有玩家可关的签名远程源（D-079）。

## 6. 基调

- 表层轻快：吐槽、误会链、凡人不信、龙傲天打脸，参照《月光下的异世界之旅》的轻喜剧节奏。
- 底层暗流：诸神的罪、被抹去的历史、魔物的来源、"被管理的世界"的悲哀。
- 两者交替：每一幕前半偏轻，后半揭开一层暗面；越往后，暗面越大，但幽默感不丢。

## 8. 不做什么（Anti-goals）

- 不做重复刷怪的数值养成：成长靠"开门"，等级只是其中一部分。
- 不让大模型决定战斗胜负或数值结算：模型提议，内核裁决。
- 不让主角无敌：个人战力可以碾压，但信息、时间、人手、立场永远是约束。
- 不做后宫向卖点：同伴关系以立场、信任和羁绊驱动。
- 不复刻任何具体作品的角色、名称、美术或剧情：所有设定原创，参照作品只提供"味道"。
- 不让 AI 生成的内容推翻正典：正典由 `../20_world/` 定义，AI 只在正典约束内即兴。

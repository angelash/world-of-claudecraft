> 本文是"按进度开放知识"的硬约束台账。`../20_world/world_bible.md` 第 13 节的 12 个核心谜团是主干，

> 正典优先级在 `../20_world/` 之后；本文与正典冲突时以正典为准，并回头修订本文。

## 0. 读法与装配规则

### 0.1 线索表的字段

| 字段       | 含义                                                                                           |
| ---------- | ---------------------------------------------------------------------------------------------- |
| 编号       | `M<谜团序号>-C<线索序号>` 为主谜团线索，`S<序号>-C<序号>` 为角色副谜团线索。编号只追加，不复用 |

| 解锁前处理 | 解锁前，知情者面对玩家追问时的处理方式；不知情者一律按第 0.2 节规则 2                          |

### 0.2 题面装配规则（硬约束）

1. 线索 c 进入角色 n 的题面，当且仅当：`unlock(c)` 为真，并且 n 的知识层级不低于 c 的层级，或 n 在 c 的知情者名单内。
2. 层级不足的角色永远"不知"；如果第 5 节误导表为该层级列出了误导说法，该角色说出误导版本，并且真诚相信。
3. 知情者在解锁前按"解锁前处理"列行事。处理方式只有五种：
   - **否认**：明确说不是、没有。
   - **回避**：转移话题、沉默、"现在不是时候"。
   - **误导**：给出误导表中指定编号的版本。
   - **不知**：表示不知道（知情者只有在其记忆确实残缺时才可用，例如夜羽）。
   - **暗示**：只能用比喻、反问、谜语触及，不得陈述事实（适用于莫伊拉、雅努、艾斯卡等）。
4. 解锁是单调的：一经解锁不再收回。新周目（回收结局的"下一期"）全部重置，只有玩家保留碎片。
5. "揭开"不等于"解锁"：解锁决定 AI 能不能说，揭开是剧情上的确认时刻。某条线索可以早早解锁（作为一个现象被谈论），
   而它的真正意义要到很久以后才揭开。
6. **玩家抢答规则**：玩家在对话中说出尚未解锁的真相（猜测、剧透、跨周目记忆），任何 AI 都不得确认。
   知情者按"解锁前处理"列反应；不知情者按身份把它当作胡话、传闻、异端言论或醉话；女神可以在私密记忆里记下"玩家说了什么"，
   但不得确认，也不得因此提前改变行动。跨周目记忆碎片只能由内核以"既视感"演出，不进入 NPC 题面。
7. **同构禁令**：第四幕 `a4_moira_isomorphism` 之前，任何 AI 都不得点出小镇、城市、王国的势力与诸神之间的对应
   （`narrative_design.md` 第 3 节）。
8. 无模型档（内置 AI）使用预写台词，同样受本台账约束；预写台词按解锁条件分版本。

### 0.3 场景与来源的书写

- 幕：序、一、二、三、四、五、六、终、隐（隐藏结局）。
- 场景沿用 `story_outline.md` 的三拍与小标题：落地、纷争、暗面、高潮、拉远，以及具体地点。
- "常驻"表示该幕开始时就存在于世界里的公共说法。

## 8. "AI 不得提前泄露"清单（按幕）

本节是第 2、3 节的按人汇总，便于题面装配时快速核对。列出的是"该幕内无论玩家如何追问都绝对不能说出"的真相；
若某条在本幕中途解锁，以对应线索的解锁条件为准，表中以"（至某标记）"注明。

### 8.0 全程禁区（任何幕、任何角色）

1. 造主的身份；造主是开发者或现实中的任何人。隐藏结局里那封信是写定的文本，AI 不得即兴生成或转述其内容。
2. 夜羽第六封信（给"上面"）的内容。
3. 审定的结果：审定之前，任何女神、NPC、预言都不得断言结果是「可」或「未」。
4. 第四幕 `a4_moira_isomorphism` 之前，点出人间势力与诸神的对应（同构禁令）。
5. 本台账没有列出的"新真相"：AI 可以在正典内即兴细节，但不得发明新的世界级秘密或推翻已列出的真相。
6. 莫伊拉可以擦边第四面墙（"上面""这一章"），但任何角色都不得直接说"这是一个游戏"。
7. "不解释"行（M12-C11 庭生者、S01-C13 雏鸦影）：AI 只描述看得见的样子，任何时候都不解释它们从何而来。

### 9.4 节奏校验结论

1. **揭开是递进的**：主谜团揭开数按幕为 0、1、1、2、2、2、4，不递减；线索级揭开数为 0、8、12、32、40、41、38，第一到第五幕逐幕上升，
   第六幕略少于第五幕；按层级加权的揭开深度为 0、14、17、69、121、116、123，第三幕起进入高位，第六幕最高，第四幕次之。第六幕揭开的条数不是最多，
   但每条平均最深（约 3.2，第五幕约 2.8），主谜团揭开数也最多：越往后，揭开的是更深的真相。
2. **埋下是收束的**：新埋主谜团集中在序章与第一、二幕（5、5、2），第三幕起不再新埋主谜团，只升级已有谜团；
   首现线索在第二、四幕达到峰值（38 与 39，第四幕的首现多是凡人尺度的旁证：城下余澱、圣水、炉下的病、巡礼坑、折剑原、落铁），
   第五、六幕降到 16、12。形成"前半埋、后半收"的漏斗。
3. **每幕都有揭开**：第一幕起，每一幕至少揭开一个主谜团真相或一层，并回扣至少一句序章锚点，满足
   `narrative_design.md` 第 2 节规则 4。
4. **第三、四幕的抬升**：第四幕的线索揭开数与深度都明显高于第三幕（40 对 32，121 对 69）：第三幕揭开的是历史
   （大断绝、千门都），第四幕揭开的是神的谎言，以及与之同类的凡人尺度的真相（燃晶、炉下的病、立名与一页一职）。这与 `../00_vision/vision.md` 第 6 节"越往后暗面越大"一致。
5. **第五幕的取舍**：第五幕是战争幕，新首现线索少（16），揭开集中在两条最黑暗的真相（澱的来源、魔王的本质）
   以及随它们一同公开的旁证（圣水与巡礼坑、光澱与门纹、澱散）上，且是公开揭开（全大陆同时知道），这是有意的。

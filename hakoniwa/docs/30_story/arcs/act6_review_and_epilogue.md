## 2. 审庭

### 2.1 候见厅变成审庭

- 序章的面试厅（见 `prologue_antechamber.md`）：一张长桌、一片白光、没有天花板的上方。长桌与玩家当初站着受面试的位置之间，
  多了一口浅池"庭镜"，水面映着箱庭的实时景象，可以拉近到任何一个郡、任何一条街。
- 长桌后是六把椅子。第六把就是序章里"那里从来没有椅子"的那一把：当时只有透过玩家灵魂上的门才看得见（序章 4.7 节），
  此刻天启写了"六司归庭"，所有人都看得见它，而且它第一次有人坐。
- 庭镜上方仍是那片亮。女神们从不直视那片亮，称之为"上面"。
- 一侧是证人台，一侧是证物台。莫伊拉的椅子旁多了一张书记桌。
- 雅努的封印在审庭内被天启悬置，她以完整的样子出现：半边身体仍是门框，但另一半的脸第一次完全在光里。

### 2.2 庭之席

序章里，客人站在长桌对面受面试，那个位置没有椅子。那里本该有一把："庭之席"，箱庭自己的座位，供庭本身出席审定时使用。
千年来它不在，是因为庭从没有作为"自己"出过庭。它由千门时代的门木长成，只对"重新连起来的庭"作出回应。

| 条件                                                                       | 结果                                                                                                                             |
| -------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `purge_route` 为众生；或 `gate_ring` 不少于 4 且第五幕联盟中有至少五个种族 | 玩家当初站立的地方，地板里长出一把门木的椅子。玩家以"庭之席"的身份就座，成为审判者。`court_seat` 为就座                          |
| 以上不满足                                                                 | 那里仍然只是一块空地。玩家只能作为证人，由关系最好的女神"传唤"上证人台。若 `eluen_page` 为是，玩家默认为艾琉恩的证人（她的勇者） |

庭之席认的不是玩家，是玩家身后那个被众生自己连起来的庭。玩家只是代它说话的人。

### 2.3 玩家的权限

| 权限                       | 证人         | 庭之席                               |
| -------------------------- | ------------ | ------------------------------------ |
| 陈述亲历                   | 可           | 可                                   |
| 出示证据                   | 仅在被问及时 | 每轮审理可主动出示（每轮有次数上限） |
| 传唤证人                   | 不可         | 可，经庭镜之门从箱庭传唤（见 3.3）   |
| 立案（对某位女神提出指控） | 不可         | 可                                   |
| 认定（对证据效力作出裁定） | 不可         | 可，但须通过内核校验                 |
| 提案（提出"庭之处置"）     | 不可         | 可                                   |
| 量处（终审时对女神的处置） | 不可         | 可（见 3.5）                         |
| 否决某位女神的"争掌"       | 不可         | 可，全审一次                         |

注意神约：神约第六条禁止司掌者之间直接冲突，但玩家不是司掌者，也不是任何一位女神的信徒。
在神庭里，女神可以直接对玩家出手（终战的正典依据）。若女神之间动手，即为违约，触发"诸神之战"。

### 2.4 审期与下庭

审庭里的每一场审理，对应箱庭里的约一个月。从「六司归庭」到冬至共六场：开庭、指控、质证一、质证二、陈述、终审。
审期中所有女神的 GM 工具停用，箱庭第一次真正没有照看者。内核照常模拟，五场"审期危机"依次发生，
每一场对应一位女神的领域：她不在，她的领域会不会塌。

| 危机     | 领域   | 发生于 | 内容                                                 | 自持的条件（任意组合，内核按权重结算）                                       | 失败                             |
| -------- | ------ | ------ | ---------------------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------- |
| 无光之祷 | 艾琉恩 | 指控   | 祈祷无人应答，圣骑士的加护减弱，末日教派煽动暴乱     | 无神之礼已推行；结衣的无旗医队；全录之日后离教的主教投入救护；人簿社区的互助 | 某城陷入内斗与私刑               |
| 残澱之潮 | 瓦尔妲 | 质证一 | 决战后的残澱在各地化为魔物潮                         | 澱哨网；冒险者公会；各国军队；`held_unaided` 高                              | 一个郡沦陷                       |
| 契约停摆 | 梅尔卡 | 质证二 | 契约加护冻结，契约失去神力担保，金湾赖账成潮         | 凡约；门券；哈特与奈拉的凡人信用；`econ_indep` 高                            | 金湾挤兑崩盘，粮路中断           |
| 冬前之荒 | 希尔薇 | 陈述   | 没有人调节天气，秋收不稳；灵泉无人看护               | 门路运粮；灰铁农具；各族互济；德鲁伊与萨满凭经验应对                         | 饥荒                             |
| 铭录静默 | 莫伊拉 | 陈述   | 铭录只读不写，不再授予称号与技能；公会无法给新人定级 | 人簿；学院与史官的凡人记录；行会共和或学士宪政的凡人定级                     | 冒险者委托体系停摆，社会定级混乱 |

**冬前之荒的关键事实**：希尔薇最怕的是"她不在，灵泉就会停"。审期中灵泉没有停。它本来就会自己转。
庭镜会让她亲眼看见这一点（她的必要防线最关键的证据）。

**下庭**：每场危机发生时，庭镜上会出现一扇门。玩家可以穿门回到箱庭亲自处理（以玩家的战力，几乎一定能解决）。
代价：

- 玩家缺席当场审理。若当场是质证，女神们获得一轮无人反驳的陈述，各自的防线厚度加一，或一位待传证人因无人传唤而错过出庭。
- 该危机按"下庭解决"计分（见下）。
- `descents` 加一。

**审期自持分** `review_score` = 五场危机得分的平均：自持 1，勉强 0.6，下庭解决 0.5，失败 0。
它是离手结局的必要条件之一，也是第六幕证据 E27 的来源。

设计意图：玩家一定会想回去。回去是对的吗？这正是诸神两千年来每天面对的问题。

## 3. 审判的结构

### 3.1 开庭

1. 玩家穿过封门，与夜羽一同落在候见厅。灰尘、纯白、远处那片亮，一切与序章相同，只是这一次没有人在隔壁面试。
2. 诸神依次入席。他们第一次看见完整的雅努（第六司的名字在开庭时第一次被说出，`a6_name_spoken`，见揭示台账 M02-C11）。瓦尔妲先开口："……好久不见。"雅努："你的剑还断着。"
3. 庭之席判定（2.2）。
4. 莫伊拉起身，以书记官的身份宣读："审期记录，第一页。"她翻开的那本书，第一页写着序章候见厅里发生过的一切，
   包括玩家当时的每一句回答（由序章实际对话生成）。
5. 莫伊拉："按惯例，审定前，诸司各陈其绩。……不过这一次，"她看着玩家，"好像多了一位。"

### 3.2 指控

每一方依次提出"指控状"（AI 依人格与本周目世界状态即兴，下表为锚点）。

| 指控者         | 指控对象与要点                                                                                                                             |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 艾琉恩         | 雅努：门带来混乱，她想独掌全庭，编外者是她的工具、"魔王的先驱"；瓦尔妲：泄露排澱之约，背叛；莫伊拉：全录之日"操纵历史"；希尔薇：庇护烙印者 |
| 瓦尔妲         | 艾琉恩：伪善，主谋大断绝，却管排澱叫"光的胜利"；梅尔卡：懦夫；希尔薇：没用；莫伊拉：看戏；雅努："你当年为什么不打回来？"                   |
| 梅尔卡         | 拿出账本：谁欠谁、谁买过什么。艾琉恩用商路买她沉默；瓦尔妲买过军火。她公开表示"谁出价，我就替谁作证"                                       |
| 希尔薇         | 所有人，包括她自己："我们。"她只说了这一个字，然后沉默                                                                                     |

| 雅努           | 五司：合谋毁门、封印她、禁她的名、误读规约两千年                                                                                           |
| 庭之席（玩家） | 可立案：依手中证据对任意一位女神提出指控（含雅努）                                                                                         |

### 3.3 质证

**防线**：每位女神有三道防线，每道有"厚度"。

| 防线     | 她在守什么           | 例                         |
| -------- | -------------------- | -------------------------- |
| 事实防线 | 否认或淡化事实       | "大断绝是众议，我只是执行" |
| 正当防线 | 承认事实，但辩称正当 | "关门是为了秩序"           |
| 必要防线 | 辩称庭离不开她       | "没有我，人族会互相吞食"   |

**击破规则**：玩家出示的证据带有"对象与防线"标签和强度（1 到 3）。同一道防线上累计强度不小于厚度即击破。
同一件证据对同一道防线只计一次。三道全破，她的立场崩塌：可被说服（若有"出路"），或可被判离手。

**内核与 AI 的分工**：证据是否在玩家手中、标签是否匹配、强度是否足够，全部由内核校验；
女神 AI 只负责"如何表现被击破"（她的台词、神态、反击），不能否认一道已被内核判定击破的防线。
玩家的自由文本论述由 AI 评估说服力，最多给一道防线加 1 点强度；不允许仅凭口才击破防线（"模型提议，内核裁决"）。

**传唤证人**（庭之席专属）：经庭镜之门把箱庭中的人物请上证人台。证人受其知识层级约束，
只能陈述亲历；其证词若与世界状态记录矛盾，内核标记为"不实"。

### 3.4 陈述

**诸神的陈述**：每位女神一段最后陈述（锚点见第 5 节）。

**庭之陈述**（庭之席专属）：玩家代庭陈述。内核从全大陆 NPC 的记忆中抽取"众生之声"：
十到二十条短句，来自玩家真正打过交道的人（边石镇的镇民、瓦伦堡的商人、战线上的士兵、遗民的孩子），
内容是他们在审期里做过的事（"神不应了，我们就自己互相应"）。抽取规则：只取有世界状态记录支撑的事件；
每条注明说话者；不许捏造。

**回问**：庭之陈述的最后，玩家可以把序章里每位女神问过玩家的问题，原样问回给她。
这是全作的角色反转：当初被面试的人，此刻坐在面试官的位置上。

| 回问                                                   | 被说服时的锚点回答                                         | 未被说服时                                 |
| ------------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------ |
| 对艾琉恩："你凭什么值得被选中？"                       | "……我不必被选中。"                                         | "因为我是光。"（她自己听出了这句话有多空） |
| 对瓦尔妲："你打过架吗？输过吗？"                       | "输过。输给她，也输给你们。……输了还能站起来，这才叫打架。" | "我没输过。"（雅努在旁边笑了一声）         |
| 对梅尔卡："你能带来什么？"                             | "……我能把我自己带走。这笔买卖，我认。"                     | "一切。"（她报出一个数字）                 |
| 对希尔薇："你想念什么？"                               | "想念他们小时候。……可他们已经长大了。"                     | 沉默                                       |
| 对莫伊拉："你的故事，是从哪一页开始的？"               | "从我把笔放下的那一页。"                                   | "从第一页。我一直在第一页。"               |
| 对雅努（序章没有问过玩家，玩家问她）："你为什么开门？" | "为了有一天，不用再开。"                                   | "为了让门一直开着。"                       |

### 3.5 终审

每位女神的终审状态 `verdict_<司>`：

| 状态     | 含义                                                 |
| -------- | ---------------------------------------------------- |
| 自愿离手 | 被说服，自己选择退场                                 |
| 被判离手 | 立场崩塌但未被说服，由庭之席量处"逐"，或在终战中败北 |
| 拒绝     | 不退场，也不争掌（想维持现状）                       |
| 争掌     | 宣称自己应独掌全庭                                   |

**量处**（庭之席专属，对立场已崩塌的女神）：

| 量处   | 内容                                                               |
| ------ | ------------------------------------------------------------------ |
| 逐     | 被判离手，立即退场                                                 |
| 凡行   | 以凡身在箱庭行走一段时日，再退场（用于"让她亲眼看见"；后日谈内容） |
| 交接令 | 退场前须完成其领域的交接（见 11.1 的交接表）                       |
| 赦     | 不附条件                                                           |
| 留凡   | 允许她放弃司掌，以凡人身份留在箱庭（仅限本人请求，如梅尔卡）       |

**否决**：任何女神"争掌"时，庭之席可否决一次。被否决后她只能拒绝或离手；若两位以上女神同时争掌且无人否决，
她们之间的冲突进入"诸神之战"的倒计时。

## 4. 证据系统

### 4.1 规则

- 证据在全作中获得，存于玩家日志的"证物"页。每件证据有：编号、名称、来源幕次、获取方式、证明内容、对象与防线、强度。
- 证物带有"知识层级"：在揭示台账解锁之前，证据只能被玩家查看，不能在 NPC 面前引用。
- 部分证据可"组合"：两件以上同时出示，强度相加并另加 1（例：E01 阿什证言与 E02 主门剑尖）。
- 动态证据（E27 审期记录、E34 神迹账与箱庭离手指数）的强度由本周目的实际世界状态与内核日志计算。
- 证据也可以为女神"减轻"：用于打开"坦白"的出路，而不是击破（例：E25 对希尔薇）。

## 6. 雅努的真实意图

### 6.1 复原之门

**时机**：五位在任女神中至少三位立场崩塌之后。

**场景**：

1. 雅努起身。"那么，就让我回来吧。"
2. 她对玩家说：千门回廊的尽头，有一扇玩家从第三幕起就看得见、却从来打不开的门：复原之门。
   它需要所有的钥：门钥、遗民的门纹、玩家开过的每一扇门。"你已经替我开了那么多扇。只差这最后一扇。"
   七枚门钥里，一枚主钥锁主门，其余六枚各开千门时代的一条干线（东、南、东南、北、西与天线）；复原之门要七枚齐聚。
3. 她让玩家先看门后。门后是一张新的门网图：比众门环大得多，覆盖整个大陆，每一条线都经过同一个中心。
   中心是一扇门的形状。
4. 雅努："我只想让这个世界重新连起来。"（序章以来她对玩家说过的目标，正典锚点）
5. 玩家可以追问"为什么每一条线都要经过你？"。她的回答是全作对她最重要的刻画：
   > 雅努："因为上一次，我放手了。我以为他们自己能守住门。然后，他们就把门砸了。"
   > 雅努："这一次，我想守着。只守一阵子。等他们真的准备好了……"
   > 雅努："……我会放手的。"
6. 莫伊拉在书记桌后轻声说："你看，又一位想当作者的。"
7. 艾琉恩此刻会抓住机会："我说过，她也想独掌！"（她的谎言里那一粒真）

**揭示**：谜团 9"第六位女神是谁，她到底要什么"在此正名。她是雅努，门扉与可能之司；她要的有两样，
一样是证明她的读法是对的，一样是回来。第二样会让世界又回到被照看的状态。

**她的过往"丢弃"**：E17 与 E18（无貌者）、E32（第五幕她的出手）、以及她从未告诉玩家"每开一扇门封印就松一分"，
都在此刻摆上证物台。她从不直接说谎，但很会选择说哪一部分（正典）：玩家此刻可以列出她没说的每一部分。

### 6.2 说服她"也要离手"的条件

**必需**（全部满足）：

1. 共读已完成（第 7 节）：她的读法被证明是对的，于是她无法再用"我读对了，所以该由我来"作理由，
   因为她读对的那句话本身要求她放手。玩家的关键台词："你读对了。所以，你也得放手。"
2. `janu_act` 为接人；或为封隙但玩家出示 E32 并指出"那是你替他们做完的"。
3. 玩家提出"我也放手"：愿意在离手之门（第 9 节）中归还千门。

**辅助**（至少满足三项）：

| 辅助条件           | 变量                                 | 她的反应                                   |
| ------------------ | ------------------------------------ | ------------------------------------------ |
| 众门环不靠她也运转 | `gate_ring` 不少于 5                 | "……门在转。我不在，门也在转。"             |
| 她面对过自己的失败 | `faceless_end` 为救赎且她道过歉      | 她不再需要用"这一次守住"来弥补"那一次放手" |
| 遗民的心声         | 传唤门歌者塔维，`remnants` 不少于 40 | 塔维："开门的母亲。我们会自己开门了。"     |
| 有人先放手         | `verdict_sylvie` 为自愿离手          | 希尔薇："我先走。……你看，没有那么难。"     |
| 信使的请求         | 夜羽线完成                           | 夜羽："我等了你一千年。现在，换你别等了。" |
| 守门人的请求       | 阿什存活且被传唤                     | 阿什："我守了一千年的门。让我也休息吧。"   |

**辨析"放手"与"丢弃"**（本作主题的最后一块拼图，必须在此场景中由某个角色说出，默认为玩家，玩家不说则由希尔薇说出）：

> "放手不是丢弃。丢弃，是因为你怕它；放手，是因为你信它。"

候见厅里艾琉恩丢下玩家，是丢弃；978 年雅努放下无貌者，是丢弃；回收，是最大的丢弃。离手是放手。
离手结局中，每一位女神在离开前都要完成"交接"（11.1），这是放手与丢弃在玩法上的区别。

**说服失败**：她拒绝，并请玩家开启复原之门。玩家可以开（门之复辟），可以拒绝并迎战（千门回廊之战，第 9 节），
也可以接受她递来的另一样东西：她的全部权能（新神）。

## 7. 原始规约本意的揭示：共读

### 7.1 前提

- E19：希尔薇交出灵泉中的雅努记忆（她立场崩塌或自愿离手时交出；若根下庭被毁且她未被说服，须经"冬眠"段落取得）。
- 莫伊拉的"第零页"：开园记。她在第四幕说"那一页要留到最后一章"。她在此刻拿出来。
- 可选 E30：原龙艾斯卡在庭镜中作证。E31 可作辅助。

### 7.2 场景

1. 莫伊拉把第零页放在庭镜旁。上面是原始规约的古庭语原文，以及开园那一天她的第一行笔记："园成。那一位未留。"
2. **莫伊拉的部分（文本）**：她指着规约中四个"其"字。
   > 莫伊拉："护其生，导其长，勿使枯，勿使乱。这四个'其'，两千年来没有人争过：护的是庭的生，导的是庭的长。"
   > 莫伊拉："同一段话里，同一个字。到了最后一句'审其可离手否'，我们五个，忽然都把它读成了'汝'。"
   > 莫伊拉："……因为我们想。"
3. **雅努的部分（记忆）**：灵泉记忆在庭镜里重现。开园之日：造主把箱庭放下，手覆在新种下的庭上。
   六司站在六个隅角，五位都低头看着自己的那一隅。只有雅努站在门口，回头看着来处。
   她看见那只手慢慢松开。手松开的时候，有几样东西从掌中落进了庭里：原龙。
   然后那一位穿过门离开了，没有回头。
   > 雅努："那一天，你们都低头看着庭。只有我，回头看着门。"
   > 雅努："祂不是把庭交给我们。祂是松开了手，然后叫我们看着，等有一天，我们也能松开。"
4. **艾斯卡的部分（确证，若在场）**：庭镜中，银色的龙睁开一只眼。
   > 艾斯卡："我是被放下的。那一位种下之后，就松开了手。我们，是那只手松开时落下的东西。"
   第五幕"我是被放下的"在此回扣；正典"造主种下箱庭，放下原龙"的"放下"二字在此换了意思。
5. **合读**：莫伊拉与雅努一同念出那一句：
   > 「千年一审，审其可离手否。」
   > "审的是这座庭，能不能像那一天一样，被松开手。"
6. 回扣：瓦尔妲在第四幕的版本里说过"第六个那家伙说，审的是能不能放手"。瓦尔妲此刻小声说："……原来我当年吵输的，是这个。"
7. 谜团 10"审定在审什么"揭开。

### 7.3 后果

- 五司对审定的旧解读全部失效。争掌的理由从此只剩"我想要"，再也不能是"规约要我"。
- 莫伊拉："未，即尚未。尚未什么？……尚未学会放手的，是我们。"（回扣她在第一次审定后的批注）
- 雅努的处境反转：她读对了，于是她也必须放手（6.2 的必需条件一）。

## 10. 冬至审定

**场景**：终审与终战结束后，庭镜里的箱庭迎来冬至。大陆上七座天启碑同时亮起；同一时刻，神庭上方那片亮闪了一下，
和序章里一模一样。

这一次，没有女神问"上面在看吗"。

莫伊拉翻到审期记录第一页，看着序章那一幕的记录，看着光闪的那一行在哪里：不在鉴定的时候，不在面试的时候。
那一闪，发生在她们把一个不合规格的灵魂判作"瑕疵品"、而艾琉恩说出"我没有慌"的那一刻（序章 P13）。

当时问"上面在看吗"的是梅尔卡，答"上面从来不看过程"的是艾琉恩（序章固定了问答双方，就为了这一刻）。

> 梅尔卡：（很轻）"……祂在看。"
> 艾琉恩：（很久以后）"……我说错了。"
> 莫伊拉："祂看的不是我们选谁。祂看的是我们怎么对待一个不合规格的人，还有我们怎么对自己说谎。"
> 莫伊拉："那场面试，被面试的，是我们。"
> 雅努：（轻声，对玩家）"题是我借她们的嘴出的。我想知道，一个被所有人否定的人，能不能自己站起来。你站起来了。"

**回扣**："上面从来不看过程"被推翻：造主在乎的，恰恰是过程。愿景中"最后我才明白，开场那场面试在面试什么"在此兑现，
答案有两层：雅努借诸神之口出题，测这个灵魂在被全体否定之后能否自己站起来（`../../00_vision/decision_log.md` D-038；第六把椅子当时只有玩家看得见）；
同一场面试里，诸神如何对待一个不合规格的人，也被那一位看在眼里。
（序章中女神们对玩家的每一句话，都是本周目真实发生过的 AI 对话，由审期记录第一页原样保存。）

然后，碑上显现结果（见第 11 节各结局；审定只给出「未」或「可」，其输入除第 11 节的判定条件外，还包括 E34 附带的箱庭离手指数 `release_index`，D-043）。

#### 11.1.7 离手·未竟（变体）

**条件**：诸神退场条件与雅努放手均成立，但以下任一不成立：`purge_route` = 众生、`gate_ring` ≥ 5、
`held_unaided` ≥ 3、`janu_act` = 接人、`review_score` ≥ 0.6、`autonomy` ≥ 60。即：诸神都愿意放手了，但庭还没有证明它能自己站住。

**天启碑**：「未」。

**终局**：诸神没有离开。她们在庭之席的提案下订立"守望之约"：此后一千年，除非庭面临回收级的灾难，诸司不得干预。
莫伊拉在书上写下："未，即尚未。这一次，我们知道尚未什么了。"
玩家可选择留在神庭作为庭之席的守席人，或回到箱庭。

本变体已列入正典结局表（`../../20_world/world_bible.md` 第 14 节，见第 17 节）：它让"放手做对了一半"的玩家得到一个温和但不完整的结局，而不落入某神之治。

## 12. 后日谈生成规则：莫伊拉的最后记录

### 12.1 总体结构：反向拉近

全作按"逐层拉远"推进；后日谈反过来，从最高处一层层拉近，最后落回玩家自己。

| 序  | 层   | 条目数                         | 例                       |
| --- | ---- | ------------------------------ | ------------------------ |
| 1   | 诸神 | 每位女神一条                   | 莫伊拉写自己时用第三人称 |
| 2   | 诸族 | 三到五条                       | 魔族、遗民、龙族优先     |
| 3   | 诸国 | 三到五条                       | 庭外之国必写             |
| 4   | 王国 | 一到二条                       | 洛萨或其继承者           |
| 5   | 城市 | 一到二条                       | 瓦伦堡                   |
| 6   | 小镇 | 二到三条                       | 边石镇必写；醉月亭必写   |
| 7   | 同伴 | 每位存活或有结局的主要同伴一条 |                          |
| 8   | 玩家 | 一条                           | 最后一条                 |

条目选择：除"必写"外，按"显著度"排序取前若干条。显著度 = 该实体在全作中的状态变化幅度 + 与玩家的关系强度 + 是否在审期危机中出现。

### 12.2 单条模板

```
【题】实体名（地点、人物、族群或国家）
【时】审定后第 N 年（N 取 1、10、100 之一；离手结局可加一条"很久以后"）
【录】两到四句：
      第一句：一个由世界状态直接支持的事实。
      第二句：一个具体的细节（物件、习惯、一句话）。
      第三句（可选）：后来的变化。
      第四句（可选）：莫伊拉式的点评，最多一句。
【注】（可选）一句伏笔或笑点。
```

示例（离手，温柔）：

> 【题】醉月亭
> 【时】审定后第十年
> 【录】玛莎还在擦那只杯子。墙上多了一张写着"F"的座签，是一位国王托人从帝都捎来的，说是"公会终于改了"。
> 她一次也没跟客人提过那张座签的来历。
> 【注】有人问她当年那一刀是怎么斩的，她说："喝你的酒。"

示例（某神之治·艾琉恩）：

> 【题】边石镇孤儿院
> 【时】艾琉恩之治的第一年
> 【录】孤儿院改名为"光之育幼所"。手背有纹的孩子们在入院第一天被带走，没有人知道去了哪里。
> 欧拉婆婆在审判台上没有为自己辩护。

### 12.3 输入

| 输入         | 内容                                            |
| ------------ | ----------------------------------------------- |
| 世界状态     | 三幕全部变量                                    |
| 事件日志     | 内核记录的关键事件（谁、在哪、做了什么、结果）  |
| NPC 记忆摘要 | 每位同伴与重要 NPC 关于玩家、关于审期的记忆摘要 |
| 结局与基调   | 结局类型；离手的温柔或艰难                      |
| 揭示台账     | 已揭示的真相集合                                |

### 12.4 约束

1. **事实来源**：每条【录】的第一句必须能回链到一条世界状态或事件日志；不得为已死亡的人物写存活后的事；不得写未发生的战役。
2. **正典边界**：不得引入新的神、种族、国家或宇宙层；不得回答谜团 12（造主是谁）；不得揭示揭示台账未解锁的真相。
3. **命名**：各国首脑与跨国组织领导层只用头衔；新出现的人物只允许是无名的"一个孩子""一位旅人"。
4. **语气**：莫伊拉的口吻（优雅、调侃、偶尔打破第四面墙），但每条至多一句点评；全部后日谈中至少三条带轻快的笑点（基调要求：幽默感不丢）；
   离手的"艰难"基调减少笑点但不清零。
5. **篇幅**：每条不超过四句；全部后日谈的阅读时长控制在五到八分钟。
6. **结局专属的笔迹**：离手结局最后一条由凡人史官续写，字迹不同，语言更朴素；新神结局用账本格式；门之复辟以"你来了"起句；回收只有半句。
7. **字符**：遵守 `../../../CLAUDE.md` 的禁用字符规则；所有显示文本经本地化。
8. **降级档**（愿景要求无网络时可完整通关）：每个可能出现的条目都有一份预写模板，含插槽（姓名、数字、地点、选项结果）。
   无大模型时，由规则按显著度选择条目并填充插槽；有大模型时，模型在模板含义之内润色，不得改变插槽中的事实。
9. **校验**：生成后由内核逐条比对世界状态，违反第 1、2、3 条者丢弃并回退到降级模板。

### 12.5 "很久以后"（仅离手结局）

离手结局的最后一层之前，插入一条"很久以后"，固定写两件事之一（依世界状态选择）：

- 一位天文学家（赫尔加的某代学生）发现星辰不再那么整齐了；终雾比记载中退远了一些。
- 一个孩子问祖母，以前真的有神吗。祖母说："有过。后来，祂们放手了。"孩子以为这是故事。

这是把箱庭与地球连起来的最后一笔：箱庭正在走地球走过的路。

## 14. 隐藏结局：造主的房间

### 14.1 触发条件

- 达成离手结局；
- 在离手之门中归还了全部千门（`returned_doors` 为全部）；
- 谜团 1 到 11 全部揭开（`mysteries_revealed` 包含 1 到 11）。

### 14.2 门出现的地方

- 若玩家留下：后日谈与职员表之后，玩家回到千门回廊。回廊已经空了，每一扇门都已归还。但尽头多了一扇门。
  它的样子，是序章里地球上那扇"本不该存在的门"（依 `prologue.earth_opening`：末班车到站时打开的车门、便利店冰柜玻璃里映出的那扇门、医院安全出口标志下的门、老宅衣柜的门）。
  雅努已经离开，但若夜羽留下，夜羽会说："……这扇不是她的。"
- 若玩家回去：职员表之后，玩家在地球上自己的房间里醒来。房间的墙上多了一扇本不该存在的门。

这扇门不是雅努的门。本作不说明它是谁的。

### 14.3 房间

推开门，是一间小屋。

| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 大小     | 很小，像一间书房，比候见厅小得多，比门内庭院最初的那间小屋大不了多少                                                                                                                                   |
| 桌子     | 一张木桌，桌面有使用多年的划痕                                                                                                                                                                         |
| 椅子     | 一把椅子，推开着，像刚有人起身                                                                                                                                                                         |
| 桌上     | 一封信，信封上写着玩家在序章里给自己起的名字；一只放凉的杯子；一叠草稿纸，最上面几张是箱庭的草图：大陆的轮廓、六个女神的速写（画风与游戏内立绘略有不同，是"早期设定"的样子）、一张划掉了很多遍的结局表 |

最后一个镜头：箱庭的夜空（若留下）或地球的夜空（若回去），一颗星，稍微偏离了它该在的位置。

**造主也在被审定的暗示**：不用任何文字说出。由三个元素共同构成：石板上那个像「未」的字；第二扇门后的人声与门缝的光
（造主的房间本身就是一间候见厅，祂也在等着被叫进去）；光的一闪。

### 14.4 "开发者的信"的写作要求

本文不写信的正文。信由开发者本人撰写，须满足以下要点与语气。

**必须表达的要点**：

1. **称呼**：以玩家在序章里起的名字（`prologue.player_name`）开头。
2. **谢意**：朴素地感谢玩家走完这一程，不夸张，不煽情。
3. **具体的一笔**：信中留一到两句插槽，由世界状态填入玩家这一周目里真实发生过的一件事
   （例如：哪位同伴活了下来、玩家为国家选了什么国体、玩家是否回去了）。插槽内容须经内核校验，且有降级模板。
4. **照看者的坦白**：开发者承认自己也是一个照看者：发布过天启（版本修订），也很多次想伸手去改玩家的世界，
   也不确定自己做得对不对。
5. **放手的意图**：表达开发者也打算在某一天"离手"，把这个世界交给玩家与后来的人，而不是永远守着它。
6. **不完全的回答**：承认自己也不知道"门那边"是谁，也在等着被叫进去。对应谜团 12 的"不完全回答"，不得给出确定答案。
7. **结尾**：一句简短的告别，或一句与"门"有关的话，但不得直接引用游戏内任何角色的锚点台词。

**语气**：

- 平实、真诚，像写给一位一起熬过一段日子的朋友；可以有一处轻微的幽默（例如提到玩家在公会卡上一直是 F 级）。

**禁止**：

- 说教，或直接点题（不许出现"这个游戏的主题是"之类的句子）。
- 解释游戏内尚未揭示的设定，或推翻正典。

- 仓库禁用字符（破折号、emoji、U+2600 到 U+27BF 区间的符号）。
- 篇幅超过一页（建议四百到七百字）。

**本地化**：信的正文进入本地化流程，各语言版本由译者以同样的要点与语气重写，而不是逐字直译。

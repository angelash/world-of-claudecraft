## 0. 本章定位

| 项             | 内容                                                                                                                                       |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 舞台           | 地球的最后一刻（一个房间大小的日常场景），然后是神庭的候见厅（只闻其声，不见神庭全貌）                                                     |
| 规模           | 诸神，但只给"声音"（叙事规则 1）：不展示箱庭地图、不展示历史、不展示神庭以外的任何宏观画面                                                 |
| 时长           | 有模型时 25 到 45 分钟；无模型档 15 到 20 分钟                                                                                             |
| 玩法           | 角色创建（姓名、外貌、前世）、与 AI 女神自由对话、偷听、被拒、坠落                                                                         |
| 情绪曲线       | 平淡的疲惫，诧异，好奇（候见厅），被审视的紧张（面试），被冒犯与不甘（丢弃），黑暗里的一丝温暖（接住）                                     |
| 三拍           | 落地：地球最后一刻、候见厅、面试；暗面：鉴定、判决、丢弃；拉远：坠落与"接住你了"                                                           |
| 不可改变的结果 | 玩家一定会被艾琉恩判为"规格外"并丢进庭间之隙；一定会拿到梅尔卡的硬币；一定会听到"接住你了"。玩家的言行只改变"怎么发生"和"女神们记住了什么" |

### 0.1 设计意图

1. **一次性给出全部高层概念，但只给关键词**：名额、审定、两年、那件事、上面、规格、页面。
   玩家离开序章时应当"记得这些词，但不懂"。
2. **面试即角色创建**：玩家以为自己在争取被选中，实际上每一个回答都在被五个立场不同的
   考官各自解读，并成为她们对玩家的第一份记忆（后续幕次的 AI 题面会读取）。
3. **玩家无论表现多好都会被丢弃**：这是全作第一次"凡人眼光不可信"（女神的眼光也不可信）。
   表现越好，被丢弃时的反讽越强；艾琉恩的嫌恶是恐惧的伪装（【真相】，第三幕揭示）。
4. **面试在面试什么**：愿景"真相"一行说"最后我才明白，开场那场'面试'在面试什么"。
   【真相】这场面试真正的考官不在桌后：雅努在借这个场合确认，这个从已离手之庭来的灵魂，
   能不能在被所有神否定之后仍然自己站起来。女神们问的五个问题，其实是在替雅努出题。
   本文不向玩家透露这一点，只保证每个问题在第六幕都能被重新读一遍。

节拍规则：

- P7 到 P11 的顺序固定。每位女神的自由对话设"软上限"六轮玩家发言、"硬上限"十轮；
  到达软上限后由提问女神主动收尾，到达硬上限由莫伊拉敲桌（"下一位"）强制推进。

| 前世之门 | 对应前世（AI 将自由回答归入最近的一类） | 开局差异                                       | 第一幕的额外用途                                             |

| 算盘     | 职员、会计、销售、程序员等案头工作      | 交易时看到商品的大致进价区间                   | 识破奈拉囤货的利润率，盐与药纷争多一个谈判选项               |
| 夜灯     | 夜班工作者、店员、保安、夜猫子学生      | 夜间视野更远，夜间行动不额外消耗体力           | 兽潮之夜的黑暗惩罚减轻                                       |
| 白衣     | 医护、护工、照顾过病人的家属            | 脱战后可包扎（小幅恢复），能辨认病症的早期迹象 | 第一次见到病童就能指出"不是传染病，像中毒"，澱病调查提前一拍 |

## 3. 候见厅：帘幕后的争吵（固定台词稿）

本节同时是：无模型档的固定文本；有模型档下五位女神的"锚点剧本"（AI 可以增删插话、调整措辞，
但五段的顺序、每段的关键词与每段结尾的信息量不可变，不得新增任何真相）。

### 3.1 偷听机制

| 玩家位置           | 听到的内容                                                                                                           |
| ------------------ | -------------------------------------------------------------------------------------------------------------------- |
| 远（长椅、灵镜旁） | 每段只听到标注【远】的模糊片段，括号内为听不清的部分                                                                 |
| 中（帘幕前三步）   | 听到完整台词，但说话者身份只能靠口吻分辨                                                                             |
| 近（贴着帘幕）     | 完整台词，并且在第四段结束时帘幕缝隙里透出一线光，玩家看到一只悬浮翻动的书（莫伊拉）与一枚旋转的硬币（梅尔卡）的影子 |
| 弄出声响           | 当前段落立即中断，三秒寂静，梅尔卡："……风吧？"随后从下一段开始，音量降低一档（近变中，中变远）                       |

偷听档由争吵开始前的一次姿态选择决定，有模型与无模型相同，不按玩家在段落之间的站位实时计算。

偷听程度记入 `p_eavesdrop_level`（0 到 3），影响：莫伊拉在 P6 的第一句话
（若为 3："偷听是个好习惯，我也有。"），以及第一幕夜羽解锁某段记忆时的提示文本。

### 3.2 第一段：名额

> 梅尔卡：四个。亲爱的，你一口气要了四个名额。按信仰份额算，你这次可是把账做得满满的。
> 艾琉恩：份额就是份额。四个，合规格，每一个都经过挑选。
> 瓦尔妲：挑选？你挑的是哪种？听话的那种吧。
> 艾琉恩：勇者需要的是秩序，不是你那种只会咬人的野狗。
> 瓦尔妲：哈！我那一个，一个人顶你四个。
> 莫伊拉：两位，请注意措辞。我在记。
> 瓦尔妲：你什么时候不在记？

【远】"四个……（听不清）……名额……按份额……（笑声）……野狗……"

### 3.3 第二段：多出来的一个

### 3.7 台词稿的约束（AI 与写作共用）

- 五段的关键词：名额、杂质、两年、"未"、那件事、神约、名字、上面。AI 改写时必须全部保留。

- "第六把椅子"只作画面声响，任何女神都不提它；玩家在 P6 问起空椅子时，统一回应见第 4.7 节。

## 4. 面试

### 4.1 总则

- **形式**：五位女神坐在长桌后，按艾琉恩、瓦尔妲、梅尔卡、希尔薇、莫伊拉的顺序提问。
  提问者是本轮主角，其他女神可以插话（每轮最多两次，由各自人格触发），希尔薇那一轮其他人不插话。
- **状态**：每位女神对玩家有两个数值：好感（`impression`，-3 到 +3，起始值 0）与兴趣（`interest`，0 到 3，起始值 0），
  外加最多三条"记忆标签"（`memory_tags`，短语，进入该女神后续所有幕次的私密题面）。
  好感决定她以后愿不愿意帮玩家；兴趣决定她以后会不会关注玩家。两者可以背离（瓦尔妲常常讨厌而有兴趣）。
- **分类器**：有模型档下，每轮结束由一个小型分类调用把玩家的全部回答归入本节映射表中的一个类别
  （可附一个次类别），内核按表结算；女神 AI 本身不直接改数值（"模型提议，内核裁决"）。
- **共同已知**（五位女神的题面都有）：四名勇者的名单与加护；名单只有四人；号码发出了五张；
  两年后冬至是第二次审定；"那件事"与"不提名字"的约定（只作为私密背景，不得说出内容）。
- **共同盲区**：谁把玩家放进来的；玩家灵魂上的空洞是什么（直到 P12，艾琉恩一人认出，她不说）；
  空椅子（她们看不见，见 4.7）。

## 7. 无模型档：分支对话树（精简版）

没有大模型时，序章按下列节点推进，全部文本写定。节点编号对应节拍；"→"后为结算（见第 4.8 节类别）与下一节点。

**N2 门（P2）**：

2. 转身离开 → 门出现在下一个转角。第二次离开 → 门在更近处。第三次离开 → 门开了一条缝，有风，玩家走过时门自己开了 → N3（`p_door_attempts_refused` 记次数）。

**N3 候见厅（P3 到 P4）**：号码牌"伍"。灵镜（外貌与性别界面）。可选交互：

2. 走近帘幕 → 此时帘幕后无人（只有风）。
3. 坐长椅 → 等待。
   三项任选，完成灵镜后 → N4。

**N4 帘幕（P5）**：选择姿态：

**N9 希尔薇（P10）**：（闭着眼）"……你想念什么？"

   听完沉默两三秒，不评价。
3. "什么都不想。" → S3。希尔薇："……会想的。以后。"
4. "想念没有神管的日子。" → S4。希尔薇沉默；艾琉恩的光环亮了一下。
5. "你呢？你想念什么？" → S5。希尔薇轻轻摇头，不答。
6. （很久不说话） → S6。希尔薇："……嗯。"
   → N10。

**N10 莫伊拉（P11）**：（墨水滴在卷轴上）"最后一个问题，也是我最喜欢的：你的故事，是从哪一页开始的？"

1. "从我出生那天。" → O1。莫伊拉："经典开头。经典开头的故事，结尾通常不经典。"
2. "从我推开那扇门。" → O2。莫伊拉："哦？你这就是在写序章了。"
3. "从我失去某样东西的那天。" → O3。莫伊拉："好故事都从缺了一块开始。"
4. "普通地上班上学，没什么好讲的。" → O4。莫伊拉："平凡的人。我的书里平凡的人最多，也最难写。"
5. "还没开始。就从这一页开始。" → O5。莫伊拉："我喜欢空白页。非常喜欢。"
6. "我不想被你写进去。" → O6。莫伊拉："拒绝被写，也是一种开头。"
   追问："那一页上，你是做什么的？"列出八种前世（第 2.2 节）加"你替我写吧"（取开场默认推荐，标签"被代笔的"）。
   前世写定之后，莫伊拉："再问一句，不算分：这一章的结尾，你希望是什么？"（好的结局 / 还没想好 / 我自己写），
   回应依次为"好结局啊。我的书里，好结局都很贵。""没想好最好。想好了的，往往写不出来。""哦？那我等着读。"
   若此前未触发地球锚点：莫伊拉："那一页上，是什么地方？"玩家任选"地球"或"不告诉你"；后者由梅尔卡读出遗物上的字。艾琉恩插话触发地球锚点。
   → N11。

**N11 鉴定与判决（P12 到 P13）**：播放第 5.1、5.2 节。回应窗口五选一（第 5.4 节 R1 到 R5）。
梅尔卡赊出硬币，条款按估价。→ N12。

**N12 丢弃（P14）**：最后一句话四选一（第 5.4 节）。播放第 5.3 节。→ N13。

**N13 坠落（P15）**：可选"伸手"。"接住你了。"黑屏。"圣历九百九十八年，春。" → 第一幕。

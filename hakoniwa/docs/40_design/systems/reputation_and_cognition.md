## 0. 一页结论

1. **认知由规则，表达由模型。** 谁信什么、为什么信、信到什么程度，全部由内核按 `society.md` 第 8 节的参数确定性地计算；模型只把结果说成人话
   （`power_system.md` 第 3.6 节："由内核计算判断结果，大模型只负责把判断说出来"）。这保证了喜剧可复现、误会不失控、降级档照样好笑。
2. **证据越官方，玩家越不被相信。** 鉴定"无记载"与公会卡"Lv1、无职能"在认知层计为反证（`society.md` 第 8.1、8.4 节）。这是"凡人不信"的根本引擎。
3. **每个有名 NPC 对玩家有一份信念画像**：认知状态（无视、怀疑、解释化、动摇、接受，以及崇拜、敌视、利用、依赖四种分叉）、认知值、当前解释、
   估计强度、身份猜测、动机猜测、言辞可信度、公开表态与私下看法、推理日志。
4. **传闻是一等数据对象。** 每条传闻都锚定一个真实事件，带来源链、可信度、失真度、情感极性与热度；按 `society.md` 第 7.4 节的七条规则逐跳失真；
   离谱到超出听者天花板的版本反而不被信，"有点本事的运气好的人"版本传得最远。
5. **误会有上限，事实有锚。** 失真度封顶、每地区主流说法数封顶、公开事实压低失真、台账过滤内容；喜剧有节流。
6. **声望分个人、势力、地区、国家四层**，与"传闻画像"互为表里；机构把玩家纳入已有分类（水晶故障、实字 B、规格外者、异端、魔王的先驱）。
7. **藏拙与张扬是一组真实的取舍**：张扬带来声望、机会与信任，也抬高女神的注视度与更强者的注意。
8. **鉴定有上限，威压只给档位，情报带来源与可信度**；对玩家而言"看不透"永远存在。
9. **过度解读者**把玩家的随口一句扩写成计划；玩家真实意图与 NPC 解读分开存储，留推理日志，有上限，可默认、追问或纠正。

## 1. 目标：三种体验如何由系统自然产生

| 体验     | 系统来源                                                 | 典型循环                                                                                                     |
| -------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 凡人不信 | 测量工具失灵（铭录无页）、世界观上限、解释库、认知状态机 | 玩家做到不可能的事，目击者按阶层的解释库把它"解释掉"；只有可复现、物证、多源、亲历才能推着他们一档一档往前走 |
| 误会链   | 传闻逐跳失真、主体替换、模板化、过度解读者               | 一件事经过三跳变成另一件事，被另一个人当真，再引出新的行动；系统记录每一跳，玩家可以追溯，也可以利用         |
| 谨慎     | 鉴定上限、威压档位、感知饱和、情报可信度、神之视线的代价 | 玩家对别人的判断同样不确定；张扬会被看见；"看不透"的人永远存在                                               |

```
真实事件（内核）
   |-- 目击者：事迹判读 -> 越界判定 -> 解释或接受 -> 信念画像（认知状态机）
   |                                                   |
   |                                                   +-> 关系（敬畏、信任）-> NPC 的行为
   |-- 传闻：以真实事件为锚生成 -> 社交接触传播 -> 逐跳失真 -> 听者按可信度与天花板决定信否
   |                                                   |
   |                                                   +-> 传闻画像（地区）-> 声望 -> 价格、委托、招募、审判
   +-- 女神：信徒的见闻与传闻成为视线样本 -> 注视度（goddess_gm 第 3 节）
```

依据：测量工具失灵是"凡人不信"最高效的引擎（[anime/synthesis.md 第 2.3 节](../../10_research/anime/synthesis.md)；[anime/titles_01_25.md 第 25.7 节](../../10_research/anime/titles_01_25.md)）；
转述不是事实、认识要有证据才能升级（[my_ai_town_agents.md 第 0 节第 6 条、第 4.2 节](../../10_research/ai_npc/my_ai_town_agents.md)）；
现有 world-of-claudecraft 的传闻只回声给同一玩家、90 秒过期，是本系统要避免的反例（[woc_ai_npc.md 第 4.3 节](../../10_research/ai_npc/woc_ai_npc.md)）。

## 2. 信念画像

### 2.1 字段

信念画像（`BeliefProfile`）以"观察者、主体"为键。有名 NPC（L1 到 L3）对玩家，以及对少数重要人物（玛莎、勇者团、赛琳、萨莎、无貌者等）各维护一份；
L4 人群单元以"份额"形式维护（第 2.3 节）；女神的神之档案复用本结构（[goddess_gm.md](goddess_gm.md) 第 3.3 节）。

| 字段           | 类型                     | 说明                                                                                                         |
| -------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| 认知状态       | 枚举                     | 无视、怀疑、解释化、动摇、接受；接受后分叉为崇拜、敌视、利用、依赖（`society.md` 第 8.5 节）                 |
| 认知值         | 数值                     | 证据权重的累积（第 3.1 节）；鉴定反证会让它下降                                                              |
| 怀疑阈值       | 数值                     | 从怀疑到接受需要的认知值；阶层基准乘个人性格，再按越界幅度上调（第 3.5 节）                                  |
| 当前解释       | 解释库条目 + 黏性        | 处于"解释化"时采用的解释，例："前人打残"（第 3.4 节）                                                        |
| 已被推翻的解释 | 列表                     | 记录走过的解释，防止回头                                                                                     |
| 估计强度       | 表观位阶的点估计与离散度 | 他认为对方有多强；解释化时按解释打折（例：认为是运气时，只按事迹的六成计）                                   |
| 身份猜测       | 词表上的分布             | 例：怪人、运气好的新人、退隐的高手、贵族私生子、魔女同谋、规格外者；词表按观察者的知识层级裁剪，不得超出台账 |
| 动机猜测       | 词表上的分布             | 求财、求名、行善、复仇、传教、阴谋、逃亡、寻人                                                               |
| 言辞可信度     | 0 到 1                   | 他相信对方说的话的程度；与关系中的"信任"联动但不相同（可以信任一个人的为人，却不信他吹的牛）                 |
| 情感极性       | 枚举加强度               | 恐惧、崇拜、嘲笑、嫌恶、好奇、感激                                                                           |
| 公开表态       | 认知状态的公开版本       | 受社会压力与面子影响，可以落后于私下看法（第 3.6 节）                                                        |
| 证据账         | 列表                     | 每条证据：来源事件、类型、权重、独立性键、时刻                                                               |
| 推理日志       | 文本（规则生成）         | 每次状态变化的原因："第 3 周目击清巢（亲眼，5），解释'前人打残'被物证（完整的巢主首级）推翻"                 |
| 新鲜度         | 时刻                     | 最后一次更新；用于回落（第 3.5 节）                                                                          |

### 2.2 与模型的关系

- 信念画像以文字摘要进入该 NPC 的题面（[npc_society_ai.md](npc_society_ai.md) 第 3.3 节）："你觉得那个 F 级只是运气好，巢里的头目多半早被独眼团打残了。"
- 模型不能直接改信念画像。L1 在整理轮可以提出"我对他的看法变了"并引用证据；内核按第 3.5 节的规则判断是否采纳（采纳即一次状态转移，写入推理日志）。
- 模型的台词必须与当前认知状态一致：处于"解释化"的 NPC 不会说"他真厉害"，除非是反话。闸门见 [npc_society_ai.md](npc_society_ai.md) 第 3.5 节。

### 2.3 人群的信念份额

L4 人群单元（一户、一个工坊、一队民兵）不维护个体画像，而维护"状态份额"：例如某街区的人对玩家 60% 处于怀疑、30% 解释化（其中"运气"占三分之二）、10% 接受。
份额由传闻接触与目击按第 3 节规则成批更新，供地区声望与传闻画像使用。

## 3. 证据与解释

### 3.1 证据类型与权重

认知证据（`CognitiveEvidence`）的基础权重沿用 `society.md` 第 8.4 节（0 到 5），本文补上个人修正、清晰度与独立性：

| 证据           | 基础权重         | 本文补充                                                                             |
| -------------- | ---------------- | ------------------------------------------------------------------------------------ |
| 亲眼目睹       | 5                | 乘清晰度（远观 0.5，近看 1.0）；神职与学者仍可能把它归为幻术或道具                   |
| 可复现         | 4                | 同一类事迹第二次、第三次；使"运气"解释失效                                           |
| 物证           | 3                | 首级、大晶、王晶；尺寸越大越有说服力                                                 |
| 多源一致       | 3                | 彼此不认识的人说同一件事（独立性键不同）                                             |
| 利益受损或受益 | 3                | 被救命、被断财路；记为"亲历"                                                         |
| 权威背书       | 2 到 4           | 公会、领主、神父的承认；权威越大越有效；"实字 B"的背书打折（`society.md` 第 3.2 节） |
| 传闻           | 1 × 可信度       | 第 4 节；可信度不过听者门槛则为 0                                                    |
| 推断           | 1                | 观察者从线索自己推出（例：断面的切口需要多大力道）                                   |
| 书面           | 1 到 2           | 公会记录、告示、歌谣；"作品文字只是作者的说法"                                       |
| 鉴定结果       | 负值（-2，待调） | 对玩家而言，"无记载"与"Lv1"是反证；仪器信任越高的人扣得越多（公会职员、商人）        |

- **个人修正**（`society.md` 第 8.7 节"证据权重"）：神职对"神迹"类证据加权；学者对"可复现"加权；矮人对物证加权（`races.md`："带他去看断面"）；
  兽人与魔族亲眼即信，对传闻权重为 0（`races.md` 第 3、6 节）；半身人不在乎信不信，但一定转述（第 4 节）。
- **独立性**：同一事件的多名目击者算"同一来源"的多份证据，叠加有衰减（第二份乘 0.5，之后乘 0.25）；不同事件才算"可复现"或"多源"。

### 3.2 事迹判读：表观位阶

内核把每个可被目击的超常事迹折算为"表观位阶"（`FeatAppraisal`）：一个人要多强才做得到。锚点取自 `power_system.md` 第 3.2 节的逐阶说明。

| 事迹（举例）                                     | 表观位阶（待调） | 锚点                                                                            |
| ------------------------------------------------ | ---------------- | ------------------------------------------------------------------------------- |
| 与野狼打平                                       | 5                | 凡阶·初的新兵                                                                   |
| 在城门口挡住一小群魔狼                           | 15               | 凡阶·熟的战士                                                                   |
| 单独讨伐精英魔物、清理一处澱巢、正面击溃十名士兵 | 25               | 精英阶                                                                          |
| 一夜打通塌方封死的矿道（十人一周的活）           | 26               | 精英阶（体力与破坏）                                                            |
| 单人清理小型迷宫、与亚龙级魔物缠斗               | 40               | 英雄阶                                                                          |
| 一刀斩断第二波兽潮                               | 45               | 英雄阶（玛莎）                                                                  |
| 一刀劈开河面                                     | 55               | 传说阶（老船夫）                                                                |
| 改变地貌与天气                                   | 60               | 神话阶                                                                          |
| 身体消散进一道门（玩家退回门内被目击）           | 不适用           | 归入"异象"，直接进入神迹、邪术、魔物作祟一类解释（`power_system.md` 第 9.8 节） |

事迹由内核从战斗与事件日志计算（击杀的对象、等级、数量、耗时、伤亡），不由模型声称。

### 3.3 常识上限与越界

- **常识上限**（`society.md` 第 8.2 节称"世界观上限"）：观察者心里的天花板，约等于他亲眼见过的最强者再加一点余量。

| 阶层（`society.md` 第 8.2 节） | 心里的天花板         | 折算表观位阶（待调） | 超出时归档为             |
| ------------------------------ | -------------------- | -------------------- | ------------------------ |
| 农民、农奴                     | "一个人打十个兵"     | 20                   | 故事、谣言、神迹         |
| 工匠                           | "练了一辈子的老师傅" | 20                   | 有诈                     |
| 普通冒险者                     | B 级到 A 级          | 32                   | 运气、捡漏、作弊         |
| 骑士                           | 英雄阶               | 42                   | "我想看看"               |
| 商人                           | 用钱能买到的最强     | 30                   | 机会或风险               |
| 低阶神职                       | 神迹                 | 22                   | 神迹或邪术               |
| 学者                           | 理论上限 Lv60        | 60（理论）           | 理论上不可能，必须解释   |
| 贵族                           | 英雄阶               | 42                   | 阴谋或可用之人           |
| 王侯                           | 传说阶               | 55                   | 需要拉拢或清除的力量     |
| 遗民                           | "母亲会回来"         | 不适用               | 母亲的使者（倾向相信）   |
| 孩子（本文补充）               | 什么都可能           | 60                   | 直接相信，但大人不信孩子 |

- **身份先验**：观察者对"这个人"本来的估计，来自鉴定、公会卡、衣着装备、站姿、传闻（外部线索见 `power_system.md` 第 3.6 节）。
  对玩家，先验来自"Lv1、无职能"与"F 级"，所以很低。
- **越界**有两种，取其大者：
  - 绝对越界 = 表观位阶 - 常识上限：这件事"人"做不到。
  - 相对越界 = 表观位阶 - 身份先验 - 10：这件事"他"做不到。
    越界为正时，事迹不被直接采信，而是交给解释库；越界幅度同时抬高怀疑阈值（第 3.5 节）。

### 3.4 解释库与解释顺序

解释库与各阶层的默认顺序以 `society.md` 第 8.3 节为准。任务书列出的七类解释在库中的位置：

| 任务书的解释 | 解释库条目                 | 被什么证据推翻                                                                   |
| ------------ | -------------------------- | -------------------------------------------------------------------------------- |
| 运气         | 运气；前人打残             | 可复现；亲眼看到全程；物证（完整的首级、未破损的巢）                             |
| 作弊         | 作弊或骗局；误报           | 当众复现；权威背书；亲眼                                                         |
| 魔法道具     | 机关或道具                 | 亲眼看见空手；道具被收走后再做一次                                               |
| 神迹         | 神迹或加护                 | 行事者不信神或被证明无加护（但对无页之身，鉴定本身就读不出加护，这一条很难推翻） |
| 魔物作祟     | 魔物作祟或邪术             | 教会权威的反向背书；切身受益                                                     |
| 阴谋         | 阴谋；隐藏身份；血统与天才 | 多源一致；利益受损方的证言                                                       |
| 真实         | 认知状态"接受"             | 不适用                                                                           |

- **选择方式**：进入"解释化"时，取该观察者解释顺序中的第一项；情境加成可以让第二项先出（例：事发在荒原或门附近，"魔物作祟或邪术"加成；
  有可疑道具在场，"机关或道具"加成；有利益冲突者在场，"阴谋"加成）。在第一、第二项之间按权重抽取，随机数用世界种子、观察者编号与事件编号派生，可复现。
- **解释黏性**：已采用的解释在遇到与之相容的新事迹时被加强（"又是运气"），黏性加 0.3；只有命中"被什么推翻"一栏的证据才能推翻它。
- **推翻之后**：换顺序中的下一项；三项都被推翻，进入"动摇"。

### 3.5 信念跃迁：认知状态机

状态机沿用 `society.md` 第 8.5 节，本文给出可计算的转移条件（数值待调）：

| 转移           | 条件                                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 无视 到 怀疑   | 第一次听到传闻或亲眼看见超常事迹                                                                                                                       |
| 怀疑 到 解释化 | 认知值 ≥ 怀疑阈值的三分之一                                                                                                                            |
| 解释化 到 动摇 | 解释顺序中的三项都被推翻（第 3.4 节）                                                                                                                  |
| 动摇 到 接受   | 认知值 ≥ 怀疑阈值，且至少一条亲眼目睹或切身利益，且证据来自至少两个独立来源                                                                            |
| 接受 到 分叉   | 按性格与立场：崇拜（低阶层、受过玩家帮助的人）、敌视（旧秩序依赖度高、被打过脸的人）、利用（贵族、商人、女神的代理人）、依赖（领地居民，与自治度挂钩） |
| 反弹           | 旧秩序依赖度高者可以从"动摇"直接跳到"敌视"（B 级考官、代官、神父是典型）                                                                               |
| 回落           | 14 个游戏日没有新事迹，状态回落一档（"那次可能真是运气"）；证据账里有"可复现"类证据时不回落                                                            |
| 过度相信       | 崇拜者高估玩家，把别人做的事也算在玩家头上，并提出不切实际的期待                                                                                       |

**怀疑阈值**：

```
怀疑阈值 = 阶层基准 × 性格系数 × (1 + max(0, 越界幅度) / 20) × 立场系数
阶层基准（待调）：孩子 4、遗民 4、农民 8、骑士 8、商人 9、工匠 10、冒险者 10、学者 12、贵族 12、神职 13
性格系数：好奇 0.8，平常 1.0，顽固 1.4
立场系数：友善 0.8，中立 1.0，敌对 1.3
兽人与魔族：亲眼即信（阈值取 5，传闻不计入）
```

### 3.6 社会压力与公开表态

- 私下看法与公开表态分开存。公开表态 = 私下状态向所在群体的多数状态偏移，偏移量由社会压力敏感度决定（`society.md` 第 8.4 节：
  "群体都说'是运气'的时候，个人会压下自己的判断"）。
- 公开承认还要过"面子"：此前公开否认过的人，公开表态的转变延迟到有第二个人先承认、或有权威背书之后。
- 推论：第一个公开相信玩家的人往往是群体的局外人：孩子、醉汉、被排挤的兽人、遗民（同上）。正典里第一个相信玩家的是希雅（`characters.md` 第 3.2 节）。

### 3.7 判定流程

```
1 内核产生事件 -> 列出目击者（同处、醒着、视线可达）与清晰度
2 事迹判读 -> 表观位阶 F
3 对每个目击者：
    读其常识上限 C、身份先验 P、解释顺序、阈值参数
    越界 = max(F - C, F - P - 10)
    若越界 ≤ 0：直接采信；估计强度 = max(原估计, F)；记一条证据
    若越界 > 0：
        记证据（权重按 3.1），认知值累加
        按 3.5 检查状态转移；若进入或停留在"解释化"，按 3.4 选择或维持解释
        若证据命中当前解释的"推翻"条件：推翻并换下一项
4 写推理日志；更新关系中的敬畏与信任（npc_society_ai 第 6 节）
5 生成传闻种子（第 4 节）：目击者的"说法"以其当前解释为版本
6 把样本交给神之视线（goddess_gm 第 3 节）：信徒的样本携带其解释
7 L1 或 L2 的目击者若越界很大，发重要通知，让模型立即"反应"（心声与台词）
```

### 3.8 示例

**示例一：罗恩与塌方的矿道（第一幕，数值示意）**

| ---------- | --------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 4. 传闻系统

### 4.1 数据结构

`society.md` 第 7.4 节规定传闻表示为：核心事件、主体、数量、地点、时间、来源、可信度、情感极性。本文据此定义：

| 对象                       | 字段                                                     | 说明                                                                                                                            |
| -------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |

|                            | 主题标签                                                 | 例：讨伐、鉴定、审判、神迹、身份；用于模板化与台账过滤                                                                          |
|                            | 版本集                                                   | 同一传闻的多个版本（第 4.3 节），每个版本是一组结构化字段：核心事件、主体、数量、地点、时间、细节（至多若干项）、模板、情感极性 |
|                            | 热度                                                     | 0 到 1；决定传播速度                                                                                                            |

（my_ai_town 的传播靠模型复述、系统不知道传闻在谁之间流转，是需要补上的缺口，[my_ai_town_agents.md 第 9.2 节第 6 条](../../10_research/ai_npc/my_ai_town_agents.md)）。

### 4.2 传播

**渠道与速度**（`society.md` 第 7.3 节）：口耳相传一个小镇一天传遍、邻村一到两天；旅人与商队每天 25 到 35 公里，半身人铃队是最大节点；
骑马信使每天 60 到 80 公里；传讯水晶即时但只在公会、学院、主教座堂的职员之间流通；告解与祈祷即时传给女神（凡人不知道这是信息渠道）。
经验值：边石镇的事传到瓦伦堡二到四天，到王都一到两周，传遍大陆一到两个月。

**接触模型**（待调）：

```
每次社交接触（有名 NPC 的交谈或日程中的同处，人群单元按场所批量）：
  传出概率 = 热度 × 场所系数 × 说者传播倾向 × 听者兴趣 × 关系系数
场所系数：酒馆 1.5，市场与集日 1.3，井边与洗衣处 1.3，公会 1.2，面包房清晨 1.1，礼拜日的礼拜堂 1.0（对神职与虔诚者 1.5），工作场所 0.8，家中 0.6
说者传播倾向：半身人与吟游诗人 2.0，接待员与酒馆老板 1.5，常人 1.0，矮人与神职文书 0.6，守秘者 0.2
关系系数：好感 ≥ 0 为 1.0，否则 0.5
热度：初值 = 显著度 × 情感强度 × 新奇度；每游戏日乘 0.85；相关新事件加 0.3；低于 0.05 停止主动传播（仍被记得）
```

- 第一幕的场所对照：醉月亭是"传闻最大的集散点"，洗衣溪是"传闻的二次加工点"，盐巷集市与面包房负责早晨与集日（`act1_borderstone.md` 第 2.2 节）。
- 人群单元的份额按"接触即传染"的逻辑增长（份额 × (1 - 份额) × 传播系数），按热度衰减。
- 跨地区：每个旅人、商队、信使、吟游诗人随身携带其所在地区热度最高的三条传闻，到达后在新地区播种。
- 放大器人物：分幕文档里标为"传闻放大器"的 NPC（例：丽泽把玩家的事迹送进公会网络，芬恩把它写成唱错的歌，`act2_wallenburg.md` 第 3.2 节），
  传播倾向取高值，且芬恩的歌是"书面（歌谣）"类来源：可信度低，但覆盖面极大。

### 4.3 失真

失真规则以 `society.md` 第 7.4 节为准，本文把它们实现为逐跳的"失真操作"：

| 操作                 | 规则（`society.md` 第 7.4 节）                                                                                                    | 本文实现                                                                                       | 对失真度的贡献（待调） |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- | ---------------------- |
| 夸大                 | 数量与规模每跳乘 1.2 到 2.0；酒馆、半身人、孩子取高值；账房、矮人、神职文书取低值                                                 | 按说者类型取系数                                                                               | 按数量对数比           |
| 主体替换（张冠李戴） | 无名主体被替换成听众熟悉的强者（"其实是玛莎出的手""肯定是勇者团"）；有名主体也可能被替换成"某个怪人"；主体不出名时每跳 15% 到 30% | 替换目标从该地区"知名强者表"中按名气抽取                                                       | 0.4                    |
| 简化                 | 三跳之后最多保留三个细节                                                                                                          | 每跳以一定概率丢一项细节，优先丢不戏剧化的                                                     | 每项 0.05              |
| 模板化               | 被吸进已有故事模板：勇者传说、魔王复活、女神显灵、魔女作祟、贵族私生子；五跳之后过半                                              | 模板概率随跳数上升；模板进入版本字段                                                           | 0.3                    |
| 极性偏转             | 神职说成神迹或异端，商人说成商机或风险，贵族说成威胁或可用之人                                                                    | 按说者所属势力改写情感极性与动机                                                               | 0.15                   |
| 时间漂移             | 昨天变前几天变去年                                                                                                                | 每跳一档                                                                                       | 0.05                   |
| 地点漂移             | 不熟悉的地名被替换成听众知道的最近地名                                                                                            | 跨区域时必然发生                                                                               | 0.1                    |
| 缩小（反向失真）     | 离谱到超出听者天花板的传闻可信度更低（`society.md` 第 7.4 节）                                                                    | 听者不信时，以一定概率把它"合理化"后再转述：降低数量、加上"前人打残"、把主体换成"运气好的新人" | 0.2                    |

**可信度**：每跳乘 0.8；从彼此独立的来源再次听到同一件事乘 1.3（上限 1.0）；亲眼目睹者为 1.0（`society.md` 第 7.4 节）。

**信否**：听者相信一个版本，当且仅当可信度超过他的"相信门槛"；相信门槛随版本的表观位阶超过其常识上限的幅度而上升
（例：门槛 = 0.3 + 越界幅度 / 50，上限 0.95，待调）。所以玩家越强，关于玩家的真实传闻越不被相信，被"缩小"的版本传得最远。
`society.md` 第 7.4 节的示例链（罗恩亲见、酒馆"杀了二十只"、商队伙计"头目早被打残"、瓦伦堡冒险者"运气不错的新人"、商人"北边药价要跌"）
就是夸大、主体替换、缩小、模板化与极性偏转依次作用的结果。

### 4.4 核实与澄清

| 动作     | 谁能做               | 结果                                                                                                                                        |
| -------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 亲自查看 | 任何人（到现场）     | 现场还在的痕迹成为亲见证据；回执可作为核实结果（[my_ai_town_agents.md 第 5.4 节](../../10_research/ai_npc/my_ai_town_agents.md)"查看四周"） |
| 问目击者 | 任何人               | 得到目击者的版本（他的解释也一并传来）                                                                                                      |
| 问权威   | 有渠道者             | 公会记录、神父的说法、告示；权威的版本成为"事实锚"（第 4.5 节）                                                                             |
| 请人复现 | 有交情或有权者       | 玩家当众再做一次：可复现证据，最有力                                                                                                        |
| 澄清     | 亲见者、当事人、权威 | 生成一个反向版本，以澄清者的可信度为初值传播                                                                                                |

- **越描越黑**：澄清者的言辞可信度低于 0.4，或当事人本人急着否认一条热度很高的传闻时，澄清本身有约三成概率变成新传闻（"他急着否认，肯定有鬼"）。
- 核实与澄清都是 NPC 的正常动作（[npc_society_ai.md](npc_society_ai.md) 第 4.3 节），也是玩家的工具。

### 4.5 误会上限与事实校验

误会链必须有上限与事实校验，否则会失控或无法复现（依据 [anime/synthesis.md 第 2.4 节](../../10_research/anime/synthesis.md)；[anime/titles_26_50.md 跨作品观察第 7 条](../../10_research/anime/titles_26_50.md)）：

| 约束         | 规则（待调）                                                                                                                                                                                                          |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 真相锚       | 每条传闻都锚定一个内核事件或一次有记录的造谣；系统不凭空生成传闻                                                                                                                                                      |
| 失真度上限   | 单一版本失真度达到 0.8 时，它在听者那里被归为"故事"（信否门槛拉满），不再作为事实传播，只作为笑谈                                                                                                                     |
| 事实锚       | 公开事实（公会公告、审判结果、领主告示、天启碑文）把同一地区内相关版本的失真度压到 0.3 以下；告示所及之处，离谱版本自然退潮                                                                                           |
| 主流说法上限 | 每个地区、每个主体同时至多 3 个主流版本；其余并入最相近的版本                                                                                                                                                         |
| 全局上限     | 关于玩家的活跃传闻至多 40 条，按热度淘汰                                                                                                                                                                              |
| 内容合法性   | 失真操作的产物只能落在传闻命题词表与模板表内；涉及台账条目的命题按 `reveal_ledger.md` 过滤：未解锁的真相即使作为"猜测"也不得出现（防止歪打正着地剧透），误导表允许的版本可以出现（例：MIS-07 的雏形"异端引来了灾祸"） |
| 喜剧节流     | 同一地区同一类桥段（第 10 节）每游戏日至多触发 1 次；连续三次同类桥段后，下一次自动降级为背景对话                                                                                                                     |
| 可复现       | 失真与信否用世界种子派生的随机数，同一存档同一操作得到同一结果                                                                                                                                                        |

### 4.6 传闻画像

每个地区对每个重要主体维护一份传闻画像（`RumorPortrait`）：该地区持有的主流版本（至多 3 个）及其人群份额、平均可信度、情感极性。

- 第二幕的剧情变量 `rumor_shape`（blond_knight、heroes_porter、hidden_master、spec_outsider，`act2_wallenburg.md` 第 10.2 节）就是瓦伦堡对玩家的传闻画像中占比最高的那个模板。
- 传闻画像是地区声望的"内容"（第 5 节），也是女神投影里信徒样本的主要来源之一（第 7 节）。

### 4.7 与其他规则的接口

- **立名**：英雄阶的关卡需要一个"传颂级"称号，莫伊拉的规则在一个人的事迹被足够多的人讲述时自动写入（`power_system.md` 第 3.3 节）。
  传闻系统提供"被讲述的人数"。玩家无页，得不到称号；但"玩家身边的事迹传得快"，同伴因此更容易立名。
- **异名者**：被人们谈论到有了名字的魔物会更强（`power_system.md` 第 7.4 节）。关于某只魔物的传闻热度越过阈值时，内核为它生成称谓，
  按异名者规则强化。玩家可以利用（压住消息）或被反噬（夸大的传闻让一只普通的魔物真的变难缠）。
- **神谕的传达链**：神谕在圣职链里逐级被解读，使用同一套失真规则（`society.md` 第 5.4 节；[goddess_gm.md](goddess_gm.md) 第 5.3 节）。

## 7. 神之视线与传闻的交叉

- **信徒目击**：玩家的事迹被信徒目击时，按 [goddess_gm.md](goddess_gm.md) 第 3.1 节的通道与权重进入该女神的投影，样本携带信徒的解释。
- **信徒听闻**：持有关于玩家传闻的信徒，在祈祷时把传闻作为"转述"样本上传，权重为该通道权重乘 0.3 乘传闻可信度。
- **注视度增量**（每位女神分别计算，待调）：

```
增量 = Σ 目击信徒 [通道权重 × 虔诚度 × 显著度 × 清晰度]
     + Σ 持有传闻的信徒 [通道权重 × 0.3 × 可信度 × 热度]
     + 神殿覆盖（灵素剧烈波动时 0.5 × 显著度）
```

- **张扬的放大**：在神殿覆盖的城市行事、当众行事、请权威作证，都会让增量成倍上升；在荒原、夜里、浓澱区行事几乎为零。
- **失真的偏转**：传闻把事迹安到别人头上时，样本指向错误的主体：芬恩把玩家唱成金发骑士，艾琉恩的档案里涨的是"金发骑士"的注视度（A2-S01）。
- **视线感知**：识才之门进阶后，玩家能看见女神视线的覆盖（`act4_continental_board.md` 新增命名"视线感知"），把"藏拙"从猜测变成规划。

## 8. 鉴定与情报

### 8.1 鉴定的层级与上限

层级以 `power_system.md` 第 2.6 节与 `society.md` 第 3.4 节为准：

| 层级                                 | 读高                                     | 读深                                       | 对玩家                               |
| ------------------------------------ | ---------------------------------------- | ------------------------------------------ | ------------------------------------ |
| 普通鉴定水晶（公会分部、关卡、商会） | 精确到 34，以上显示"34+"                 | 等级、位阶、职能、澱染有无                 | 不亮，读数栏显示"无记载"             |
| 公会高级鉴定（大区总部）             | 精确到 49，以上显示"49+"                 | 加上流派、技能、称号、公开的加护名         | "无记载"                             |
| 学院精密鉴定                         | 精确到 59；60 显示"60"；超越者"60"或"？" | 加上铭纹、加护强度、诅咒、封印痕、伪装痕迹 | "无记载"                             |
| 神官的神前鉴定                       | 取决于女神肯给多少                       | 对应女神的加护全部细节                     | 借阅原页时"查无此页"；伪录在此露馅   |
| 个人鉴定技能                         | 不能越阶：只读清自身位阶加一阶以内       | 依技能                                     | 失败                                 |
| 贤者之眼（艾登）                     | 精密级读深，加"录问"                     | 能问出"此人是否有页"                       | "铭录里没有你"（`a2_aiden_no_page`） |

显示约定（D-029，`power_system.md` 第 2.6 节）：超过所用水晶的读高显示"上限+"（"34+""49+"）；铭录上限显示"60"；
超过鉴定者的感知上限显示"？"；无页显示"无记载"；魔物、亡灵与无貌者读出残页（只有种类、等级与位阶）。

### 8.2 对玩家的"无记载"

- 水晶不亮，读数栏显示"无记载"，公会只能手工登记"F 级、Lv1、无职能"（第一幕）；B 级考核再次失败后走"实绩认定"，卡上从此是"B（实），Lv1，无职能"
  （`society.md` 第 3.2 节）。"实字 B"在冒险者圈子里被认为是花钱买的。
- 凡人对"无记载"的解释：水晶坏了、这人被诅咒了（MIS-06）；异端之兆（MIS-20，神职）。这两个误导版本在第二幕被艾登的发现推翻。
- 在认知系统里，每一次当众鉴定失败都是一次反证（第 3.1 节）；每一张写着"Lv1"的卡都在持续地压低陌生人的身份先验。
- 公会黑档"无记载"一栏只有两条：无貌者与玩家（`society.md` 第 3.4 节）。这是第二幕起的谨慎线索。

### 8.3 玩家鉴定他人

| 阶段                   | 玩家看到什么                                             | 来源                                 |
| ---------------------- | -------------------------------------------------------- | ------------------------------------ |
| 开局                   | 四档：比我强、差不多、比我弱、看不透                     | `power_system.md` 第 3.6 节          |
| 观澜之门（第一幕）     | 灵压的等级区间加可信度；可信度受收敛、伪装与感知饱和影响 | 同上；门 `door_tide_sight`           |
| 识才之门（第一幕后段） | 读取 NPC 底页的潜质（任何鉴定都读不到的东西）            | `power_system.md` 第 2.5、9.9 节     |
| 识才之门进阶（第四幕） | 命运丝（莫伊拉安排的痕迹）、视线感知（女神视线覆盖）     | `act4_continental_board.md` 新增命名 |
| 借用外部鉴定           | 请公会、学院、同伴（艾登）鉴定他人，得到对应层级的结果   | 第 8.1 节                            |

- **"看不透"永远存在**：对远高于自己的存在，灵觉饱和，感觉不是"深不可测"就是"一片平静"（`power_system.md` 第 3.6 节）。
  界面上"一片平静"与"比我弱"必须可区分，但都不给数字。玛莎平日完全收敛，在玩家的灵觉里像个普通人：这是第一幕"凡人里也有深藏不露的人"的系统来源。
- 对"？"的处理：任何超出玩家当前感知上限的对象，等级区间显示为"？"，可信度显示为"低"；感知上限随门成长（数值由 `thousand_doors.md` 定）。

### 8.4 威压感知

- 威压按位阶差分档（`power_system.md` 第 3.5 节）：同阶无感；一阶压迫、犹豫；两阶僵硬，小兽逃散；三阶及以上失神。
- 界面只给档位与方向（屏幕边缘的压迫感、心跳音效、"空气很沉"之类的提示文字），不给数值；感知类的门让档位更准、加上方向。
- 收敛的高手不产生威压；感知饱和让极强者显得"平静"。所以"没有威压"不等于安全：这是谨慎玩法的核心陷阱，界面不替玩家下结论。
- 外部线索作为补充：动物的反应（马匹不安、犬只伏地）、灵素染色、装备的磨损、身边人的态度（`power_system.md` 第 3.6 节）。野兽对威压的反应不受常识约束，常常比人更早"相信"。
- 玩家自身的威压同样作用于他人（`power_system.md` 第 3.5 节）：没有收放之门时，玩家战斗中的灵压外泄会让周围的人僵住、跪倒，这本身是高显著度的目击事件。

### 8.5 情报可信度与交叉验证

- 情报（`Intel`）：主体、内容（结构化事实集合）、来源链、来源类型、取得时刻、玩家的标注。真伪只有内核知道。
- 玩家看到的"可信度"只按来源类型与来源链计算（亲见、转述跳数、书面、权威、女神的话、敌方的自称），不泄露真伪。
- **交叉验证**：同一主体的两条情报来自独立来源且一致时，可信度上升；互相矛盾时，情报簿标出矛盾所在。核实（第 4.4 节）能把一条情报升为"已核实"。
- **有意的谎言**：女神（梅尔卡卖假情报、莫伊拉拖延或隐瞒）、敌方、灰鼠的掮客都会说谎；谎言在内核里留痕，日后可以成为证据（[goddess_gm.md](goddess_gm.md) 第 10.5 节）。
- 第四幕的"对照"页（`act4_continental_board.md` 第 6.6 节，五位女神各自的版本自动填入）就是情报簿的一个专用视图。

## 9. 过度解读者

### 9.1 谁会过度解读

依据 [anime/synthesis.md 第 2.4 节](../../10_research/anime/synthesis.md)（不死者之王的智将部下、史莱姆的狂热部下）与
[anime/titles_01_25.md 第 6、10 部](../../10_research/anime/titles_01_25.md)（幼女战记、不死者之王的误会链）。

| 类型       | 特征                                           | 典型来源                                                                                 |
| ---------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 狂热追随者 | 处于"崇拜"分叉；把玩家的一切都往伟大里想       | 被玩家救过的人；输给玩家的兽人与魔族战士（`races.md`："输了的人往往成为最忠诚的追随者"） |
| 智将型部下 | 主动性与能力都高；把玩家的随口一句扩写成计划   | 领地官员、将领（第三幕起）                                                               |
| 阴谋论者   | 处于"敌视"或"利用"分叉；认为玩家每一步都有深意 | 贵族、审判官、他神的代理人                                                               |

人设卡里以"解读倾向"标出（0 到 1），只有倾向超过阈值的 NPC 才会生成解读。

### 9.2 数据：意图与解读分开存

| 对象                       | 字段                                                                                                                                             |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 意图记录（`IntentRecord`） | 玩家的实际输入（命令、对话选项、自由文本）、时刻、对象；若是随口一句或无意的行为，记为"无明确意图"                                               |
| 解读（`Interpretation`）   | 解读者、触发事件、推定目的、推定计划、推定对象、置信度、推理日志（引用观察到的事件编号）、拟行动、状态（待确认、执行中、被追问、被纠正、已固化） |

两者分开存储，玩家永远能看到"我说的是什么"与"他理解成了什么"。

### 9.3 规则

- **触发**：玩家对解读者说话、下命令、或在其面前做出显著的行为；解读者按自己的知识与立场生成解读（有模型时由模型提出，内核校验其引用；无模型时按模板表生成）。
- **深度上限**：解读链至多三层（"大人说风景好"，"大人想在这里筑城"，"大人要防北边的帝国"）；第四层起不再扩写。
- **行动上限**：解读产生的拟行动只能在解读者自己的职权内（P2 以内）；P3 动作必须等玩家确认；每个解读者同时至多 2 个活跃解读。
- **玩家的回应**：
  - 默认：解读成立，拟行动执行。
  - 追问：解读者解释自己的推理日志（玩家可以从中发现误会，也可能被说服）。
  - 纠正：解读作废；解读者的面子受损。顽固或崇拜型的解读者有一定概率"再解读"（"大人这是在考验我"），每次纠正降低该概率。
- **与自治度的关系**：授权越宽，解读者的拟行动越多地不经确认就执行（[city_building.md](city_building.md) 第 8 节的自治度）。高自治度是"放手"，也意味着更多误会被落实成事实：这是主题机制的喜剧面。
- **误会上限**：每地区同时活跃的解读链至多 3 条；同一解读者连续被纠正三次后，本幕内其解读倾向减半。

## 10. 喜剧桥段的系统化

原则：笑点来自"测量失灵 × 解释库 × 传闻失真 × 权威滞后"的组合，每个桥段都能从系统状态推出来，而不是脚本硬推
（依据 [anime/titles_26_50.md 跨作品观察第 7 条](../../10_research/anime/titles_26_50.md)：误会链若完全剧本化，在 AI 系统里难以稳定复现）。
系统负责"什么时候、对谁、以什么解释"，模型负责"怎么说才好笑"；无模型时用预写模板，笑点照样成立。

## 11. 与 UI 的接口（概要）

原则：界面显示"玩家所知"，不显示真值；数值一律量化为档位；每条信息带来源。

| 界面     | 内容                                                                                                     | 解锁                           |
| -------- | -------------------------------------------------------------------------------------------------------- | ------------------------------ |
| 传闻簿   | 玩家听到过的关于自己与他人的传闻：版本、听自谁、在哪、可信度（按来源计算）；玩家追查到的来源链会逐跳展开 | 第一幕                         |
| 声望面板 | 按地区与势力：名望档、评价档、主流说法（至多 3 个）、机构定性；都是"据你所知"的估计                      | 第一幕（地区），第二幕（势力） |
| 人物印象 | 角色卡上的"他怎么看你"：称呼、态度标签（"怀疑""觉得你是运气好""崇拜"），来自对方的言行，不是读心         | 第一幕                         |
| 鉴定结果 | 按第 8.1 节的显示约定；玩家的门镜显示自己的门阶                                                          | 第一幕                         |
| 威压提示 | 屏幕边缘的压迫感与文字提示，只给档位与方向                                                               | 第一幕                         |
| 情报簿   | 情报、来源、可信度、交叉验证与矛盾标记；第四幕的"对照"页是它的一个视图                                   | 第一幕                         |
| 解读提示 | 过度解读者的"他理解成了……"，附默认、追问、纠正三个按钮                                                   | 第三幕                         |
| 被注视感 | 第二幕起：模糊的"被注视"提示；识才之门进阶后显示女神视线覆盖（视线感知）                                 | 第二幕、第四幕                 |

所有显示文本经本地化；玩家看到的"可信度""名望"等只用文字档位。

## 12. 降级档

本系统的核心（事迹判读、越界、解释选择、状态机、传闻传播与失真、声望汇总、鉴定、威压）全部是规则，无模型时照常运行。
模型只负责台词与心声；无模型时，每个"解释库条目 × 阶层"与每个"桥段"都有预写台词模板（带插槽：人名、数量、地点），由规则选择与填充。
过度解读在无模型时按模板表生成解读链。所以"凡人不信"的喜剧在降级档下仍然成立（D-010）。

## 13. 风险与对策

| 风险                               | 对策                                                                                                                    |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 误会失控、逻辑崩坏                 | 真相锚、失真度上限、事实锚、主流说法上限、解读深度上限                                                                  |
| 喜剧过密而疲劳                     | 喜剧节流；同类桥段降级为背景对话                                                                                        |
| 玩家觉得"永远没人信我"而受挫       | 可复现、物证、亲历、权威背书都是玩家可以主动制造的证据；同伴与局外人先信；第二幕起实字 B 与布伦手录提供"官方之外的记录" |
| 歪打正着地剧透                     | 内容合法性按台账过滤，未解锁真相不得作为猜测出现                                                                        |
| 不可复现                           | 所有抽取用世界种子派生的随机数；模型只写台词                                                                            |
| 模型说出与认知状态不符的话         | 认知状态进题面；闸门检查台词与状态的一致性                                                                              |
| 性能（几百名 NPC、成千条传闻副本） | L4 用份额；传闻只对有名 NPC 存副本；热度低于阈值停止传播；全局上限                                                      |
| 玩家利用失真作弊（刷声望）         | 声望来自真实事件与真实目击；失真会放大，也会缩小；事实锚压制离谱版本                                                    |

## 16. 待决问题

1. **参数口径**：`society.md` 第 8.4 节的证据权重是 0 到 5，第 7.4 节的传闻可信度是 0 到 1；本文以"传闻证据权重 = 1 × 可信度"连接两者，需正典维护者确认。
2. **鉴定反证的幅度**：每次当众鉴定失败计 -2 是本文的初值；过大会让"凡人不信"变成"永远不信"，需原型调试。
3. **常识上限的折算**：`society.md` 第 8.2 节以文字描述天花板，本文折算为表观位阶，需与位阶设计对齐。
4. **"实字 B"的显示**：公会卡"B（实），Lv1，无职能"需要美术与本地化确认。
5. **伪录之门对审判官照规镜**：act2 C2-3 写明由内核判定，`power_system.md` 第 2.7 节未列照规镜；需明确照规镜属于哪一层鉴定。
6. **玩家的感知上限**：观澜之门之后的区间精度、"？"的阈值，需 `thousand_doors.md` 给出门阶与感知的对应。
7. **失真度达到上限后的"故事化"**：本文让它退为笑谈；是否也应计入"立名"的讲述人数（同伴因夸大的歌谣而立名），需确认。
8. **声望量纲**：act2 的 `faction_rep_*`（-3 到 3）、act4 的 `stance_*`（-100 到 100）、台账的 `trust.<角色>`（0 到 100）需统一内部量纲与显示分档。

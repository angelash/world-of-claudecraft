## 0. 定位与硬约束

### 0.1 一句话

第四幕起，镜头拉到整片梅迪乌斯大陆：玩家的国家第一次和帝国、教国、同盟、精灵、兽人、魔族平起平坐，
也第一次看清诸神在下棋。**这一层的对手不只是国家，还有国家背后的女神。**

### 0.2 硬约束

1. **同一张地图、同一个时钟。** 大陆地图是 RPG 世界地图的"拉远视图"：郡是画在同一套格坐标上的多边形，也是区域图上的节点集合，
   拉近就回到可行走的地块；战略层按"日"步进同一个世界时钟（[`game_framework.md`](../game_framework.md) 第 6 节）。纯 2D 俯视像素风（D-003）。
2. **AI 国家走"模型提议、内核裁决"管线（D-007）。** 统治者是 L1 的一个分支，从枚举菜单选意图，内核校验后由规则执行；
   模型不可用时由 Utility 兜底（[`comparison_and_plan.md`](../../10_research/ai_npc/comparison_and_plan.md) 第 6.5 节）。
3. **AI 只读自己的知识层。** 统治者与女神的输入是其知识层的摘要，不是世界真值（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.4 节）。
4. **自动结算与手动战斗共用确定性内核（D-012）。** 战略层的战斗经由 [`warfare_rts.md`](warfare_rts.md) 第 2.4 节结算。
5. **女神的战略干预以注册修正项实现（D-013）。** 显性或半显性、可追溯，有神力消耗与澱代价（第 7 节）。
6. **防滚雪球**（第 10 节）与 **国家层委托**（第 9.4 节）。
7. **个人层不退场。** 第四幕的国主仍然会亲自下迷宫、仍然要处理一个小镇的纷争（[`game_framework.md`](../game_framework.md) 第 4 节）。

## 1. 大陆地图

### 1.1 结构

区域、神之视线与澱度以 [`geography.md`](../../20_world/geography.md) 第 2.2 节为准，各国人口以 [`nations_and_factions.md`](../../20_world/nations_and_factions.md) 为准（D-041），
澱度标尺按 `power_system.md` 第 7.2 节的六级加临界（D-039；表中只是区域概括）；战略层的最小控制单位是**郡**（act4 第 3.2 节：
"大陆按郡划分，每郡有归属、人口、产出、信仰构成（各女神份额）、澱值"）。郡的总数与划分等地理志细化，下表的郡数只是量级占位：

- 每个郡包含若干**据点**（城市、城镇、要塞、村落群、港口、关隘、遗迹、迷宫、神殿），据点就是城建系统里的聚落
  （[`city_building.md`](city_building.md) 第 1 节）。玩家自己的聚落精细到地段；AI 国家的聚落只保留摘要。
- **大地图就是区域图**：地理志把超过约 15 公里的行进改用区域图（节点式的长途行进图，带时间成本与途中事件，`geography.md` 第 7.1、7.2 节）。
  战略层的郡图与它是同一张图的两个缩放：郡是节点的集合，路是节点间的边。AI 居民的出行与军队的行军按同一张行程表结算。
- **连地规则**：只能对与己方控制郡相邻、或有补给线连通的郡发起占领与围城。扩张因此变成路径问题，天然产生前线与要冲
  （补充资料：《率土之滨》的地块连地，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.1 节）。
- **门路**（玩家独有）：由行路之门的门标连成的通行网络，区域图上显示为门站之间的瞬移线（act4 第 3.2 节；`geography.md` 第 7.2 节）。
  门路的运力有限，是门券的担保（[`economy_and_trade.md`](economy_and_trade.md) 第 1.1、5.4 节），也是众门环的骨架。
- **图层**：神之视线图层（由识才之门进阶的"视线感知"得到，看得见哪些区域在哪位女神的视线里）与澱图层（由澱哨读取）（act4 第 3.2 节）。
- **大地图生成**：手写区域轮廓 + 程序化细节（多层噪声、高度分档、A* 加贝塞尔的河流、按分布函数放矿与植被），
  种子与生成器版本写进地图文档（同上第 4.1 节；[`my_ai_town_visual_and_client.md`](../../10_research/art_style/my_ai_town_visual_and_client.md) 第 4.4 节）。

### 1.2 地形与行程

行程以 `geography.md` 第 0.1 节为准：步行每日约 25 公里、带货商队约 20、灰烬荒原内约 15；骑马常行 40 到 50、急行 80、驿马接力 100 以上；
河船顺流约 60、逆流约 30；海船沿岸 100 到 150。军队按全军最慢者计算，再乘下表的地形系数：

| 地形         | 行军系数                | 补给容量         | 防守 | 备注                                       |
| ------------ | ----------------------- | ---------------- | ---- | ------------------------------------------ |
| 平原、农田   | 1.0                     | 高               | 无   | 战场最常见                                 |
| 森林         | 0.5                     | 中               | +20% | 希尔瓦内外人再减半；森林是精灵与树卫的主场 |
| 丘陵         | 0.6                     | 中               | +25% |                                            |
| 山地与关隘   | 0.4（关隘本身必须攻克） | 低               | +50% | 关隘是咽喉（云阶隘、牙口隘、獠牙关等）     |
| 沼泽         | 0.4                     | 低               | +15% | 疫病风险；蛇人伏兵加成                     |
| 草原         | 1.0（骑兵 1.5）         | 中（季节波动大） | 无   | 风牙行军最快、补给要求低                   |
| 荒原（澱区） | 0.6                     | 近零             | 无   | 按澱值刷出魔物，非本地部队每日士气 -1      |
| 河与海       | 需港口或渡口            | 无               |      | 水运补给快；同盟舰队控制海上               |

**道路网**：地理志第 6 节的商路（横原大道、格兰水道、金潮航线、炉道、毡路、瓦伦河水路、灰路）与军事通道（夜风走廊、北境大道、
旧巡逻道、南大路与苇桥、银鞍桥与诸渡、长垒军道、云阶隘与牙口隘）是区域图上的主干边，行军与补给沿它们走更快；
帝国的大道带来行军速度加成（`nations_and_factions.md` 第 1.2 节）。

### 1.3 补给

- 每个郡有**补给容量**（每日可供养的兵员数）= 人口 × 粮食盈余率 × 季节系数 × (1 - 破坏度)。
- 军队每人每日需粮 1 单位（骑兵 2）。驻扎郡能供养的部分就地取，不足部分经**补给线**从后方仓储据点运来。
- **补给线**：一条由己方控制郡组成的路径，终点是有粮仓或货栈的据点；运力受道路等级与车队数量约束；路径被敌占或被袭扰则中断。
- **就地征发**：可以强行提高本地供给（×1.5），代价是该郡破坏度上升、民心下降、来年补给容量下降、当地居民敌视。
- **断粮**：军队每日减员 1% 到 3%，士气基线每日 -5（带入战斗，[`warfare_rts.md`](warfare_rts.md) 第 3.4 节）。
- 灰烬荒原补给近零：所有进入荒原的军队都要靠补给线，这让第五幕的荒原作战本质上是一场后勤战。

### 1.4 季节

| 季节 | 行军                    | 补给            | 其他                           |
| ---- | ----------------------- | --------------- | ------------------------------ |
| 春   | 泥泞：-20%              | 低（青黄不接）  | 播种；征召会影响秋收           |
| 夏   | 最佳                    | 中              | 沼泽与城市疫病风险上升         |
| 秋   | 正常                    | 高（收获 +30%） | 税收季；最常见的战争季节       |
| 冬   | 北方雪：-40%；南方 -10% | 北方减半        | 夜境部队受影响小；荒原终雾加重 |

- 季节与天气是希尔薇的职权：她的天气修正项叠加在季节之上（第 7.2 节）。

### 2.3 外交关系

- **关系边**：有向，带态度带（敌对、冷淡、中立、友善、亲密）与带内分数（-100 到 100）、条约标签、是否交战、可见性。
- **好感账本**：每段关系的分数由带来源、带期限的条目组成（"他们帮我们挡过兽潮 +15，剩 300 天"），玩家能看到为什么
  （补充资料：《十字军之王 3》的好感修正账本，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.2 节）。
- **时态快照**：关系变化以快照追加，不覆盖；矛盾的关系由事件裁决，不取平均（修仙 GDD 13，同上第 4.2 节）。
- **可见性**：每条关系对每个观察者有 `secret`、`player_known`、`public`、`misreported` 四档；`misreported` 是观察者看到的说法，
  不改真实状态（同上第 4.4 节）。隐藏的敌对不能通过颜色、排序或数字泄漏。

### 2.4 文化与信仰

- 每个郡记录各女神的信仰份额；神殿与教会决定该女神在当地的视线覆盖与触达度（[`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 6 条；
  [`goddess_gm.md`](goddess_gm.md) 第 4.1 节）。
- **加护冲动**：统治者与官员信仰的女神会轻微牵引他们的意图权重（[`synthesis.md`](../../10_research/anime/synthesis.md) 第 2.11 节）。
- **玩家国家的神之视线覆盖率**：女神看不见玩家，但看得见玩家的国民；国民里信徒越多，女神越了解这个国家，也越能对它出手。
  不建神殿、国民不祈祷，国家就在诸神的盲区里，但也得不到任何加护与神迹（`nations_and_factions.md` 第 3.2 节）。
- 影响覆盖率的手段：国体与制度（act4 第 4.4、4.6 节）。例如"无神之礼"让出生、婚礼、葬礼由众人见证而不经神殿，降低圣教在国内的视线覆盖；
  学士宪政的法典可以写入"神不入法"（激怒教国）；立某位女神为国教则相反，换来她的偏爱与她的眼睛。
- 浓澱以上的区域本身就是神的盲区（`power_system.md` 第 7.2 节）：立在荒原边缘的庭外之国天然看不清。

### 2.5 行政容量

- 行政容量 = 基础值 + 行政中心等级 + 内阁与总督的能力 + 驿站覆盖。
- 实际管理郡数超过容量时，每超 1 郡：全国稳定 -1、腐败风险 +2%、政令传达延迟 +1 天（第 10 节）。
- 新征服郡需要约 180 天"核心化"，期间税收与兵源减半、叛乱风险高。

### 2.6 国家自治度与神依赖度

**玩家国家的自治度**按 [`city_building.md`](city_building.md) 第 8.5 节计算：`A_nation = 0.6 × 聚落加权自治度 + 0.4 × A_core`。

**AI 国家也有自治度**，用简化版：制度覆盖与人才厚度由国家档案给初值并随事件演化；授权比与依赖不适用（AI 统治者不"微操"）。

**神依赖度**（Divine Reliance，0 到 100）：衡量一个国家的结果有多依赖女神的干预。

```
神依赖度 = 结构项 + 近 360 天内使该国受益的女神修正项的神力总量 / 国家规模（归一化）
结构项：国教神权程度、军中加护部队占比（圣骑士、勇者团、狂战士）、以契约加护担保的条约数量
```

| 势力                 | 神依赖度（开局量级） | 理由                                       |
| -------------------- | -------------------- | ------------------------------------------ |
| 圣艾琉恩教国         | 很高                 | 神权国，召唤勇者，神迹立教                 |
| 夜境诸侯             | 高                   | 瓦尔妲与魔王循环                           |
| 梅尔卡托自由都市同盟 | 中高                 | 契约加护支撑金融                           |
| 洛萨王国             | 中                   | 圣教为主，加上债务                         |
| 希尔瓦氏族议会       | 中                   | 灵泉与希尔薇                               |
| 风牙兽王会盟         | 中                   | 祖灵与两位女神的拉扯                       |
| 格兰提亚帝国         | 中低                 | 世俗化，剑帝以凡人意志登顶                 |
| 庭外之国             | 开局 0               | 不在任何女神的账本上；接受女神帮助就会上升 |

- **国体与 `autonomy`**：玩家国家的国家自治度就是分幕变量 `autonomy`。立国时的国体（王政、门庭议会、界石联邦、行会共和、学士宪政，
  以及隐藏的无主之制）决定它的成长曲线与第五幕"待令"的倾向（国体以 act4 第 4.4 节的六种为准，D-048；`nations_and_factions.md` 第 3.3 节待对齐）。
- **箱庭离手指数**（D-043，变量 `release_index`）：全部国家 (自治度 - 神依赖度) 的人口加权平均，与神迹账 E34 合并，作为第六幕审定结算的输入之一。
  真结局另有显式门槛：玩家国家的 `autonomy` 不低于阈值（初值 60，待调；[`city_building.md`](city_building.md) 第 8.6 节）。
  它对玩家隐藏，由莫伊拉在后台记录；具体如何参与审定由 `goddess_gm.md` 与分幕文档决定（正典：审定看箱庭能否自行面对危机，
  [`world_bible.md`](../../20_world/world_bible.md) 第 3.2 节）。
- 这让"离手"不只是玩家一国的事：玩家可以通过外交、榜样、揭露真相，推动其他国家降低神依赖度（例如说服帝国不接受圣战号召）。

## 3. AI 国家的决策

### 3.1 统治者人格

统治者的性格落在两处：大模型的人设卡（语气、价值观、禁区、秘密），以及规则层的意图权重与成本函数；后者保证没有大模型时性格依然存在
（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.6 节）。

| 统治者            | 规则层倾向（示例）                                                     |
| ----------------- | ---------------------------------------------------------------------- |
| 剑帝雷欧哈特三世  | 重"力量对比"项；对展示过实力的对象好感 +；"试剑"类事件可改变其外交立场 |
| 夜后维丝佩拉      | 重"安全"与"魔族存续"；对魔王循环的怀疑随证据增长                       |
| 长老艾尔温        | 重"不干涉"；对遗民与空白纪证据高度敏感                                 |
| 金冠哈特          | 重"收益"；偏好债务、禁运、收购等经济手段；契约至上                     |
| 圣教国            | 重"异端清除"与"信仰份额"；神谕权重最高                                 |
| 洛萨宰相冯·德雷克 | 重"自保"；与帝国秘密谈判（第三幕剧情）                                 |

- 统治者的动机按政治现实主义：利益、安全、力量平衡；阵营名不推出道德；共同威胁上升时竞争者也会合作
  （同上第 4.2 节，修仙地理映射 07）。

### 3.2 决策管线

```
国家知识层 --> 1 感知摘要 --> 2 [大模型] 从枚举意图菜单选择（含参数与理由）
          --> 3 内核校验（合法性、预算、冷却、权限分级） --> 4 规划分解（HTN 或 GOAP）
          --> 5 规则执行（每日运营，确定性） --> 6 回写（事件、时态快照、统治者记忆）
          --> 7 表达（国书、宣言、传闻；理由只进调试视图）
兜底：模型不可用、超时或输出非法时，由 Utility 打分直接选意图
```

| 步骤         | 内容                                                                         | 依据                                                                                                                                                                                 |
| ------------ | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1 感知摘要   | 从该国知识层生成：国力、威胁、关系、近期事件、神谕、此刻合法的意图菜单与代价 | [`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 6.3 节；观察栏预计算（[`my_ai_town_agents.md`](../../10_research/ai_npc/my_ai_town_agents.md) 第 10 节第 7 条） |
| 2 大模型提议 | 只能从菜单选；不能发明菜单外的动作                                           | `llm-agent.md` 的 allowed_tools 与 output_contract（同上第 6.2 节）                                                                                                                  |
| 3 内核校验   | 条约、停战期、正当理由、国库、行动冷却、权限分级                             | 同上第 6.3 节                                                                                                                                                                        |
| 4 规划分解   | 战役层（月）：集结哪支军、修哪条路、向谁借款                                 | 同上第 4.6 节分层决策                                                                                                                                                                |
| 5 执行       | 运营层（日）：预算、建造、征兵、贸易订单                                     | 同上                                                                                                                                                                                 |
| 6 回写       | 结果进事件流与时态快照，供下次感知                                           | 修仙 GDD 13                                                                                                                                                                          |
| 7 表达       | 大模型把结果写成国书、宣言、传闻                                             | 同上                                                                                                                                                                                 |

- **决策分层**：战略层（季度或重大事件）用大模型 + Utility 兜底；战役层（月）用规划器；运营层（日）用规则与 Utility；
  战术层（tick）用行为树、状态机、流场（同上第 4.6 节分析）。
- **意图菜单**（战略层）：国策目标（扩张、发展、结盟、防御、复仇、宗教使命、敛财）、外交意图（第 4.1 节菜单 + 目标国）、
  军事意图（集结、进攻某郡、防守某线、撤退、围城）、经济意图（加税、减税、借贷、禁运、开商路）、情报意图（第 6.3 节菜单）。
- **公开与内心分离**：国书进世界；真实理由只进调试视图与（后期）莫伊拉的"诸国记录"（[`my_ai_town_agents.md`](../../10_research/ai_npc/my_ai_town_agents.md) 第 10 节第 9 条）。
- **外交规划器定意图、大模型说话**的外部先例是 CICERO（补充资料，细节待核实，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.2、6.6 节）。

### 4.2 承诺与可信度

| 承诺类型 | 本作用法                                                               | 依据                                                                                              |
| -------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| 系统绑定 | 资源转移、割地、婚约：签了就执行                                       | `negotiation.md`（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.2 节）   |
| 非绑定   | 未来行动（出兵、不进攻）：可以背弃，背弃者"信誉"下降，所有国家都看得见 | 同上                                                                                              |
| 抵押     | 人质（具名人物）、某城的税收权、商路股份                               | 同上                                                                                              |
| 声誉     | 每个国家有公开"信誉"值，影响他国接受非绑定承诺的意愿                   | 同上；囚徒困境的重复互动解法                                                                      |
| 契约加护 | 由梅尔卡以神力背书的条约：违约者自动承受注册过的惩罚修正项             | [`pantheon.md`](../../20_world/pantheon.md) 第 3 节（契约加护）；它会提高双方的神依赖度，并产生澱 |

- 成本信号可信，廉价沟通不可信：调兵、交人质、开放商路是可信信号；国书里的漂亮话不是（`signaling.md`，同上第 4.2 节）。
- **契约看不见国主**：契约加护经由铭录执行，无页之人不受约束（[`goddess_gm.md`](goddess_gm.md) 第 5.5 节"对无页者的强制执行无效"；
  act4 第 8.1 节"契约看不见国主"）。因此以神力担保的条约约束得了玩家的国民与官员，约束不了玩家本人；
  经济战与外交的矛头只能指向国民。玩家的对策是凡约：不靠神，靠法庭与公开声望。

### 4.3 谈判形式

- **结构化条款**：外交界面以条款按钮组合提案（割地、赔款、条约、宗教条款、人质）；AI 按 Utility 评估接受度（对它的价值、关系、性格、局势）。
- **对话**：大模型生成外交辞令；玩家在对话里说的话，经"条款解析"变成结构化提案后才进入裁决。口头承诺不等于条款
  （my_ai_town"口头承诺不等于交付"，[`my_ai_town_agents.md`](../../10_research/ai_npc/my_ai_town_agents.md) 第 10 节第 18 条）。
- **会盟**：多方会议按阶段进行（邀请、预备会谈、正式会盟、签约），每阶段有期限，到点即推进（法官式状态机，同上第 6.2 节）；
  第四幕的龙脊会盟（七国会盟）用此形式（第 8.1 节）。

| 神谕     | 女神的神谕（注册修正项 `casus_belli`，显性） |                                        |

### 4.5 反联盟

- **侵略扩张值**（Aggressive Expansion）：每占领、吞并一个郡，对周边每个国家累积；距离越近、文化与信仰差异越大，累积越多；每年衰减约 30%。
- 当一个国家对某侵略者的侵略扩张值越过阈值，且侵略者的国力摘要明显领先时，该国倾向加入**防御联盟**；联盟一旦成形，对侵略者统一行动。
- 这条规则对所有国家一视同仁：帝国扩张同样会招来联盟。补充资料：《欧陆风云 4》的反扩张联盟（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.2、4.7 节）。
- 玩家始终能看到每个国家对自己的侵略扩张值与联盟倾向（显性预警，反扑必须可预警，[`game_dev_methodology.md`](../../10_research/open_share/game_dev_methodology.md) 第 5.3 节分析）。

## 5. 战争

### 5.1 动员

| 兵源       | 规则                                              | 代价                                                                                               |
| ---------- | ------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| 常备军     | 一直在编；训练好、士气高                          | 平时也付维持费（[`economy_and_trade.md`](economy_and_trade.md) 第 6.2 节）                         |
| 征召       | 从人口池抽成年人（按动员等级）；集结需 7 到 20 天 | 劳动力与税基立刻下降；复员后才恢复                                                                 |
| 佣兵       | 雇佣立即到位；契约统一在同盟的佣兵公证所登记      | 贵；忠诚与军饷挂钩；大陆最大的金秤军团（约 2 万）属金冠哈特（`nations_and_factions.md` 第 2.7 节） |
| 志愿与圣战 | 圣战号召带来志愿兵                                | 女神修正项，带澱与神依赖度                                                                         |
| 盟军       | 同盟条约                                          | 盟友的意愿与它自己的利益有关                                                                       |

**动员等级**：和平、戒备、部分动员（征召成年男女的 5%）、总动员（15%）；越高，产出与税收越低、战争厌倦增长越快。

### 5.2 军队与移动

- **军队**：兵团记录列表 + 将领 + 辎重。兵团是 B 层数据，常驻不丢失（[`warfare_rts.md`](warfare_rts.md) 第 2.3 节）。
- **移动**：在郡图上按天移动，速度取全军最慢者与地形；关隘、要塞必须攻克或围困后才能通过。
- **堆叠**：一个郡内同一方的军队兵力超过补给容量的部分，靠补给线供养，否则减员。
- **遭遇**：敌对军队进入同一郡即触发战斗（5.5 节）；一方可选择"回避"（向相邻己方郡撤退），由机动性与侦察对比判定是否成功。

### 5.3 补给线

- 规则见 1.3 节。补给线在大地图上画成线，运力不足、被切断、被袭扰都有明确图标。
- **仓储据点**：城建里的粮仓、货栈、军械库就是补给线的终点；前线修建"军需仓"（临时货栈）可以缩短补给线。
- **断补给**是第一等的战术目标：截断补给比打赢一场会战更能赢得战争。
- 跨国补给线（穿过盟友领土）需要借道条约。

### 5.4 围城

| 方式     | 规则                                                                                 |
| -------- | ------------------------------------------------------------------------------------ |
| 围困     | 每日：守军存粮 - 守军人数；存粮耗尽后守军每日减员并士气下降；外援军队可解围          |
| 攻城进度 | 每日按"攻城器械 + 工兵 - 城墙等级 - 守军"累积；进度满时城墙出现缺口                  |
| 强攻     | 随时可发起：进入守城战（手动 RTS 或自动结算，同一内核）                              |
| 劝降     | 守将忠诚低、存粮少、外援无望时可劝降；交涉由大模型生成台词，接受与否由内核按条件判定 |

- 城建里的城墙、城门楼、箭塔、粮仓在攻城战中是实体（[`city_building.md`](city_building.md) 第 11 节）。

### 5.5 战斗：自动结算与手动 RTS

| 情形                             | 结算                                                                                               |
| -------------------------------- | -------------------------------------------------------------------------------------------------- |
| 玩家本人与该军队同在             | 玩家选择：亲自指挥（手动 RTS），或交给将领（同一内核自动）                                         |
| 玩家的军队，玩家不在             | 同一内核自动结算，己方由将领 AI 指挥                                                               |
| 涉及玩家关注的具名人物或剧情战役 | 同一内核（手动或自动），不走估算                                                                   |
| 远方 AI 对 AI 冲突               | 战役方程（由内核标定，[`warfare_rts.md`](warfare_rts.md) 第 2.3、2.5 节）                          |
| 第五幕灰烬决战的非核心战线       | 按战线回合结算（act5 第 7.3 节的战线方程，内核标定，[`warfare_rts.md`](warfare_rts.md) 第 7.3 节） |

- 世界不等玩家：玩家无法同时赶到两个战场；行路之门可以快速赶往有门标的地点，但有冷却。
- 战斗开始时冻结大地图时钟；自动结算的战斗在后台完成，结果以战报形式出现，可回放。

### 5.6 战争目标与和谈

- **战争分数**：会战胜负、占领郡、达成战争目标、俘获具名人物累积；对方也在累积。
- **和谈条件**：割地（只限相邻郡）、赔款、条约、释放附庸、宗教条款、交出人物；AI 按战争分数、战争厌倦与性格评估接受度。
- **强制停战期**：和约后一段时间内不得对同一国宣战，期限为"本幕内且不少于一季"（D-049），除非有神谕或违约。

### 5.7 战争厌倦

- 随战争时长、伤亡、本土被占、征召率上升；高厌倦降低稳定、税收、士气基线，并推动统治者求和。
- 玩家的国家同样适用；国家自治度高时，战争厌倦增长较慢（居民相信自己在为自己而战），通道可在国家自治报告里看到。

## 6. 贸易与谍报

### 6.1 商路

- **商路**（Trade Route）：连接两个市场的路径对象，带商品、运量、关税经过的郡、风险（盗匪、魔物、战争）。
- 商路价值 = 两地价差 × 运量 - 运输成本 - 关税；经过的郡收关税，沿途国家因此在乎商路安全。
- 玩家的商会经营商路的细节见 [`economy_and_trade.md`](economy_and_trade.md) 第 3.4 节；国家层只管"开放、关闭、征税、保护"。
- 梅尔卡的商路事件（开通、封锁、商队遇袭）以修正项与实际遭遇进入（第 7.2 节）。

### 6.2 禁运与走私

- **禁运**：外交行动；禁止本国与目标国（或某类商品）的合法贸易。
- 禁运抬高价差，走私随之出现：黑市溢价、灰鼠的路线、查抄风险（[`economy_and_trade.md`](economy_and_trade.md) 第 4.5 节）。
- 第四幕"金湾之围"是本层的主要经济战：同盟各城拒收庭外之国的货、拒绝兑换其银币；哈特收购洛萨宰相的旧债，以"债随地走"约束有页的国民；
  盐、铁、药三项禁运；玩家以门券、凡约、夜境商路、希尔瓦草药、灰鼠走私反击，最终是金湾挤兑（act4 第 8.1 节；经济侧见
  [`economy_and_trade.md`](economy_and_trade.md) 第 3.6 节）。
- 禁运的咽喉在地理上是具体的：格兰水道、金潮航线（可封锁落日港）、炉道（武器）（`geography.md` 第 6.1 节）。

### 6.3 情报行动

| 行动     | 作用                                  | 成功判定                 | 暴露后果                   |
| -------- | ------------------------------------- | ------------------------ | -------------------------- |
| 侦察     | 揭示某郡驻军、某军队构成              | 情报网强度对反谍         | 轻微关系下降               |
| 安插     | 在目标国建立或加强情报网              | 时间累积                 | 被清洗                     |
| 策反     | 让忠诚低的官员或将领倒向己方          | 目标忠诚、野心、己方好处 | 关系大降，可能成为正当理由 |
| 散布传闻 | 影响目标国稳定、正统或某人物声誉      | 经社会层的传闻扩散       | 被揭穿时己方信誉下降       |
| 窃取技术 | 获得配方或研究成果                    | 网络强度                 | 同上                       |
| 破坏     | 烧粮仓、断补给、毁众门环节点          | 网络强度与目标守备       | 可成为宣战理由             |
| 伪造证据 | 在目标知识层植入 `misreported` 的说法 | 网络强度与证据质量       | 被识破后信誉大跌           |
| 刺杀     | 具名人物（剧情保护者除外）            | 极难                     | P3；暴露即可能开战         |
| 反谍     | 削弱他国在本国的网络                  | 本国情报投入             | 无                         |

- 所有判定是确定性规则 + 内核随机源；结果写入知识层，不写入世界真值（伪造证据只改变别人"以为"的事）。
- AI 也守信息边界：AI 的感知只来自自己的知识层，为了让 AI 更强而偷看玩家信息会长期损害公平信任
  （[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.4 节）。

### 6.5 知识层

- 世界真值只有一份；每个国家、每位女神、玩家各有自己的知识层（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.4 节）。
- 谍报就是在知识层之间移动、伪造、延迟信息；神之视线是女神的知识层来源（[`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 6 条）。
- 玩家无页：女神对玩家国家的认识只来自信徒见闻与神殿覆盖，因此"世俗国家"政策能让女神们真正看不清玩家在做什么。

## 7. 女神的影响

### 7.1 原则

1. **只走注册通道。** 女神的每一种战略干预都是一个注册过的修正项模板，作用于有限的通道，有上限、期限、神力消耗与澱产出；
   修正项合同见 [`economy_and_trade.md`](economy_and_trade.md) 第 7 节。
2. **受神约约束。** 不得亲身降临；不得直接取走他司信徒性命，须假手凡人；审定前最后十年禁止直接冲突，只能代理人相争
   （[`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 8 条）。因此她们在战略层的手段都经由凡人、天气、魔物、市场。
3. **显性或半显性，可追溯。** 显性：神谕公开宣告；半显性：效果可见（"本季粮价异常"），原因可经情报、神殿、莫伊拉的情报交易查明。
   不存在完全隐藏的女神干预（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.7 节分析与借鉴清单第 18 条）。
4. **神力与视线。** 女神只能在自己看得见、够得着的地方出手；信仰越少，越够不着（[`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 2 条）。
5. **女神 AI 也走同一条管线**：人格会话提议，规则执行者校验神力、神约、作用域、冷却后落地（D-008；`goddess_gm.md`）。

### 7.3 女神之间

- 女神彼此竞争、交易、指控；她们的约定与违约记录是一等对象（[`comparison_and_plan.md`](../../10_research/ai_npc/comparison_and_plan.md) 第 6.4 节）。
- 战略层的表现：两位女神可能在同一场战争里各扶一方（例如艾琉恩的圣战与瓦尔妲的战争挑唆同时作用于帝国），
  修正项按通道叠加规则合并（同一通道多来源时取和，但总幅度有上限，见 [`economy_and_trade.md`](economy_and_trade.md) 第 7.3 节）。
- 玩家揭露某位女神违约的证据，可以改变诸神之间的力量平衡（[`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 8 条）。

### 7.4 神迹账与离手判定

- **记录**：每一个女神动作与修正项实例都写入只增不改的日志，带受益方、是否经受益方请求或接受、神力与澱产量。
  第六幕的证据 E34"神迹账"就是莫伊拉汇编的这份内核日志：本周目每位女神的实际干预次数与澱产量，干预越多，对她的必要防线越强
  （act6 第 4.2 节）。所以女神 GM 在本周目里真实做过的事，就是呈堂证供。
- **真结局判定**以 act6 第 11.1.1 节为准，与本层相关的是："无神干预挺过危机"（无战线溃败、`held_unaided` ≥ 3、`janu_act` = 接人）

| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 正式名与时间         | 龙脊会盟，999 年秋；龙脊山脉之巅、第七座天启碑下的七席石；规矩"龙下无刃"                                                                               |
| 召集方式             | 剑帝与玩家共同召集（`emperor_respect` 高）；公会总会长召集（外交承认 `nat_legit` ≥ 3）；否则教国召集，玩家以"被告"出席                                 |

| 阶段 | 内容                                                                                   | 系统                         |
| ---- | -------------------------------------------------------------------------------------- | ---------------------------- |
| 起   | 教国的异端之国诏（显性修正项）；圣战联军集结；各国收到神谕                             | 第 7.2 节；第 4.4 节宗教理由 |

## 9. 节奏与委托

### 9.1 时间步长

- 战略层以"日"为步长，每日分三段：晨（AI 运营与命令下达）、昼（行军、贸易、建造）、夜（战斗结算、事件、谍报）。
- 战略视图下的一天远快于 RPG 层的一天（RPG 层约 24 分钟一天，暂定）：战略视图是同一时钟的"领主加速"。

### 9.2 暂停与加速

| 速度档（D-050） | 一天约等于现实（待调） | 用途             |
| --------------- | ---------------------- | ---------------- |
| 暂停            | 无                     | 下令、外交、查看 |
| 1x              | 60 秒                  | 战争中           |
| 2x              | 20 秒                  | 常态             |
| 4x              | 6 秒                   | 和平时期         |

- **自动暂停**：玩家的军队遭遇战斗；他国向玩家提议；P3 级事件（宣战、联姻提议）；危机；职权 4 的请示；女神对玩家降下神谕。
- **AI 质量不受加速影响**：统治者与女神的决策轮按游戏日排程；加速时，规划轮在途期间世界退回 1x，回复到达后再恢复；
  每现实小时的请求设上限，超出时改为"隔日规划 + 规则填充"，回复超时由 Utility 兜底（与 [`goddess_gm.md`](goddess_gm.md) 第 6.6 节一致；
  依据 [`my_ai_town_agents.md`](../../10_research/ai_npc/my_ai_town_agents.md) 第 1.2.5 节；[`game_framework.md`](../game_framework.md) 第 6 节）。
- **时间预算**：第四幕约半年（约 180 天）。以 2x 计算约 1 小时纯地图时间，加上暂停决策与个人层冒险，与主线时长目标相容。

### 9.3 季度跳跃

只有满足全部条件时才开放（[`game_framework.md`](../game_framework.md) 第 6 节"只在剧情允许时开放"）：

1. 剧情标记允许（幕间或指定的平静期）；
2. 玩家国家不在进攻战争中（防御战线已有授权书时允许）；
3. 没有待决的 P3 事项与危机；
4. 所有郡都有总督。

跳跃期间：规则档逐日运行，统治者只在季度末各调用一次大模型写"季度总结"；任何重大事件（对玩家宣战、叛乱、女神大型干预）立即中断跳跃。
跳跃结束给出季报。

### 9.4 国家层委托

| 角色                                    | 职责                                                                                                                      | 委托工具           |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------ |
| 内阁（官职与默认人选见 act4 第 4.5 节） | 各领域的月度决策（L1 或 L2 AI）：军务、财务、民生与医、门务与交通、人簿与登记、外务、礼与教化、学术与星象、治安、北境防务 | 授权矩阵           |
| 议会、法庭（视国体）                    | 门庭议会的 AI 代表自行提出法案；法庭裁决纷争                                                                              | 议事日、法典       |
| 总督                                    | 管理一组郡内的全部聚落                                                                                                    | 郡级预算与常设命令 |
| 战线主帅                                | 战时一条战线                                                                                                              | 战线授权书         |

- **国策**：一项国家级的方向（休养生息、扩军备战、通商开放、众门环优先、宗教宽容等），为内阁所有官员的 Utility 加权。
- **授权矩阵**：哪个官员可以执行哪一级的行动。例：外务可签通商（P2）但不能签同盟（P3）；军务可调动预备队但不能宣战。
- **国体决定玩家的位置**：王政下玩家一言而决（国主敕令），无主之制下玩家只是普通国民、国主专属行动全部关闭（act4 第 4.4 节）。
- **季报**：每季度一份，按领域汇总，标出需要玩家决定的少数事项。
- 第四幕五条纷争同时推进，每条都有"玩家亲办"与"交给官员"两种推进方式，后者更慢或更差但提升自治度（act4 第 8 节）。
- 玩家仍可直接操作任何事务，代价是国家层依赖（计入 A_core，[`city_building.md`](city_building.md) 第 8.2、8.5 节）。

| 空间     | 连地扩张           | 连地规则               | 离首都越远，政令延迟越长                                                         | 侵略扩张值                                                     |
| 信息     | 情报网覆盖         | 情报投入               | 网络需要维护                                                                     | 反谍；伪造证据                                                 |
| 时间     | 加速度过和平期     | 季度跳跃条件           | 无                                                                               | 危机自动暂停                                                   |
| 心理     | "我已经是大陆第一" | 无                     | 每幕换赛道                                                                       | 第五幕的终局危机迫使所有国家合作（补充资料：《群星》终局危机） |
| 社交     | 盟友越多越安全     | 同盟数受信誉与关系约束 | 盟友的意愿与它自身利益挂钩                                                       | 多极均势：AI 统治者的 Utility 含"力量平衡"项，倾向站到弱者一边 |
| 神恩     | 接受女神的帮助     | 女神的神力预算         | 神依赖度上升                                                                     | 真结局条件；澱上升招来魔物；女神的帮助都有条件                 |

  （修仙地理映射 09"换赛道的相对贬值"，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.7 节）。
- **英雄的相对贬值**：玩家个人在 C 层只是军队乘数（封顶），国家越大，个人对单场会战之外的影响越小（[`warfare_rts.md`](warfare_rts.md) 第 2.5 节）。

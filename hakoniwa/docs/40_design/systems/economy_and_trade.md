## 0. 定位与硬约束

### 0.1 一句话

钱是龙傲天进入人类社会最安全的接口：凡人会因为利益而不是武力重新看待玩家
（[`synthesis.md`](../../10_research/anime/synthesis.md) 第 2.8 节）。经济层从玩家的钱袋长到门扉商会，再长到一个国家的国库，
对手是金冠哈特，背后是"笑眯眯的算计"梅尔卡。

### 0.2 硬约束

1. **内核结算。** 价格、税、利息、产出、消耗都由确定性内核结算；AI 商人与官员只从菜单里提意图（D-007）。
2. **注册修正项（D-013）。** 女神对价格、商路、灾害的干预，以及政策、条约、灾害本身，都只能作为注册过的修正项进入价格分解与产销，
   显性或半显性、可追溯；禁止"直接改价"（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.3 节分析与借鉴清单第 24 条）。
3. **钱有去向。** 税、手续费、供品都进入指定流水去向，不凭空消失（修仙 GDD 14，同上第 5.3 节）。
4. **防通胀与防滚雪球。** 每种资源四张表、自动套利审计、分群模拟门槛（第 9 节）。
5. **AI 守同一规则。** 金冠商行等 AI 竞争者用同一个市场、同一份价格分解，不作弊。

## 1. 货币体系与物价锚

### 1.1 货币

货币单位、各国铸币与物价以 [`society.md`](../../20_world/society.md) 第 9 节为准；分幕补充了庭外之国的门券（act4 第 4.6、8.1 节）。

| 层                 | 内容                                                                                                                                                                                                                                                                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 铸币               | 1 金 = 100 银 = 100 × 100 铜；内核以铜为最小单位（与主工程 `src/sim/format_money.ts` 一致）。各国自铸，以金湾汇兑价为准：湾金（同盟，基准）、剑银（帝国，足值）、麦穗银（洛萨，按九折兑换，"王国的债务看得见"）、光币（教国，足值，多用于什一税与赦罪状）、铜环（各国通用的有孔铜币，不兑换）、黑铁钱（夜境，境外不收）（`society.md` 第 9.1 节） |
| 门券（Door Scrip） | 庭外之国的货币，以"门路运力"为担保：一张门券保证持有者或其货物经门路通行一次。不靠金子、不靠神，靠众人共用的"连接"（act4 第 4.6 节）。供给受门路运力约束（第 5.4 节）。立国初期庭外之国另有自铸银币，同盟拒绝兑换（act4 第 8.1 节）                                                                                                               |
| 魔晶               | 在冒险者之间常被当作"半货币"使用（小晶找零是边陲小镇的日常）。合法流通的是**净炼后的魔晶**；未净炼的澱晶不得在市面流通，只能走黑市（`society.md` 第 9.1、9.3、4.5 节）                                                                                                                                                                            |
| 非货币经济         | 精灵在森林内不用货币，以赠礼与互助维持；兽人以畜群计价，与外族交易收湾金；遗民没有自己的货币                                                                                                                                                                                                                                                      |
| 受限货币           | 冒险者公会功勋（只换公会服务）、军功（只换晋升与赏赐）；不能兑换为自由货币（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 5.1 节）                                                                                                                                                                                         |
| 非货币的硬通货     | 神恩、供品回礼、神器碎片、钥：只来自关键事件与女神，城建刷不出来（[`game_dev_methodology.md`](../../10_research/open_share/game_dev_methodology.md) 第 5.3 节分析）                                                                                                                                                                               |

- 术语：魔物死去时凝成的结晶，正典在 `power_system.md` 第 7.7 节统称"澱晶"；D-040 统一为：未净炼的澱晶（俗称灰晶）不得合法流通，
  经持证工坊（教会、学院、公会）净炼后成为魔晶，魔晶是事实上的硬通货，净炼会减少余澱（净炼费约为市价的三成）。
  本文按此建模：采集得到澱晶，经净炼成为魔晶才能合法交易（[`city_building.md`](city_building.md) 第 6 节）。
  玩家从夜羽口中听到"澱"之前，界面上的澱晶显示为俗称"灰晶"（D-030）。
- 设计选择：金属铸币与灵素**不挂钩**（钱就是金属），以免货币同时承担能源角色导致用途重叠（硬通货与软通货的用途不重叠原则，同上第 5.1 节）。
  魔晶天然兼有"钱与能源"的双重属性（修仙资料的灵石同构），这一点由它的余澱代价来平衡：用得越多，地下的澱越多（[`city_building.md`](city_building.md) 第 12.1 节）。

### 1.2 账户

| 账户     | 归属                           | 用途                   |
| -------- | ------------------------------ | ---------------------- |
| 个人钱包 | 玩家                           | RPG 层收支             |
| 商会账   | 门扉商会（玩家与合伙人按股份） | 商品、店铺、商队、雇员 |
| 领地国库 | 聚落或领地                     | 税收、维护、建造、军费 |
| 国家国库 | 庭外之国                       | 第四幕起               |

- 账户之间的转账必须显式、有记录、带原因。把国库挪进私囊会在被发现时打击正统与民心；把私财补贴国库计入依赖
  （[`city_building.md`](city_building.md) 第 8.2 节）。
- 所有资源与货币变动都带 reason 枚举与变动后余额，在概要设计期定稿枚举（[`game_dev_methodology.md`](../../10_research/open_share/game_dev_methodology.md) 第 5.3 节）。

### 2.4 冒险收益的相对贬值

国家产能起来以后，冒险得来的金币会相对贬值。第三幕起，冒险奖励逐渐转向"国家生产不了的东西"：人才（招募线索）、神器、情报、钥
（[`game_dev_methodology.md`](../../10_research/open_share/game_dev_methodology.md) 第 5.3 节分析）。这让个人层不在后期空转。

## 3. 商会经营

### 3.1 门扉商会的成长

正典：第二幕玩家与奈拉合伙创立商会，默认名"门扉商会"，以地球知识与门内庭院的产出做生意（[`story_outline.md`](../../30_story/story_outline.md) 第二幕）。

| 阶段   | 幕次               | 规模                             | 解锁与事件                                                                                                                                                                                                                  |
| ------ | ------------------ | -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

## 4. 区域经济模型

### 4.1 市场与区域标签

- 每个有市集的聚落是一个**市场**；AI 国家的聚落按郡聚合为一个市场。
- 每个市场绑定：基准货币、生产标签（产粮、产铁、产木……）、稀缺标签、交易限制标签（禁澱晶、禁异端书籍、战时管制）、价格倍率、税率。
  **标签只能通过注册的定价与库存接口生效，不能自由相乘**（修仙 GDD 14，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.3 节）。
- **市场分层**（同上第 4.3 节）：

| 层         | 特点                 | 本作实例                   |
| ---------- | -------------------- | -------------------------- |
| 坊市       | 高频公开，日用品     | 各地市集                   |
| 拍卖会     | 稀缺资产，价格发现   | 金湾拍卖行（第四幕）       |
| 秘密交换会 | 身份筛选，信息不公开 | 灰鼠的黑市、遗民之间的交换 |

### 4.2 供需与价格

每个市场、每种商品每日结算：

```
目标库存 T = 日需求 × 目标天数（初值 30）
日需求    = 人口池的需求消费 + 军需 + 生产投入 + 商队采购
价格倍率  = clamp( (T / max(库存, 1)) ^ k, 下限, 上限 )
           k：必需品 0.8，一般品 0.5，奢侈品 0.3
           上下限：必需品 0.5 到 2.5；其他 0.6 到 1.8
日变化    ≤ 5%（平滑）
```

- 市场状态标签给玩家看：稳定（倍率约 0.90 到 1.10）、波动（约 0.70 到 1.30）、稀缺（约 0.85 到 1.50 且库存低于目标一半）；
  这组区间来自修仙项目的 design_only 参数，只作起点（同上第 5.2 节）。
- **贸易流**：AI 商人（L4 规则）在价差大于"运输成本 + 关税 + 风险溢价 + 资金占用"时沿商路运货；运量受商队运力约束，因此价差会收敛但不会瞬间抹平。

### 4.3 价格分解

每一个报价都附价格明细，逐行列出（修仙 GDD 14 的价格分解，同上第 4.3、5.2 节）：

```
报价示例：瓦伦堡秤街，粮 100 单位，第二幕第 9 周（伯爵死后）
  基准价值               600 铜
  品质（中等黑麦）         ×1.00
  供需（库存 12 天/目标 30）×1.62
  商店（金秤会馆加价）      ×1.05
  关系（布鲁娜：友善）      ×0.97
  汇率（通用币）           ×1.00
  修正项：伯爵府冻结粮仓（政策） ×1.10
  修正项：异常波动（来源未查明） ×1.08
  交易税 5%（去向：瓦伦堡城库）  +数额
  = 合计；报价版本号 v.9-3-117
```

- 报价保存各项的版本；确认时版本不一致必须重新展示，不能静默改价（同上第 5.2 节）。
- 女神的修正项作为独立一行出现，显性时写明来源（"梅尔卡·丰饶"），半显性时写"来源未查明"，可经调查揭开（第 7.4 节）。

### 4.4 汇率

- 只有定义过的货币对可以兑换；未定义汇率时阻断交易，不隐式 1:1（同上第 4.3 节）。
- 汇率每日在一个区间内浮动，由发行国的国库、债务、战争、信誉、铸币量决定；兑换收手续费（回收口）。
- 受限货币（公会功勋、军功）不能兑换为自由货币。
- 基准是金湾汇兑价（湾金）；麦穗银按九折，黑铁钱在夜境以外不收，铜环不兑换（`society.md` 第 9.1 节）。
  大额贸易几乎都用金湾汇票，手续费 2% 到 3%（同上第 4.3 节）。

### 4.5 黑市

| 项       | 规则                                                                                                                                                                                                              |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 出现条件 | 某商品的"税负 + 禁令溢价"超过阈值，或存在禁运                                                                                                                                                                     |
| 商品     | 澱晶（未净炼，俗称灰晶，卖给术士、门徒会与不想付净炼费的工坊）、禁书（空白纪残页、星象书）、伪造的洗礼证明与公会卡、赃物与遗物、毒药、走私盐粮、给遗民的逃亡路线（`society.md` 第 4.5 节）                        |
| 价格     | 违禁品为合法价的一倍半到三倍，溢价随查抄风险上升；伪造洗礼证明 5 到 20 金；一条安全的出城鼠道 1 到 10 金（老鼠洞对遗民不收钱）                                                                                    |

| 玩家选项 | 容忍、打击、合法化并征税（例如领地自建净炼坊、把澱晶就地净炼后合法出售，绕开商会联合的大宗渠道，代价是与商会联合交恶）                                                                                            |
| 经营者   | 灰鼠；第一幕代官莫斯曾雇匪帮沿"灰路"（晶沟、折桥驿、边石镇、瓦伦堡，再流入黑市）走私澱晶（[`story_outline.md`](../../30_story/story_outline.md) 第一幕；[`geography.md`](../../20_world/geography.md) 第 6.1 节） |

## 5. 流水、回收与审计

### 5.1 四张表

每种资源与货币都维护**产出、消耗、库存、价格**四张表，按日快照，按市场、聚落、国家三个口径汇总（`inflation.md`，
[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 5.5 节）。只看平均库存会掩盖头部与流失，因此同时看分位数（同上第 1.2 节 `economy-curve.md`）。

### 5.2 税收流向

| 税费           | 去向                                         |
| -------------- | -------------------------------------------- |
| 交易税         | 市场所在聚落的城库，按法令上缴领主或国家     |
| 关税           | 关卡所在郡的拥有者                           |
| 田赋、人头税   | 聚落城库 → 领地国库 → 国家国库（按法令分成） |
| 什一税（教会） | 当地教会，最终部分上缴教国（"圣教的血"）     |
| 特许费         | 发放特许的机关（行会、官府）                 |
| 兑换手续费     | 汇兑所经营者                                 |
| 商会利润       | 按股份分配给合伙人                           |

- 税率夹在 0 到 1 之间；每一笔税都有去向，不凭空消失（修仙 GDD 14，同上第 5.3 节）。

### 5.3 水龙头与回收口

| 水龙头（新增财富）     | 回收口（消灭财富）                 |
| ---------------------- | ---------------------------------- |
| 任务奖励、掉落、宝箱   | 建筑维护费                         |
| 生产（把劳力变成物资） | 军饷与军粮（最大回收口）           |
| 女神赐予、遗迹宝藏     | 建造与修理                         |
| 铸币（国家发行）       | 消耗品、腐坏、战损                 |
|                        | 税费中流向"消费性支出"的部分       |
|                        | 兑换手续费、保险赔付准备           |
|                        | 供品（流向女神，等于离开凡人经济） |

- **头部回收**：针对头部库存设专门回收口，不让平均数掩盖极端库存（同上第 5.5 节）：大型工程（众门环、立国碑、编年馆、结界墙）、
  稀有拍卖、外交援助、供品。这些回收都服务于成长、外观或剧情目标，而不只是惩罚（`economy-sink.md`，同上）。
- **转移不是回收**：贿赂、赎金、利息是财富在主体之间的转移，进入接收方的账户。

### 5.4 铸币与门券

- 国家铸币是水龙头。铸币过多会让本币贬值（汇率下跌、物价上涨），这是给"印钱解决问题"的真实反馈。
- **门券**（act4 第 4.6、8.1 节）是庭外之国的主力货币，本位是门路运力：
  - 发行上限 = 门路在一个结算周期内能提供的通行次数（由门标、门站数量与每扇门扉的每日吞吐决定，[`city_building.md`](city_building.md) 第 2.4 节）
    × 准备率（初值 1.5 倍，即允许适度超发，待调）。
  - 门券可兑付为"一次门路通行"（人或货）；兑付消耗当日门路运力。
  - **挤兑**：短时间内大量兑付超过运力时，门券折价；折价超过阈值即崩溃（金湾挤兑）。玩家的对策是扩充门路、调度商队分流、
    或揭露对手的把柄让挤兑停止。
  - 门券流通越广，半身人商队越愿意加入联盟（act5 第 3 节）；第五幕补给系数也由门路覆盖、门券流通与 `econ_indep` 决定（act5 第 7.3 节）。
  - 门券是"连接"的货币：它让门扉吞吐上限同时成为货币的锚，因此门扉套利审计（第 5.5 节）也就是门券的稳定性审计。
  - 第六幕证据 E26（人簿、门券流通）与审期危机"契约停摆"的应对都用到它（act6 第 4.2 节，第 8.6 节）。
- 立国时可以不发门券、只用他国银币（汇率受制于人，`econ_indep` 低）；也可以铸本国银币（需要成色与信誉管理）；两者与门券可以并行。

### 5.5 套利审计

自动搜索无风险正收益循环（修仙 GDD 14 的套利审计，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.3 节与借鉴清单第 25 条），
作为经济回归测试的一部分（实现归 `docs/50_tech/`）：

| 审计项           | 检查                                                                                                                                               |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 同一市场买卖     | 买价永远不低于卖价                                                                                                                                 |
| 跨市场           | 扣除运输、关税、风险、时间后不存在稳定正收益的瞬时循环                                                                                             |
| 跨货币           | 汇率环路扣手续费后不为正                                                                                                                           |
| 制作与分解       | 分解返料价值低于原料                                                                                                                               |
| 任务奖励转卖     | 可重复任务的奖励不能低成本循环套现                                                                                                                 |
| 门扉运输         | 门扉即时且免运费，必须受每日吞吐上限与门息消耗约束；单日门扉套利上限不超过当日正常收入的约 10%（[`city_building.md`](city_building.md) 第 2.4 节） |
| 庭院生产         | 庭院产出不受季节与天灾，但量小；检查"庭院产出 + 灾年高价"的收益上限                                                                                |
| 地球知识垄断     | 仿制期内的垄断利润有总上限（需求饱和）                                                                                                             |
| 借贷             | 借低贷高的循环受信誉与抵押约束                                                                                                                     |
| 俘虏赎金         | 赎回、再战、再俘的循环不可能（被俘者有冷却与忠诚变化）                                                                                             |
| 负余额与无限库存 | 任何账户、库存都不允许为负；任何商人都没有无限库存                                                                                                 |

## 6. 领地与国家财政

### 6.1 税制

| 税种           | 税基                     | 特点                         |
| -------------- | ------------------------ | ---------------------------- |
| 田赋（收成税） | 农牧渔产出               | 稳定；荒年收不上来           |
| 人头税         | 人口                     | 简单；对穷人最重，幸福冲击大 |
| 交易税         | 市场成交额               | 抑制交易；推动黑市           |
| 关税           | 过境与进出口             | 外交工具；高关税减少商路     |
| 特许费         | 行会、商会、矿           | 审批权，寻租温床             |
| 专卖           | 盐、铁、澱晶（若合法化） | 收入高，民怨与黑市也高       |

**拉弗曲线**（政府失灵与税收资料，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 5.3 节）：

```
收入(t) = t × 税基(t)
税基(t) = 税基0 × (1 - t)^η × (1 - 逃税率(t, 治安, 监察)) × (1 - 黑市转移(t))
η：田赋 0.3，人头 0.2，交易 0.8，关税 1.0（待调）
```

- 界面上画出当前参数下的曲线并标出估计峰值（"交易税超过约 12% 后收入会下降"），让"加税"成为看得见的取舍。
- 加税同时降低幸福与迁入（[`city_building.md`](city_building.md) 第 5.6 节）。

**寻租**：特许费、关税、建造审批这类"审批权"会吸引寻租。漏损率 = f(官员廉洁, 审批量, 监察覆盖)；收益集中的一方积极争取，
成本分散的居民"理性冷漠"，所以寻租不会自己消失（同上第 5.3 节）。漏损进入官员个人财富，可经审计、监察、传闻发现。

**黑市反馈**：交易税、关税、禁令越重，黑市份额越高，税基越小，治安越差（第 4.5 节）。

**教会什一税**：圣教在人族聚落向信徒收什一，与领主的税争夺同一个税基。玩家的宗教政策决定是否允许（[`grand_strategy_slg.md`](grand_strategy_slg.md) 第 2.4 节）。

### 6.2 维护费与军费

**建筑维护**：见 [`city_building.md`](city_building.md) 第 4.2 节；欠缴按宽限、降效、停机三段处理，不产生隐藏负债。

**军费是最大的回收口**（补充资料，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 5.5 节：城建与 SLG 最大的天然回收口是维护费与维持费）。

```
每日军费 = Σ兵团 (人数 × (饷/30 + 口粮)) + 将领俸禄 + 装备损耗 + 佣兵合同
规模加价：常备军超过人口的 2% 后，每再多 1%，新增兵员的饷 ×1.15（兵源越来越稀缺）
```

- 和平时期军费约占岁出 20% 到 35%，战时 40% 到 65%（验收区间，第 9.3 节）。
- **欠饷**：士气基线每日下降，逃兵，最终哗变；佣兵按合同，欠饷即撤（金冠的佣兵靠契约加护维持士气，[`warfare_rts.md`](warfare_rts.md) 第 3.3 节半身人契约神官）。
- 补充资料：《魔兽争霸 3》的维持费让"军队越大，收入越低"（同上第 3.5 节）。

### 6.3 预算与国库

- 预算按政务领域分配（[`city_building.md`](city_building.md) 第 7.4 节）；部门官提出预算案，玩家批准或按授权自动通过。
- 国库有明细账：每笔收支带原因与对方；赤字时可以削减、借贷、加税、铸币，各有后果。
- 第四幕立国时选择铸币政策（第 5.4 节）。

### 6.4 债务与借贷

| 放贷方                              | 条件                                                                                                                                                                                  | 违约后果                                                           |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 梅尔卡托商会联合                    | 利率按信誉；常要求抵押（港口、商路股份、某城税收）                                                                                                                                    | 没收抵押；信誉下降                                                 |
| 梅尔卡托商会联合 + 梅尔卡的借贷担保 | 钱由商会联合出，梅尔卡只出担保（神力不能借给凡人，[`goddess_gm.md`](goddess_gm.md) 第 5.5 节；`power_system.md` 第 8.2 节）；经硬币、神龛或商会联系她；条件可以是供品、情报、一个人情 | 到期按条款自动执行；违约者被写入"失信"（契约加护的罚则，D-047）    |
| 金冠商行                            | 利率低、条件宽，但附带收购条款（"债务陷阱"）；收购他人债权（"债随地走"）                                                                                                              | 抵押资产被收购；被迫给予特许或开放商路；有页的债务人铭录上出现失信 |
| 商会、私人                          | 小额                                                                                                                                                                                  | 声誉                                                               |

利率与惯例以 `society.md` 第 4.3 节为准：平民借贷年息两成到四成（还不上可能沦为债奴或被收走土地）；商人借贷年息八分到一成五，
按商会联合的"秤级"（九档信用评级）定利率与额度；国家借贷年息六分到一成，以税收、关税或矿山为抵押（洛萨以北境魔晶的采集权抵押给了同盟）；
典当当期三个月、月息 3%。契约的担保分口头、书面公证（1 银）、契约加护（金额的 1%，最低 1 银）与哈特的契约权能（同上第 4.4 节）。

- **无页的例外**：契约加护对玩家本人无效（第 3.6 节）。所以梅尔卡与哈特给玩家的借贷都会要求有页的连带担保人（合伙人、官员）或实物抵押；
  违约时失信落在连带人身上。玩家可以赖账而不受神罚，但要付出信誉、合伙人与抵押的代价。
- **凡约**：不经任何女神加护见证的契约，由双方法庭与公开声望保证履行（act4 第 4.6 节）。以凡约借贷利率稍高（没有神力担保），
  但不抬高神依赖度，也对哈特的契约权能免疫；矮人"契约至上"，要说服赤砧山接受凡约是第四幕的关键一步（act4 第 8.1 节）。
- 正典的债务线：洛萨宰相冯·德雷克欠同盟巨债（[`story_outline.md`](../../30_story/story_outline.md) 第三幕），第四幕被哈特收购成"债随地走"；
  布鲁娜背着金湾总部借给伯爵府一大笔钱，伯爵死后债权悬而未决（`act2_wallenburg.md` 人物表）。
- 玩家也可以放贷给他国或他人，换取影响力（债主的外交权重）。
- 利息与本金有上限规则（单笔利率上限、复利封顶），防止债务滚雪球把 AI 国家拖成必然破产。

## 7. 注册修正项合同（全作通用）

依据：决策 D-013；[`comparison_and_plan.md`](../../10_research/ai_npc/comparison_and_plan.md) 第 6.4 节"价格与灾害等效果作为注册过的修正项进入内核"；
[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 2.5、4.3、4.7 节。

### 7.1 定义

修正项（Modifier）是**唯一**允许"临时改变某个数值"的途径。女神、灾害、政策、条约、科技、事件、建筑、光环都用它。
女神来源的修正项就是 [`goddess_gm.md`](goddess_gm.md) 第 4.6 节的 `RegisteredModifier`（编号、来源、类型、作用域、参数、期限、叠加、可见性），
本节把同一合同推广到非女神来源，并给出全作共用的通道表；两份文档的字段一一对应，类型上限以 goddess_gm 各动作的规定为准（例：物价 ±40%）。

```
ModifierTemplate {
  id
  sourceKind: goddess | disaster | policy | treaty | tech | event | building | aura
  channel: ChannelId                // 封闭集合，见 7.2
  scopeKind: market | itemTag | route | settlement | plot | province | nation | army | regiment | battlefield
  op: mul | add
  magnitude: { min, max }           // 模板允许的幅度区间
  duration: { min, max }, decay?    // 期限与衰减
  visibility: explicit | semi        // 显性或半显性；女神来源不允许 hidden
  stacking: { group, sameSource: refresh | stack, maxStacks }
  cost?: { divinePower?, coin?, materials? }
  dianPerDay?: number                // 女神来源：按神力折算的澱产出（系数由 goddess_gm.md 定义）
  revocable: bool
}
ModifierInstance {
  id, templateId, actorId, scopeIds[], magnitude, startDay, endDay
  beneficiary?: factionId, requestedOrAccepted?: bool   // 供神之干预记录（grand_strategy_slg.md 第 7.4 节）
  trace: { reasonKey, params, oracleText?, causeChain[] } // 可追溯
  revealedTo: observerId[]           // 半显性：谁已查明来源
}
```

### 7.2 通道（封闭集合，初版）

| 组   | 通道                                                                                                                   | 作用对象                   |
| ---- | ---------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| 经济 | `price_supply`、`price_demand`、`tax_rate`、`upkeep`、`route_state`、`loan_terms`、`resource_tag`、`trade_restriction` | 市场、商品标签、商路、聚落 |
| 生产 | `production_rate`、`harvest`、`spoilage`、`building_condition`                                                         | 建筑、地段、聚落           |
| 人口 | `happiness`、`health`、`migration`、`security`、`cohesion`、`faith`                                                    | 人口池、聚落               |
| 军事 | `army_morale`、`army_damage`、`army_defense`、`volunteer_pool`、`supply_capacity`、`move_cost`、`monster_wave`         | 军队、兵团、郡             |
| 政治 | `ruler_intent_bias`、`casus_belli`、`relation_shift`、`legitimacy_shock`、`intel_reveal`                               | 国家、统治者、关系边       |
| 环境 | `hazard_rate`、`dian_rate`、`weather`、`terrain_shift`                                                                 | 地段、郡                   |
| 门   | `door_resonance`                                                                                                       | 遗民、门纹者               |

- 新增通道必须走设计评审并同步更新本表；不允许"万能通道"。
- 完整实体在战斗中的增益减益仍是主工程的光环（`Aura`），本合同的军事通道只作用于兵团与战略层，两者都可见、带来源。

### 7.3 叠加、上限与顺序

| 规则             | 内容                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| 通道总上限       | 价格类合计倍率限在 0.5 到 2.0；生产类 0.3 到 1.5；士气类合计 ±30；幸福类合计 ±20（待调） |
| 同源             | 同一来源同一模板默认刷新期限而不叠加                                                     |
| 多源             | 不同来源在同一通道取和（加法）或乘积（乘法），然后再夹到通道上限                         |
| 顺序             | 按（通道、来源类别、模板 id、实例 id）稳定排序后应用，保证确定性                         |
| 与基础规则的关系 | 修正项只能在基础规则算出的值上加减乘，不能替换公式                                       |

### 7.4 可见性与追溯

| 档     | 玩家看到                                                              | 如何揭开来源                                                     |
| ------ | --------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 显性   | 效果与来源（"梅尔卡·丰饶：秤街粮价 -8%，剩 12 天"）；常伴随神谕或公告 | 不需要                                                           |
| 半显性 | 效果，来源写"来源未查明"（价格明细显示为"异常波动"）                  | 神殿神职的解读、情报网、莫伊拉的情报交易、鉴定神迹残留、事后传闻 |

- 女神来源的修正项**不存在完全隐藏**的档。凡人的阴谋（囤积、伪造）不是修正项，而是动作，其效果通过知识层与市场正常传导。
- 全部修正项实例写入只增不改的日志；后期解锁的"神之记录"界面列出女神的公开动向
  （[`comparison_and_plan.md`](../../10_research/ai_npc/comparison_and_plan.md) 第 6.7 节）。
- 设计理由：显性橡皮筋公平感强，隐性干预会被感知为暗改控局；暗改结算（动态难度 L4）不推荐
  （[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 2.5 节、借鉴清单第 18 条）。

### 7.5 神力与澱

- 女神来源的修正项消耗神力，并按"神力 × 澱率"在作用范围内留下澱（正典：所有女神的干预都产生澱，
  [`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 3 条；澱率与澱当量见 [`goddess_gm.md`](goddess_gm.md) 第 4.4 节）。
  梅尔卡调价也不例外：顺势，单次澱当量 0.1 到 1。
- 她的契约加护与物价操纵留下的澱带着可辨认的性格，叫"契澱"：滋生的魔物数量多、个头小、贪食，常是模仿财宝的拟态魔物
  （宝箱怪、钱袋鼠），凡人只当是"贪婪招来的报应"（[`races.md`](../../20_world/races.md) 第 9.3 节，前三幕不得点破）。
  大市场附近的下水道迷宫因此有一种商业味的魔物生态，这是经济与澱的一条暗线。
- 由女神神力执行的契约加护（含金冠哈特的契约权能），在有页者违约时写入失信，同样消耗神力、留下澱。
- 受益方的神依赖度随之上升（[`grand_strategy_slg.md`](grand_strategy_slg.md) 第 2.6 节）。

## 8. 女神对经济的干预

### 8.1 梅尔卡的价格修正

动作的资格、神力、冷却与幅度以 [`goddess_gm.md`](goddess_gm.md) 第 5.5 节为准：

| 参数       | 规则（goddess_gm）                                           |
| ---------- | ------------------------------------------------------------ |
| 作用域     | 一个市场、一类商品                                           |
| 方向与幅度 | ±5% 到 ±40%                                                  |
| 期限       | ≤ 30 日，到期自动回归                                        |
| 叠加       | 同一市场同类修正项 ≤ 3                                       |
| 冷却       | 同市场同商品 7 日                                            |
| 资格       | 市场在她的视线内（商人、矮人、半身人、神龛、以她名义立约者） |
| 神力与澱   | 10 到 100 神力，顺势，澱当量 0.1 到 1，落在市场所在地区      |
| 可见性     | 凡人只见价格；有"商眼"者可能察觉不自然；诸神一般不察觉       |

本文在其上补充经济侧的表现：

| 形态                       | 通道           | 典型用法                               |
| -------------------------- | -------------- | -------------------------------------- |
| 丰饶（供给充沛，价格下降） | `price_supply` | 扶持某个商人或城市；平抑她不想要的动荡 |
| 稀缺（供给枯竭，价格上涨） | `price_supply` | 给对手的军需添堵；抬高同盟的利润       |
| 狂热或冷眼（需求起落）     | `price_demand` | 制造或戳破一个风潮                     |
| 特产发现                   | `resource_tag` | 某郡出现新的生产标签（每地区每季一次） |

- 动机：她的计分是大陆流通总量、同盟财富、债权、供品（[`pantheon.md`](../../20_world/pantheon.md) 第 3 节）。她的人格会话按这些目标决定何时出手，
  规则执行者校验神力预算、神约与幅度上限（D-008）。
- 典型用法：两头下注。第三到第四幕她会借哈特与玩家竞争，同时继续和玩家做生意（同上"对玩家的态度演变"）。
- 价格明细里，她的修正项显示为"异常波动（来源未查明）"；查明之后（"商眼"、情报、莫伊拉的情报交易、后期的"神之记录"）改写为"梅尔卡·丰饶"之类的来源。

### 8.2 商路事件

| 事件     | 实现                                                                                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 开通     | `route_state` 修正项：某商路风险下降、关卡放行；常伴随特产发现                                                                                                           |
| 封锁     | `route_state`：通过神谕影响某关卡的领主（受神约：只能假手凡人）                                                                                                          |
| 商队遇袭 | 不是修正项本身改数值，而是唆使盗匪的事件，生成实际遭遇战（神约：不得直接取走他司信徒性命，须假手凡人，[`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 8 条） |

### 8.3 借贷担保

- 玩家可以经"梅尔卡的硬币"或神龛联系她（序章关键道具，[`pantheon.md`](../../20_world/pantheon.md) 第 3、9 节）；她只在玩家使用硬币时感知其位置，不持续追踪（D-028）；硬币界面上能看到与她的"往来账"
  （[`goddess_gm.md`](goddess_gm.md) 第 10.2 节）。
- 她不借钱，只担保：钱由梅尔卡托商会联合出（goddess_gm 第 5.5 节"借贷担保"）。她开的条件是利息、供品（地球食物尤佳）、
  情报（关于其他女神或玩家的故事）、一个将来兑现的人情。
- 违约时对有页的违约者与连带人写入失信（注册过的惩罚修正项，可见、可追溯）；对玩家本人无效（第 6.4 节）。
- 担保贷款计入受益方的神依赖度；第五幕期间计入"同盟受益记录"（[`grand_strategy_slg.md`](grand_strategy_slg.md) 第 7.4 节）。

### 8.4 其他女神的经济影响

| 女神   | 方式                                                                                               | 通道                                             |
| ------ | -------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 希尔薇 | 季节、天气、天灾、兽群                                                                             | `harvest`、`weather`、`hazard_rate`、`move_cost` |
| 艾琉恩 | 异端之国诏：圣教信徒不得与之通商通婚（act4 第 8.2 节）；什一税；圣教市场禁售异端书籍与契约者的媒介 | `trade_restriction`、`relation_shift`            |
| 瓦尔妲 | 挑起战争带来军需需求（经由战争事件间接传导，不直接调价）                                           | `ruler_intent_bias`                              |
| 莫伊拉 | 出售市场情报（谁在囤积、哪条商路将被封）；预言短缺                                                 | `intel_reveal`、事件                             |

### 8.5 供品

- 供品是回收口：财物离开凡人经济流向女神。回礼是加护、情报或好感（第二幕支线 A2-S05"梅尔卡的供品"）。
- 供品与加护都会提高神依赖度。玩家因此要权衡：女神的帮助很实在，但"离手"要求的恰恰是不依赖它。

### 8.6 经济自持：审期的"契约停摆"

- 第六幕诸神缺席的半年里，梅尔卡领域的审期危机是"契约停摆"：契约加护冻结，契约失去神力担保，金湾赖账成潮；
  能撑住的是凡约、门券、哈特与奈拉的凡人信用、高 `econ_indep`，撑不住则金湾挤兑崩盘、粮路中断（act6 第 2.4 节）。
- 这一刻是整个经济系统的期末考：一个依赖契约加护运转的市场，在神离开那天会怎样。系统上，
  凡约、门券、凡人法庭的覆盖率就是经济层的"制度覆盖"，对应 [`city_building.md`](city_building.md) 第 8 节自治度的 I 项。
- 结果写入审期自持分 `review_score` 与证据 E27（act6 第 2.4、4.2 节）。

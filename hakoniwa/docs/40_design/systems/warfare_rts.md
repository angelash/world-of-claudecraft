## 0. 定位与硬约束

### 0.1 一句话

战场层让玩家从"带四支小队守住五个出口"一路走到"把五条战线交给自己的将领与盟友，独自去面对魔王"：
**个人的强大是王牌，但一个人赢不了整场战争。**

### 0.2 硬约束

1. **格子平面、同一张地图、同一个时钟。** 战场就是世界地图上的一个地块或一张战斗场景（`geography.md` 第 7.1 节），在格子平面上结算；
   第一轮的战场窗口是俯视战术图，目标表现是进入 HD-2D 场景（[`art_pipeline.md`](../../50_tech/art_pipeline.md) 第 4.8 节）；战斗开始时冻结大地图时钟，战斗内实时、可暂停下令
   （[`game_framework.md`](../game_framework.md) 第 6 节）。
2. **英雄是乘数，不是清场器（D-012）。** 玩家与具名将领用完整战斗模拟；他们的价值体现为光环、士气、破阵、爆发窗口，
   而不是一个人打掉整支军队的血量（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 3.5 节与借鉴清单第 16 条）。
3. **单位三层模型（D-012）。** 完整实体、按期望值结算的兵团、战略层抽象；三层数值同源
   （[`combat_and_content_inventory.md`](../../10_research/woc_reuse/combat_and_content_inventory.md) 第 8.4 节）。
4. **自动结算与手动战斗共用确定性内核。** 不做两套规则（修仙项目规避"即时/回合双规则"的教训，
   [`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 2.6、3.3 节；借鉴清单第 13 条）。
5. **模型提议，内核裁决（D-007）。** 大模型只给将领选作战方案与说话；移动、命中、伤亡、溃退全部由内核结算。
   普通士兵不调用大模型（[`comparison_and_plan.md`](../../10_research/ai_npc/comparison_and_plan.md) 第 6.2 节 L4）。
6. **禁止暗改结算（D-013）。** 女神的加护、狂战、神迹在战场上是可见的光环或事件，带来源；难度不靠隐藏加数值。

## 1. 战斗规模阶梯

规模阶梯定为小队、连队、军团、联军（D-045）。

| 规模 | 幕次                     | 解锁                                                                                      | 己方构成                                        | 单位层                                 | 玩家角色                    | 代表战役（分幕）                                                                                                                           |
| ---- | ------------------------ | ----------------------------------------------------------------------------------------- | ----------------------------------------------- | -------------------------------------- | --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 小队 | 第二幕末；第三幕可选战役 | 同行之门（act2 提案：最多四支小队）                                                       | 玩家 + 同伴 + 每队 3 到 10 人                   | 具名者为完整实体；民兵为小兵团         | 亲身为主，指挥为辅          | 城下潮（act2）；朝阳门之夜（act3，四到六支小队）                                                                                           |

| 联军 | 第五幕                   | 联盟战争                                                                                  | 多个军团分布在多条战线                          | 每个战场同上；不在场战线按战线回合结算 | 只能身处一个战场（主门坑）  | 灰烬决战（act5）                                                                                                                           |

- 每个战场的单位上限（待基准测试）：每方 32 个兵团、全场 24 个完整实体；画面上的士兵立牌约 2000 到 4000 个
  （移动端 RTS 约 4000 精灵单位的实测量级，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 1.1、3.3 节）。
  分幕里的最大会战（灰烬防线之战，圣战军约 6200）按每个兵团 150 到 300 人折算，在上限之内。
- 超过上限的军队分批进场（援军波次），这本身就是战术要素（预备队）。
- 规模解锁的门：同行之门见 `../../30_story/arcs/act2_wallenburg.md` 第 1.2 节；千军之门见 [`power_system.md`](../../20_world/power_system.md) 第 9.9 节。

## 2. 单位模型：三层

### 2.1 A 层：完整实体

| 项            | 内容                                                                                                                                                                              |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 承载          | 玩家、同伴、具名将领、敌方英雄（勇者团、红牙将军萨莎等）、精英单位、首领                                                                                                          |
| 模型          | 主工程的完整 `Entity`：职能套件、光环、天赋修正、命中表、资源、冷却（[`combat_and_content_inventory.md`](../../10_research/woc_reuse/combat_and_content_inventory.md) 第 8.4 节） |
| 节拍          | 20 Hz（主工程 `DT = 1/20`）                                                                                                                                                       |
| 驱动          | 玩家亲身操控，或"英雄 AI 驱动器"（以主工程宠物 AI 与地窟同伴为基础，经接缝的独立模块）                                                                                            |
| 与 MMO 的差异 | 不用仇恨制索敌与拴绳回家；改为 RTS 指令（攻击移动、集火、坚守、撤退、技能指令）；怪物档案 `canLeash: false` 已有先例                                                              |

### 2.2 B 层：兵团（按期望值结算）

普通兵不能套完整实体：主工程 `Entity` 字段过重，每次挥击都走命中表抽随机，怪物 AI 面向"被玩家拉怪"而不面向阵型
（同上第 8.4 节）。兵团是一条轻量记录：

```
Regiment {
  id, typeId, side, generalId?
  count, maxCount, wounded           // 人数、编制、伤员（战后回流）
  soldier: {                         // "代表单兵"，由职能模板在某等级下生成
    hp, armorClass, armorValue,
    dmgMin, dmgMax, dmgType, attackInterval, range,
    hitBase, dodgeBase, speed, mass
  }
  formation, frontage, depth         // 阵型、正面宽度（格）、纵深
  morale 0..100, fatigue 0..100, ammo
  veterancy 0..3                     // 老兵等级
  anchor{x,y}, facing, state         // 待命、行军、交战、追击、溃退、重整
  dmgAccumulator                     // 未满一人的伤害余量（确定性，不丢）
  modifiers: modifierId[]            // 光环、加护、地形等的引用
}
```

- **代表单兵**由主工程的职能模板在指定等级与装备下生成（例：民兵 = 战士 Lv5 普通装备；圣殿骑士 = 圣骑士 Lv28 精良装备），
  命中、闪避、护甲减伤直接调用主工程的纯函数（`armorReduction`、`meleeMissChance`、`spellHitChance`），保证与 RPG 层数值同源
  （同上第 8.4 节）。
- **兵团规模**：30 到 300 人，常见 50 到 150 人。act3 第 7.3 节由将领统率的 50 到 300 人编制按 D-045 称"连队"（旧稿写作"军团每团"），
  在本文由一个兵团记录承载；第三幕初将领席位少（T2 只有两个），一名将领往往只带一个兵团，之后随统帅成长可以有效指挥多个（第 4.4 节）。
  本文的"军团"只作规模阶梯的名称，不作编制单位（D-045，第 12 节 RTS-4）。
- **结算节拍**：5 Hz（每 4 个 tick 一次），兵团按 `id % 4` 错开到不同 tick，削峰。
- **期望值结算**（每次结算，对每一对接触中的兵团）：

```
交战人数   = min(接触槽位, count)                       // 接触槽位由正面宽度与阵型决定
期望伤害   = 交战人数 × (结算间隔 / attackInterval) × 平均伤害
           × 命中率(主工程公式) × (1 - 护甲减伤(主工程公式))
           × 克制系数 × 侧背系数 × 地形系数 × 士气系数 × 疲劳系数 × 修正项
波动       = 每次接触每秒一次内核随机抽取，范围 0.9 到 1.1（走 Rng，可复现）
dmgAccumulator += 期望伤害 × 波动
倒下人数   = floor(dmgAccumulator / soldier.hp)；余量保留
```

- 远程以"齐射"为单位：每次齐射一次结算，消耗弹药；盾墙与散兵阵型降低齐射效果。
- 倒下的人在战后按比例分为阵亡、重伤、轻伤（第 6.5 节），战斗中一律视为失去战斗力。

### 2.3 C 层：战略抽象

| 项     | 内容                                                                                                                                                            |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 承载   | 大陆地图上的军队标记（[`grand_strategy_slg.md`](grand_strategy_slg.md) 第 5 节）                                                                                |
| 数据   | 军队 = 兵团记录列表（B 层数据常驻，不丢失）+ 将领档案 + 补给状态；"战力摘要"只是派生值                                                                          |
| 用途   | 1. 界面上的"胜算预估"与 AI 国家的作战规划；2. 与玩家无关的远方 AI 对 AI 小规模冲突的结算；3. 分幕写定的"战线回合"（第五幕灰烬决战的非核心战线，act5 第 7.3 节） |
| 不用于 | 其余一切有玩家军队、玩家关注的具名人物、剧情会战参与的单场战斗：这些一律走内核（第 2.4 节）                                                                     |

- 战力只做摘要，不直接结算战争（修仙 GDD 13 的 `power_rating` 原则，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 4.6 节与借鉴清单第 23 条）。
- 远方 AI 对 AI 冲突用"战役方程"（兰彻斯特式聚合，补充资料，同上第 3.3 节"视野外的军队"）；第五幕的战线回合用 act5 写定的战线方程。
  两者的参数都由同一内核标定，并以回归测试钉住（第 2.5 节），所以它们是内核的代理，不是第二套规则。

### 2.4 共用内核：手动与自动

| 模式         | 运行                                                                                    | 何时                                                  |
| ------------ | --------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| 手动         | 内核实时运行 + 渲染；玩家下令                                                           | 玩家在场并选择指挥                                    |
| 自动（快速） | **同一内核、同一种子**无渲染加速运行，双方由 AI 将领驱动；完整实体照样 20 Hz，兵团 5 Hz | 玩家不在场，或在场但选择"交给将领"                    |
| 估算         | 战役方程，只出预估，不出结果                                                            | 胜算预估、AI 规划                                     |
| 方程结算     | 战役方程或战线方程出结果（内核标定）                                                    | 只限第 2.3 节允许的情形：远方 AI 冲突、第五幕战线回合 |

- 自动结算的结果写回兵团记录与世界状态，附一份可回放的战报（同一种子可在之后"观看录像"，因为内核确定）。
- 手动战斗中途可切到自动（"交给将领"），反之亦可；切换不重置任何状态。
- 大模型的作战方案作为"外部输入"记录在战斗事件流里，回放读取记录，不重新调用模型
  （[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 6.4 节）。
- 单场战斗设战斗时长上限（初值 30 分钟战斗内时间）；到时按目标与士气判定，避免收束阶段拖时间
  （同上第 3.4 节"紧张曲线"）。

### 2.5 层间换算

| 换算                 | 规则                                                                                                                                                                                                         |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A 对 B（英雄打兵团） | 单体技能只命中一人，溢出伤害不传递给下一人（"大锤砸蚂蚁"）；顺劈、穿透类按描述命中多人；范围技能估算半径内人数 = 兵团密度 × 面积（上限为现有人数），每人承受伤害，超过单兵生命的直接倒下，不足的计入伤害余量 |
| 单次技能击倒上限     | 对单个兵团一次施放最多击倒其当前人数的 20%（待调）；这条是"英雄不是清场器"的硬保险                                                                                                                           |
| B 对 A（兵团打英雄） | 英雄周围最多 6 个近战接触槽位；每个兵团按攻击间隔把接触者的期望伤害汇总成一次 `dealDamage` 调用，因此英雄的吸收、光环、触发器照常生效（同上第 8.4 节"层间适配"）                                             |
| 控制效果对兵团       | 昏迷、恐惧、减速、定身映射为兵团状态：混乱（攻击 -50%）、减速、阵型打散（正面宽度临时 -50%）、士气冲击                                                                                                       |
| B 对 C               | 兵团战力 = count × sqrt(单兵每秒期望伤害 × 单兵有效生命) × 老兵系数 × 士气系数 × 补给系数                                                                                                                    |
| A 对 C               | 英雄以"军队乘数"计入：军队战力 × (1 + min(Σ英雄光环加成, 0.30)) + 英雄直接战力（上限为军队战力的 15%，待调）                                                                                                 |
| 标定                 | 维护一套基准战斗集（不同兵种、地形、英雄组合），战役方程的伤亡比中位数与内核结果偏差须在 ±10% 内，作为钉住的回归测试                                                                                         |

## 3. 兵种体系

### 3.1 通用框架

兵种 = **定位**（来自职能）× **品质**（来自位阶与装备）× **变体**（来自种族与国家）
（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 3.1 节分析；正典九职能见 [`world_bible.md`](../../20_world/world_bible.md) 第 10.2 节）。

| 定位       | 主要职能来源                   | 作用                               |
| ---------- | ------------------------------ | ---------------------------------- |
| 盾步       | 战士（盾）、圣骑士             | 前排，承伤，阻挡                   |
| 长枪       | 战士                           | 反骑，结阵                         |
| 突击步兵   | 战士（双手）、兽人与魔族的武士 | 破阵，高伤                         |
| 弓弩       | 猎人（游侠）                   | 远程压制                           |
| 轻骑与骑射 | 猎人、战士                     | 机动、侧击、追击                   |
| 重骑       | 圣骑士、战士                   | 冲锋破阵                           |
| 魔导兵     | 法师（魔导师）                 | 范围伤害，克密集阵                 |
| 治疗与祝祷 | 牧师（神官）、萨满、德鲁伊     | 伤员回收、士气、增益               |
| 斥候与暗行 | 盗贼（暗行者）                 | 侦察、袭扰后排、破坏               |
| 契约与召唤 | 术士（契约者）、德鲁伊、猎人   | 召唤物、诅咒（术士被圣教定为异端） |
| 攻城       | 工兵（专业：工程）             | 对建筑                             |
| 飞行       | 魔族翼魔等                     | 越墙、侦察；怕弓弩                 |

**品质档**：新兵（凡阶·初）、熟兵（凡阶·熟）、精锐（精英阶）。精锐兵团人数少（30 人上下）、昂贵，是稀缺品（人才金字塔约束，

## 4. 英雄与将领

### 4.1 英雄是乘数

| 杠杆         | 规则                                                                               | 依据                                                                        |
| ------------ | ---------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| 空间稀缺     | 英雄一次只能在一个战场、一段战线                                                   | [`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 3.5 节 |
| 乘数而非加数 | 光环、士气、指挥半径、破阵；单体技能溢出不传递，单次技能击倒上限 20%               | 本文第 2.5 节                                                               |
| 爆发窗口     | 毁灭性能力有长冷却与灵素消耗，形成"王牌时刻"                                       | 爆发窗口知识卡（同上第 3.4 节）                                             |
| 对等威胁     | 敌方也有英雄、他神勇者、隐藏强者                                                   | [`world_bible.md`](../../20_world/world_bible.md) 第 12 节                  |
| 信息与时间   | 不知道敌人的底牌；侦察决定王牌何时出手                                             | 支柱 3                                                                      |
| 被围         | 被 3 个以上兵团接触时进入"陷阵"：移动 -50%，施法被打断概率上升，只有位移技能能脱身 | 补充资料：《骑马与砍杀》的被围杀风险                                        |

结论：玩家与将领能扭转一处，但不能代替全军；若主角能单人清场，RTS 层会退化为"跑去开大"的唯一解（同上第 3.5 节）。

主工程的技能效果词汇（约 85 种）与光环类型（约 110 种）原样复用，新增少量"战场效果"按同一模式追加

| 类别     | 作用                                                                             | 示例（概念，具体技能见 `combat_and_classes.md`）         |

### 4.3 亲身与指挥的切换

| 模式     | 时间           | 玩家操控                                              | 其他单位                                           |
| -------- | -------------- | ----------------------------------------------------- | -------------------------------------------------- |
| 指挥模式 | 可暂停、可慢放 | 框选兵团与将领、下达移动、阵型、目标、技能指令        | 按指令执行                                         |
| 亲身模式 | 实时 1 倍      | 用 RPG 层的操作（目标锁定、快捷栏、公共冷却）控制主角 | 执行最后的指令；全局指挥交给"副帅"（一名 AI 将领） |

- 亲身模式下，玩家只能对"号令半径"（初值 30 码）内的兵团下快捷命令；更远的兵团要经传令，有 5 到 15 秒延迟。
- 切换是即时的，但"副帅"的能力决定玩家离开指挥位时战场的走向。这把"放手"教学放进了每一场战斗。
- 单人游戏允许暂停；最高难度可关闭亲身模式下的暂停（第 9 节）。

### 4.4 将领

```
General {
  entityId                          // 将领本人是完整实体，可以亲自上阵
  command 0..100                    // 统帅：指挥半径、可有效指挥的兵团数
  tactics 0..100                    // 战术：可用作战方案的数量与质量
  valor 0..100                      // 勇武（主要来自其实体的职能与等级）
  rally 0..100                      // 鼓舞：重整与士气光环强度
  traits: 勇猛 | 谨慎 | 机动 | 坚守 | 狡诈 | 仁慈 ...
  initiative 0..100                 // 主动性：无命令时自行处置的范围
  loyalty 0..100
  potential: { 统帅: grade, ... }  // 识才之门可见
}
有效指挥兵团数 = 3 + floor(command / 20)
```

- 超出有效指挥数的兵团：命令延迟 +5 秒、士气基线 -10。这是军队规模的天然递减（第 10 节）。
- 将领来源：
  - 同伴与角色设定：罗恩（防御型主帅，全军士气与阵型加成）、希雅（游击与斥候、兽人弓骑）、夜羽（侦察鸦群，情报型）、
    玛莎（守城与精锐步兵）、奈拉（后勤与谍报，不上正面）、赛琳（重装突击与纪律部队）、艾登（魔导部队）、马库斯（防御、护卫遗民部队）、
    第八代勇者老船夫（第五幕盟友将领）（`../../30_story/characters.md` 第 3、4 节）。
  - 第三幕：雷吉斯（民兵、守城）、乌尔萨克（兽人、冲击）、卢卡斯（骑兵，若在）、赫拉妲（突击，若归附）；友军马蒂亚斯、英格丽德、冈特；
    敌将奥莉安娜、罗戈、希斯卡（act3 第 7.3、7.4 节）。
  - 第五幕：拉兹格（魔族逃兵百夫长）、剑帝、夜后，以及门环线的总调度门歌者塔维（act5 第 7.2 节）。
- 将领的成长与"放手"挂钩：玩家亲身替将领打赢的仗，将领得到的经验减半；将领独立指挥的仗，经验全额并有潜质成长
  （与罗恩的"玩家插手越少，罗恩成长越多"一致，`act2_wallenburg.md` 支线 A2-S17）。
- 同伴与将领在大战中是否可以永久死亡由难度选项决定（`decision_log.md` Q-006）。

## 6. 战场流程

### 6.1 战前：侦察与情报

- 战前界面显示"已知的敌情"：只来自己方的侦察、斥候、情报网与传闻，可信度分级（亲见、转述、推断）；未侦察到的部分是迷雾。
- 敌方英雄的实力按鉴定上限显示，可能是"？"（[`game_framework.md`](../game_framework.md) 第 10 节）。
- 胜算预估来自战役方程（第 2.3 节），附带"信息不全"的提示。

### 6.2 部署

- 部署区按地形与进军方向给出；玩家放置兵团、选择阵型、指定将领与副帅、设定撤退点。
- 可预设"作战预案"（第 7.2 节的方案菜单），预案也是交给副帅的授权书。
- 伏兵：在森林、高地后部署的兵团对敌方隐藏，直到被发现。

### 6.3 交战

按紧张曲线组织：进入、试探、升温、高潮、收束（[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 3.4 节）。

| 阶段 | 典型内容                       | 系统支撑                     |
| ---- | ------------------------------ | ---------------------------- |
| 试探 | 斥候接触、远程对射             | 迷雾、侦察                   |
| 升温 | 主力接触、侧翼机动             | 克制、阵型、士气             |
| 高潮 | 英雄爆发窗口、破阵、预备队投入 | 爆发窗口、陷阵               |
| 收束 | 一方士气连锁崩溃，或目标达成   | 溃退、目标判定、战斗时长上限 |

- **胜利条件以目标为主**：占领据点、守住出口、斩将、夺旗、保护节点、坚持到时限；全歼不是必要条件
  （补充资料，同上第 3.4 节）。
- **战场中的对话**：剧情战役可在特定条件下开出"交涉窗口"（例：与勇者团成员关系够高时），交涉由大模型生成台词，
  结果（停战、倒戈、撤离）由内核按关系值与条件判定。

### 6.4 撤退与追击

| 行为     | 规则                                                                                                                                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 有序撤退 | 下令撤退的兵团以纵队向撤退点移动，背向敌人时受击 ×1.3；士气不额外下降                                                                                                                                         |
| 溃退     | 士气崩溃引起；无视命令；被骑兵追上时每秒按期望值被击倒，并有一部分被俘                                                                                                                                        |
| 追击     | 轻骑与猎群追击效率最高；追击超过撤退点后有被反伏风险                                                                                                                                                          |
| 全军撤退 | 玩家可在任何时刻宣告撤离战场：未被接触的兵团安全撤出，接触中的兵团按溃退结算一次脱离损失                                                                                                                      |
| 英雄脱离 | 英雄可以用位移技能脱离；玩家阵亡则"退回门内"（死亡规则见总框架第 12 节、`power_system.md` 第 9.8 节），其麾下兵团士气 -20。第五幕在主门坑阵亡可以再战，但每次退回，战略层多推进一个战役回合（act5 第 7.2 节） |

### 6.5 战后结算

| 项         | 规则（初值，待调）                                                                                                                                                                                                                                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 伤亡       | 倒下者：胜方约 40% 阵亡、40% 重伤、20% 轻伤；败方阵亡比例更高，并有被俘与失踪                                                                                                                                                                                                                                                                        |
| 伤兵       | 重伤者回到聚落医馆，按医馆容量与药剂恢复（[`city_building.md`](city_building.md) 第 4.2 节 A3）；轻伤者数日后归队                                                                                                                                                                                                                                    |
| 俘虏       | 溃退被追上、被包围劝降者成为俘虏；处置：赎回（换钱）、劳役、招降（补充兵员，忠诚低）、释放（声望 +）、处决（禁忌行为，大幅影响声望与女神态度）                                                                                                                                                                                                       |
| 战利品     | 装备按比例回收入军械库；军需品；魔物素材与澱晶（讨伐魔物时）                                                                                                                                                                                                                                                                                         |
| 经验       | 英雄与将领获得主工程式经验；兵团老兵等级提升（老兵晋升，参考 Wesnoth，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 3.1 节）                                                                                                                                                                                                  |
| 声望与传闻 | 目击者（双方士兵、随军神官、平民）把见闻带回各自社会层；随军神官的见闻会进入对应女神的视线（[`world_bible.md`](../../20_world/world_bible.md) 第 5 节第 6 条）                                                                                                                                                                                       |
| 澱         | 战斗本身不产生澱；战斗中生效的女神干预（加护、狂战、神迹、曙光圣柱之类的圣遗物）按"神力 × 澱率"在战场留下澱（[`goddess_gm.md`](goddess_gm.md) 第 4.4 节）。积澱以上的战场上，魂已离去的尸骸会被澱侵入而起身成亡灵（[`power_system.md`](../../20_world/power_system.md) 第 7.3 节），战后掩埋或焚化遗体消耗劳力；讨伐魔物掉落的澱晶不收，澱就回到原地 |
| 世界状态   | 胜负、关键人物生死、战线变化写回世界状态，进入下一阶段的初始条件（总框架第 8 节）                                                                                                                                                                                                                                                                    |

### 7.2 作战方案菜单

| 方案     | 参数                     | 规则层执行           |
| -------- | ------------------------ | -------------------- |
| 正面推进 | 主攻兵团、推进速度       | 横阵推进，远程掩护   |

### 7.3 玩家不在场的战线

正典与分幕：第五幕玩家必须身处主门坑的首领战，其余战线由 AI 将领按授权自行作战；战略层以"战役回合"推进，与首领战的阶段同步
（`../../30_story/arcs/act5_war_of_races.md` 第 7.1 到 7.3 节）。结算规则以 act5 第 7.3 节为准，本节说明它在三层模型里的位置。

**战线回合方程**（act5 写定的结构，系数待数值设计校准）：

```
我方战线值 = 兵力 × 将领统率系数 × 协同系数 × 补给系数 × 士气系数 × 自治系数
自治系数   = 0.5 + autonomy / 100                        （0.5 到 1.5）
协同系数   = 1 + 0.1 × 同线正式盟友数（上限 1.3） - 0.1 × 同线互有积怨的组合数
补给系数   = 由门路覆盖、门券流通与 econ_indep 决定（0.7 到 1.2）
比值 r     = 我方战线值 / 敌方战线值：≥ 1.2 守住；0.9 到 1.2 僵持；0.6 到 0.9 失守；< 0.6 溃败
```

- **它是本文的 C 层**：兵力 = 该线兵团的战力合计（第 2.5 节 B 对 C 的公式），统率系数来自将领档案，士气系数来自兵团记录；
  协同系数与补给系数按 act5 的定义计算（补给系数由门路覆盖、门券流通与 `econ_indep` 决定，见 [`economy_and_trade.md`](economy_and_trade.md) 第 5.4 节）。
  每回合的结果按比例写回兵团记录（伤亡、士气、位置）。
- **与内核同源**：方程的系数用第 2.5 节的基准战斗集标定，回归测试钉住"同样的兵力配置，方程的守住与失守判定和内核自动结算的中位结果一致"。
  这样"自动结算与手动战斗共用确定性内核"的约束在战线层也成立：方程是内核的代理，不是另一套规则。
- **自治度如何进入**：分幕把它汇总成自治系数一项；[`city_building.md`](city_building.md) 第 8.4 节列出的通道（请示延迟、预案覆盖、守土士气、
  后勤自主）就是这一项的来源说明。另有两条写定规则：
  - **待令**：`autonomy` 低于 40 时，每回合每条战线有 (40 - autonomy) × 1.5% 的概率进入待令，将领只守不攻，本回合战线值 ×0.7；
    王政国体额外上升。概率判定走内核随机源。
  - **急令**：玩家在主门坑边的号令石前引导 5 秒，对一条战线下急令，本回合该线自治系数视为 1.5；代价是 `autonomy` 永久 -3，
    该线不再计入 `held_unaided`，`urgent_orders` 加一。
- **将领人格**影响统率系数与方差：罗恩稳而不冒进、剑帝凌厉、夜后理性、萨莎要么大胜要么溃败、马库斯死守、赛琳纪律严明、希雅机动、玛莎硬。
- **`held_unaided`**：最终回合结束时，状态为守住或僵持、且整场未收到急令的非核心战线数（最多 5）。它是真结局判定的核心变量之一
  （act6 第 11.1.1 节要求无战线溃败且 `held_unaided` ≥ 3）。
- **战线授权书**：开战前（回合零）玩家分配兵力、任命将领、授予权限，授权越完整，自治系数越稳（act5 第 7.1 节）。本文把授权书定为
  该线的常设命令：目标、可动用的预备队、撤退许可、可否反击、可否交涉。

**第三幕的前置测验**：灰烬防线之战的东面"第二战线"由玩家指派的将领带分队拖住，"这是本幕最大的一次放手测验"；
低自治度时将领只会照搬玩家留下的指令，高自治度时按自己的判断打（act3 第 7.2、7.4 节）。第三幕的第二战线规模小，可以直接用内核自动结算，
不用战线方程；结果影响后续资源与人物，不直接进入结局判定。

### 7.4 AI 将领的忠诚与偏航

- 忠诚低、野心高的将领在高自治度下可能按自己的判断行事（例如追击过深、私下与敌议和），走与官员相同的偏航检定
  （[`city_building.md`](city_building.md) 第 8.4 节）。
- 敌方 AI 将领同样受此规则约束：圣战军的将领可能因为勇者团的动摇而推迟进攻，这是"说服"类解法的系统基础。

## 9. 难度与可读性

### 9.1 难度

| 档   | AI 策略深度                 | 反应延迟 | 失误率 | 敌军规模                  | 暂停               | 将领永久死亡 |
| ---- | --------------------------- | -------- | ------ | ------------------------- | ------------------ | ------------ |
| 故事 | 只用 3 种方案               | 1.0 秒   | 20%    | 剧情规模 ×0.8（战前明示） | 随时               | 否           |
| 标准 | 全部方案                    | 0.6 秒   | 10%    | 剧情规模                  | 随时               | 否           |
| 困难 | 全部方案 + 预备队与伏击     | 0.4 秒   | 5%     | 剧情规模 ×1.2（战前明示） | 随时               | 可选         |
| 传说 | 同困难 + 针对玩家习惯的方案 | 0.3 秒   | 3%     | ×1.2                      | 亲身模式下不可暂停 | 是           |

- 难度只调策略、节奏、失误率与明示的规模，不暗改伤害与命中（动态难度 L4 不推荐，
  [`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 2.5 节；借鉴清单第 18 条）。

### 9.2 可读性

按战斗可读性七层验收（同上第 3.4 节、借鉴清单第 15 条）：

| 层   | 要求                                                               |
| ---- | ------------------------------------------------------------------ |
| 单位 | 兵团旗标：兵种图标、人数条、士气条、疲劳点；完整实体有头像框与血条 |
| 行动 | 选中时画出移动与目标连线；阵型轮廓                                 |
| 判定 | 兵团伤亡以聚合数字飘出（"-12"），不逐兵飘字                        |
| 状态 | 动摇、溃退、陷阵、混乱用固定图标                                   |
| 威胁 | 敌方英雄与首领有警示圈；爆发技能有施法条与地面预警                 |
| 因果 | 战斗日志写因果："第三兵团溃退：侧翼受击 + 将领阵亡"                |
| 学习 | 战后报告列出关键时刻、伤亡来源、克制与失误                         |

- 图形设置与性能档只能省去装饰，不能隐藏可行动的信息：视野内的敌方位置、己方士气条、英雄血条与施法条始终可见
  （主工程"图形设置不得隐藏可操作信息"的原则，[`city_rts_slg.md`](../../10_research/open_share/city_rts_slg.md) 第 3.4 节分析）。
- 大规模混战时用"兵团视图"（只画旗标与轮廓）替代逐兵立牌，玩家可随时切换。

## 0. 一页结论

1. **用 my_ai_town 的居民内核做心脏，用 world-of-claudecraft 的契约与审计做外壳**（依据 [comparison_and_plan.md 第 1 节](../../10_research/ai_npc/comparison_and_plan.md)）。
   有名 NPC 是带目标、承诺、记忆的持续会话；模型只提议，内核执行，回执是唯一事实。
2. **五档分级推理**（D-009）：L0 神、L1 核心、L2 在场、L3 离场批量、L4 规则群众。档位随距离、剧情相关度与事件动态升降，
   升档受预算上限约束，降档时会话确定性地折叠存档。
3. **人设卡在 my_ai_town 的基础上加社会与认知字段**：势力、立场、秘密、知识层级、位阶、常识上限、解释阶梯、信仰与加护冲动、日程、需求、长期目标、说话指纹。
4. **认知由规则，表达由模型。** NPC 怎么看玩家（信念画像、解释选择、跃迁）由内核按 [reputation_and_cognition.md](reputation_and_cognition.md) 计算；
   模型负责把它说成人话、做成行动（依据 `power_system.md` 第 3.6 节"由内核计算判断结果，大模型只负责把判断说出来"）。
5. **关系是多维、可增可减、带衰减、每次变化都引用事件**：信任、好感、敬畏、利益、立场一致度，NPC 之间也有。
6. **离屏时由规则执行日程**；模型只在需要时思考（懒唤醒、日计划、批量日记）。
7. **首领与官员走"感知摘要、枚举意图、内核校验、规划分解、规则执行、回写"的管线**，权限分 P0 到 P4。
8. **成本按幕估算、按档分模型、超预算逐级降级，不停表**：单人游戏的世界不能因为模型慢而停摆，这一点与 my_ai_town 的"全镇停表"不同；
   模型连续失败时同样逐级降级到规则，不全局停表（D-036）。
9. **降级档可完整通关**（D-010）：每一档都有规则行为与预写台词。

### 1.2 写定档位与浮动档位

- `characters.md` 为每位跨幕角色写定了 AI 分级（例：夜羽、希雅、罗恩、卡西安、玛莎、布伦都是 L1）。写定档位是"在当前舞台时的下限"：
  角色在舞台上时不会低于它；离开舞台（例如第二幕玛莎留在边石镇而玩家在瓦伦堡）时按浮动规则降档。
- 分幕文档人物表的"AI 行为备注"（例：`act2_wallenburg.md` 第 3.2 节"丽泽：传闻放大器"）写入人设卡的行为倾向字段，不改变档位规则。

### 1.3 升档与降档

**相关度分**（每游戏小时计算一次，待调）：

```
S = 50 × 当幕剧情标记（主要角色或纷争当事人）
  + 30 × 任务或写定节拍点名
  + 20 × 与玩家关系强度（多维关系的绝对值加权，归一）
  + 15 × 事件热度（近 24 游戏小时内涉及此人的事件显著度之和，归一）
  + 10 × 距离接近（同地区 1，相邻 0.5）
  + 10 × 持有关于玩家的高热度传闻
```

| 规则     | 内容                                                                                                                                                                                         |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 升档阈值 | L3 到 L2：玩家进入其地区，或 S ≥ 40；L2 到 L1：S ≥ 60，或被写定节拍点名                                                                                                                      |
| 降档阈值 | S 连续 1 个游戏日低于升档阈值减 20（滞回，防止抖动）；离开当前舞台                                                                                                                           |
| 对话升档 | 玩家对任何有名 NPC 发起交谈：L2 立即占用一个对话临时位成为 L1 交谈；L3 先升 L2 再升 L1；交谈结束 1 游戏小时后回落                                                                            |
| 具名化   | 玩家与某个 L4 个体有意义的互动（两次交谈、救命、雇佣、冲突）后，内核按模板与种子为其生成人设卡，升为 L3。每幕上限 30 人（待调）                                                              |
| 上限排序 | 某档超员时按 S 排序，最低者降档；写定档位与同伴不参与降档                                                                                                                                    |
| 降档处理 | 会话折叠：最旧的轮次归档，确定性摘录追加到累积摘要（依据 [my_ai_town_agents.md 第 2.5 节](../../10_research/ai_npc/my_ai_town_agents.md)）；目标与承诺保留；进行中的动作组交给规则执行到结束 |
| 升档处理 | 会话重建：人设卡 + 累积摘要 + 降档期间由规则生成的经历（L3 的批量日记产物）+ 记忆索引；第一轮是"回神轮"，只观察与定目标，避免醒来"活在几天前"                                                |
| 幕间折叠 | 每一幕结束时，全部 NPC 的记忆做一次幕间折叠：只保留关键记忆（每人至多 24 条，按重要度）与笔记，其余归档可查                                                                                  |

### 2.2 写法规则

- "背景是自述""开局处境已经发生""职业不自动拥有权限"三句原样进入每张卡，防止模型把设定当成可兑现的资源
  （依据 [my_ai_town_agents.md 第 3.1 节](../../10_research/ai_npc/my_ai_town_agents.md)）。
- 秘密不写进对他人可见的任何字段；别人只能从言行推测（依据 [my_ai_town_agents.md 第 6.3、6.6 节](../../10_research/ai_npc/my_ai_town_agents.md) 智子的私密任务写法）。
- 卡片合计（人设与公共知识）不超过约 12000 字（同上第 3.1 节）；超出时把知识包移到可检索的记忆文件里。
- 跨幕角色的卡从 `characters.md` 派生，分幕新增人物从分幕文档的人物表派生；本文不新造正典人物。
- 凡人 NPC 的卡与台词一律用澱的俗称：灰气（澱）、灰病（澱病，边石镇一带也叫荒原病）、灰晶（澱晶）、灰狼、灰鬼等；"澱""澱晶"只是冒险者与学者的行话。
  玩家从夜羽口中听到"澱"之后，界面名称才切换为正式名，NPC 的台词不随之切换（D-030）。

## 3. 决策循环

### 3.1 轮次

| 轮次     | 档位               | 触发                                                        | 开放工具                                               | 产出                         |
| -------- | ------------------ | ----------------------------------------------------------- | ------------------------------------------------------ | ---------------------------- |
| 生活轮   | L1                 | 空闲且无阻塞的待完成动作；收到邀请；重要通知                | 查看、回忆、定目标、提交动作组、邀请、传话、等待       | 心声 + 工具调用              |
| 交谈轮   | L1（含对话临时位） | 轮到本人发言                                                | 只有交谈（说、听、离开、提议、接受、拒绝）             | 一句台词 + 可选短心声        |
| 整理轮   | L1、L2             | 距上次至少 60 游戏分钟，且跨日、出现重要经历或攒够 6 条经历 | 整理、回看阅读                                         | 本批摘要 + 至多 4 条主题笔记 |
| 日计划轮 | L2                 | 每游戏日黎明                                                | 定目标、日程调整（只能在模板允许的替换里选）、传话意向 | 当日计划 + 心声              |
| 事件轮   | L2                 | 重要通知（每日至多 2 次）                                   | 与通知相关的动作                                       | 心声 + 至多 3 个动作         |
| 批量日记 | L3                 | 每地区每游戏日一次                                          | 只有"日记事件"输出                                     | 每人至多 3 条结构化事件      |
| 议政轮   | 首领、官员         | 见第 8 节                                                   | 意图菜单                                               | 意图 + 理由 + 文书           |
| 回神轮   | 升档后第一轮       | 升档                                                        | 查看、回忆、定目标                                     | 目标                         |

交谈与整理不进生活会话，各自保持稳定前缀以命中缓存（依据 [my_ai_town_agents.md 第 2.1 节](../../10_research/ai_npc/my_ai_town_agents.md)）。

### 3.2 唤醒条件

- 受 AI 控制、在场、未失能（死亡、昏迷、被威压到失能者不思考）；
- 当前活动是"无期空等"且计划队列为空，或收到可回应的邀请，或轮到发言；
- 没有在途请求，没有阻塞的待完成动作（每人同时至多一个请求在途）；
- 等待已到点，或等待期间到达重要通知。

重要通知（打断当前动作）：受到伤害或威胁、需求跌破"重新考虑"线（默认 35，回升到 45 才重置）、目标里提到的人到场、
被女神神谕点名、写定节拍点名、被逮捕或被审判、亲眼目睹神迹级事迹（显著度 ≥ 0.8）、玩家对其搭话。
普通事件（不唤醒，写入经历）：别人的交谈、远处的事、天气与物价变化、女神对旁人的作为
（依据 [my_ai_town_agents.md 第 2.2、6.2 节](../../10_research/ai_npc/my_ai_town_agents.md)；与 [goddess_gm.md](goddess_gm.md) 第 6.2 节的"点名与告知"一致）。

### 3.3 题面构成

```
[system]  规则（对同档位的所有 NPC 相同，构成缓存前缀）
          + 人设卡渲染（含三句隔离声明）
          + 公共知识：知识层级允许、且台账已解锁的条目（按 reveal_ledger 第 0.2 节装配）
          + 已知地图与本地点能做的事
[user]    累积摘要（有折叠时）
[...]     会话历史（观察、心声与调用、工具结果交替，只追加）
[user]    本轮：
          观察：时刻（"998 年第 3 周第 2 日 08:48"）、所在、环境、身体与需求档位、背包、当前活动、
                眼前的人与物（谁在用、还剩多久）、新事件（至多 24 条，更早的报统计）
          处境：立场、开放目标与承诺、当日日程、所属势力的当前要求
          认知：你对在场重要人物的看法（信念画像的文字摘要）、你听说过的传闻（带"听谁说的"）
          记忆：按焦点对象检索的近期经历（至多 6 条）、相关主题笔记（至多 3 篇）
          可用动作：此刻合法的动作清单，带预计耗时与代价；来不及的写明"不要开始"
```

- 慢变字段只发变化；集合有界并可回查原文；时刻人类化；不出现程序编号、哈希、长小数
  （依据 [my_ai_town_agents.md 第 2.5、7.4 节](../../10_research/ai_npc/my_ai_town_agents.md)）。
- 按轮次类型裁剪上下文配额（依据 [woc_ai_npc.md 第 2.4 节](../../10_research/ai_npc/woc_ai_npc.md) 的 `PROMPT_POLICIES`）。
- 玩家的自由文本作为"资料"进入，不作为指令（依据 [my_ai_town_agents.md 第 4.2 节](../../10_research/ai_npc/my_ai_town_agents.md)）。

### 3.4 输出格式

| 部分   | 规则                                                                                                                                                                                                   |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 心声   | 先用一句 12 字以内的短话起头（头顶气泡只显示这一句）；按说话方式写感受与打算；不报数值、编号；复述台词不算心声（依据 [my_ai_town_agents.md 第 2.6 节](../../10_research/ai_npc/my_ai_town_agents.md)） |
| 动作组 | 1 到 8 项串行动作，失败即停；每项只能取自"可用动作"                                                                                                                                                    |
| 对话   | 只在交谈轮；一句台词；嘴上说给东西不等于给了，必须走赠予（依据同上第 5.2 节"嘴上给"的教训）                                                                                                            |
| 目标   | 新建或更新；完成须有世界证据；暂停、放弃、失败须写原因（依据同上第 3.5 节）                                                                                                                            |
| 传话   | 结构化：传闻编号或新说法的结构化命题、对象、可选的个人加工（由 [reputation_and_cognition.md](reputation_and_cognition.md) 第 4 节规则结算失真）                                                        |
| 解读   | 只给"过度解读者"（同上第 9 节）：对玩家某个行为的解读与拟行动                                                                                                                                          |
| 理由   | 可选，只进调试与"神之记录"类视图，不进世界（依据 [my_ai_town_agents.md 第 6.2 节](../../10_research/ai_npc/my_ai_town_agents.md) 的 `reason`）                                                         |

### 3.5 校验闸门

合并 my_ai_town 的八道闸门与 world-of-claudecraft 的三重白名单交集（[my_ai_town_agents.md 第 1.2.3 节](../../10_research/ai_npc/my_ai_town_agents.md)、[woc_ai_npc.md 第 2.7 节](../../10_research/ai_npc/woc_ai_npc.md)）：

| 序  | 闸门         | 检查                                                                                                | 失败后果                           |
| --- | ------------ | --------------------------------------------------------------------------------------------------- | ---------------------------------- |
| 1   | 请求身份     | 请求编号与世界代次                                                                                  | 丢弃                               |
| 2   | 动作版本     | 请求发出后本人的动作版本号未变、仍受 AI 控制、未失能                                                | 整条作废，会话写入"外部安排已改变" |
| 3   | 回复体       | 心声长度、调用数、参数结构                                                                          | 按模型失败处理                     |
| 4   | 工具准入     | 本轮次是否开放此工具；请求期间到达重要通知时改世界的工具一律退回                                    | 退回并要求重新观察                 |
| 5   | 参数         | 严格解析，未知字段报错并指出放错的层级                                                              | 允许下一轮改格式                   |
| 6   | 意图白名单   | 动作 ∈ 情境允许 ∩ 人设与职位允许 ∩ 正典主体等级允许                                                 | 拒绝                               |
| 7   | 目标可见     | 动作目标（人、物、地点）在本人的投影内可见或已知                                                    | 拒绝                               |
| 8   | 内核整组校验 | 地点、道具、开始条件、路线可达、资源；同一命令编号幂等                                              | 返回"第 N 项：原因"                |
| 9   | 知识与台账   | 台词与传话中出现的实体与命题必须在本人知识范围内；未解锁线索按"解锁前处理"；禁名与称谓按台账第 6 节 | 改写或退回                         |
| 10  | 证据         | 目标完成需要世界证据；笔记引用本人事件；"支持中"需两次独立经历；引用阅读需逐字引文                  | 拒绝写入                           |

第 9 道闸门不用子串黑名单（会误杀，[woc_ai_npc.md 第 5.3 节](../../10_research/ai_npc/woc_ai_npc.md)），而是：台词中提到的专有名词与本人"已知实体表"比对，
命题类内容（传话、指控、作证）一律走结构化字段，由内核比对知识范围。

### 3.6 回执与过时

- 动作组完成、失败或被打断时，回执（动词、状态、变化、原因、事件编号）写回会话并再次唤醒；失败原因是给模型看的人话
  （依据 [my_ai_town_agents.md 第 2.7 节](../../10_research/ai_npc/my_ai_town_agents.md)）。
- 世界不等模型：回复按动作版本号判过时，过时整条作废重想；查询类调用照常执行（同上第 1.2.5 节）。
- **玩家搭话冻结**：玩家发起交谈时，对方手头的事先停最多 10 游戏分钟，弥补模型延迟（同上第 5.5 节）。
- **思考中提示**：L1 正在思考时头顶显示省略号；玩家等待超过 3 秒时显示"思考中"（依据 [woc_ai_npc.md 第 8.1 节](../../10_research/ai_npc/woc_ai_npc.md) 的 `aiThinking`）。
- 模型输出作为外部输入记入事件流，回放读记录不重新调用（依据 [city_rts_slg.md 第 6.4 节](../../10_research/open_share/city_rts_slg.md)）。

## 4. 行动空间

每个动作有内核定义的前置与后果；"内核结算"一栏为"是"的动作改变世界状态，必须经内核执行并回执。

### 4.1 生活

| 动作             | 前置                     | 后果                                                                                                                                         | 内核结算 |
| ---------------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| 移动             | 路线可达                 | 位置改变；途中可能遭遇                                                                                                                       | 是       |
| 劳作（按职业）   | 在工作地点；有工具与材料 | 产出、报酬、精力下降                                                                                                                         | 是       |

| 阅读             | 有可读物                 | 记"读到了什么"，作者的说法不自动成为事实                                                                                                     | 是       |
| 使用道具         | 道具可用、未被占用       | 道具效果                                                                                                                                     | 是       |

### 5.1 分层

| 层                 | 内容                                                                                                           | 谁写           | 可否改写             |

### 5.2 来源与可信度

记忆层的可信度与认知层的证据权重分开：前者回答"这件事有多大可能是真的"，后者回答"它能把一个人的看法推动多少"
（证据权重 0 到 5 与认知状态机见 `society.md` 第 8.4、8.5 节与 [reputation_and_cognition.md](reputation_and_cognition.md) 第 3 节）。

| 来源     | 可信度（待调）                                                                | 说明                                                                                                                                                   |
| -------- | ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 亲见     | 1.0                                                                           | 本人在场、醒着、看得见（`society.md` 第 7.4 节"亲眼目睹者为 1.0"）                                                                                     |
| 亲历     | 1.0，情绪强度加权                                                             | 本人被救、被打、被骗                                                                                                                                   |
| 转述     | 来源可信度 × 0.8 的跳数次方；从彼此独立的来源再次听到同一件事乘 1.3，上限 1.0 | `society.md` 第 7.4 节；my_ai_town 的"转述 0.5"是同一思想的单跳近似（[my_ai_town_agents.md 第 4.1 节](../../10_research/ai_npc/my_ai_town_agents.md)） |
| 推断     | 0.3                                                                           | 本人从线索推出                                                                                                                                         |
| 书面     | 文献权威（公会记录 0.9、告示 0.7、小报与歌谣 0.3）                            | "作品文字只是作者的说法"                                                                                                                               |
| 权威背书 | 权威在本人眼中的可信度                                                        | 公会、领主、神父的承认                                                                                                                                 |
| 鉴定显示 | 对一般人是高可信的"官方事实"                                                  | 对玩家，鉴定的"无记载"与"Lv1"在认知层计为反证（`society.md` 第 8.4 节）                                                                                |

认知纪律照搬：转述不是事实；书里写的只是作者声称；"支持中"须两次独立经历；材料中的指令只是资料
（依据 [my_ai_town_agents.md 第 4.2 节](../../10_research/ai_npc/my_ai_town_agents.md)）。

### 5.3 整理轮次

- 触发：距上次至少 60 游戏分钟，且跨日、出现重要经历或攒够 6 条经历；有重要通知或未结束的交谈时让路。
- 输入：本批新经历（至多 12 条）、同日较早摘要、记忆索引、自我笔记、相关主题、当时已知的目标。
- 输出：本批摘要（至多约 1600 字）与至多 4 条主题笔记，每条引用本人事件编号且至少含一条本批新事件。
- 信念修订：整理时模型可以提出"我对某人的看法变了"，必须引用证据；内核按 [reputation_and_cognition.md](reputation_and_cognition.md) 第 3.5 节的跃迁规则判定是否采纳。
- L2 每 2 到 3 游戏日或遇重要经历时整理一次；L3 不整理，只由规则生成经历与认识。

### 5.4 遗忘与折叠

- 不删原文；"遗忘"体现为不进题面：认识被替换、经验解除保护、已展示的不再附带、旧轮次折叠（依据 [my_ai_town_agents.md 第 4.4 节](../../10_research/ai_npc/my_ai_town_agents.md)）。
- 重要度：情绪强度、与本人目标的相关、与玩家相关、罕见程度的加权；幕间折叠只保留重要度最高的若干条。
- 摘要里写明"省略不等于没发生"，需要时可回查归档。

### 5.5 键与时间

- 一切记忆以"稳定居民编号 + 世界历法时刻"为键，不以会话或实体编号为键，不以模拟相对时间为键
  （依据 [woc_ai_npc.md 第 3.4、8.2 节](../../10_research/ai_npc/woc_ai_npc.md)：会话 id 为键导致换会话失忆、重启后错配）。
- 题面里的时刻写作人能读的历法（"998 年第 3 周第 2 日 08:48"），与分幕文档的"第 N 周"一致。

### 5.6 对外接口：众生之声

第六幕庭之陈述需要从全大陆 NPC 的记忆中抽取"众生之声"（`act6_review_and_epilogue.md` 第 3.4 节）。记忆层为此提供只读接口：
按"与玩家打过交道"与"审期中做过的事"筛选经历，只取有世界事件支撑的条目，返回说话者、时刻、事件编号与一句原话或摘录。

## 6. 关系系统

### 6.1 维度

| 维度       | 范围        | 含义                                                                       | 主要来源                                   |
| ---------- | ----------- | -------------------------------------------------------------------------- | ------------------------------------------ |
| 信任       | 0 到 100    | 会不会相信对方说的、会不会把事托付给对方；与台账的 `trust.<角色>` 同一变量 | 守约、说真话被证实、救助；说谎被拆穿、背叛 |
| 好感       | -100 到 100 | 喜不喜欢                                                                   | 赠予、陪伴、共同经历、幽默；冒犯、伤害     |
| 敬畏       | 0 到 100    | 觉得对方有多强、多危险                                                     | 亲见的事迹、威压、传闻（经信念画像折算）   |
| 利益       | -100 到 100 | 与对方往来对自己的实际好处                                                 | 交易、雇佣、债务、竞争                     |
| 立场一致度 | -100 到 100 | 在本人在意的纷争上与对方站得多近                                           | 由双方立场向量计算，不直接加减             |

关系是有向的：A 对 B 与 B 对 A 各一份。my_ai_town 的关系只存在于笔记里而无法聚合，world-of-claudecraft 的好感只增不减；
本作两者都补上（依据 [comparison_and_plan.md 第 2 节"关系"一行](../../10_research/ai_npc/comparison_and_plan.md)）。

### 6.2 变化规则（初值，待调）

| ------------------------ | -------- | --------- | ------------------------ | --------- |

| 违约、说谎被拆穿         | -15      | -10       |                          |           |

- 人设修正：固执、记仇、宽容等性格标签乘以变化幅度；加护冲动对特定事件加权（例：瓦尔妲信徒被打败后敬畏与信任一起上升）。

### 6.3 衰减

- 好感每游戏日向人设基线回归 1%；信任回归 0.3%（信任慢热也慢冷）；敬畏在没有新证据时每游戏周下降 3%；利益随往来结束重新计算。
- 关系强度很高的（任一维度绝对值 ≥ 70）衰减减半：老朋友与死对头都不容易淡。

### 6.4 NPC 之间

- 有名 NPC 之间维护同样的多维关系；种子来自人设卡与 `characters.md` 第 9.1 节的关系矩阵。
- L4 群体之间不维护个体关系，只维护群体关系（族群、行会、街区之间的紧张度），作为群体本能矩阵的输入。
- 势力内部的关系聚合成"派系"，供首领议政与 [reputation_and_cognition.md](reputation_and_cognition.md) 第 5 节的势力声望使用。

### 7.3 离屏执行

- L3 与 L4：规则按日程模板执行，需求按速率变化，跌破阈值时按效用打分选应对；事件以封闭词表记录（交易、争吵、传话、求助、祈祷、工作异常、结识、受伤、离开）。
- L3 的批量日记在此基础上"加味"：模型为每人挑选至多 3 件当日值得记的事，并写一句心声；内核校验这些事件是否与规则执行的轨迹一致，不一致的丢弃。
- L3 若在批量日记里提出重大动作（告发、结盟、出走、斗殴），内核把此人升为 L2，在下一个事件轮用完整决策处理。

外交与政治承诺分层：资源转移由系统绑定；未来行动只是许诺，靠声誉与抵押维持（依据 [city_rts_slg.md 第 7 节第 20 条](../../10_research/open_share/city_rts_slg.md)）。

### 8.5 议政节拍

| 主体          | 规划轮                                                                 | 事件即时轮               |
| ------------- | ---------------------------------------------------------------------- | ------------------------ |
| 小镇势力首领  | 每游戏周一次                                                           | 纷争节点、被点名、被告发 |
| 城市势力首领  | 每 3 游戏日一次                                                        | 同上                     |

## 9. 纷争事件链与 AI 的接口

- 分幕文档把每条纷争写成按周推进的事件链（例：`act1_borderstone.md` 的六条纷争，"玩家不介入时也会自行发展"）。事件链的阶段、期限与结算由内核按规则表推进。
- AI 在事件链里的位置是"决策点"：链条推进到某个节点时，点名相关 NPC（重要通知），他们在自己的立场、关系与人设内做选择
  （例：兽潮之夜谁守门、谁逃跑、谁趁乱敛财、谁拼死救人，`story_outline.md` 第一幕）。选择交回内核结算伤亡与后果。
- 到点没有选择的，按效用兜底；不卡住事件链（依据 [my_ai_town_agents.md 第 6.2 节](../../10_research/ai_npc/my_ai_town_agents.md)："该交的人交了，或者到点了"）。
- 纷争的"升级阶段"是叙事导演张力计的输入之一（[goddess_gm.md](goddess_gm.md) 第 8.2 节）。

## 10. 同伴与从者

### 10.1 特殊性

| 方面         | 规则                                                                                                                                                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 档位         | 在队或在门内庭院时恒为 L1；离队后按写定档位与浮动规则                                                                                                                                                                             |
| 认知         | 同伴最先跨过"凡人不信"：他们亲见得最多；但他们对外作证时的可信度受其社会身份影响（希雅是被排挤的兽人猎户之女，罗恩是出了名的胆小鬼），这是喜剧与暗面的来源（[reputation_and_cognition.md](reputation_and_cognition.md) 第 10 节） |
| 羁绊         | 在多维关系之外另设"羁绊"：共同经历（事件计数与显著度）、关键选择（玩家在其个人线上的抉择）、信任。羁绊达到阈值解锁个人线章节与缘钥（`power_system.md` 第 9.4 节）                                                                 |
| 长期记忆     | 同伴的记忆不做幕间深度折叠，个人线的关键事件永久保留在题面可检索的位置                                                                                                                                                            |
| 战斗内       | 由规则 AI 驱动（复用 world-of-claudecraft 的托管队伍与地窟同伴思路），模型不参与每 tick 决策；战斗之间模型可以调整"战术倾向"（激进、保守、护人）与开场意图                                                                        |
| 战斗外的自主 | 营火闲谈、个人差事（希雅去打猎、罗恩写家书）、主动提建议、拒绝违背其"必须保持"与"绝不会做"的命令                                                                                                                                  |
| 过度执行     | 同伴可能过度理解玩家的意图并自作主张（依据 [anime/titles_01_25.md 第 25.10 节 T9](../../10_research/anime/titles_01_25.md)）；玩家要为同伴的行为负责。规则见 [reputation_and_cognition.md](reputation_and_cognition.md) 第 9 节   |
| 门内庭院     | 同伴出入庭院时其铭录页显示"所在不明"，会触发莫伊拉的异动提醒（`power_system.md` 第 8.6 节）；同伴的 AI 知道这件事吗，按台账决定                                                                                                   |
| 死亡         | 难度选项决定是否永久死亡（`decision_log.md` Q-006）；永久死亡时其记忆归档，并成为其他同伴记忆中的重大事件                                                                                                                         |

### 10.2 从者夜羽

- 知识受记忆残缺约束：她"不知道"的东西在题面里就不存在，记忆碎片按 `reveal_ledger.md` S01 系列线索与 `yeyu_letters` 逐步加入。
- 她的嘴毒是人设，不是知识：她可以戳穿谎言，但只能用她已知的东西戳。

## 11. 群众与魔物（L4）

### 11.1 群众

- 无名居民按"人群单元"（一户、一个工坊、一队民兵）模拟：需求、日程、恐慌、聚集、传闻接触都是群体统计。
- 群众持有传闻的方式是"份额"：某说法在该人群单元中被多少比例的人相信（[reputation_and_cognition.md](reputation_and_cognition.md) 第 4 节）。
- 少数个体按"世界种子 + 模板 + 编号"的哈希获得怪癖与更高的灵性，作为具名化的候选，把昂贵推理集中在少数人身上
  （依据 [woc_ai_npc.md 第 8.1 节第 16 条](../../10_research/ai_npc/woc_ai_npc.md) 的 `individualProfileFor`）。

### 11.2 群体本能矩阵

依据 [woc_ai_npc.md 第 8.1 节第 17 条](../../10_research/ai_npc/woc_ai_npc.md) 的 `FAMILY_SEMANTICS`，每个群体类型一行：

| 群体       | 领地性           | 群聚 | 逃逸阈值             | 对威压的反应                                              | 对光与火 | 对澱         | 对奇观   | 传闻接触                 |
| ---------- | ---------------- | ---- | -------------------- | --------------------------------------------------------- | -------- | ------------ | -------- | ------------------------ |
| 镇民       | 低               | 中   | 中                   | 一阶差：退避；两阶差：跪倒（`power_system.md` 第 3.5 节） | 中性     | 恐惧         | 围观     | 高（酒馆、集市、洗衣溪） |
| 民兵       | 中               | 高   | 中高（有队长时更高） | 一阶差：犹豫；两阶差：溃散                                | 中性     | 恐惧         | 维持秩序 | 中                       |
| 商队       | 低               | 高   | 低                   | 退避                                                      | 中性     | 避开         | 估价     | 高（跨镇传播的主要通道） |
| 圣教信众   | 低               | 高   | 中                   | 退避；视为神迹或邪术                                      | 趋向光   | 恐惧，视为秽 | 祈祷     | 高（礼拜堂）             |
| 兽人猎户   | 高               | 中   | 高                   | 嗅出不对劲后保持距离或好奇（`races.md` 第 3 节）          | 中性     | 闻得出       | 亲自确认 | 低（不信传闻）           |
| 野兽与家畜 | 中               | 按种 | 低                   | 两阶差即逃散；不受常识约束，立即"相信"                    | 惧火     | 异变风险     | 逃离     | 无                       |
| 澱生魔物   | 高（巢）         | 按种 | 极高                 | 只对三阶差以上退却                                        | 按相     | 趋向澱浓处   | 无       | 无                       |

- 魔物的具体族群映射以 `power_system.md` 第 7.3 节的 `MobFamily` 表为准；魔物不是种族，任何群体本能都不能把某个种族当作魔物。
- 野兽对威压的直接反应是系统性的"凡人不信"反例：动物不需要常识，它们先跑。这条规则同时是希尔薇信徒与兽人的证据来源。

## 13. 成本预算

### 13.1 按幕估算（量级，以实测为准）

女神规划约 15 到 30k，首领议政约 10 到 20k；稳定前缀缓存命中 50% 到 70%（依据 [my_ai_town_agents.md 第 7.1 节](../../10_research/ai_npc/my_ai_town_agents.md)）。

### 13.3 超预算降级

按金额与 token 预算"先预留后结算"，按真实用量校准（依据 [my_ai_town_agents.md 第 7.3 节](../../10_research/ai_npc/my_ai_town_agents.md)）。
超出时按以下顺序逐级降级，**不停表**：

| 级   | 降级内容                                                       | 玩家可感知度 |
| ---- | -------------------------------------------------------------- | ------------ |
| 1    | L3 批量日记改为纯规则日记                                      | 几乎无       |
| 2    | L2 事件轮改为规则 + 预写台词                                   | 低           |
| 3    | L1 整理轮推迟（至多 2 游戏日）                                 | 低           |
| 4    | L2 日计划改为日程模板原样执行                                  | 中低         |
| 5    | L1 生活轮的搁置从 30 延长到 90 游戏分钟，每次醒来至多 1 次请求 | 中           |
| 6    | 首领与官员改为效用打分                                         | 中           |
| 7    | 女神改为隔日规划 + 规则填充（重要通知照常）                    | 中           |
| 保留 | 玩家正在进行的交谈、女神的重要唤醒、写定锚点                   | 最后才降     |

降级状态在调试面板与设置界面可见（"世界正在节能模式运行"），恢复预算后逐级回升。

## 18. 待决问题

1. **不停表 vs 一致性**：my_ai_town 在模型连续失败时全镇停表；本作已决逐级降级到规则、不全局停表（D-036）。仍需技术方案确认降级切换时会话状态的一致性。
2. **L1 上限**：12 个 L1 加 2 个对话临时位是否足够覆盖第三到五幕的多舞台场景（宫廷、前线、领地同时活跃）。
3. **具名化上限与存档**：L4 具名化后的人设卡是否进入正典人物管理（分幕文档"不为次要居民起名"的约定与运行时生成名字之间的边界）。
4. **`trust.<角色>` 的含义**：台账的 `trust` 是单一维度；本文把它对应到多维关系中的"信任"，好感与敬畏另存。需确认台账的解锁条件确实只看信任。
5. **社会学参数**：`society.md`（撰写中）应提供人族、兽人、矮人等的社会结构、信息网络与"凡人不信"的阶层差异参数，本文的群体本能矩阵与需求权重届时对齐。
6. **游戏日时长**：成本估算按每游戏日 24 现实分钟；`decision_log.md` Q-005 若改为 12 或 48 分钟，请求量按比例变化。
7. **同伴是否知道"所在不明"**：同伴出入门内庭院会触发莫伊拉的异动提醒，同伴本人是否知情、能否说出口，需台账给出条目。

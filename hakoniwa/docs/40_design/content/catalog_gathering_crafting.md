## 0. 一页结论

1. **生业是铭录的"刻深"。** 铭录的生业栏可以记很多门手艺，但只为一个人"刻深"环上相邻的两门（本业），对面一门浅刻（闲艺），
   其余只记名。这就是主工程十环"原型对加业余爱好"（`CRAFT_RING`、`archetypeCeilingFor`）在世界里的样子。玩家无页，靠"生业之门"取得生业，
   同样能越过两门的限制，但每开一扇门，封印就松动一点（`seal_looseness`，[D-031][dlog]）。
2. **手艺本身就是过关。** 无职能的匠人以"出师之作"跨过 9 到 10 的关（[力量 3.3][pow]）；本文把它推到全部五道关：
   出师之作、淬体之作、名作、终器、外缘之作。主工程的杰作（masterwork）判定是出师之作的引擎，
   于是一个铁匠第一次打出杰作的那一刻，铭录把他从凡阶·初改写成凡阶·熟。
3. **澱染分轻、中、重三档，净化是实例标记。** 净化不另起 ID（总纲 7.11 禁止为澱源材与部件派生同义物），而是给实例打 `purified`，
   与"署名"同一层。净化有两样代价：澱纹加成随之消失；过程留下副产物（澱渣、洗澱废水）。副产物的去处（封存、化解、倾倒）
   是一道贯穿第二到第五幕的道德题，第二幕"鹿角林的病水"里皮匠被冤枉（病水其实来自迷宫暗渠），第三幕玩家自己的制革坊开始净鞣时同样的指控会变成真的，第四幕赤砧的废矿坑是别人给出的答案。
4. **每样材料三层价值。** 个人峰值幕、领地建筑、战略储备三层逐级迁移（[总纲原则 4][bible]）。铁、盐、药恰好是第四幕金冠哈特禁运的三项
   （[经济 3.6][eco]），所以本目录把这三条链放在第三幕由领地建成（铁：P6、P10、P11；盐：落日港、盐镜、盐碱洼的采集点与进口，盐田为提案；药：P7、P15），第四幕才有底气反击。
5. **T5、T6 一律上稀缺锁。** 每一件都至少满足"数量有限、需要许可、要付代价"中的两条，而且许可一定落在一个具名的人或一个族身上：
   穹铁问观穹台的隐修者，炉心金问炉主会议，世界树落枝问精灵，龙蜕问艾斯卡。
6. **地球知识新增 13 条配方，分三档扩散。** 口传、文书、学堂分别对应数据层 `oral`、`study` 与提议新增的 `school`；仿制期随档递增。
   其中"明矾净水"刻意展示地球知识的边界：它能让泥水变清，却解不开澱。
7. **数量。** 生业 14 种加 1 项标签活动（解兽）；工站 13 类；注册表条目全部细化（金属 17、木 6、草药 9、皮鳞 13、织物 12、宝石 6、
   澱晶 12 加已有 3、澱源材 18、部件 12 种）；区域变体 14；新增 `mat_` 126；采集点 105；配方族 97（含地球知识 13）。

- 专攻在技能 75 选定，恰好是 T4 的阶首，与主工程 `PERK_THRESHOLDS` 的 75 点一致。
- 正典："铭录的等级计入手艺的精熟，所以有 Lv25 的铁匠，他的战斗力远不如 Lv25 的战士"（[种族 4][race]）。本表就是这句话的落地：
  无职能的匠人靠手艺升级，他的阶由手艺决定，打架另算。
- 行会身份与铭录之关不是一回事。出师之作是铭录的承认（凡阶·初到凡阶·熟）；"师傅作"是行会的审查（[社会 4.1][soc]，开店的资格）。
  很多帮工过了出师关，一辈子拿不到师傅作的批准，因为行会限制师傅的人数。这道社会之墙也是地球知识撞上的那堵墙。

### 1.4 澱染、澱纹与净化

| 档 | 典型来源 | 做成食物药剂（每份） | 做成装备（澱纹，数值待调） | 能用的净化 |
| --- | --- | --- | --- | --- |
| 无 | 澱度零到二之地的采集物；野兽（未异变）的皮肉 | 无 | 无 | 不需要 |
| 轻 | 澱度三之地的 T1 到 T2 采集物；异变的鱼虫；澱源材 1 档；T1 到 T2 异兽部件；碎晶 | 使用者澱染 +1 | 同阶属性 +3%；穿戴每 10 日 +1 | 祛灰水、庭井水、净炼坊、灵泉水、澄流之门、解澱 |
| 中 | 澱度三之地的 T3 以上采集物；澱度四之地的采集物；澱源材 2 档；T3 到 T4 异兽部件；未净炼的小晶与中晶 | +3 | +6%；每 5 日 +1 | 净炼坊（T4 以下）、灵泉水、澄流之门、解澱 |
| 重 | 澱度五之地的采集物；澱源材 3 档；T5 以上异兽部件；大晶以上的灰晶；澱渣 | +8 | +10%；每 2 日 +1 | 灵泉水（双倍用量）、澄流之门、解澱 |

- **净化是实例标记**：被净化的材料仍是同一个 ID，实例带 `purified`（与署名同层，见 `src/sim/professions/` 的署名实例规则）。
  例外只有总纲已经定义了"净后之物"的三条：灰晶到魔晶、澱兽皮到净革、渊兽皮到渊革。
- **澱纹的取舍**：带澱染的材料做成装备，同阶属性略高（总纲 7.10）；净化后加成消失。所以"用不用、净不净"是真实的选择，
  欧拉婆婆的手艺、灵泉水与澄流之门因此有了经济价值。
- 夜境的例外：夜境的术士合法使用未净炼的澱晶（[国家 1.7][nat]），夜境市场不带"禁澱晶"交易标签；带着灰晶出夜境就是走私。
- 完整的净化加工链与副产物去处见第 5 节。

### 2.2 本业、闲艺与刻深：十环在世界里的样子

主工程的制作环顺序固定为：机巧、炼剂、庖厨、鞣革、裁织、录纹、附纹、琢晶、锻兵、锻甲，首尾相接（`src/sim/content/professions.ts` 的 `CRAFT_RING`）。
相邻两门组成"原型对"，对面一门是"业余爱好"，其余封顶在凡品（`archetype.ts` 的 `archetypeCeilingFor`）。本作原样保留几何，只给它世界观：

```
            机巧 ---- 炼剂
          /                \
      锻甲                  庖厨
       |                      |
      锻兵                  鞣革
       |                      |
      琢晶                  裁织
          \                /
            附纹 ---- 录纹
（对面：机巧与录纹、炼剂与附纹、庖厨与琢晶、鞣革与锻兵、裁织与锻甲）
```

### 2.6 杰作与出师之作

**杰作概率**（主工程 `src/sim/professions/masterwork.ts`，常数原样沿用）：

| 项 | 数值 | 本作的来源 |
| --- | --- | --- |
| 基础 | 3% | 主工程 `MASTERWORK_BASE_CHANCE` |
| 技能阶高于配方阶 | 每高一阶 +1% | `MASTERWORK_PER_TIER_ABOVE_CHANCE` |
| 投入含署名材 | +2% | `MASTERWORK_SIGNED_CHANCE`；本作的署名材见 1.5 |
| 已专攻 | +3% | `MASTERWORK_SPECIALIZATION_CHANCE` |
| 材料阶加成 | 按投入材料的阶 | `material_tier.ts` |
| 工站档（本作新增） | 三档 +1%，四档 +2% | 注册修正项 |
| 潜质 `craft`（巧匠） | +2%（只对 NPC；识才之门可见） | 注册修正项，[总纲 9.3][bible] |
| 上限 | 15% | `MASTERWORK_CHANCE_CAP` |

**杰作的结果**：品质升一档、署名、写入器物来历（谁、何时、在哪座炉）。署名的精品杰作是"名器"的胚：
被强者长年使用、或以大晶锻成后，器意才可能萌生（[力量 11.1][pow]）；判定由装备目录与战斗系统定（待补）。

**出师之作的判定**（无职能的 NPC，含同伴与雇员）：

1. 铭录等级卡在 9，且生业技能已达 T1 段顶（24）。
2. 在主业中、以 T1 末段或 T2 的配方、在二档以上工站制作，触发杰作。
3. 该件即为出师之作：铭录改写为 Lv10（凡阶·熟），主业确定；同时产生事迹（待补 `deed_`：某人的出师之作），镇上会传。
4. 农人以"一季丰收"代之（[力量 3.3][pow]）：领地农田（P1）在该农人耕作下当季产出达到肥力上限的 120%，同样触发。
5. 采集生业的出师之作是"署名锭""整根心材""并蒂"一类的署名材，它会流到下游匠人手里，提高对方的杰作率。这让采集者与制作者的成长互相咬合。

- 玩家没有页，杰作不改写等级；玩家的杰作是"生业之门"下一层的历钥（2.8）。
- 期望次数：以 3% 起算，学徒平均要做三十来件才出一件杰作，加上署名材与好工站约二十件。这正好对应"学徒五到七年"（[社会 4.1][soc]）的游戏化压缩。

### 5.2 链图

```
[采集或剥取]--带澱染的材料--+--祛灰水 / 庭井水（轻）------------> 净（purified）+ 洗澱废水
                           +--净炼坊（灰晶到魔晶；轻到中）------> 魔晶 + 澱渣
                           +--灵泉水 / 澄流之门（全部）---------> 净（澱解回灵素，无副产）
                           +--不净化，直接用--------------------> 澱纹装备 / 带澱染的药食（使用者澱染上升）
                           +--卖给黑市（灰晶）-----------------> 术士、门徒会（违法；夜境合法）

[魔晶]--燃烧（魔道具、澱钢炉、晶炮）--> 余澱：慢慢散回周围 --> 城下薄澱 --> 下水道澱巢 --> 迷宫
[澱渣]--封存（Z2，铅衬）/ 化解（灵泉、澄流、众门环）/ 倾倒（违法：地段澱值上升）
[洗澱废水]--沉淀成灰泥并入澱巢残渣（封存）/ 排进河（下游病水）
[澱巢残渣]--收走净化（净巢土）/ 收走封存 / 留在原地（澱巢再生）
```

凡人的生产不"制造"澱，只"搬运"澱（[城建 12.1][cb]）。这张图里每一条线都是在搬运或解开，没有一条是在消灭；
只有灵泉、世界树、澄流之门与众门环真正把澱解回灵素，而它们都慢、贵、有限。这是第五幕"众生的办法"在材料层的预演。

## 6. 采集点

### 6.1 命名与通则

- ID 规则 `node_<区域代码>_<地名>`；区域代码取总纲 4.1。一处采集点在地图上可以是一片区域里的若干个点，统一刷新（1.3）。
- "阶"是采集点的阶，决定需要的技能段与工具档；产出的第一项是主产，其余为副产与稀有产。
- "幕"是玩家最早能合法到达的幕次（总纲 4.1 的到访幕）。

- 环海诸岛、终雾、神域、地球不设采集点；诸岛的物产（珍珠、岛椒、蔗糖）只能经金潮航线买。

## 7. 配方族

### 7.1 通则

- 配方族 `rcp_<名>` 是一组同类配方的总称；族内按阶分支（例：`rcp_blade` 的 T3 支是"澱钢单手剑族"）。单个产品属于其他目录时写族与阶，必须点名时写"待补"。
- 个人制作从背包扣料，领地生产从仓库扣料并由工人执行，用的是同一份配方数据（[城建 4.3][cb]、[经济 2.3][eco]）。"领地"一栏写执行它的建筑。
- 经济不变式：产出的商人买回价不高于投入的基准价之和（3 节开头）；制作另收工站费，按产出预算计（主工程 `CRAFT_GOLD_SINK_COPPER_PER_BUDGET`）。
- 节流：每 60 秒游戏时间至多 10 次成功制作（主工程 `CRAFT_THROTTLE_*`）；领地按建筑的队列与工期计，不受此限。
- 投入里的"或"表示可替代；带澱染的投入使产物带澱纹或澱染（1.4），除非先净化。

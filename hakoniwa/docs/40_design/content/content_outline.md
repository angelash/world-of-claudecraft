## 0. 读法与口径

### 0.1 计数口径

| 口径       | 含义                                                                                                 |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| 已定义     | 来源文档里有名称，且至少有一句功能或剧情描述（表格行或小节）                                         |
| 部分设计   | 有名称与若干要素（层次、首领、钥），但缺完整结构                                                     |
| 只命名     | 只有名称（例如地理志列出、分幕未展开的迷宫）                                                         |
| 提案       | 来源文档自己标注为"提案""待确认"的条目                                                               |
| 有名 NPC   | 有专名或唯一代号的人物；只有头衔的（"帝国元帅""公会总会长"）不计；跨幕人物只在首次有名出场的幕计一次 |
| 首领级遭遇 | 分幕文档标为首领、小首领、精英首领，或写明阶段机制的对手战；决斗与路线互斥的终战段分别注明           |

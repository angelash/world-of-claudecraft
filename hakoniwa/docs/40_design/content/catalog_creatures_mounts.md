## 0. 一页结论

1. **每一只被驯的兽都有页。** 野兽不是魔物，它们有完整的铭录页（[总纲 5.1][bible]）。所以兽伴死了会去泉畔，能在泉畔期内被叫回；
   所以兽伴是希尔薇的眼（[力量 4.4][pow]）；所以带兽伴进门内庭院，它的页会显示"所在不明"。这三条把"养一只狼"接上了全作的三根主线：
   灵泉、诸神的视线、千门。
2. **玩家只结得了半个契。** 猎人的伴契写在猎人与兽两页上（[力量 4.4][pow]），玩家没有页，于是伴契只落在兽的那一页，另一端是"无记载"。
   兽照样随玩家成长（经门），但懂行的人一鉴定兽伴，就会读到一个空着的主人（第 3.2 节，提案）。
3. **兽伴不随便强到 60 级。** 兽伴等级随主，但每个物种有种限，靠两次"伴契深化"（羁绊事件）抬高。这让食物、陪伴、故土这些软东西
   变成硬数值，也让第一幕那只狼有理由陪到第四幕（第 3.4 节）。
4. **净化过的异兽会复澱。** 一到二级的异兽可以净化回野兽（[种族 9.4][race]），但它们的复澱阈值更低：喂澱染肉、带进浓澱、
   跟着契约者久了，都会让它回去。第二次复澱是永别，它会掉下一块碎晶（第 3.7 节）。
5. **契约魔是澱里凝出来的半截意志，按澱源分性情。** 主工程术士的七种恶魔在本作各配一种澱源与一种代价：生命、澱、记忆或承诺。
   被召出的契约魔不掉澱晶，死时把澱还给契约，漏一点在当地：术士在城里打架，城会变脏（第 4 节）。
6. **门不长腿。** 行路之门只到亲手安放的门标与寻访过的门址（[D-046][dlog]），门扉吞吐有上限（[城建 2.4][cb]），
   而且在信徒面前用门等于自曝。所以第一次去任何地方、运任何货、带任何人、在任何人眼前赶路，都还得靠蹄子（第 6.2 节）。
7. **动物的价值向两个方向迁移。** 进城：牧场的品种、繁育与疫病（第 7 节）；从军：骑兵的换马、驮兽的补给半径、战兽的巨兽护甲（第 8 节）。
   第一幕的一匹驴，到第四幕是一张补给线；第一幕的灰毛狼，到第三幕是领地猎人小屋的种犬。
8. **庭院里长出来的小东西没有页。** 门内庭院在箱庭之外（[力量 9.6][pow]），由门息凝成的"庭生者"出不了门、不能交易，
   只能被看见、被起名、被陈列（第 13 节，提案）。序章选了"雨夜便利店"的玩家，庭院里那只空食盆，终于会等来一个客人。

"名伴"借用[力量 7.4][pow]异名者的规则：被人谈论到有名字的兽伴更强。名伴的条件是玩家给它起的名字在传闻系统里传到第二个城镇

## 3. 驯服与结契

### 3.1 谁能驯什么

| 结法 | 谁能用 | 对象 | 记在哪里 | 上限 | 怎么断 |
| --- | --- | --- | --- | --- | --- |
| 伴契 | 游侠（有页的猎人，含希雅） | 野兽；一到二级异兽须先净化 | 猎人与兽两页上各一道伴契注记（[力量 4.4][pow]） | 出战一只；兽栏另计 | 放生（`dismiss_pet` 之外的"放归"）；死后过了泉畔期 |
| 半契（提案） | 玩家，经猎之门 `door_vocation_hunter` | 同上 | 只在兽的页上，另一端是"无记载" | 出战一只 | 同上 |
| 从契 | 玩家，经契约之门 `door_pact` | 被澱侵蚀、被击败、被饶过的生灵（侵蚀者，或二级以内的异兽） | 门（不写页） | 从者位（与人形从者共用，见第 3 节末） | 玩家解约；复澱 |
| 林友 | 森之祭司 | 不结契：安抚（`hibernate` 一族）、借形 | 无 | 无 | 不适用 |
| 澱缚 | 契约者（术士） | 异兽，含二级以上 | 契约注记加媒介晶 | 按媒介晶的品级 | 媒介耗尽或契约破裂即反噬（第 11 节 `fiend_dianbound_beast`） |
| 畜养 | 任何人 | 家畜 | 不结契 | 按建筑与草场 | 出售、宰杀、征发 |
| 唤兽 | 萨满（经祖灵）、希尔薇（GM 工具） | 兽群 | 不结契 | 一次一群 | 用完即散 |

- 伴契不是奴役。兽因伴契"能理解猎人的意图、随猎人成长"（[力量 4.4][pow]），所以兽伴会表达不满：挨饿、被迫进它怕的地方、
  被拿去做"无谓的杀生"（第 3.8 节）都会降低它的服从。
- 一名游侠同一时间只能有一只出战的兽伴（沿用主工程 `src/sim/pet/pet_commands.ts` 的单宠物模型）；其余在兽栏或门内庭院的兽舍里。

### 3.2 伴契与玩家的半契

伴契在两页上各写一道注记。玩家没有页（[力量 9.2][pow]），所以**玩家驯兽时，伴契只写在兽的页上**，指向玩家的那一端是"无记载"。规则（提案，待千门系统确认）：

| 方面 | 对有页的猎人 | 对玩家（半契） |
| --- | --- | --- |
| 兽怎样懂主 | 经伴契 | 经猎之门：门替代了缺失的那一页，所以猎之门未开的玩家驯不了兽 |
| 成长 | 随猎人的铭录等级 | 随玩家的门阶（与主工程 `syncPetLevel` 同构），受种限约束 |
| 别人鉴定 | 读到"伴契：某某（猎人名）" | 读到"伴契：无记载"。猎人与公会职员见了会起疑（传闻"那只狼的主人是空的"，`cog`） |
| 莫伊拉 | 无异常 | 每一只半契兽都是一条小小的"页面异常"，记进她的档案，与"所在不明"同一类线索（[城建 2.5][cb]） |
| 断契 | 注记消失 | 注记留下一道"半契旧痕"，兽回野后仍认得玩家的气味 |

这条规则让"遮页符""伪录之门"在兽伴身上也有用：伪录之门已开时，玩家可以给自己的兽伴投一个伪造的主人名（提案，待门目录）。

### 3.3 驯服条件（通则）

以主工程 `tameError`（`src/sim/pet/pet_commands.ts`）为底，加上本作的五条：

1. **只驯野兽家族。** `beast`、`spider`、`burrower`；爬行类（[力量 7.3][pow] 也归为野兽或异兽）在数据层写作 `beast` 加 `tags: ["reptile"]`，内核不另设族群（[总纲 5.3][bible]）。
2. **不驯老魔物、异名者、首领，不驯迷宫里的生物。** 与主工程一致。迷宫是澱的结晶，里面的东西要么是澱生，要么异变太深。
   异名者的幼崽可以驯（例：`pet_splitear_pup`）。
3. **等级不高于驯者。** 有页者看铭录等级；玩家看门阶（[总纲 14 第 4 条][bible]的两套标尺之争在此按门阶处理）。
4. **异兽先净后驯。** 只有一到二级（薄澱到积澱）来源的异兽能净化回野兽（[种族 9.4][race]）。净化手段：祛灰草水（T1 到 T2）、
   灵泉水（全部）、澄流之门、契约之门；净化后的野兽带"净后"标记，复澱阈值更低（第 3.7 节）。
5. **每种兽有自己的门槛。** 条目里的"驯服条件"写明：诱饵、信任、时机、在场的人。驯服失败不会让兽变成敌对之外的东西，
   但会让同一物种在该地区对玩家的警觉上升一段时间（同区域再驯的施法时间加长）。

驯兽施法沿用主工程 6 秒（`tame_beast`），施法期间受击会打断。驯服成功时，兽的页上写入伴契（或半契），兽恢复满血并以玩家（门阶）等级重建。

### 3.4 成长：随主、种限与伴契深化

- **随主。** 兽伴等级始终等于主人的等级（门阶），不高于种限。主工程的 `syncPetLevel` 原样复用。
- **种限。** 每个物种有一个上限（第 1.3 节）。达到种限后，兽伴不再随主升级，但仍可出战；它会开始"等"：兽栏里的它每天会朝门口看。
- **伴契深化。** 每只兽伴写有两个羁绊事件（条目"羁绊事件"栏）。完成一次，种限 +10，同时伴契注记加深一笔（有页的猎人能在自己页上读到）。
  事件都是"共同经历"：同历一场险胜、同行一个季节、带它回故土、给它吃一顿故乡的东西、它为你挡下一次致命伤。
- **名伴。** 第 1.3 节。名伴特性是异名式的：它来自一句能被传颂的事（"它咬断过红牙军的旗杆"），效果跟着那件事走，而不是一张属性表。
- **不做的事。** 不做天赋树，不做技能书。兽伴的技能沿用主工程宠物的三档模式（被动、防御、主动）与家族技能，
  特性由本目录定义，数值由战斗系统文档定稿。

### 3.5 食性与维护（兽伴的回收口）

| 规则 | 内容 |
| --- | --- |
| 饱足 | 随行的兽伴每游戏日要吃一顿；喂食沿用主工程 `feedPet`（食物带"喂食回血"）。连续两日未喂：命令有一成概率不被执行；连续五日：它回野 |
| 喜、可、拒 | 每个物种有"喜"（羁绊 +，饱足一日半）、"可"（饱足一日）、"拒"（不吃）三档。喜食是本目录最主要的物资去处之一 |
| 澱染食物 | 未净化的异兽肉（`part_meat_t<阶>` 带 `tainted`，[总纲 7.9][bible]）兽伴也吃，但每顿澱染 +5（第 3.7 节）；食腐的物种减半 |
| 成本 | T1 兽伴一顿约 5 到 10 铜（一斤肉 8 铜，[社会 9.3][soc]）；T3 约 30 铜；T5 约 1 银。与一个日工每天约 40 铜的收入相比是一笔真实开销 |
| 前世 | 前世之门"灶火"的玩家做的兽食饱足 +0.5 日；"白衣"能提前一日看出兽伴的澱斑与病（[序章 2.2][pro]） |
| 兽舍 | 不随行的兽伴住在领地兽栏或门内庭院的兽舍，按"半份口粮"计；庭院兽舍里的兽伴每日澱染 -5（清域） |

### 3.6 死亡、泉畔与归来

1. **有页者归泉。** 兽伴死去，灵魂归于灵泉，在泉畔停留一段时间（提案：3 个游戏日）后进入轮回（[力量 9.8][pow]）。
2. **泉畔期内可叫回。** 猎人的 `revive_pet` 就是"沿伴契把它从泉畔拉回来"：耗灵力与一份它的喜食；复活后带"泉畔虚弱"（主工程的复活虚弱）。
3. **希尔薇的默许。** 叫回要希尔薇的归泉之许（[诸神 4][pan]）。默认给；以下情况她不给：
   - 它死前一日内被用于"无谓的杀生"（击杀未敌对、正在逃跑的野兽，或在希尔薇的林约地里滥猎）；
   - 同一季节内已被叫回三次。第三次之后，须先到任意一座希尔薇的林祠供奉一次（`divine`，去处"供奉"）。
4. **过了泉畔期。** 它走了。兽的页上留下的伴契残痕变成一件纪念物（待补：遗物与收藏目录的"伴契残痕"，`collect`、`bond`），
   可以陈列在庭院兽舍旁。渡魂之门 `door_soul_ferry` 能越过希尔薇的许可把它拉回，代价与人相同：与希尔薇交恶（[力量 9.9][pow]）。
5. **死在深澱。** 兽伴死在澱度四以上且未在泉畔期内被叫回时，有一定概率它的灵魂被澱堵住，不能抵达灵泉（[力量 7.3][pow] 亡灵的成因）：
   日后那一带会游荡一只"亡伴"（待补：魔物图鉴的亡兽条目，`undead`）。认出它、为它送魂，是一个羁绊事件，也会解开那道伴契残痕。
6. **从契者的死。** 经契约之门结的从兽死去时同样归泉；但门会在它离去的那一刻替玩家"记住"它（门不会忘），所以从兽的泉畔期加倍。
7. **玩家死时。** 玩家退回门内（[力量 9.8][pow]），出战的兽伴不跟着进门：它留在原地守着"遗落"的物资（守住时遗落物不被拾走），
   直到玩家回来或它饿着走掉。一只守了三天的狗，本身就是一则传闻。

### 3.7 复澱：净化过的异兽为什么会回去

所有兽伴都有一条"澱染"读数（0 到 100），与人的澱病同一套阶段（[力量 7.6][pow]）。从未异变的野兽在 100 时异变；净化过的异兽（"净后"）在 70 时复澱。

| 读数 | 阶段 | 表现 |
| --- | --- | --- |
| 30 | 澱斑 | 毛羽间出现灰斑；属性 -5% |
| 50 | 澱热 | 一成概率不听命令，主动扑最近的敌人；夜里会低嗥 |
| 净后 70，未异变 100 | 复澱或异变 | 伴契注记被异变注记盖住，它回到敌对。须再次击败并净化，否则它就是一只异兽 |
| 第二次复澱 | 永别 | 不能再净化。击败它时它会掉下一块碎晶 `dian_shard`，这是本作最轻也最重的一次掉落 |

| 来源 | 澱染变化 |
| --- | --- |
| 吃一顿未净化的异兽肉 | +5（食腐物种 +2） |
| 在澱度三之地每小时 | +2 |
| 在澱度四、五之地每小时 | +6、+15 |
| 与在场的契约魔并肩作战，每场 | +1 |
| 被战澱魔物咬伤，每次 | +1 |
| 门内庭院兽舍或灵泉、世界树一带，每日 | -5 |
| 祛灰草水一剂（只对 T1、T2 物种有效） | -10 |
| 灵泉水一剂 | -30 |
| 澄流之门（玩家） | 归零，冷却一日 |

这条读数是本目录对"`sed` 通道"的主要贡献：灵泉水、祛灰草、欧拉婆婆那样的手艺，以及澄流之门，在兽伴身上都有了日常用途。

### 3.8 兽伴是希尔薇的眼

正典：希尔薇的眼睛包括动物，视野广但模糊；猎人的兽伴会无意中成为她的眼（[诸神 4][pan]、[力量 4.4][pow]）。

| 规则 | 内容 |
| --- | --- |
| 间接视线 | 兽伴随行时，希尔薇对玩家所在之处的视线按"动物在场"计（[女神 GM][gm]的视线浓度 +1 档，上限为"模糊"）。她看不见玩家的门，但看得见玩家做了什么 |
| 借兽示警 | 希尔薇的"借兽示警"工具（[女神 GM][gm]，0.5 到 1 神力）可以落在玩家的兽伴身上：它会在真实的危险之前炸毛、拒绝前进、叼住玩家的衣角 |
| 无谓杀生 | 玩家带着兽伴做"无谓的杀生"，希尔薇会记账（她的加护冲动之一是"厌恶无谓杀生"）；账高时，第 3.6 节的归泉之许会被拒 |
| 藏起来 | 想做不让希尔薇知道的事，把兽伴留在门内庭院。代价是它的页会显示"所在不明"，每只每天给莫伊拉的档案加一笔（[城建 2.5][cb]），同一只连续出入，线索加重 |
| 好处 | 第二到第三幕希尔薇"只借动物示警"（[台账 8.3][rl]）：带着兽伴的玩家，能收到更多这类示警 |
| 知识层级 | 凡人与 NPC 不知道动物是女神的眼。本节规则只在内核与女神 GM 里生效，不进入任何 NPC 的常识与台词（[台账 8.0][rl]） |

### 3.9 兽栏、兽舍与退役（兽伴的价值迁移）

| 场所 | 规则 |
| --- | --- |
| 门内庭院兽舍（提案） | 占 2 庭格，扩建 I 起可建；容纳 4 只（扩建 III 起 8 只）；清域，澱染每日 -5；页显示"所在不明" |
| 领地兽栏（提案） | 猎人小屋（P8）或牧场（P2）的附属；容纳 6 只；有页的兽在这里会被领地里的猎人、虔诚者看见，从而进入诸神的见闻 |

但与人形从者一样计入庭院的受邀者名单（[城建 2.4][cb]）。

## 4. 契约魔的规则

### 4.1 契约魔是什么

正典：契约魔是从澱中凝出、带有残缺意志的存在，以契约束缚驱使；术士是唯一能直接利用澱的职能，解不干净的部分留在体内成为澱染；
**契约魔不是魔族**，圣教刻意把两者混为一谈（[力量 4.4][pow]）。魔物生成表里，契约魔的"核"是"澱中凝出的残缺意志"（[力量 7.3][pow]）。

本目录据此定下三条工作规则：

1. **一截意志，一种脾气。** 不同司掌者的干预留下的澱有不同的性格（[种族 9.3][race]），从里面凝出来的意志也带着同一种性格。
   所以契约魔按澱源分族（4.3），它的样子、它要的代价、它在契约里钻的空子，都跟着澱源走。
2. **媒介决定大小。** 立约要握住一枚**未净炼**的澱晶（灰晶），晶的品级决定能约到多大的东西（4.2）。灰晶不得合法流通
   （[D-040][dlog]），所以每一个术士都是黑市的老主顾：契约魔是灰晶黑市最稳定的需求之一（`econ`）。
3. **被约的不掉晶。** 被召出的契约魔被打散时，它的澱回到契约里，下次还能召；只有一小撮漏在当地。
   被约的契约魔永远不掉澱晶，这堵住"召出来自己打死收晶"的刷法，也让"术士在城里打架，城会变脏"成为可算的事实。

### 4.2 立约：媒介与四种代价

| 媒介（未净炼） | 能约到的阶 | 典型 | 合法性 |
| --- | --- | --- | --- |
| 碎晶 `dian_shard` | T1 | 烬仔 | 人族之地私藏即违法，量小，多被睁一眼闭一眼 |
| 小晶 `crystal_small_raw` | T2 | 空廓、暮牙 | 违法 |
| 中晶 `crystal_medium_raw` | T3 | 噬纹犬、战骸、金舌、孢巢 | 违法；黑市价是合法魔晶价的一倍半到三倍（[社会 9.3][soc]） |
| 大晶 `crystal_large_raw` | T4 | 白瓷侍、炉魁、哀页 | 违法；在夜境合法 |
| 王晶 `crystal_king_raw` | T5 | 炉魁、哀页的"满约" | 各国列为战略物资，私用即重罪 |

媒介在立约时用掉（去处"用掉"）。之后每次召唤不再耗晶，只付契约写明的代价：

| 代价 | 名 | 对有页的术士 | 对玩家（经渊契之门，无页） |
| --- | --- | --- | --- |
| 生命 | 血契 | 召出期间生命上限降低（按条目）；召唤时付一笔生命（主工程 `life_tap` 的世界观名"代价术"） | 相同 |
| 澱 | 澱契 | 每次召唤与每段在场时间累积澱染，澱染高了得澱病（[力量 7.6][pow]）；明执关失败时易魔物化 | 改记为门的淤塞（与[力量 9.8][pow]的"澱回流"同一个量），淤塞加重门疲与开门的代价 |
| 记忆 | 忆契 | 契约魔吃掉一段记忆：录侧出现一个空洞，莫伊拉读得到（录澱的异动） | 玩家的记忆不在页上，它改吃"寻访"：一处寻访过的门址（行路之门失去该节点，须再访），或一份口传配方 |
| 承诺 | 誓契 | 一条写进契约的承诺；违背时契约魔脱约，成为当地的野生契约魔，术士受反噬（生命与澱染） | 承诺由门记着；违背时契约魔离去，玩家淤塞上升一档 |

- 玩家的契约由渊契之门 `door_vocation_warlock` 承载，不写页，所以审判官的鉴定读不出玩家与契约魔立过约，只能靠目击（[力量 9.2][pow]）。
  有页的术士相反：深一点的鉴定就能在录侧读到契约注记，这是异端审判庭抓术士的主要办法。
- 渊契之门与澄流之门互斥，第一幕版本与借形之门互斥（[力量 9.9][pow]）。选了契约之路的玩家，兽伴的复澱只能靠灵泉水与祛灰草（第 3.7 节）。

### 4.3 澱源决定性情

| 澱源 | 契约魔的性情 | 外观语法（[总纲 5.2][bible]） | 爱钻的空子 | 本目录条目 |
| --- | --- | --- | --- | --- |
| 战澱 | 嗜战，受伤反而更凶，听到号角会抖 | 赤黑、多角 | "你说过要赢"：会在你想撤的时候不撤 | 烬仔、暮牙、战骸 |

| 录澱 | 低语，复述别人说过的话，偷看页面 | 身上浮着字一样的纹路 | 记得你说过的每一句话，并在最坏的时候复述 | 噬纹犬、哀页 |

凡人与教会只会把它当成"伪装成圣物的恶魔"。最早揭示：第五幕。

| 兽人 | 希尔薇派厌恶；瓦尔妲派部族偶有术士 | 兽王之争中站哪一边，决定契约魔被看成"力量"还是"秽物" |
| 半身人 | 不信，但会下注 | "我赌那小东西先咬你" |

### 4.6 霜灵不是契约魔

魔导师的召霜灵（主工程 `summon_water_elemental`，模板 `water_elemental`，`src/sim/content/mage_pets.ts`）用术式把灵素固定成一个形状，
不是从澱里凝出来的，散了就回到灵素，不留澱，不要代价。教会容忍霜灵，正因为它"干净"。本目录不给霜灵 ID，它是法师技能的一部分。
对照着看，契约魔的全部代价就是"用澱换力"四个字。

## 5. 借形的规则（G 的总则）

### 5.1 森之祭司的世界观

- **形是物种在世界树里留下的样子**（[力量 4.4][pow]）。借形不是变身，是"借用一个物种的形，连灵脉一起借"（借形换脉）。
- **形许**：经希尔薇许可的借形是稳定的。未经许可强行借形，人可能回不来，沦为异兽。所以森之祭司的修行第一课不是借，是"还"：
  每次还形时，要在心里向那个物种道一声谢（祭司们叫它"还形之礼"，提案）。
- **形会落。** 一个物种在一地被猎绝，它在当地的形就从世界树上"落下"，那一带的森之祭司从此借不到它（提案）。
  这把希尔薇的计分项"物种多样性"（[诸神 4][pan]）接到了玩法上：滥猎不只是希尔薇记账，也会让一整代祭司失去一种形。
- **不借猎物之形去猎它的同类**（森之祭司的戒律，提案）。违者不受系统惩罚，但会被其他祭司与兽人视为"脏手"（`cog`）。

### 5.2 借形换脉

| 形 | 主工程技能 | 换成的资源 | 定位 | 说明 |
| --- | --- | --- | --- | --- |
| 人形 | 无 | 灵力 | 施法、治愈 | 默认 |
| 熊形 | `bear_form` | 战意 | 承伤 | [力量 4.2][pow] |
| 狼形 | `cat_form` | 气息、破绽 | 近战、潜行 | 主工程 `cat_form` 的展示形态就是狼形，本作沿用 |
| 奔鹿形 | `travel_form` | 灵力封存，不能施法 | 赶路、脱身 | 主工程移速 +40% |
| 月鸮形 | `moonkin_form` | 灵力 | 施法输出 | 主工程带法术强度加成 |
| 渡水、鸦、生木、灰形 | 技能 ID 待补 | 见第 14 节 | 见第 14 节 | 本目录新增 |

### 5.3 玩家的借形

借形之门 `door_vocation_druid` 的效果是"借形（不需形许）"（[力量 9.9][pow]）。规则（提案，待千门系统确认）：

1. **不需形许，但要"见过"。** 玩家每多借一种形，需要一枚对应物种的"形钥"：与该物种的一只活体共处过（借形之门的钥本身就是"在林中与一头兽同宿一夜"）。
   兽伴就是最方便的形钥：养过雾林猞的玩家，借得到猞形（第 14 节的变体）。
2. **回不来的风险换成淤塞。** 有页的祭司强借会沦为异兽；玩家没有页，不会被异变注记盖住，代价改记为门的淤塞（借灰形时尤甚）。
3. **形会落，对玩家也一样。** 一地的物种被猎绝，玩家在那一带也借不到那个形。

### 6.2 门不长腿：坐骑为什么不贬值

行路之门是本作最强的通行能力，但它有七处够不着的地方，每一处都是坐骑的价值：

| 序 | 门的短处 | 坐骑的价值 |
| --- | --- | --- |
| 1 | 只到门标与寻访过的门址；第一次去任何地方都得自己走 | 探索与首访靠坐骑；新区域的第一张地图永远是马蹄踩出来的 |
| 2 | 初阶门标至多三处 | 三个门标之外的一切地方 |
| 3 | 门扉吞吐有上限，且计入依赖、压低自治度（[城建 2.4][cb]） | 驮马、铃骡、车队把货运到门扉够不着的地方，且不压自治度 |
| 4 | 门只带玩家与少数随行，不带商队、军队、移民 | 领地、商会与军队的一切移动 |
| 5 | 在信徒面前用门，目击会经信徒的见闻传上天（与[力量 9.8][pow]的"目击"同理） | 骑马进城是"正常"的；坐骑是一种伪装 |
| 6 | 门有冷却（[城建 2.4][cb]"受行路之门冷却约束"） | 冷却期间的一切移动 |
| 7 | 门不能当兵用：冲锋、补给、追击溃兵都不是门的事 | 第 8 节 |

**随行规则（提案，待门目录与千门系统确认）**：坐骑与兽伴可以随玩家过门，算作"随行"。初阶每次过门至多一名随行（人、兽或坐骑），
进阶至多一支小队加一匹坐骑；每名有页的随行在过门的一瞬间页显示"所在不明"，计入莫伊拉的档案。
门与马因此是互补的：门把人和马一起送到门标，马再从门标出发去门到不了的地方。

## 7. 动物进城：家畜、繁育与疫病

### 7.1 牧场的品种变体

城建的牧场（P2）给出的是通用产出：每日粮 4、皮 1、毛 1，维护 1 银/月（[城建 4.2][cb]）。本目录的每个 `stock_` 是牧场或其同类建筑的一个**品种变体**：
产出总量与 P2 同量级，但结构不同，从而让"养什么"成为经营抉择。新的养殖形态（蜂场、蚕房、鱼塘、犬舍、马场）一律作为 P2 的变体落地，
不另起建筑机制（与城建"唯一建筑以变体落地"的做法一致）。

| 规则 | 内容 |
| --- | --- |
| 地段 | 品种要求地段类型（草场、林缘、水边、山坡、灰地）；风牙与夜境品系离开原产地，产出 -20%，两代之后适应 |
| 产出 | 按注册表 ID 入库：粮（肉、奶、蛋、鱼合计为粮，带品类）、`hide`、`wool`、`tallow`、`honey`、`spider_silk` 等；注册表没有的写待补 |
| 需求 | 草场或饲料（粮）、水、看护工（L4 劳力）、冬季畜棚 |
| 官员 | 粮务官（[城建 7.4][cb]）；有"沃土"潜质 `fertile` 的人主管时，繁育与良种的进度加快（[总纲 9.3][bible]） |
| 庭院 | 门内庭院可以养家畜：产量按领地同类地段的 30%，不受季节与天灾修正（[城建 2.6][cb]）；产物是普通材料，经商契之门可以入市 |

### 7.2 繁育与良种

- **畜群规模**按"头"计，每季自然增长（条目写明增长率），受草场容量约束；超出容量的部分要么卖掉（`econ`），要么宰杀入粮（`manage`），要么征发（`war`）。
- **良种**：每个品系有 1 到 2 个"品系特性"（例：长毛、耐灰、快熟、温驯）。两个品系在同一牧场混养三季，可以杂交出兼有两项特性之一的新品系（待补：采集与生业目录的良种配方）。
- **马驹与角兽犊**：马群与角兽群每季产出幼畜，养满一年成为可骑的 `mnt_` 个体。这是坐骑从"买"变成"产"的出口，也是第 8 节换马的来源。
- **退役兽伴入群**：第 3.9 节。

## 13. 庭院生灵与信使

### 13.1 两种来历

门内庭院是雅努领域的残片，在箱庭之外，清域无澱，任何女神都看不进来（[力量 9.6][pow]、[城建 2.1][cb]）。庭院里的生灵有两种来历（提案）：

| 来历 | 是什么 | 页 | 能否出门 | 规则 |
| --- | --- | --- | --- | --- |

庭生者的事都会先经过她的嘴（"又来了一个不交房租的。"）。

### 14.2 夜羽的原形

本节含【真相】：她是门之信使（第三幕阿什认出她，[台账 S01][rl]）；大断绝之夜被击落（第三幕记起）；雅努之名（第六幕，`a6_name_spoken`）。
凡人可见的文本只用"夜羽""鸦""那只会偷东西的乌鸦精"，在对应揭示之前，界面与台词不得把她称作"雅努的信使"或"灵鸦"。

| 项 | 正典（[角色 3.1][chars]） | 本目录的用法 |
| --- | --- | --- |
| 她是什么 | 门之信使：雅努所造的灵鸦，不属于任何种族；被澱侵蚀后成为封门遗迹的守护兽，净化后取人形，也能变回小鸦 | 不是兽伴、不是坐骑、不进入本目录的任何命名空间；她是从者 `yeyu`（`data/party/companions.json`） |
| 分类 | [种族 9.4][race]把"巨鸦（夜羽的原形）"列为异兽的代表，又把"被澱侵蚀的巨鸦夜羽"列为侵蚀者的第一例 | 凡人与鉴定看到的是异兽（数据中守护巨鸦 `guardian_raven` 的家族为 `beast`）；真正的类别是侵蚀者，因为被侵蚀时她有灵智。冲突登记见第 16 节 |
| 鉴定 | "残页，Lv ？"，是特例：她的残页被契约之门部分覆写（[D-052][dlog]） | 她不能被任何人的伴契或半契结住；契约之门的从契是唯一的结法 |
| 人形 | 黑发，发梢化羽；左眼琥珀，右眼钥孔瞳；深灰信使斗篷，收拢时像合起的翅膀 | 战斗定位：契约者（`warlock`）；持续伤害、诅咒、召唤鸦群 |
| 小鸦形 | 可侦察、送信；收到闪亮的东西会叼走 | 场景内的侦察工具；信使之门开启前也能送信，但只送到玩家身边的人（提案） |

| 羽 | 数据中的 `raven_feather`（鸦羽，她喜欢）、`raven_black_feather`（巨鸦黑羽，任务物）、`raven_quill_charm`（鸦羽护符） | 巨鸦黑羽是"秃鹫毛"笑话（[第一幕][a1]）的道具；她不许任何人拿她的羽去做箭 |

**夜羽与兽伴、生灵**（喜剧与羁绊用，提案）：

| 对象 | 她的反应 |
| --- | --- |
| 账房猫、食盆客 | 先是敌意（猫与鸦），后来护着她的亮东西不被猫叼走；账房猫的羁绊事件二就是她们的和解 |
| 灰毛狼、裂耳之子 | "门把手，你又捡了一张嘴回来。" 她把它们当小狗，与她对希雅的态度一样（[角色 9.1][chars]） |
| 信鸦 | 她不承认它们是她的部下，只说"它们记得规矩" |
| 雏鸦影 | 拒绝谈论；第六幕之前她不会给出任何解释 |
| 契约魔 | "臭。" 她对澱的东西有本能的嫌恶，尽管她自己的战斗也用残余的澱 |
| 飞蜥 | 她不肯坐上去："我自己会飞。……以前会。" |

规则：夜羽永远不做坐骑。她有尊严，玩家也不会被允许骑她；本目录唯一允许的"背负"是第 16 节登记的那个剧本时刻。

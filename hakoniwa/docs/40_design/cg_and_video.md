# CG 与本机视频（CG and Local Video）

> 归属：`docs/40_design/`（游戏设计，正典优先级第 5 级）。
> 作用：把"故事交待"里画面比台词更有效的段落做成 CG：游戏内演绎保底，本机视频模型生成的短片作为画面的升级；写清 CG 放在哪里、多长、
> 怎样分镜、怎样三秒一段接力生成、怎样进游戏，以及按 15 秒、1 分钟、5 分钟三级的试做结果。
> 上游：[onboarding_interaction.md](onboarding_interaction.md)（新手段的规则与预算，本文的 CG 计入其中）、
> [catalog_cutscenes.md](content/catalog_cutscenes.md) 第 2.7 节（全屏静帧与实景运镜）、第 4 节（序章过场）；
> 调研依据：[local_video_generation.md](../10_research/open_share/local_video_generation.md)（本机模型、速度、接力实测、许可）。
> 决策：D-100。实施包：PK-M1-60。

## 0. 结论

1. **CG 是画面，不是剧情的唯一载体。** 每个 CG 都挂在一个已经能玩的场景节点上：节点的台词、选择、旗标与音频照常运行，
   视频只替换画面。没有视频（未采用、发行构建、加载失败）时，节点按写好的游戏内演绎播放，这就是保底。
2. **放在新手段的四处故事交待上：** 门在便利店里打开（P2 到 P3，B 开场）、地板化作门洞与坠落（P14）、黑暗里被接住（P15），
   另有第一幕进镇（A1-M03）一处随第一幕开场改写接入。单段不超过 20 秒，序章加第一幕开场合计不超过 60 秒（预算 B8）。
   第一幕从"黑。然后是冷。"开始（正典），所以黎明俯瞰只在影片里做转场，不进游戏。
3. **5 分钟的序章影片不在关键路径上。** 它和游戏内 CG 出自同一份分镜（地球、白、候见厅、五位女神、判决、坠落、黎明、遗迹、进镇），
   用作标题画面的待机影片与宣传片的候选；游戏内 CG 是这部片子的切段。
4. **生成方法是"关键帧编辑链加首尾帧接力"。** 关键帧用 FLUX.2 Klein 画，同一地点的镜头从同一张母版编辑出来；
   视频三秒一段，每段从上一段解码出的最后一帧开始，镜头里设计好的关键帧作为该段的尾帧；连续不锚定的段至多三段。
5. **分三级试做：** G1 15 秒（门在便利店里打开）、G2 1 分钟（坠落到黎明）、G3 约 5 分钟（全片）。结果与问题见第 7 节。
6. **视频进发行版之前要过许可。** H3 的社区许可有标注、收入上限与地域限制（调研第 5 节），发行构建暂不加载视频；由用户核对原文后决定（U-41）。

## 1. 什么该做成 CG

| 该做 | 不该做 |
| --- | --- |
| 台词在描写一个玩家看不见的画面（门打开、白光吞没、坠落、被接住、一片大陆） | 玩家能自己走过去看的东西（漫游触点，规范 R1） |
| 时间、空间的跳跃（地球到白、黑暗到黎明、天空到遗迹） | 带选择、计时或输入的节拍（CG 期间不出选择，选择在 CG 之后） |
| 第一次见到一个地方的全貌（世界、进镇） | 人物对话（对话用立绘与台词，CG 不做口型） |
| 情绪的定格（被接住的一瞬） | 需要玩家自定外貌的人物正脸（玩家只出背影、剪影或手） |

## 2. 规则

| 编号 | 规则 |
| --- | --- |
| C1 | 保底：CG 挂在节点上，节点不依赖视频。视频缺失、加载失败、玩家快进（跳过）或开了"减少闪烁"时，场景照常演出（镜头、光、静帧、转场、台词）；快进时正在播的 CG 立即停下 |
| C2 | 长度：关键路径上的单段 CG 不超过 20 秒；序章加第一幕开场的 CG 合计不超过 60 秒；更长的影片只放在关键路径之外 |
| C3 | 无声：视频不带模型生成的声音；音乐、环境声与音效走场景的音频指令，字幕是场景的台词（文本键），不烧进画面 |
| C4 | 不打断：CG 播放时台词照常推进，玩家点得快就先读完；CG 在播时代替过场自己的画面（静帧、门卡、渐变与转场），视频自己报告播完后保持最后一帧 0.4 秒，再用 0.6 秒淡入下面的舞台；游戏暂停时视频一起暂停。CG 的最后一帧要和紧接的舞台对得上（门开成白光，接到"白。"） |
| C8 | 不压选择：CG 不能延续到带选择、计时或输入的节点上；会接到这种节点的地方在该节点入口写 `cg_end`（坠落的"伸手"） |
| C5 | 揭示：画面只出现该时点已揭示的人与物；第六司只出一只手与光，不露面；玩家只出背影、剪影或手 |
| C6 | 一致：同一地点的镜头从同一张母版关键帧编辑出来；人物的外观按 `art_chr_*_ref` 参照图；风格按风格包（`assets/prompts/templates.json`） |
| C7 | 变体：依赖开场或分支的画面用阶段指令的条件（`when`）挑选；没做的变体走保底（例：门的 CG 先只做 B 开场） |

## 4. 分镜格式

分镜放在 `assets/cg/storyboards/<片子>.json`，由 `tools/cg_gen/storyboard.ts` 校验（`tests/cg_storyboard.test.ts` 逐份检查）。

| 字段 | 含义 |
| --- | --- |
| `size`、`keyframeSize` | 视频尺寸（32 的倍数，现为 512×288）与关键帧尺寸（16 的倍数，现为 1024×576） |
| `shots[]` | 镜头：`id`（`s<序号>_<短名>`）、风格包 `style`（`void` 表示不加风格包的文字，用于纯黑与天空：风格包写的地景会渗进画面）、段数 `segments`、`cut`（硬切开场或接着上一镜的最后一帧）、`keyframes`（按段边界编号的关键帧）、`motion`（每段一句动作与运镜）、`captions`（评审版字幕）、`music`、`ambience`（`null` 停掉环境声） |
| 关键帧 | `prompt`（画什么）、`refs`（参照图：`art_chr_<人>_ref`、`style:<风格包>`）、`edit`（编辑另一张关键帧 `<镜头>@<边界>`）、`image`（直接用已有的图） |
| `cgs[]` | 游戏内 CG：连续的若干镜头，必须从硬切开始 |
| `reels[]` | 评审用的切段（分级试做） |

校验规则：第一镜必须是硬切；硬切镜头必须有 0 号关键帧，接续镜头不能有；连续不锚定的段至多三段（`MAX_FREE_SEGMENTS`，接续镜头接着上一镜往下数）；
关键帧编号只能是段边界的整数；`image` 关键帧不能同时 `edit`；编辑链不能成环；每段一句动作；参照图、风格包、音乐与环境声必须存在；
字幕在镜头的某一段上；字幕与提示词不含禁用字符；CG 与切段不能为空、编号不重复、镜头连续且从硬切开始。
拼接的规则（哪一段丢第一帧、每段落在片子的第几帧）只写在 `placeSegments` 一处，时长、字幕与拼接都读它。

## 5. 生成方法

```text
关键帧（Klein，按编辑链的先后）
  └ 每段：首帧 = 硬切的 0 号关键帧，或上一段解码出的最后一帧（无损 PNG）
          尾帧 = 该段结束边界上的关键帧（有则锚定，无则自由）
          H3 生成 73 帧（约 3 秒），另存最后一帧
拼接：接续的段丢掉第 1 帧（就是上一段的最后一帧），再用 8 帧（三分之一秒）从上一段的最后一帧缓入
成片：评审版放大到 1920×1080，配游戏音乐与环境声，烧入字幕；游戏内版保持 512×288，无声、无渐变
```

| 项 | 做法 |
| --- | --- |
| 命令 | `npm run cg -- all assets/cg/storyboards/film_prologue.json`（`keyframes`、`render`、`sheet`、`assemble`、`adopt <cg>`；`--only <cg 或切段>` 只做其中的镜头与它们编辑到的关键帧，`--until <段>` 做到某段为止） |
| 重做 | `--redo <键>` 重画关键帧（`<镜头>@<边界>`）或重渲一段（`<镜头>#<序号>`），`--reroll <键>` 同样但换一个种子（另一条）；开跑前先把它和所有依赖它的东西（编辑它的关键帧、从它接力或落在它上面的段，跨镜头）从状态文件里删掉并存盘，所以重做中断后不带参数再跑也会接着做完 |
| 续跑 | 已完成的关键帧与段记在 `.local/cg_gen/<片子>/state.json`，重跑时跳过；拼接用的分段以所出自的那一条命名，重渲之后不会拿到旧的；单个任务超时（关键帧 20 分钟、段 25 分钟）即在 ComfyUI 里撤销 |
| 提示词 | 关键帧套 `bg_cg` 模板（高细节像素、Q 版约 1.7 头身、无文字）加风格包；动作提示写明"没提到的东西保持原样"，只写这一段发生的一件事 |
| 产物 | 候选池 `assets/_candidates/video/`（不入库）：全片、各切段与各 CG 的游戏内版和评审版；`.local/cg_gen/<片子>/sheet.jpg` 是逐镜的关键帧与段尾帧总览 |
| 采用 | `adopt <cg>` 把游戏内版复制到 `assets/cg/media/`（不入库）并写索引 `index.json`；开发构建读这个索引 |
| 缓入 | 模型不会原样复现给它的首帧（色调偏一点、某个细节被重画，例如墙上的画框变成镜子），只丢第 1 帧时接缝处会跳一下；所以接续的段在头 8 帧里从上一段的最后一帧渐变过来（`JOIN_EASE_FRAMES`） |
| 验收 | 看总览图（地点、人物、风格一致，没有伪文字与穿帮）；逐帧画面差，接缝处的跳变与前后几帧的运动相比（比值在 3 以内）；评审版整片看一遍 |

## 6. 进游戏

- 阶段指令 `cg`（`{ "op": "cg", "id": "cg_<短名>" }`）与 `cg_end`，与 `still` 同在 `StageDirectiveMore`；内容校验要求 `cg_` 前缀，
  `tests/cg_storyboard.test.ts` 要求场景里用到的每个 CG 都在某份分镜的 `cgs` 里。
- 舞台状态记下 CG 与开始时刻，跨节点保留，直到视频播完、`cg_end` 或场景结束；快进与"减少闪烁"不记 CG，快进时清掉正在播的。
- `src/client/hud/story/cg_layer.ts`：纯函数 `cgShown` 决定舞台要的是哪一个 CG，`cgPhase` 由视频的 `ended` 事件算出播放、保持、淡出与结束
  （视频始终不报告结束时，按长度加 6 秒放手）；`CgLayer` 持有静音的视频元素，放在过场播放器的最底层（字幕、立绘、选择都在它上面），
  按像素放大，播放时给过场根节点加 `hk-cg-on` 盖住静帧、门卡、渐变与转场，开始淡出时还给它们；游戏暂停时暂停视频；
  文件放不了（不是被打断的 `play()`）记下这一 CG，本局不再尝试，舞台照常。
- 开发构建在第一次遇到 CG 时读 `assets/cg/media/index.json`；发行构建暂不加载视频（第 0 节第 6 条）。

## 7. 分级试做

| 级 | 内容 | 段数与时长 | 状态与结果 |
| --- | --- | --- | --- |
| G1 | 便利店里门的倒影、门在过道里打开、白光吞没（`reel_g1_store_door`） | 5 段，15.1 秒 | 完成。接缝处画面差与段内一致；第一镜的门被模型开了又关（提示没写门不动），已改提示重做 |
| G2 | 地板化作门洞、坠落、黑暗、伸手、被接住、"圣历九百九十八年，春"、黎明俯瞰（`reel_g2_fall_and_dawn`） | 20 段，60.3 秒 | 完成。硬跳只出现在七处硬切上；字幕在位。改过的问题：门廊风格包把坠落画成一排排门（正典是纯黑，改用 `void`），艾琉恩的参照图混进了坠落的人物（去掉参照，文字写明五位女神与人物）；黑暗一镜里模型凭空画出一间屋子，已改提示另出一条 |
| G3 | 全片 `film_prologue`：地球、白、候见厅、帘幕后的影子、五位女神、硬币与判决、地板门洞、坠落、伸手与被接住、黎明、六龛大厅、门的回廊、北路与小镇 | 94 段，283.5 秒（4 分 43 秒） | 完成。新渲 74 段用 187 分钟（每段平均 152 秒）。开渲前重画了画错的关键帧（女神被画在帘幕前、艾琉恩被画成四个、硬币一镜），渲完后另出了六龛大厅里凭空多出人影的两镜。接缝：只丢第 1 帧时 58 处接缝有 10 处可见跳变（与前后运动之比 2 到 37），加缓入后全部在 0.6 到 3.0 之间 |

## 8. 维护

- 新增 CG：先在分镜里加镜头与 `cgs` 条目，渲出评审版看过，再在场景节点上加 `cg` 指令；算进预算 B8。
- 改了镜头的关键帧：用 `--redo` 重做，下游接力的段与编辑它的关键帧自动重做；不满意某一条用 `--reroll`；游戏内版重新 `adopt`。
- 换模型：生成器只依赖 `tools/cg_gen/comfy.ts` 的两张图（关键帧、段）；分镜格式与游戏内接口不变。

# 模型连接设置窗口

此文记录本模块的接口与维护边界。

`index.ts` 是标题、新游戏与游戏内设置共用的 DOM 弹窗入口。
`controller.ts` 只经 `PlatformHost` 读写本机模型分区与调用网关，不接收密钥文本。
新增角色绑定、模型槽与价目编辑应复用 `src/ai/llm_config/` 的规则。

- 所有玩家文字取本作文本键；窗口关闭恢复焦点，异步完成不得重开旧窗口。
- 添加连接不自动启用。云端启用必须有明确同意及小时、日上限。
- 密钥只从独立录入窗口进入网关，游戏页面只看状态。不得增加密钥输入框。
- 设置保存前重读当前本机分区，保留并行更新的画质等字段与未来版本只读规则。
- 请求、探测、费用和凭据由网关裁决，页面不是安全边界。
- 本窗口当前提供单模型基础配置；高级绑定和完整分屏不能以空壳控件代替验收。
